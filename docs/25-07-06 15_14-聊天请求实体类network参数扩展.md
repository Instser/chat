# 07-06 15:14 - 聊天请求实体类network参数扩展

## 更新时间
2025年7月6日 15:14 (北京时间)

## 版本标识
v1.3.0-network-parameter-extension

## 功能概述
为所有带有deepThinking参数的聊天请求实体类添加Boolean类型的network参数，支持网络搜索功能的开关控制。

## 修改内容

### 1. ChatRequestDTO类扩展

#### 新增字段
```java
/**
 * 是否启用网络搜索
 */
private Boolean network;
```

#### fromMap方法扩展
```java
// 设置网络搜索参数
Object networkObj = requestMap.get("network");
if (networkObj != null) {
    if (networkObj instanceof Boolean) {
        dto.setNetwork((Boolean) networkObj);
    } else if (networkObj instanceof String) {
        dto.setNetwork("true".equalsIgnoreCase((String) networkObj) || "1".equals(networkObj));
    } else if (networkObj instanceof Number) {
        dto.setNetwork(((Number) networkObj).intValue() == 1);
    }
}
```

### 2. ChatServiceImpl服务层更新

#### 续写请求处理
```java
// 创建续写请求
ChatRequestDTO continuationRequest = new ChatRequestDTO();
continuationRequest.setMessages(continuationMessages);
continuationRequest.setUserId(request.getUserId());
continuationRequest.setModelId(model.getId());
continuationRequest.setSessionId(request.getSessionId());
continuationRequest.setDeepThinking(request.getDeepThinking());
continuationRequest.setNetwork(request.getNetwork()); // 新增
```

#### 重新生成请求处理
```java

editResendRequest.setSessionId(sessionId);
editResendRequest.setDeepThinking(false); // 编辑重发时使用默认模式
```

## 技术特点

### 参数类型支持
- **Boolean类型**: 直接使用true/false值
- **String类型**: 支持"true"、"1"等字符串转换
- **Number类型**: 支持1/0数字转换

### 兼容性处理
- **向后兼容**: 现有请求不传network参数时不会报错
- **类型转换**: 支持多种数据类型的自动转换
- **空值处理**: 参数为null时不进行设置

### 默认行为
- **续写请求**: 继承原始请求的network设置
- **重新生成**: 默认禁用网络搜索（false）
- **编辑重发**: 默认禁用网络搜索（false）

## 使用示例

### API请求示例
```json
{
  "messages": [
    {
      "role": "user",
      "content": "请搜索最新的AI技术发展"
    }
  ],
  "userId": 123,
  "modelId": 1,
  "sessionId": "session-123",
  "deepThinking": true,
  "network": true
}
```

### 参数组合说明
- **deepThinking: true, network: true**: 深度思考模式 + 网络搜索
- **deepThinking: true, network: false**: 深度思考模式，不使用网络搜索
- **deepThinking: false, network: true**: 普通模式 + 网络搜索
- **deepThinking: false, network: false**: 普通模式，不使用网络搜索
