## 2. 代码变更

### 2.1 支付权限

- `PaymentAuditController`
  - `GET /payment/audit/order/{orderNo}`
  - `GET /payment/audit/operation/{operationType}`
  - `GET /payment/audit/operator/{operatorId}`
  - 均增加 `@PreAuthorize("hasRole('ADMIN')")`
- `PaymentController`
  - `POST /payment/sync/{orderNo}`
  - `POST /payment/sync/batch`
  - `POST /payment/sync/all`
  - `POST /payment/admin/sync/order/{orderNo}`
  - 均增加 `@PreAuthorize("hasRole('ADMIN')")`
  - `GET /payment/status/{orderNo}`、`/order/{orderNo}`、`/status/sync/{orderNo}` 增加订单归属校验（管理员可跨用户）
  - `GET /payment/orders` 默认查本人；指定他人 `userId` 需管理员

### 2.2 Management API Key

- `ManagementApiKeyService.extractApiKey` 仅读取 `X-API-Key` Header
- `init()` 不再打印完整主密钥，也不再提示 `?apiKey=`
- `getMasterApiKey()` 标记 `@Deprecated` 并返回 `null`
- 新增 `getMasterApiKeyFingerprint()` 仅返回指纹

### 2.3 Ops AI 分析

- `ErrorAnalysisRequest`：`errorLog` max 8000，`contextInfo` max 2000
- `OpsController.sanitizeForAi`：脱敏 apiKey/password/Bearer/JWT/邮箱
- 送入模型前使用脱敏文本

### 2.4 文档

- `README-OPS.md`：明确 8080 业务/ops、8081 仅 Actuator 本机；鉴权矩阵；禁止 query apiKey

## 5. 部署注意

1. 生产需配置 `CACHE_API_KEY` / `cache.management.api-key.master`；未配置时仅进程内临时密钥，日志不输出明文。
2. 依赖 `?apiKey=` 的脚本需改为 `X-API-Key` Header。
3. 普通用户调用支付审计/同步接口将 403；前端若有调用需改为管理员 JWT 或等待阶段 B 新入口。
4. 本次无 SQL、无依赖变更、无 JDK 变更。
