# 运维监控：手动模型探测 + 排除 self path v1.0

- 时间：2026-08-06 15:12（北京时间）

## 原探测频率（问题）

运维监控页每次加载 / 30s 自动刷新都会请求 `GET /admin/ops/monitoring`，该接口原先会：

1. `checkAiApi()`：并行真实可聊探测全部可用模型（预算约 8s）
2. `health()` 内部再 `checkAiApi()` 一次

即：**约每 30 秒最多两轮全量外网探测**，浪费上游额度且拖慢刷新。

仪表盘 `overview` 的 health 仍会探测（进入首页时），与运维页自动刷新解耦。

## 改动

1. `monitoring` 默认 `probeModels=false`，返回 `models.status=IDLE` 占位
2. 新增 `GET /admin/ops/monitoring/models-probe` 手动探测
3. 监控页 health 用 `healthLite()`（DB/Redis，AI=SKIPPED）
4. HTTP 路径：
   - `SlowRequestInterceptor` 不再记录 `/admin/ops/monitoring*`
   - `buildHttpMetrics` 汇总时再过滤一遍（兼容旧计数）
5. 前端：探测区「探测模型」按钮；自动刷新不覆盖手动结果

## 验收

- 默认 monitoring ≈0.4s，`probe=manual-only`
- 手动 models-probe ≈3s，返回 6 模型明细
- topPaths 无 monitoring
