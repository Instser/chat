# OAuth2用户权限验证问题修复报告

**修复时间**: 2025-07-19 04:50  
**版本标识**: v1.2.3-oauth2-fix  
**问题类型**: 权限验证失败  
**影响范围**: OAuth2注册用户  

## 问题描述

OAuth2创建的新用户在进行聊天时显示"没有权限"，但数据库检查显示用户已正常绑定套餐。同时权限验证失败的日志返回错误信息为null，缺乏有效的错误信息。

## 问题分析

### 1. 根本原因

通过数据库查询发现，OAuth2用户的套餐过期时间设置错误：

```
用户ID: 1945912505721913345
套餐ID: 1 (Free套餐)
套餐过期时间: 2025-07-17 02:24:30 (已过期2天)
当前时间: 2025-07-19 04:43:49
```

### 2. 问题根源

**Free套餐配置**:
- `validity_days = -1` (表示永久有效)
- `limit_type = "daily"` (每日限制模式)

**代码缺陷**:
在`UserAccountServiceImpl.activatePackage`方法中：
```java
LocalDateTime expireTime = getBusinessDateTime().plusDays(validityDays);
```

当`validityDays = -1`时，相当于执行`当前时间.plusDays(-1)`，导致套餐一创建就过期。

### 3. 日志问题

在`ChatResponseDTO.errorWithContent()`方法中，只设置了`aiResponseContent`，没有设置`errorMessage`字段，导致`getErrorMessage()`返回null。

## 修复方案

### 1. 修复套餐过期时间计算逻辑

**文件**: `src/main/java/com/instser/chat/service/serviceimpl/UserAccountServiceImpl.java`

```java
// 计算过期时间：-1表示永久有效
LocalDateTime expireTime;
if (validityDays == -1) {
    // 永久有效：设置为null
    expireTime = null;
    log.info("套餐{}为永久有效套餐，过期时间设置为null", packageId);
} else {
    expireTime = getBusinessDateTime().plusDays(validityDays);
    log.debug("套餐{}有效期{}天，过期时间：{}", packageId, validityDays, expireTime);
}
```

### 2. 完善过期时间验证逻辑

**文件**: `src/main/java/com/instser/chat/service/serviceimpl/ChatLimitServiceImpl.java`

```java
// 检查套餐是否过期（使用业务时区）
// 注意：过期时间为null表示永久有效
if (userAccount.getPackageExpireTime() != null &&
    userAccount.getPackageExpireTime().isBefore(getBusinessDateTime())) {
    log.warn("用户{}套餐已过期，套餐ID：{}，套餐名称：{}，过期时间：{}，当前时间：{}", 
        userId, userAccount.getPackageId(), packageInfo.getPackageName(),
        userAccount.getPackageExpireTime(), getBusinessDateTime());
    return ChatLimitVO.failed("套餐已过期");
}
```

### 3. 修复错误响应DTO

**文件**: `src/main/java/com/instser/chat/dto/ChatResponseDTO.java`

```java
public static ChatResponseDTO errorWithContent(String errorContent) {
    ChatResponseDTO response = new ChatResponseDTO();
    response.setSuccess(false);
    response.setHasContentSent(true);
    response.setRealAiResponse(false);
    response.setAiResponseContent(errorContent);
    response.setErrorMessage(errorContent); // 同时设置错误消息，确保getErrorMessage()不返回null
    response.setShouldRecordUsage(false);
    return response;
}
```

### 4. 改进错误日志记录

**文件**: `src/main/java/com/instser/chat/controller/ChatApiController.java`

```java
// 记录处理结果
if (chatResponse.isSuccess()) {
    log.info("【API响应】聊天请求处理成功，用户ID：{}", chatRequest.getUserId());
} else {
    String errorMsg = chatResponse.getErrorMessage();
    if (errorMsg == null || errorMsg.trim().isEmpty()) {
        errorMsg = "未知错误";
    }
    log.warn("【API响应】聊天请求处理失败，用户ID：{}，会话ID：{}，错误：{}",
        chatRequest.getUserId(), chatRequest.getSessionId(), errorMsg);
}
```

## 数据修复

### 1. 修复现有用户数据

执行数据修复脚本，将所有使用Free套餐且`validity_days=-1`的用户的过期时间设置为NULL：

```sql
UPDATE t_user_account 
SET package_expire_time = NULL,
    update_time = NOW()
WHERE package_id = 1 
AND package_id IN (
    SELECT id FROM t_package WHERE validity_days = -1
)
AND package_expire_time IS NOT NULL;
```

**修复结果**: 成功修复9个用户的套餐过期时间
