## 优化背景

用户提供了新的标题生成提示词，要求系统生成纯英文标题，具有以下特点：
- 只生成英文标题（3-8个单词）
- 不包含中文、日文、韩文等非英文字符
- 无特殊符号或标点
- 语法正确且描述对话主要话题

### 关键要求

2. **长度限制**: 3-8个单词
3. **格式要求**: 无特殊符号、标点符号
4. **内容要求**: 语法正确，描述对话主题
5. **输出纯净**: 只返回标题，无其他内容

### 2. 对话内容构建

**新增方法**: `buildConversationContent()`
```java
private String buildConversationContent(List<Map<String, String>> messages) {
    StringBuilder conversationBuilder = new StringBuilder();
    
    for (Map<String, String> message : messages) {
        String role = message.get("role");
        String content = message.get("content");
        
        if ("user".equals(role) && content != null && !content.trim().isEmpty()) {
            conversationBuilder.append("User: ").append(content.trim()).append("\n");
        } else if ("assistant".equals(role) && content != null && !content.trim().isEmpty()) {
            conversationBuilder.append("AI: ").append(content.trim()).append("\n");
        }
    }
    
    return conversationBuilder.toString().trim();
}
```

### 4. 英文标题清理优化

**新的cleanTitle()方法特点**:
```java
private String cleanTitle(String title) {
    if (title == null) {
        return "New Chat";
    }

    // 移除引号、特殊符号和多余空格
    title = title.trim()
        .replaceAll("^[\"']+|[\"']+$", "") // 移除开头和结尾的引号
        .replaceAll("[^a-zA-Z0-9\\s]", "") // 移除非英文字母、数字和空格的字符
        .replaceAll("\\s+", " ") // 合并多个空格
        .trim();

    // 验证是否为有效的英文标题（3-8个单词）
    String[] words = title.split("\\s+");
    if (words.length < 3 || words.length > 8 || title.isEmpty()) {
        return "New Chat";
    }

    // 确保每个单词都是有效的英文单词（至少包含一个字母）
    for (String word : words) {
        if (!word.matches(".*[a-zA-Z].*")) {
            return "New Chat";
        }
    }

    // 首字母大写处理
    StringBuilder result = new StringBuilder();
    for (int i = 0; i < words.length; i++) {
        if (i > 0) {
            result.append(" ");
        }
        String word = words[i].toLowerCase();
        if (word.length() > 0) {
            result.append(Character.toUpperCase(word.charAt(0)));
            if (word.length() > 1) {
                result.append(word.substring(1));
            }
        }
    }

    return result.toString();
}
```

## 功能特性

### 1. 严格的语言过滤
- 使用正则表达式`[^a-zA-Z0-9\\s]`过滤所有非英文字符
- 确保标题只包含英文字母、数字和空格
- 自动过滤中文、日文、韩文等字符

### 2. 单词数量验证
- 验证标题包含3-8个单词
- 不符合要求时自动使用"New Chat"
- 确保每个单词至少包含一个字母

### 3. 格式标准化
- 自动首字母大写处理
- 移除多余空格和特殊符号
- 统一标题格式

### 4. 默认值处理

- 保持与英文标题要求的一致性
