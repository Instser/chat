# 07-03 18:44 续写清理策略调整

## 调整目标

根据用户反馈，调整续写内容清理策略：**只清除开头的AI标记，保留结尾的标记**。

## 问题背景

之前的清理算法会同时清除开头和结尾的AI标记，但用户希望：
- ✅ **清除开头标记**：`<thinking>`、`<response>`、````javascript`等
- ❌ **保留结尾标记**：`</response>`、````等

这样可以保持续写内容的完整性，同时去除不必要的开头标记。

## 调整内容

### 🔧 **修改响应标签清理**

#### 修改前（清理开头和结尾）
```java
private String removeResponseTags(String content) {
    String result = content;
    
    // 移除开头的 <response> 标签
    result = result.replaceAll("^\\s*<response>\\s*", "");
    
    // 移除结尾的 </response> 标签
    result = result.replaceAll("\\s*</response>\\s*$", "");
    
    return result;
}
```

#### 修改后（只清理开头）
```java
private String removeResponseTags(String content) {
    String result = content;
    
    // 只移除开头的 <response> 标签
    result = result.replaceAll("^\\s*<response>\\s*", "");
    
    if (!result.equals(content)) {
        log.debug("移除了开头的 response 标签，原长度: {}, 新长度: {}", content.length(), result.length());
    }
    
    return result;
}
```
