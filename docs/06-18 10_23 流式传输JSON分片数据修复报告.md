## 问题描述

### 问题现象
在流式传输过程中，AI API返回的JSON数据在网络传输时被分片，导致JSON解析失败和数据丢失。

### 具体表现
1. **JSON截断错误**：
   ```
   "finish_reason":nul  // 应该是 null
   ```

2. **分片数据**：
   ```
   第一行: {"id":"...","choices":[{"delta":{"content":"..."},"finish_reason":nul
   第二行: l}]}]
   ```

3. **解析异常**：
   ```
   Unrecognized token 'nul': was expecting (JSON String, Number, Array, Object or token 'null', 'true' or 'false')
   ```

### 影响范围
- 流式聊天响应不完整
- 用户体验受损
- 数据传输可靠性问题

## 根本原因分析

### 技术原因
1. **网络分片**：HTTP流式传输在网络层被分片
2. **缓冲区处理**：原代码按行处理，未考虑JSON跨行分片
3. **错误恢复**：解析失败后直接跳过，未尝试数据重组

### 代码层面
```java
// 原有问题代码
String jsonData = line.substring(6).trim();
ObjectMapper mapper = new ObjectMapper();
JsonNode jsonNode = mapper.readTree(jsonData); // 直接解析可能不完整的JSON
```

## 修复方案

### 核心思路
实现JSON数据缓冲和重组机制，确保只有完整的JSON才会被解析。

### 技术实现

#### 1. 添加数据缓冲区
```java
// 添加JSON数据缓冲区，用于处理分片数据
StringBuilder jsonBuffer = new StringBuilder();
```

#### 2. JSON完整性验证
```java
/**
 * 验证JSON字符串是否完整有效
 */
private boolean isValidJson(String jsonString) {
    if (jsonString == null || jsonString.trim().isEmpty()) {
        return false;
    }
    
    try {
        ObjectMapper mapper = new ObjectMapper();
        mapper.readTree(jsonString);
        return true;
    } catch (Exception e) {
        return false;
    }
}
```

#### 3. 分片数据重组逻辑
```java
// 提取JSON数据部分
String jsonData = line.substring(6).trim();

// 将当前行的JSON数据添加到缓冲区
jsonBuffer.append(jsonData);

// 尝试解析完整的JSON
String bufferedJson = jsonBuffer.toString();
if (isValidJson(bufferedJson)) {
    // JSON完整，可以解析
    processCompleteJson(bufferedJson, response);
    // 清空缓冲区
    jsonBuffer.setLength(0);
} else {
    // JSON不完整，等待更多数据
    log.debug("JSON数据不完整，等待更多数据: [{}]", bufferedJson);
}
```

#### 4. 跨行数据处理
```java
else if (!line.startsWith("data:") && jsonBuffer.length() > 0) {
    // 这可能是分片JSON的剩余部分
    jsonBuffer.append(line);
    
    // 再次尝试解析
    String bufferedJson = jsonBuffer.toString();
    if (isValidJson(bufferedJson)) {
        processCompleteJson(bufferedJson, response);
        jsonBuffer.setLength(0);
    }
}
```
