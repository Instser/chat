## 🔍 Vercel AI SDK 流式协议

根据官方文档，Vercel AI SDK v4.3.16 支持两种流式协议：

### 1. Text Stream Protocol (简单文本流)
- **格式**: 纯文本流
- **用途**: 仅支持基础文本数据
- **启用方式**: `streamProtocol: 'text'`

### 2. Data Stream Protocol (数据流协议) ⭐ **默认使用**
- **格式**: 特殊的数据流协议
- **用途**: 支持文本、工具调用、错误处理等
- **启用方式**: `streamProtocol: 'data'` (默认)

## ✅ 本项目需要的格式

### 🎯 **确认：使用 Data Stream Protocol**

由于项目中没有显式设置 `streamProtocol`，因此使用默认的 **Data Stream Protocol**。

### 📡 正确的响应格式

#### 响应头设置
```
Content-Type: text/plain; charset=utf-8
Cache-Control: no-cache
Connection: keep-alive
```

#### 数据格式规范
每个流式数据块的格式：`TYPE_ID:CONTENT_JSON\n`

## 🔧 后端修复方案

### 1. 响应头设置
```javascript
res.setHeader('Content-Type', 'text/plain; charset=utf-8')
res.setHeader('Cache-Control', 'no-cache')
res.setHeader('Connection', 'keep-alive')
res.setHeader('x-vercel-ai-data-stream', 'v1')  // 关键标识
res.setHeader('Access-Control-Allow-Origin', 'http://localhost:3000')
res.setHeader('Access-Control-Allow-Credentials', 'true')
```

### 2. 数据发送格式

#### ❌ 当前错误的发送方式：
```javascript
res.write(`data:0:"${content}"\n\n`)  // 错误：多了data:前缀
```

#### ✅ 正确的发送方式：
```javascript
// 发送文本块
res.write(`0:${JSON.stringify(content)}\n`)

// 发送完成标记
res.write(`d:${JSON.stringify({
  finishReason: "stop",
  usage: {
    promptTokens: 10,
    completionTokens: 20
  }
})}\n`)
```

### 3. 完整的后端实现示例

```javascript
app.post('/api/chat', async (req, res) => {
  try {
    // 设置Data Stream响应头
    res.setHeader('Content-Type', 'text/plain; charset=utf-8')
    res.setHeader('Cache-Control', 'no-cache')
    res.setHeader('Connection', 'keep-alive')
    res.setHeader('x-vercel-ai-data-stream', 'v1')  // 关键！
    res.setHeader('Access-Control-Allow-Origin', 'http://localhost:3000')
    res.setHeader('Access-Control-Allow-Credentials', 'true')
    
    const { messages, userId, deepThinking } = req.body
    
    // 模拟AI响应
    const aiResponse = "你好！看起来你可能在测试或输入随机数字。如果你有任何问题或需要帮助，请告诉我，我会尽力提供支持。😊"
    
    // 按字符或词组发送
    const chunks = aiResponse.match(/.{1,3}/g) || [aiResponse]
    
    for (const content of chunks) {
      // 发送文本块 - 格式：0:"内容"
      res.write(`0:${JSON.stringify(content)}\n`)
      
      // 模拟延迟
      await new Promise(resolve => setTimeout(resolve, 50))
    }
    
    // 发送完成标记 - 格式：d:{finishReason,usage}
    res.write(`d:${JSON.stringify({
      finishReason: "stop",
      usage: {
        promptTokens: 10,
        completionTokens: 20
      }
    })}\n`)
    
    res.end()
    
  } catch (error) {
    console.error('Chat API error:', error)
    
    // 发送错误 - 格式：3:"错误信息"
    res.write(`3:${JSON.stringify(error.message || "Internal server error")}\n`)
    res.end()
  }
})
```

## 📊 Data Stream Protocol 支持的类型

| 类型ID | 格式 | 说明 | 示例 |
|--------|------|------|------|
| `0` | `0:string` | 文本块 | `0:"你好"` |
| `2` | `2:Array<JSONValue>` | 数据块 | `2:[{"key":"value"}]` |
| `3` | `3:string` | 错误信息 | `3:"error message"` |
| `8` | `8:Array<JSONValue>` | 消息注释 | `8:[{"id":"msg-123"}]` |
| `9` | `9:{toolCallId,toolName,args}` | 工具调用 | `9:{"toolCallId":"call-123"}` |
| `a` | `a:{toolCallId,result}` | 工具结果 | `a:{"toolCallId":"call-123"}` |
| `d` | `d:{finishReason,usage}` | 完成标记 | `d:{"finishReason":"stop"}` |

## ⚠️ 关键注意事项

### 1. 格式严格性
- **不要** 使用 `data:` 前缀
- **不要** 使用双换行符 `\n\n`
- **必须** 设置 `x-vercel-ai-data-stream: v1` 头
- **必须** 使用正确的类型ID

### 2. 与OpenAI格式的区别
- **OpenAI格式**: `data: {"id":"chatcmpl-xxx",...}`
- **Vercel格式**: `0:"内容"`

### 3. 完成标记
- **OpenAI格式**: `data: [DONE]`
- **Vercel格式**: `d:{"finishReason":"stop","usage":{...}}`
