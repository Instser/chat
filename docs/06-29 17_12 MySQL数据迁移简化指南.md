# MySQL 5.7到8.0数据迁移简化指南

## 前提条件
- MySQL 5.7和8.0服务器都已安装并运行
- 具有数据库管理员权限
- 网络连接正常

## 方案一：完整数据库迁移（推荐）

### 1. 备份MySQL 5.7数据
```bash
# 导出完整数据库
mysqldump -h [5.7服务器IP] -u root -p \
  --single-transaction \
  --routines \
  --triggers \
  --set-gtid-purged=OFF \
  --default-character-set=utf8mb4 \
  chat > chat_57_backup.sql
```

### 2. 在MySQL 8.0创建数据库
```sql
-- 连接到MySQL 8.0服务器
mysql -h [8.0服务器IP] -u root -p

-- 创建新数据库
CREATE DATABASE chat CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. 导入数据到MySQL 8.0
```bash
# 导入数据
mysql -h [8.0服务器IP] -u root -p chat < chat_57_backup.sql
```

### 4. 验证数据完整性
```sql
-- 连接到MySQL 8.0
mysql -h [8.0服务器IP] -u root -p chat

-- 检查表数量和记录数
SELECT 
    table_name,
    table_rows
FROM information_schema.tables 
WHERE table_schema = 'chat'
ORDER BY table_rows DESC;

-- 验证关键表数据
SELECT COUNT(*) as ai_models FROM t_ai_model WHERE deleted = 0;
SELECT COUNT(*) as users FROM t_user WHERE deleted = 0;
SELECT COUNT(*) as sessions FROM t_chat_session WHERE deleted = 0;
SELECT COUNT(*) as messages FROM t_chat_message WHERE deleted = 0;
```

## 方案二：分表迁移（大数据量推荐）

### 1. 按表导出数据
```bash
# 导出AI模型表
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_ai_model > t_ai_model.sql

# 导出用户表
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_user > t_user.sql

# 导出会话表
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_chat_session > t_chat_session.sql

# 导出消息表（最大的表）
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_chat_message > t_chat_message.sql

# 导出其他表
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_package > t_package.sql
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_user_order > t_user_order.sql
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_user_package > t_user_package.sql
mysqldump -h [5.7服务器IP] -u root -p --single-transaction chat t_upload > t_upload.sql
```

### 2. 创建MySQL 8.0表结构
```bash
# 使用提供的MySQL 8.0结构文件
mysql -h [8.0服务器IP] -u root -p < sql/chat_mysql8.0.sql
```

### 3. 按顺序导入数据
```bash
# 先导入基础表（无外键依赖）
mysql -h [8.0服务器IP] -u root -p chat < t_ai_model.sql
mysql -h [8.0服务器IP] -u root -p chat < t_user.sql
mysql -h [8.0服务器IP] -u root -p chat < t_package.sql

# 再导入有外键依赖的表
mysql -h [8.0服务器IP] -u root -p chat < t_chat_session.sql
mysql -h [8.0服务器IP] -u root -p chat < t_user_order.sql
mysql -h [8.0服务器IP] -u root -p chat < t_user_package.sql

# 最后导入大数据表
mysql -h [8.0服务器IP] -u root -p chat < t_chat_message.sql
mysql -h [8.0服务器IP] -u root -p chat < t_upload.sql
```

## 方案三：使用mydumper/myloader（超大数据量）

### 1. 使用mydumper导出
```bash
# 多线程导出
mydumper -h [5.7服务器IP] -u root -p[密码] \
  --database=chat \
  --compress \
  --build-empty-files \
  --threads=4 \
  --outputdir=./chat_backup
```

### 2. 使用myloader导入
```bash
# 先创建数据库结构
mysql -h [8.0服务器IP] -u root -p -e "CREATE DATABASE chat CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 多线程导入
myloader -h [8.0服务器IP] -u root -p[密码] \
  --database=chat \
  --threads=4 \
  --directory=./chat_backup
```

```sql
SELECT COUNT(*) as total_users, 
       COUNT(CASE WHEN deleted = 0 THEN 1 END) as active_users
FROM t_user;

-- 验证聊天数据
SELECT COUNT(*) as total_messages,
       COUNT(CASE WHEN deleted = 0 THEN 1 END) as active_messages,
       COUNT(DISTINCT session_id) as unique_sessions

-- 验证外键关系
SELECT 
    (SELECT COUNT(*) FROM t_chat_session) as sessions,
    (SELECT COUNT(*) FROM t_chat_message) as messages,
    (SELECT COUNT(DISTINCT session_id) FROM t_chat_message) as message_sessions;
```

## 快速迁移脚本

### 一键迁移脚本
```bash
#!/bin/bash
# 设置变量
SOURCE_HOST="[5.7服务器IP]"
TARGET_HOST="[8.0服务器IP]"
DB_USER="root"
DB_NAME="chat"

# 备份数据
echo "正在备份数据..."
mysqldump -h $SOURCE_HOST -u $DB_USER -p \
  --single-transaction --routines --triggers \
  --set-gtid-purged=OFF --default-character-set=utf8mb4 \
  $DB_NAME > chat_backup.sql

# 创建目标数据库
echo "正在创建目标数据库..."
mysql -h $TARGET_HOST -u $DB_USER -p -e "CREATE DATABASE $DB_NAME CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 导入数据
echo "正在导入数据..."
mysql -h $TARGET_HOST -u $DB_USER -p $DB_NAME < chat_backup.sql

# 验证数据
echo "正在验证数据..."
mysql -h $TARGET_HOST -u $DB_USER -p $DB_NAME -e "
SELECT table_name, table_rows 
FROM information_schema.tables 
WHERE table_schema = '$DB_NAME';"

echo "迁移完成！"
```
