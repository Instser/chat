## 🔧 **恢复方案实施**

### 1. Caffeine缓存统计恢复

#### 修改前
```java
private final Cache<String, Boolean> permissionCache = Caffeine.newBuilder()
        .maximumSize(1000)
        .expireAfterWrite(5, TimeUnit.MINUTES)
        .build(); // 没有启用统计

public String getCacheStats() {
    return String.format("权限缓存统计 - 大小: %d", permissionCache.estimatedSize());
}
```

#### 修改后
```java
private final Cache<String, Boolean> permissionCache = Caffeine.newBuilder()
        .maximumSize(1000)
        .expireAfterWrite(5, TimeUnit.MINUTES)
        .recordStats() // 重新启用统计功能
        .build();

public String getCacheStats() {
    try {
        // 使用反射获取统计信息，兼容不同版本的Caffeine
        Object stats = permissionCache.getClass().getMethod("stats").invoke(permissionCache);
        
        long size = permissionCache.estimatedSize();
        
        try {
            double hitRate = (Double) stats.getClass().getMethod("hitRate").invoke(stats) * 100;
            long loadCount = (Long) stats.getClass().getMethod("loadCount").invoke(stats);
            long evictionCount = (Long) stats.getClass().getMethod("evictionCount").invoke(stats);
            
            return String.format("权限缓存统计 - 大小: %d, 命中率: %.2f%%, 加载次数: %d, 驱逐次数: %d",
                    size, hitRate, loadCount, evictionCount);
        } catch (Exception e) {
            return String.format("权限缓存统计 - 大小: %d (详细统计不可用)", size);
        }
    } catch (Exception e) {
        return String.format("权限缓存统计 - 大小: %d (统计获取失败)", permissionCache.estimatedSize());
    }
}
```

### 2. 错误分类监控恢复

#### 修改前
```java
public void recordError(Timer.Sample sample, String errorCode) {
    sample.stop(requestTimer);
    errorCounter.increment(); // 只有总计数，没有分类
    activeRequestCount.decrementAndGet();
}
```

#### 修改后
```java
public void recordError(Timer.Sample sample, String errorCode) {
    sample.stop(requestTimer);
    
    // 使用动态标签记录不同类型的错误
    Counter.builder("web_search_update_errors_total")
            .description("网络搜索内容更新错误总数")
            .tag("error_code", errorCode)
            .register(meterRegistry)
            .increment();
    
    // 同时增加总错误计数
    errorCounter.increment();
    activeRequestCount.decrementAndGet();
}
```

### 3. 新增详细错误统计方法

```java
/**
 * 获取详细的错误统计信息
 */
public String getErrorBreakdown() {
    try {
        StringBuilder breakdown = new StringBuilder("错误分类统计: ");
        
        // 通过MeterRegistry获取按错误码分类的统计
        meterRegistry.getMeters().stream()
                .filter(meter -> meter.getId().getName().equals("web_search_update_errors_total"))
                .filter(meter -> meter.getId().getTag("error_code") != null)
                .forEach(meter -> {
                    String errorCode = meter.getId().getTag("error_code");
                    double count = ((Counter) meter).count();
                    if (count > 0) {
                        breakdown.append(String.format("%s: %.0f, ", errorCode, count));
                    }
                });
        
        String result = breakdown.toString();
        return result.endsWith(", ") ? result.substring(0, result.length() - 2) : result;
    } catch (Exception e) {
        log.warn("获取错误分类统计失败", e);
        return "错误分类统计获取失败";
    }
}
```

### 3. 监控告警配置
```yaml
# Prometheus告警规则
groups:
  - name: web_search_monitoring
    rules:
      # 缓存命中率过低告警
      - alert: WebSearchCacheHitRateLow
        expr: cache_hit_rate{cache="permission"} < 0.7
        for: 5m
        annotations:
          summary: "网络搜索权限缓存命中率过低"
          
      # 错误率过高告警
      - alert: WebSearchErrorRateHigh
        expr: rate(web_search_update_errors_total[5m]) / rate(web_search_update_requests_total[5m]) > 0.05
        for: 2m
        annotations:
          summary: "网络搜索错误率过高"
          
      # 特定错误类型告警
      - alert: WebSearchRateLimitExceeded
        expr: rate(web_search_update_errors_total{error_code="RATE_LIMIT_EXCEEDED"}[5m]) > 10
        for: 1m
        annotations:
          summary: "网络搜索频率限制触发过多"
```
