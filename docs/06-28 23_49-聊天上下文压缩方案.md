# 聊天上下文压缩实施方案

**文档创建时间**: 2025-06-28 23:49
**版本**: v2.0
**作者**: Augment Agent

## 1. 背景分析

### 1.1 当前系统状况
- 聊天消息存储在 `t_chat_message` 表中
- 每条消息包含完整的用户输入和AI响应
- 向AI发送请求时包含完整的历史消息
- 没有上下文长度限制和压缩机制
- 长对话可能导致token超限和性能问题

### 1.2 面临的问题
- **Token限制**: 长对话超出AI模型上下文窗口
- **性能下降**: 大量历史消息影响响应速度
- **成本增加**: 每次请求都发送完整历史增加API调用成本
- **内存占用**: 长对话占用大量内存资源
- **用户体验**: 响应时间变长，影响交互流畅性

## 2. 核心压缩流程设计

### 2.1 压缩触发机制

#### 2.1.1 阈值检查
系统在每次聊天请求前检查当前会话的消息长度：
```java
public class CompressionTrigger {
    private static final int MESSAGE_COUNT_THRESHOLD = 20;  // 消息数量阈值
    private static final int TOKEN_COUNT_THRESHOLD = 4000;  // Token数量阈值

    public boolean needsCompression(String sessionId) {
        List<ChatMessage> messages = chatMessageService.getSessionMessages(sessionId);

        // 检查消息数量
        if (messages.size() > MESSAGE_COUNT_THRESHOLD) {
            return true;
        }

        // 检查Token数量
        int totalTokens = calculateTotalTokens(messages);
        if (totalTokens > TOKEN_COUNT_THRESHOLD) {
            return true;
        }

        return false;
    }
}
```

### 2.2 消息筛选逻辑

#### 2.2.1 筛选规则
```java
public class MessageFilter {

    public FilterResult filterMessages(List<ChatMessage> allMessages, int recentKeepCount) {
        List<ChatMessage> recentMessages = new ArrayList<>();
        List<ChatMessage> messagesToSummarize = new ArrayList<>();

        // 按时间排序（最新的在后面）
        allMessages.sort(Comparator.comparing(ChatMessage::getCreatedTime));

        int totalCount = allMessages.size();
        int summaryStartIndex = 0;
        int recentStartIndex = Math.max(0, totalCount - recentKeepCount);

        for (int i = 0; i < allMessages.size(); i++) {
            ChatMessage message = allMessages.get(i);

            // 排除错误消息
            if (isErrorMessage(message)) {
                continue;
            }

            // 排除已经被摘要的消息
            if (message.getIsCompressed() != null && message.getIsCompressed() == 1) {
                continue;
            }

            if (i >= recentStartIndex) {
                // 最近的消息保持完整
                recentMessages.add(message);
            } else {
                // 早期消息需要摘要
                messagesToSummarize.add(message);
            }
        }

        return new FilterResult(messagesToSummarize, recentMessages);
    }

    private boolean isErrorMessage(ChatMessage message) {
        return message.getStatus() != null && message.getStatus() == 2; // 失败状态
    }
}
```

### 2.3 LLM摘要生成

#### 2.3.1 摘要提示词设计
```java
public class SummaryPrompts {

    public static final String CONVERSATION_SUMMARY_PROMPT =
        "请对以下对话历史进行智能摘要，要求：\n" +
        "1. 保留用户的核心需求和问题\n" +
        "2. 保留重要的信息和数据\n" +
        "3. 保留关键的决策和结论\n" +
        "4. 保留用户的偏好和设置\n" +
        "5. 摘要应简洁但完整，控制在300字以内\n" +
        "6. 使用第三人称描述，格式：用户询问了...，助手回答了...\n\n" +
        "对话历史：\n{conversation_history}";

    public static String buildSummaryPrompt(List<ChatMessage> messages) {
        StringBuilder conversationHistory = new StringBuilder();

        for (ChatMessage message : messages) {
            String role = "user".equals(message.getRole()) ? "用户" : "助手";
            conversationHistory.append(role).append("：").append(message.getContent()).append("\n\n");
        }

        return CONVERSATION_SUMMARY_PROMPT.replace("{conversation_history}", conversationHistory.toString());
    }
}
```

#### 2.3.2 摘要生成服务
```java
@Service
public class ConversationSummaryService {

    private final ChatService chatService;
    private final AiModelService aiModelService;

    public String generateSummary(List<ChatMessage> messages) {
        try {
            // 构建摘要提示词
            String summaryPrompt = SummaryPrompts.buildSummaryPrompt(messages);

            // 获取摘要模型（使用固定的模型ID 1）
            AiModel summaryModel = aiModelService.getById(1L);
            if (summaryModel == null) {
                throw new RuntimeException("摘要模型不存在");
            }

            // 构建摘要请求
            List<Map<String, String>> summaryMessages = new ArrayList<>();
            Map<String, String> userMessage = new HashMap<>();
            userMessage.put("role", "user");
            userMessage.put("content", summaryPrompt);
            summaryMessages.add(userMessage);

            // 调用AI生成摘要
            String summary = callAiForSummary(summaryMessages, summaryModel);

            log.info("对话摘要生成成功，原始消息数：{}，摘要长度：{}", messages.size(), summary.length());
            return summary;

        } catch (Exception e) {
            log.error("生成对话摘要失败", e);
            throw new RuntimeException("摘要生成失败：" + e.getMessage());
        }
    }

    private String callAiForSummary(List<Map<String, String>> messages, AiModel model) {
        // 复用现有的AI调用逻辑，但使用非流式调用
        // 实现细节类似于现有的标题生成逻辑
        return chatService.callAiForTitleWithHttpClient(messages.get(0).get("content"), model);
    }
}
```

#### 2.4.2 摘要存储服务
```java
@Service
public class SummaryStorageService {

    public void storeSummary(String sessionId, String summaryContent,
                           List<ChatMessage> summarizedMessages) {
        try {
            // 创建摘要记录
            ChatSessionSummary summary = new ChatSessionSummary();
            summary.setSessionId(sessionId);
            summary.setSummaryContent(summaryContent);
            summary.setOriginalMessageCount(summarizedMessages.size());
            summary.setTokenCount(estimateTokenCount(summaryContent));

            if (!summarizedMessages.isEmpty()) {
                summary.setSummaryStartMessageId(summarizedMessages.get(0).getMessageId());
                summary.setSummaryEndMessageId(summarizedMessages.get(summarizedMessages.size() - 1).getMessageId());
            }

            // 计算压缩比例
            int originalTokens = summarizedMessages.stream()
                .mapToInt(msg -> msg.getTokenCount() != null ? msg.getTokenCount() : 0)
                .sum();
            if (originalTokens > 0) {
                double ratio = (double) summary.getTokenCount() / originalTokens;
                summary.setCompressionRatio(BigDecimal.valueOf(ratio).setScale(2, RoundingMode.HALF_UP));
            }

            // 保存摘要
            chatSessionSummaryService.save(summary);

            // 标记原始消息为已摘要
            markMessagesAsSummarized(summarizedMessages);

            log.info("摘要存储成功，会话ID：{}，摘要长度：{}，原始消息数：{}",
                    sessionId, summaryContent.length(), summarizedMessages.size());

        } catch (Exception e) {
            log.error("存储摘要失败，会话ID：{}", sessionId, e);
            throw new RuntimeException("摘要存储失败：" + e.getMessage());
        }
    }

    private void markMessagesAsSummarized(List<ChatMessage> messages) {
        for (ChatMessage message : messages) {
            message.setIsSummarized(1);
            chatMessageService.updateById(message);
        }
    }

    private int estimateTokenCount(String content) {
        return content.length() / 4; // 简单估算
    }
}
```

## 3. 上下文组装机制

### 3.1 上下文组装顺序

系统按以下固定顺序组装发送给LLM的上下文：

#### 3.1.1 组装流程
```java
@Service
public class ContextAssemblyService {

    public List<Map<String, String>> assembleContext(String sessionId,
                                                    List<Map<String, String>> currentMessages,
                                                    boolean isDeepThinking) {
        List<Map<String, String>> assembledContext = new ArrayList<>();

        // 1. 系统提示词
        assembledContext.add(buildSystemPrompt(isDeepThinking));

        // 2. 长期记忆（历史摘要）
        List<Map<String, String>> longTermMemory = buildLongTermMemory(sessionId);
        assembledContext.addAll(longTermMemory);

        // 3. 预设提示词（如果有面具配置）
        List<Map<String, String>> presetPrompts = buildPresetPrompts(sessionId);
        assembledContext.addAll(presetPrompts);

        // 4. 短期记忆（最近的n条消息）
        List<Map<String, String>> shortTermMemory = buildShortTermMemory(sessionId);
        assembledContext.addAll(shortTermMemory);

        // 5. 当前用户消息
        assembledContext.addAll(currentMessages);

        log.info("上下文组装完成，会话ID：{}，总消息数：{}", sessionId, assembledContext.size());
        return assembledContext;
    }
}
```

#### 3.1.3 长期记忆构建
```java
private List<Map<String, String>> buildLongTermMemory(String sessionId) {
    List<Map<String, String>> longTermMemory = new ArrayList<>();

    // 获取会话的所有摘要（按时间顺序）
    List<ChatSessionSummary> summaries = chatSessionSummaryService.getBySessionId(sessionId);

    if (!summaries.isEmpty()) {
        // 将所有摘要合并为一个长期记忆消息
        StringBuilder combinedSummary = new StringBuilder();
        combinedSummary.append("以下是之前对话的摘要：\n\n");

        for (ChatSessionSummary summary : summaries) {
            combinedSummary.append(summary.getSummaryContent()).append("\n\n");
        }

        Map<String, String> memoryMessage = new HashMap<>();
        memoryMessage.put("role", "system");
        memoryMessage.put("content", combinedSummary.toString());
        longTermMemory.add(memoryMessage);

        log.debug("长期记忆构建完成，摘要数量：{}，内容长度：{}",
                summaries.size(), combinedSummary.length());
    }

    return longTermMemory;
}
```

#### 3.1.4 短期记忆构建
```java
private List<Map<String, String>> buildShortTermMemory(String sessionId) {
    List<Map<String, String>> shortTermMemory = new ArrayList<>();

    // 获取最近的未被摘要的消息
    List<ChatMessage> recentMessages = chatMessageService.getRecentUnSummarizedMessages(sessionId, 10);

    for (ChatMessage message : recentMessages) {
        // 跳过错误消息
        if (message.getStatus() != null && message.getStatus() == 2) {
            continue;
        }

        Map<String, String> messageMap = new HashMap<>();
        messageMap.put("role", message.getRole());
        messageMap.put("content", message.getContent());
        shortTermMemory.add(messageMap);
    }

    log.debug("短期记忆构建完成，消息数量：{}", shortTermMemory.size());
    return shortTermMemory;
}
```

### 3.2 完整压缩流程实现

#### 3.2.1 主压缩服务
```java
@Service
public class ChatContextCompressionService {

    private final CompressionTrigger compressionTrigger;
    private final MessageFilter messageFilter;
    private final ConversationSummaryService summaryService;
    private final SummaryStorageService storageService;
    private final ContextAssemblyService contextAssemblyService;

    /**
     * 执行完整的压缩流程
     */
    public void executeCompressionIfNeeded(String sessionId) {
        try {
            // 1. 阈值检查
            if (!compressionTrigger.needsCompression(sessionId)) {
                log.debug("会话{}无需压缩", sessionId);
                return;
            }

            log.info("开始执行会话{}的上下文压缩", sessionId);

            // 2. 获取所有消息
            List<ChatMessage> allMessages = chatMessageService.getSessionMessages(sessionId);

            // 3. 消息筛选
            FilterResult filterResult = messageFilter.filterMessages(allMessages, 10);
            List<ChatMessage> messagesToSummarize = filterResult.getMessagesToSummarize();

            if (messagesToSummarize.isEmpty()) {
                log.info("会话{}没有需要摘要的消息", sessionId);
                return;
            }

            // 4. 调用LLM生成摘要
            String summary = summaryService.generateSummary(messagesToSummarize);

            // 5. 存储摘要结果
            storageService.storeSummary(sessionId, summary, messagesToSummarize);

            log.info("会话{}压缩完成，摘要了{}条消息", sessionId, messagesToSummarize.size());

        } catch (Exception e) {
            log.error("执行会话{}压缩失败", sessionId, e);
            // 压缩失败不影响正常聊天流程
        }
    }

    /**
     * 获取组装后的上下文（用于发送给AI）
     */
    public List<Map<String, String>> getAssembledContext(String sessionId,
                                                        List<Map<String, String>> currentMessages,
                                                        boolean isDeepThinking) {
        // 先检查是否需要压缩
        executeCompressionIfNeeded(sessionId);

        // 然后组装上下文
        return contextAssemblyService.assembleContext(sessionId, currentMessages, isDeepThinking);
    }
}
```

## 6. 风险控制和应急预案

### 6.1 主要风险识别
1. **摘要质量风险**: AI生成的摘要可能丢失关键信息
2. **性能风险**: 摘要生成可能增加响应时间
3. **兼容性风险**: 新功能可能影响现有聊天流程
4. **数据风险**: 压缩过程可能导致数据不一致

### 6.2 风险缓解措施
1. **质量保证**
