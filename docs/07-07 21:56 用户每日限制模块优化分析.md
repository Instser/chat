## 🔍 发现的问题

### 1. 数据库设计问题

#### ❌ 问题1: 复合主键设计不合理
```sql
-- 当前设计
UNIQUE KEY uk_user_package_model_date (user_id, package_id, model_name, usage_date)
```
**问题**: 
- `package_id` 在唯一键中是冗余的，因为用户在同一时间只能有一个有效套餐
- 增加了索引维护成本和存储开销

#### ❌ 问题2: 数据冗余严重
```java
// UserDailyUsage实体中
private Long packageId;     // 冗余字段
private Integer dailyLimit; // 冗余字段，可从套餐配置获取
```
**问题**:
- `package_id` 可以通过 `user_id` 从 `t_user_account` 表获取
- `daily_limit` 可以从套餐的 `model_permissions` JSON配置获取
- 数据不一致风险：套餐变更时历史记录的 `daily_limit` 可能过时

#### ❌ 问题3: JSON配置解析性能问题
```java
// 每次检查都要解析JSON
Map<String, ModelPermission> permissions = packageInfo.getModelPermissionsMap();
```
**问题**:
- 频繁的JSON解析影响性能
- 没有缓存机制
- 解析失败时的降级策略不够完善

### 2. 服务层设计问题

#### ❌ 问题4: 向后兼容代码冗余
```java
@Override
public boolean canChatToday(Long userId, Long packageId) {
    // 注意：这个方法现在已经被模型维度的方法替代
    // 为了向后兼容，默认使用STANDARD模型
    return canChatWithModel(userId, packageId, "STANDARD");
}
```
**问题**:
- 大量向后兼容代码增加维护成本
- 代码逻辑混乱，新老接口并存

#### ❌ 问题5: 缺乏有效的缓存策略
**问题**:
- 套餐配置没有缓存，每次都查数据库
- 用户今日使用情况没有缓存
- 高并发场景下数据库压力大

#### ❌ 问题6: 原子性操作不够优化
```sql
-- 当前的原子操作
INSERT INTO t_user_daily_usage (...) VALUES (...)
ON DUPLICATE KEY UPDATE chat_count_used = chat_count_used + 1
```
**问题**:
- 每次操作都要执行完整的INSERT语句
- 在高并发场景下可能存在性能瓶颈

### 3. 业务逻辑问题

#### ❌ 问题7: 限制检查逻辑分散
**问题**:
- 限制检查逻辑分散在多个服务中
- `ChatLimitService` 和 `UserDailyUsageService` 职责重叠
- 代码重复，维护困难

#### ❌ 问题8: 错误处理不统一
**问题**:
- 不同场景下的错误信息不一致
- 缺乏统一的异常处理机制
- 日志记录不规范

## 🔧 移除daily_limit字段后的统计方案

### 问题：如何统计用户使用次数？

移除 `t_user_daily_usage` 表中的 `daily_limit` 字段后，我们需要重新设计统计机制。

### 解决方案

#### 方案1: 动态获取限制次数（推荐）

```java
@Service
public class OptimizedUserDailyUsageService {

    @Cacheable(value = "package:permissions", key = "#packageId")
    private Map<String, ModelPermission> getPackagePermissions(Long packageId) {
        Package packageInfo = packageService.getPackageById(packageId);
        return packageInfo != null ? packageInfo.getModelPermissionsMap() : new HashMap<>();
    }

    public int getRemainingModelChats(Long userId, String modelName) {
        // 1. 通过用户账户获取套餐ID
        UserAccount userAccount = userAccountService.getUserAccount(userId);
        if (userAccount == null || userAccount.getPackageId() == null) {
            return 0;
        }

        // 2. 从缓存中获取套餐权限配置
        Map<String, ModelPermission> permissions = getPackagePermissions(userAccount.getPackageId());
        ModelPermission permission = permissions.get(modelName);

        if (permission == null) {
            return 0;
        }

        // 3. 无限制套餐
        if (permission.getDailyLimit() == -1) {
            return -1;
        }

        // 4. 获取今日使用情况（不再需要daily_limit字段）
        UserDailyUsage todayUsage = getTodayModelUsage(userId, modelName);
        if (todayUsage == null) {
            return permission.getDailyLimit();
        }

        return Math.max(0, permission.getDailyLimit() - todayUsage.getChatCountUsed());
    }

    // 简化的今日使用记录查询（移除package_id依赖）
    public UserDailyUsage getTodayModelUsage(Long userId, String modelName) {
        return baseMapper.selectByUserModelDate(userId, modelName, getBusinessDate());
    }
}
```

#### 方案2: 缓存优化的统计服务

```java
@Component
public class UsageStatisticsService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /**
     * 获取用户今日剩余次数（带缓存）
     */
    public int getCachedRemainingChats(Long userId, String modelName) {
        String cacheKey = String.format("usage:remaining:%d:%s:%s",
            userId, modelName, LocalDate.now().toString());

        // 1. 先从缓存获取
        Integer cached = (Integer) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }

        // 2. 计算剩余次数
        int remaining = calculateRemainingChats(userId, modelName);

        // 3. 缓存结果（缓存到当天结束）
        long secondsUntilEndOfDay = getSecondsUntilEndOfDay();
        redisTemplate.opsForValue().set(cacheKey, remaining,
            Duration.ofSeconds(secondsUntilEndOfDay));

        return remaining;
    }

    private int calculateRemainingChats(Long userId, String modelName) {
        // 实现具体的计算逻辑
        UserAccount userAccount = userAccountService.getUserAccount(userId);
        if (userAccount == null) return 0;

        // 从套餐配置获取限制
        Package packageInfo = packageService.getPackageById(userAccount.getPackageId());
        if (packageInfo == null) return 0;

        ModelPermission permission = packageInfo.getModelPermissionsMap().get(modelName);
        if (permission == null || permission.getDailyLimit() == -1) {
            return permission != null && permission.getDailyLimit() == -1 ? -1 : 0;
        }

        // 获取今日使用情况
        UserDailyUsage todayUsage = getTodayUsage(userId, modelName);
        int used = todayUsage != null ? todayUsage.getChatCountUsed() : 0;

        return Math.max(0, permission.getDailyLimit() - used);
    }
}
```
