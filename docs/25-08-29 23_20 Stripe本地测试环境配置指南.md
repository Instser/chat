## 🎯 本地测试环境配置

### 方案一：Stripe CLI（推荐）

#### 1. 安装Stripe CLI

**Windows:**
```bash
# 使用 Chocolatey
choco install stripe-cli

# 或下载安装包：https://github.com/stripe/stripe-cli/releases/latest
```

**macOS:**
```bash
brew install stripe/stripe-cli/stripe
```

**Linux:**
```bash
wget https://github.com/stripe/stripe-cli/releases/latest/download/stripe_linux_x86_64.tar.gz
tar -xvf stripe_linux_x86_64.tar.gz
sudo mv stripe /usr/local/bin
```

#### 2. 配置步骤

**第一步：登录Stripe**
```bash
stripe login
# 会打开浏览器进行授权登录
```

**第二步：获取测试密钥**
1. 访问 [Stripe Dashboard](https://dashboard.stripe.com/test/apikeys)
2. 确保切换到"测试数据"模式
3. 复制测试密钥：
   - 可发布密钥：`pk_test_...`
   - 密钥：`sk_test_...`

**第三步：启动Webhook转发**
```bash
stripe listen --forward-to localhost:8080/api/payment/stripe/webhook

# 输出示例：
# > Ready! Your webhook signing secret is whsec_1a2b3c4d5e6f...
# 记录这个signing secret
```

**第四步：配置环境变量**
```bash
export STRIPE_PUBLIC_KEY="pk_test_你的测试公钥"
export STRIPE_SECRET_KEY="sk_test_你的测试私钥"
export STRIPE_WEBHOOK_SECRET="whsec_从CLI获取的签名密钥"
export STRIPE_SANDBOX=true
```

**第五步：启动应用**
```bash
mvn spring-boot:run

# 检查日志应显示：
# Stripe配置初始化成功
# 环境: 测试环境
```

### 方案二：ngrok（替代方案）

#### 1. 安装ngrok
- 从 [ngrok.com](https://ngrok.com/download) 下载安装

#### 2. 创建隧道
```bash
# 启动应用后，新开终端：
ngrok http 8080

# 获得公网URL，如：https://abc123.ngrok.io
```

#### 3. 配置Stripe Webhook
1. 在 [Stripe Dashboard](https://dashboard.stripe.com/test/webhooks) 创建Webhook
2. URL：`https://abc123.ngrok.io/api/payment/stripe/webhook`
3. 选择事件：
   - `payment_intent.succeeded`
   - `payment_intent.payment_failed`
   - `payment_intent.canceled`
4. 复制签名密钥：`whsec_...`

## 🧪 测试流程

### 1. API测试

**用户登录：**
```bash
curl -X POST "http://localhost:8080/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "你的用户名",
    "password": "你的密码"
  }'

# 保存返回的JWT Token
```

**创建支付订单：**
```bash
curl -X POST "http://localhost:8080/api/payment/create" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer JWT_TOKEN" \
  -d '{
    "packageId": 1,
    "paymentMethod": "stripe",
    "currency": "USD"
  }'

# 获得PaymentIntent的client_secret
```

### 2. 前端支付测试

```javascript
// 使用返回的client_secret进行支付
const stripe = Stripe('pk_test_你的公钥');

const { error, paymentIntent } = await stripe.confirmCardPayment(
  'client_secret_from_api',
  {
    payment_method: {
      card: {
        number: '4242424242424242', // 测试卡号
        exp_month: 12,
        exp_year: 2030,
        cvc: '123'
      }
    }
  }
);
```

### 3. Webhook事件测试

**使用Stripe CLI触发事件：**
```bash
# 模拟支付成功
stripe trigger payment_intent.succeeded

# 模拟支付失败  
stripe trigger payment_intent.payment_failed

# 查看应用日志验证处理结果
```

### 4. 测试卡号

**成功场景：**
- `4242424242424242` - Visa成功
- `5555555555554444` - Mastercard成功
- `378282246310005` - American Express成功

**失败场景：**
- `4000000000000002` - 通用拒绝
- `4000000000000009` - 资金不足
- `4000000000000069` - 过期卡
- `4000000000000127` - CVC错误

## 🚨 常见问题

### Q1: Stripe CLI连接失败
```bash
# 检查网络连接
ping api.stripe.com

# 重新登录
stripe login --force
```

### Q2: Webhook签名验证失败
- 确保使用CLI提供的signing secret
- 检查应用端口是否正确(8080)
- 验证endpoint路径正确

### Q3: PaymentIntent创建失败
- 检查API密钥是否正确设置
- 验证金额和货币格式
- 查看Stripe Dashboard错误日志

### Q4: 订单状态不更新
- 检查Webhook是否正常接收
- 验证数据库连接
- 查看应用处理日志

## 📝 注意事项

1. **测试环境隔离**：确保使用 `pk_test_` 和 `sk_test_` 密钥
2. **Webhook安全**：使用签名验证确保事件来源可信
3. **日志监控**：关注支付流程日志，及时发现问题
4. **数据清理**：测试后清理测试订单数据
5. **配置管理**：敏感信息使用环境变量，不要硬编码
