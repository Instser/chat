# 06-27 15:38 文档解析器元数据分离优化

## 📋 优化需求

根据用户反馈，需要在文档解析结果中分别显示：
1. **文件名**：显示用户上传的原始文件名
2. **元数据文档名**：从文档内部元数据中获取的标题

这样可以让用户同时看到文件名和文档内部的标题信息，提供更完整的文档信息。

## 🎯 修改方案

### 1. 输出格式调整

**修改前**：
```
文档类型: Word文档 (.docx)
文档名称: 多模态感知与认知一致性驱动的实时游戏帧生成算法研究

文档内容...
```

**修改后**：
```
文档类型: Word文档 (.docx)
文件名: 多模态感知与认知一致性驱动的实时游戏帧生成算法研究.docx
元数据文档名: 无标题

文档内容...
```

### 2. 方法重构

将原来的`getDocumentName`方法拆分为两个独立的方法：
- `getFileName(String fileName)` - 获取原始文件名
- `getDocumentTitleFromMetadata(Document document)` - 从元数据获取标题

## ✅ 修改详情

### 1. Word文档解析器 (`WordDocumentParser.java`)

#### 新增方法
```java
/**
 * 获取文件名
 * 返回原始文件名，如果为空则返回默认值
 */
private String getFileName(String fileName) {
    if (fileName != null && !fileName.trim().isEmpty()) {
        return fileName.trim();
    }
    return "未知文件";
}

/**
 * 从文档元数据获取标题
 * 支持DOCX格式的元数据读取
 */
private String getDocumentTitleFromMetadata(XWPFDocument document) {
    if (document != null) {
        try {
            String title = document.getProperties().getCoreProperties().getTitle();
            if (title != null && !title.trim().isEmpty()) {
                return title.trim();
            }
        } catch (Exception e) {
            log.debug("无法获取DOCX文档元数据标题: {}", e.getMessage());
        }
    }
    return "无标题";
}

/**
 * 从文档元数据获取标题
 * 支持DOC格式的元数据读取
 */
private String getDocumentTitleFromMetadata(HWPFDocument document) {
    if (document != null) {
        try {
            String title = document.getSummaryInformation().getTitle();
            if (title != null && !title.trim().isEmpty()) {
                return title.trim();
            }
        } catch (Exception e) {
            log.debug("无法获取DOC文档元数据标题: {}", e.getMessage());
        }
    }
    return "无标题";
}
```

### 2. Excel文档解析器 (`ExcelDocumentParser.java`)

#### 新增方法
```java
/**
 * 获取文件名
 */
private String getFileName(String fileName) {
    if (fileName != null && !fileName.trim().isEmpty()) {
        return fileName.trim();
    }
    return "未知文件";
}

/**
 * 从Excel文档元数据获取标题
 */
private String getDocumentTitleFromMetadata(Workbook workbook) {
    if (workbook != null) {
        try {
            if (workbook instanceof XSSFWorkbook) {
                // XLSX格式
                XSSFWorkbook xssfWorkbook = (XSSFWorkbook) workbook;
                if (xssfWorkbook.getProperties() != null && 
                    xssfWorkbook.getProperties().getCoreProperties() != null) {
                    String title = xssfWorkbook.getProperties().getCoreProperties().getTitle();
                    if (title != null && !title.trim().isEmpty()) {
                        return title.trim();
                    }
                }
            } else if (workbook instanceof HSSFWorkbook) {
                // XLS格式
                HSSFWorkbook hssfWorkbook = (HSSFWorkbook) workbook;
                if (hssfWorkbook.getSummaryInformation() != null) {
                    String title = hssfWorkbook.getSummaryInformation().getTitle();
                    if (title != null && !title.trim().isEmpty()) {
                        return title.trim();
                    }
                }
            }
        } catch (Exception e) {
            log.debug("无法获取Excel文档元数据标题: {}", e.getMessage());
        }
    }
    return "无标题";
}
```

#### 输出格式更新
```java
content.append("文件名: ").append(getFileName(fileName)).append("\n");
content.append("元数据文档名: ").append(getDocumentTitleFromMetadata(workbook)).append("\n");
content.append("工作表数量: ").append(workbook.getNumberOfSheets()).append("\n\n");
```

## 🔍 技术实现特点

### 1. 信息分离
- **文件名**：显示用户上传时的完整文件名（包含扩展名）
- **元数据文档名**：从文档内部属性获取的标题信息

### 2. 兼容性处理
- 支持新旧Office格式（DOC/DOCX, XLS/XLSX, PPT/PPTX）
- 针对不同格式使用相应的API获取元数据
- 安全的异常处理，避免解析失败

### 3. 默认值处理
- 文件名为空时显示"未知文件"
- 元数据标题为空时显示"无标题"
- 保证输出的完整性和一致性
