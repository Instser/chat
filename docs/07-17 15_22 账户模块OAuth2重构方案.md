# 账户模块OAuth2重构方案

**时间**: 2025年07月17日 15:22  
**版本**: v1.0  
**作者**: Augment Agent

## 重构概述

基于业务需求，将账户模块重构为OAuth2优先的注册登录体系，新用户只能通过OAuth2（Google/GitHub）进行注册，系统自动获取邮箱并创建账户，移除传统邮箱注册功能。

## 1. 核心设计原则

### 1.1 OAuth2优先策略
- **新用户注册**：仅通过OAuth2（Google/GitHub）进行
- **邮箱自动绑定**：OAuth2获取的邮箱直接作为用户邮箱
- **随机密码**：系统生成随机密码，用户无需设置
- **默认套餐**：自动分配套餐ID为1的基础套餐

### 1.2 向后兼容性
- **现有用户**：保持原有登录方式不变
- **数据完整性**：不破坏现有用户数据
- **API兼容**：保持现有API接口结构

## 3. OAuth2注册流程重构

### 3.1 新用户注册流程
```
用户点击OAuth2登录 → 跳转到OAuth2提供商 → 用户授权 → 获取用户信息
→ 检查邮箱是否存在 → [存在]绑定OAuth账号到现有用户 → 生成JWT令牌
                    → [不存在]创建新用户 → 生成随机密码 → 设置用户基本信息
                    → 创建OAuth绑定记录 → 初始化用户账户 → 分配默认套餐 → 生成JWT令牌
```

### 3.2 关键实现点
1. **邮箱唯一性检查**：确保一个邮箱只能对应一个用户
2. **随机密码生成**：使用UUID生成强随机密码
3. **默认套餐分配**：自动绑定packageId=1的基础套餐
4. **OAuth信息存储**：完整保存OAuth提供商信息

### 5.2 OAuth2Service简化 ✅
简化createUserFromOAuth方法，使用重构后的registerUser：

**简化后的实现**:
```java
private User createUserFromOAuth(OAuth2UserInfo userInfo) {
    // 生成唯一用户名和随机密码
    String username = generateUniqueUsername(userInfo.getName());
    String randomPassword = UUID.randomUUID().toString();

    log.debug("【OAuth2用户创建】用户名：{}，邮箱：{}，提供商：{}",
            username, userInfo.getEmail(), userInfo.getProvider());

    // 使用重构后的registerUser方法，包含完整的用户创建和套餐绑定逻辑
    return userService.registerUser(username, userInfo.getEmail(), randomPassword, userInfo.getAvatar());
}
```

**优化效果**:
- ✅ 代码行数减少约60%（从36行减少到9行）
- ✅ 移除重复的用户创建逻辑
- ✅ 统一的错误处理和日志记录
- ✅ 更好的代码可维护性
