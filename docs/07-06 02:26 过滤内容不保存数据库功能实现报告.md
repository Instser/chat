## 需求背景

### 用户反馈
用户要求过滤掉的内容不要保存到数据库，确保被过滤的AI响应内容不会存储在系统中。

### 问题分析
- 之前的逻辑是被过滤的内容仍然会累积到`aiResponseContent`中，然后保存到数据库
- 需要修改逻辑，确保被过滤的内容既不发送给前端，也不保存到数据库
- 同时要保持`isRealAiResponse`状态的正确性，区分"没有AI响应"和"AI响应被过滤"

## 解决方案

### 🔧 实现过滤内容不保存策略

#### 1. 修改主要内容处理逻辑
在`processCompleteJson`方法中，被过滤的内容返回`null`而不是原始内容：

```java
// 如果内容被过滤，不返回任何内容（既不发送给前端，也不累积到数据库）
if (cleanResult.wasFiltered()) {
    log.debug("AI响应内容被过滤，不发送给前端且不保存到数据库: [{}]",
        content.length() > 50 ? content.substring(0, 50) + "..." : content);
    return null; // 返回null，不累积到aiResponseContent
}
```

#### 2. 修改续写后续内容处理
在`processContinuationJson`方法中，被过滤的内容不累积到保存内容中：

    // 不累积到内容中，也不发送给前端
    return null; // 返回null，不累积任何内容

#### 3. 修改续写缓存处理
在`processContinuationJson`方法中，如果清理后内容为空（被过滤），跳过处理：

#### 4. 增强状态判断逻辑
新增`isRealAiResponseButFiltered`方法来区分"没有AI响应"和"AI响应被过滤"：

```java
/**
 * 检查JSON响应是否是被过滤的真实AI响应
 * 用于区分"没有AI响应"和"AI响应被过滤"
 */
private boolean isRealAiResponseButFiltered(String jsonData) {
    try {
        ObjectMapper mapper = new ObjectMapper();
        JsonNode jsonNode = mapper.readTree(jsonData);
        
        // 检查是否有choices数组且包含delta内容
        JsonNode choices = jsonNode.get("choices");
        if (choices != null && choices.isArray() && choices.size() > 0) {
            JsonNode firstChoice = choices.get(0);
            JsonNode delta = firstChoice.get("delta");
            if (delta != null && delta.has("content")) {
                String content = delta.get("content").asText();
                // 如果内容不为空且被过滤，则认为是被过滤的真实AI响应
                if (content != null && !content.trim().isEmpty()) {
                    return shouldFilterContent(content) || shouldRestartChat(content);
                }
            }
        }
    } catch (Exception e) {
        log.debug("解析JSON检查过滤状态时出错: {}", e.getMessage());
    }
    return false;
}
```

#### 5. 修改流式处理状态设置
在流式处理中正确设置`isRealAiResponse`状态：

```java
if (isValidJson(bufferedJson)) {
    String contentSent = processCompleteJson(bufferedJson, response);
    if (contentSent != null) {
        hasContentSent[0] = true;
        isRealAiResponse[0] = true;
        aiResponseContent.append(contentSent);
    } else {
        // 检查是否是被过滤的真实AI响应
        if (isRealAiResponseButFiltered(bufferedJson)) {
            isRealAiResponse[0] = true;
            // 不设置hasContentSent，因为内容被过滤了
            log.debug("检测到被过滤的真实AI响应，设置isRealAiResponse=true但不累积内容");
        }
    }
    jsonBuffer.setLength(0);
}
```

## 技术实现细节

### 1. 数据流控制
- **过滤检测**: 在内容处理的最早阶段进行过滤检测
- **返回值控制**: 被过滤的内容返回`null`，阻止后续累积
- **状态区分**: 通过`isRealAiResponseButFiltered`方法区分过滤状态

### 2. 保存逻辑保护
- **空内容检查**: `handleAiResponseResult`方法中的`contentToSave != null && !contentToSave.trim().isEmpty()`检查
- **累积阻止**: 被过滤的内容不会累积到`aiResponseContent`中
- **一致性保证**: 所有聊天分支都应用相同的过滤不保存策略

### 3. 状态管理策略
- **isRealAiResponse**: 正确区分真实AI响应和过滤响应
- **hasContentSent**: 只有实际发送给前端的内容才设置为true
- **业务逻辑**: 标题生成、Token计算等基于实际保存的内容

### 4. 过滤范围覆盖
- **普通聊天**: 通过`processCompleteJson`方法
- **续写缓存**: 通过`cleanAllTagsOnce`方法
- **续写开始**: 通过`cleanContinuationContent`方法
- **续写后续**: 通过`processContinuationJson`中的直接检测
- **重试/编辑重发**: 通过主流程自动覆盖
