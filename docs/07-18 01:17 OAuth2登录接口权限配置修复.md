# OAuth2登录接口权限配置修复

**时间**: 2025年07月18日 01:17  
**版本**: v1.0.1  
**问题**: 前端请求 `/api/oauth2/login/google` 时返回 401 未授权错误

## 问题分析

前端调用 OAuth2 登录接口时收到 401 错误：
```json
{
  "code": 401,
  "message": "请先登录",
  "data": null,
  "timestamp": 1752772456514
}
```

**根本原因**: Spring Security 配置中 OAuth2 登录路径配置错误，导致登录接口被拦截要求认证。

## 修复内容

### 1. SecurityConfig.java 路径配置修复

**修改前**:
```java
// OAuth2接口 - 登录和回调需要公开访问
.requestMatchers("/auth/oauth2/login/**", "/auth/oauth2/callback/**").permitAll()
```

**修改后**:
```java
// OAuth2接口 - 登录和回调需要公开访问
.requestMatchers("/oauth2/login/**", "/oauth2/bind/**", "/oauth2/providers").permitAll()
```

### 2. JwtAuthenticationFilter.java 过滤器配置修复

**修改前**:
```java
// 跳过不需要认证的路径
return path.startsWith("/auth/login") ||
       path.startsWith("/auth/register") ||
       path.startsWith("/druid/") ||
       // ... 其他路径
```

**修改后**:
```java
// 跳过不需要认证的路径
return path.startsWith("/auth/login") ||
       path.startsWith("/auth/register") ||
       path.startsWith("/oauth2/login") ||
       path.startsWith("/oauth2/providers") ||
       path.startsWith("/druid/") ||
       // ... 其他路径
```

## 修复说明

1. **路径匹配问题**: 原配置使用 `/auth/oauth2/login/**`，但实际控制器路径是 `/oauth2/login/{provider}`
2. **双重保护**: 在 SecurityConfig 和 JwtAuthenticationFilter 两处都添加了 OAuth2 路径的排除配置
3. **完整覆盖**: 添加了所有 OAuth2 相关的公开接口路径

## 影响的接口

现在以下接口可以无需认证访问：
- `POST /api/oauth2/login/{provider}` - OAuth2 登录
- `GET /api/oauth2/providers` - 获取支持的 OAuth2 提供商
- `POST /api/oauth2/bind/{provider}` - 绑定 OAuth2 账号（仍需要用户登录）

## 测试验证

修复后，前端可以正常调用：
```javascript
POST /api/oauth2/login/google
Content-Type: application/json

{
  "code": "4/0AVMBsJgeEmCBwz5qUl5GhVymh8txOHvbTvPBHnaHkvjWICj-nb6dT3_raEDMNaMpcjvM3w"
}
```

## 注意事项

- OAuth2 登录接口现在可以匿名访问，这是正确的行为
- 绑定和解绑接口仍然需要用户认证
- 修改不影响其他接口的安全性
