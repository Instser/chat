## 问题描述

应用启动时出现Redis连接失败错误：

```
org.springframework.beans.factory.UnsatisfiedDependencyException: Error creating bean with name 'paymentController' defined in file [...]: Unsatisfied dependency expressed through constructor parameter 0: Error creating bean with name 'paymentServiceImpl' [...]: Error creating bean with name 'redisDistributedLockService': Unsatisfied dependency expressed through field 'redissonClient': Error creating bean with name 'redisson' defined in class path resource [org/redisson/spring/starter/RedissonAutoConfigurationV2.class]: Failed to instantiate [org.redisson.api.RedissonClient]: Factory method 'redisson' threw exception with message: Unable to connect to Redis server: localhost/127.0.0.1:6379
```

**核心问题**:
1. Redisson尝试连接到`localhost:6379`而不是配置的远程Redis服务器
2. Redisson Spring Boot Starter没有正确读取Spring Boot的Redis配置

### 2. 根本原因

**Redisson Spring Boot Starter配置问题**:
- Redisson有自己的自动配置机制
- 在某些情况下，Redisson的自动配置不能正确读取Spring Boot的Redis配置
- 特别是当Redis配置包含用户名认证时，可能出现配置读取问题

## 修复方案

### 1. 创建专用的Redisson配置类

**文件**: `src/main/java/com/instser/chat/config/RedissonConfig.java`  
**新增文件**

```java
@Slf4j
@Configuration
public class RedissonConfig {

    @Value("${spring.redis.host:your-db-host.example.com}")
    private String redisHost;

    @Value("${spring.redis.port:31122}")
    private int redisPort;

    @Value("${spring.redis.username:default}")
    private String redisUsername;

    @Value("${spring.redis.password:pt7tv2k4}")
    private String redisPassword;

    @Value("${spring.redis.database:0}")
    private int redisDatabase;

    @Value("${spring.redis.timeout:3000ms}")
    private String redisTimeoutStr;

    /**
     * 解析timeout字符串为毫秒数
     * 支持格式：3000ms, 3000, 3s等
     */
    private int parseTimeout(String timeoutStr) {
        if (timeoutStr == null || timeoutStr.trim().isEmpty()) {
            return 3000; // 默认3秒
        }
        
        String timeout = timeoutStr.trim().toLowerCase();
        
        if (timeout.endsWith("ms")) {
            return Integer.parseInt(timeout.substring(0, timeout.length() - 2));
        } else if (timeout.endsWith("s")) {
            return Integer.parseInt(timeout.substring(0, timeout.length() - 1)) * 1000;
        } else {
            // 假设是毫秒数
            return Integer.parseInt(timeout);
        }
    }

    /**
     * 配置Redisson客户端
     * 使用单节点模式连接Redis
     */
    @Bean
    public RedissonClient redissonClient() {
        Config config = new Config();
        
        // 解析timeout值
        int timeoutMs = parseTimeout(redisTimeoutStr);
        
        // 构建Redis连接地址
        String redisAddress = String.format("redis://%s:%d", redisHost, redisPort);
        log.info("配置Redisson连接地址: {}, 超时时间: {}ms", redisAddress, timeoutMs);
        
        // 配置单节点模式
        config.useSingleServer()
                .setAddress(redisAddress)
                .setUsername(redisUsername)
                .setPassword(redisPassword)
                .setDatabase(redisDatabase)
                .setConnectTimeout(timeoutMs)
                .setTimeout(timeoutMs)
                .setRetryAttempts(3)
                .setRetryInterval(1500)
                .setConnectionMinimumIdleSize(5)
                .setConnectionPoolSize(20)
                .setIdleConnectionTimeout(10000)
                .setPingConnectionInterval(30000)
                .setKeepAlive(true);

        try {
            RedissonClient redissonClient = Redisson.create(config);
            log.info("Redisson客户端创建成功，连接到: {}:{}", redisHost, redisPort);
            return redissonClient;
        } catch (Exception e) {
            log.error("创建Redisson客户端失败: {}", e.getMessage(), e);
            throw new RuntimeException("无法连接到Redis服务器: " + redisHost + ":" + redisPort, e);
        }
    }
}
```

### 2. 配置特点

#### 2.1 显式配置
- 直接从Spring Boot配置中读取Redis连接参数
- 不依赖Redisson的自动配置机制
- 确保配置的准确性和可控性

#### 2.2 超时处理
- 支持多种timeout格式：`3000ms`, `3000`, `3s`
- 自动解析并转换为毫秒数
- 提供默认值保证系统稳定性

#### 2.3 连接池优化
- 最小空闲连接数：5
- 最大连接池大小：20
- 连接超时：3000ms
- 重试机制：3次重试，间隔1500ms
- 心跳检测：30秒间隔

#### 2.4 错误处理
- 详细的日志记录
- 异常时抛出明确的错误信息
- 便于问题排查和监控
