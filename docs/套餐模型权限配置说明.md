## 📋 配置概述

`t_package` 表中的 `model_permissions` 字段需要填写JSON格式的模型权限配置，用于控制不同套餐对不同AI模型的使用限制。

## 🎯 JSON配置格式

### 标准格式
```json
{
  "STANDARD": {
    "daily_limit": 300,
    "description": "标准模型每日300次"
  },
  "PERFORMANCE": {
    "daily_limit": 20,
    "description": "性能模型每日20次"
  },
  "BETA_MODEL": {
    "daily_limit": 5,
    "description": "测试模型每日5次"
  }
}
```

### 字段说明
- **模型名称**：`STANDARD`、`PERFORMANCE`、`BETA_MODEL`
- **daily_limit**：每日使用限制次数（-1表示无限制，0表示不可用）
- **description**：描述信息（可选，用于管理界面显示）

## ✅ 配置验证

### 1. 检查JSON格式
```sql
SELECT 
    id,
    package_name,
    package_type,
    CASE 
        WHEN JSON_VALID(model_permissions) = 1 THEN 'Valid JSON'
        ELSE 'Invalid JSON'
    END as json_status
FROM t_package 
WHERE model_permissions IS NOT NULL;
```

### 2. 查看格式化配置
```sql
SELECT 
    id,
    package_name,
    package_type,
    JSON_PRETTY(model_permissions) as formatted_permissions
FROM t_package 
WHERE model_permissions IS NOT NULL;
```

### 3. 测试特定模型限制
```sql
SELECT 
    id,
    package_name,
    package_type,
    JSON_EXTRACT(model_permissions, '$.STANDARD.daily_limit') as standard_limit,
    JSON_EXTRACT(model_permissions, '$.PERFORMANCE.daily_limit') as performance_limit,
    JSON_EXTRACT(model_permissions, '$.BETA_MODEL.daily_limit') as beta_limit
FROM t_package 
WHERE model_permissions IS NOT NULL;
```

## 🎯 特殊值说明

### daily_limit 值含义
- **正整数**：每日可使用的具体次数（如：300、500、1000）
- **-1**：无限制使用
- **0**：不可使用该模型

### 示例场景
```json
{
  "STANDARD": {
    "daily_limit": 100,     // 每日100次
```

## 📊 配置建议

### 1. 套餐层级设计
```
免费套餐 < 基础套餐 < 中级套餐 < 高级套餐 < 企业套餐
```

### 2. 模型使用策略
- **STANDARD**：基础模型，所有套餐都应该有一定额度
- **PERFORMANCE**：高性能模型，付费套餐专享
- **BETA_MODEL**：测试模型，高级套餐或特定用户群体

### 3. 限制数量建议
- **免费用户**：10-50次/天
- **基础付费**：100-500次/天
- **中级付费**：500-1000次/天
- **高级付费**：无限制或很高的限制

## ⚠️ 注意事项

### 1. JSON格式要求
- 必须是有效的JSON格式
- 字段名使用双引号
- 数值类型不要加引号

### 2. 模型名称一致性
- 模型名称必须与系统中定义的一致
- 区分大小写：`STANDARD`、`PERFORMANCE`、`BETA_MODEL`

### 3. 向后兼容
- 如果配置为空或解析失败，系统会使用默认配置
- 新增模型时，旧配置仍然有效

### 4. 性能考虑
- JSON解析有一定性能开销，建议启用缓存
- 避免过于复杂的JSON结构
