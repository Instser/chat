## 总览

### 实施原则

1. **不破坏现有业务** — 所有改动为增量式，不改业务逻辑
2. **SSE 流式接口特殊处理** — 不强制套用 `Result<T>` 包装
3. **Webhook 回调保留现有格式** — 第三方协议不修改
4. **敏感信息脱敏** — 密码、API Key 仅通过环境变量注入
5. **高危操作仅记录不执行** — 运维审计记录操作，不自动重启/删除/回滚

## 第一阶段：可观测性基础（P0）

> 目标：让每一次请求都能通过 traceId 串联接口响应、日志、异常。

### 1.1 新增 TraceIdFilter

**改什么**：新增 `filter/TraceIdFilter.java`

**为什么改**：当前日志无 traceId，故障时无法从几百 MB 日志中串联单个请求的完整调用链。TraceId 是所有可观测性改造的基础。

**怎么改**：

```java
// src/main/java/com/instser/chat/filter/TraceIdFilter.java
package com.instser.chat.filter;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.slf4j.MDC;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.UUID;

@Component
@Order(Ordered.HIGHEST_PRECEDENCE)  // 最优先执行，确保后续所有日志都带 traceId
public class TraceIdFilter extends OncePerRequestFilter {

    private static final String TRACE_ID_HEADER = "X-Trace-Id";
    private static final String TRACE_ID_KEY = "traceId";

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {

        // 1. 优先从请求头获取 traceId（支持全链路传递）
        String traceId = request.getHeader(TRACE_ID_HEADER);
        if (traceId == null || traceId.isBlank()) {
            traceId = UUID.randomUUID().toString().replace("-", "");
        }

        // 2. 写入 MDC，此后所有日志自动带 traceId
        MDC.put(TRACE_ID_KEY, traceId);

        // 3. 响应头返回 traceId，前端可将 traceId 提交给后端排查
        response.setHeader(TRACE_ID_KEY, traceId);

        try {
            filterChain.doFilter(request, response);
        } finally {
            // 4. 清理 MDC，防止线程池复用时的内存泄漏
            MDC.remove(TRACE_ID_KEY);
        }
    }
}
```

**影响范围**：
- 所有 HTTP 请求的日志自动带 `[traceId=xxx]`
- 响应头新增 `X-Trace-Id`
- 前端可将此值随报障提交

### 1.2 修改 Logback Pattern 加入 traceId

**改什么**：修改 `logback-spring.xml` 中 4 处 pattern

**为什么改**：当前 pattern 不含 `%X{traceId}`，即使 MDC 写入了也无法输出。

**怎么改**：

```xml
<!-- 控制台 -->
<pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] [%X{traceId}] %-5level %logger{36} - %msg%n</pattern>

<!-- 普通日志文件 -->
<pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] [%X{traceId}] %-5level %logger{50} - %msg%n</pattern>

<!-- 错误日志文件 -->
<pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] [%X{traceId}] %-5level %logger{50} - %msg%n%ex</pattern>

<!-- 监控日志文件 -->
<pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] [%X{traceId}] %-5level %logger{50} - %msg%n</pattern>
```

在 `[%thread]` 后追加 `[%X{traceId}]`。

### 1.4 全局异常处理优化

**改什么**：修改 `GlobalExceptionHandler.java`

**为什么改**：
1. catch-all handler 当前用 `currentTimeMillis-threadId` 拼装异常 ID，改用 traceId
2. 异常响应中统一显示可追溯的异常追踪标识

**怎么改**：

```java
// GlobalExceptionHandler.java — handleException 方法修改
@ExceptionHandler(value = Exception.class)
public Result<String> handleException(Exception e, HttpServletRequest request) {
    String requestUrl = request.getRequestURL().toString();
    String method = request.getMethod();
    String traceId = MDC.get("traceId");  // 从 MDC 获取，而非拼装
    String message = "系统异常，请联系管理员";

    log.error("未知异常 [{}] {} (traceId: {}): {}",
            method, requestUrl, traceId, e.getMessage(), e);

    Result<String> result = new Result<>(ResultCode.FAILED.getCode(),
            message + " (traceId: " + traceId + ")", null);
    return result;
}
```

### 2.1 慢接口拦截器

**改什么**：新增 `interceptor/SlowRequestInterceptor.java`

**为什么改**：当前无法感知接口性能劣化。Druid slow SQL 监控仅覆盖数据库层面，API 整体耗时盲区。

**怎么改**：

```java
// src/main/java/com/instser/chat/interceptor/SlowRequestInterceptor.java
package com.instser.chat.interceptor;

import io.micrometer.core.instrument.MeterRegistry;
import io.micrometer.core.instrument.Counter;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.extern.slf4j.Slf4j;
import org.slf4j.MDC;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

@Slf4j
@Component
public class SlowRequestInterceptor implements HandlerInterceptor {

    private static final String START_TIME_KEY = "req.startTime";
    private static final long WARN_THRESHOLD_MS = 1000;   // 1秒 WARN
    private static final long ERROR_THRESHOLD_MS = 3000;  // 3秒 ERROR

    private final Counter slowWarnCounter;
    private final Counter slowErrorCounter;

    public SlowRequestInterceptor(MeterRegistry meterRegistry) {
        this.slowWarnCounter = Counter.builder("slow_requests_total")
                .description("慢请求计数")
                .tag("threshold", "warn")
                .register(meterRegistry);
        this.slowErrorCounter = Counter.builder("slow_requests_total")
                .description("慢请求计数")
                .tag("threshold", "error")
                .register(meterRegistry);
    }

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response,
                             Object handler) {
        request.setAttribute(START_TIME_KEY, System.currentTimeMillis());
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response,
                                Object handler, Exception ex) {
        Long startTime = (Long) request.getAttribute(START_TIME_KEY);
        if (startTime == null) return;

        long costMs = System.currentTimeMillis() - startTime;
        String method = request.getMethod();
        String path = request.getRequestURI();
        String traceId = MDC.get("traceId");

        if (costMs > ERROR_THRESHOLD_MS) {
            slowErrorCounter.increment();
            log.error("SLOW_REQUEST_ERROR method={} path={} costMs={} traceId={}",
                    method, path, costMs, traceId);
        } else if (costMs > WARN_THRESHOLD_MS) {
            slowWarnCounter.increment();
            log.warn("SLOW_REQUEST_WARN method={} path={} costMs={} traceId={}",
                    method, path, costMs, traceId);
        }
    }
}
```

**注册到 WebConfig**：

```java

@Override

}
```

### 2.2 全局 API 指标（ApiMetrics）

**改什么**：新增 `metrics/ApiMetrics.java`

**为什么改**：现有 `WebSearchMetrics` 只覆盖 WebSearch 场景，没有全局 API 调用量、异常量的统一指标。

**怎么改**：

```java
// src/main/java/com/instser/chat/metrics/ApiMetrics.java
package com.instser.chat.metrics;

import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.MeterRegistry;
import io.micrometer.core.instrument.Timer;
import org.springframework.stereotype.Component;

import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;

@Component
public class ApiMetrics {

    private final MeterRegistry registry;
    private final ConcurrentMap<String, Counter> requestCounters = new ConcurrentHashMap<>();
    private final ConcurrentMap<String, Counter> exceptionCounters = new ConcurrentHashMap<>();

    public ApiMetrics(MeterRegistry registry) {
        this.registry = registry;
    }

    /** 记录一次 API 请求 */
    public void recordRequest(String method, String path, int statusCode) {
        String key = method + ":" + path;
        requestCounters.computeIfAbsent(key, k ->
                Counter.builder("api_requests_total")
                        .description("API 请求总数")
                        .tag("method", method)
                        .tag("path", path)
                        .tag("status", String.valueOf(statusCode))
                        .register(registry)
        ).increment();
    }

    /** 记录一次异常 */
    public void recordException(String method, String path, String exceptionType) {
        String key = method + ":" + path + ":" + exceptionType;
        exceptionCounters.computeIfAbsent(key, k ->
                Counter.builder("api_exceptions_total")
                        .description("API 异常总数")
                        .tag("method", method)
                        .tag("path", path)
                        .tag("exception_type", exceptionType)
                        .register(registry)
        ).increment();
    }
}
```

**集成到 `SlowRequestInterceptor.afterCompletion`**：

```java

if (ex != null) {
    apiMetrics.recordException(method, path, ex.getClass().getSimpleName());
}
```

### 2.3 AI 调用监控封装（AiCallMetrics + AiCallMonitor）

**改什么**：
- 新增 `metrics/AiCallMetrics.java` — Prometheus 指标
- 新增 `monitor/AiCallMonitor.java` — AI 调用监控封装类
- 修改 `ChatServiceImpl.java` — 接入监控

**为什么改**：AI 调用是核心业务，当前无首 Token 延迟、Token 消耗、失败原因分类等可观测性。出问题时无法判断是模型慢还是网络慢。

**怎么改**：

```java
// AiCallMetrics.java — Prometheus 指标
package com.instser.chat.metrics;

import io.micrometer.core.instrument.*;
import org.springframework.stereotype.Component;

import java.util.concurrent.atomic.AtomicLong;

@Component
public class AiCallMetrics {

    private final MeterRegistry registry;

    // 调用次数
    private final Counter totalCalls;
    private final Counter successCalls;
    private final Counter failedCalls;

    // Token 消耗
    private final Counter promptTokens;
    private final Counter completionTokens;

    // 当前活跃调用数
    private final AtomicLong activeCalls = new AtomicLong(0);

    public AiCallMetrics(MeterRegistry registry) {
        this.registry = registry;

        this.totalCalls = Counter.builder("ai_calls_total")
                .description("AI 调用总数").register(registry);
        this.successCalls = Counter.builder("ai_calls_total")
                .description("AI 调用总数").tag("status", "success").register(registry);
        this.failedCalls = Counter.builder("ai_calls_total")
                .description("AI 调用总数").tag("status", "failed").register(registry);
        this.promptTokens = Counter.builder("ai_token_consumption_total")
                .description("Token 消耗量").tag("type", "prompt").register(registry);
        this.completionTokens = Counter.builder("ai_token_consumption_total")
                .description("Token 消耗量").tag("type", "completion").register(registry);

        Gauge.builder("ai_calls_active", activeCalls, AtomicLong::get)
                .description("当前活跃 AI 调用数").register(registry);
    }

    public Timer.Sample startCall() {
        activeCalls.incrementAndGet();
        totalCalls.increment();
        return Timer.start(registry);
    }

    public void recordSuccess(Timer.Sample sample, String model,
                               long ttftMs, long totalMs, long promptTok, long completionTok) {
        sample.stop(Timer.builder("ai_call_duration_seconds")
                .tag("model", model).tag("status", "success")
                .register(registry));
        recordLatency(registry, "ai_ttft_seconds", model, ttftMs);
        successCalls.increment();
        promptTokens.increment(promptTok);
        completionTokens.increment(completionTok);
        activeCalls.decrementAndGet();
    }

    public void recordFailure(Timer.Sample sample, String model,
                               String errorType, String errorMessage) {
        sample.stop(Timer.builder("ai_call_duration_seconds")
                .tag("model", model).tag("status", "failed")
                .register(registry));
        Counter.builder("ai_calls_failed_total")
                .tag("model", model).tag("error_type", errorType)
                .register(registry).increment();
        failedCalls.increment();
        activeCalls.decrementAndGet();
    }

    private void recordLatency(MeterRegistry r, String name, String model, long ms) {
        Timer.builder(name).tag("model", model)
                .register(r).record(ms, java.util.concurrent.TimeUnit.MILLISECONDS);
    }
}
```

```java
// AiCallMonitor.java — AI 调用监控封装（供 ChatService 使用）
package com.instser.chat.monitor;

import com.instser.chat.metrics.AiCallMetrics;
import io.micrometer.core.instrument.Timer;
import lombok.extern.slf4j.Slf4j;
import org.slf4j.MDC;
import org.springframework.stereotype.Component;

import java.time.Instant;

@Slf4j
@Component
public class AiCallMonitor {

    private final AiCallMetrics metrics;

    public AiCallMonitor(AiCallMetrics metrics) {
        this.metrics = metrics;
    }

    /**
     * AI 调用上下文 — 贯穿一次完整 AI 调用
     */
    public static class CallContext {
        private final String model;
        private final Timer.Sample sample;
        private final Instant startTime;
        private Instant firstTokenTime;
        private long promptTokens;
        private long completionTokens;

        public CallContext(String model, Timer.Sample sample) {
            this.model = model;
            this.sample = sample;
            this.startTime = Instant.now();
        }

        public void markFirstToken() {
            this.firstTokenTime = Instant.now();
        }

        public void addTokens(long prompt, long completion) {
            this.promptTokens += prompt;
            this.completionTokens += completion;
        }
    }

    /** 开始一次 AI 调用监控 */
    public CallContext beginCall(String model) {
        Timer.Sample sample = metrics.startCall();
        log.info("AI_CALL_START model={} traceId={}", model, MDC.get("traceId"));
        return new CallContext(model, sample);
    }

    /** 标记收到首 Token */
    public void markFirstToken(CallContext ctx) {
        ctx.markFirstToken();
        long ttftMs = java.time.Duration.between(ctx.startTime, ctx.firstTokenTime).toMillis();
        log.info("AI_FIRST_TOKEN model={} ttftMs={} traceId={}",
                ctx.model, ttftMs, MDC.get("traceId"));
    }

    /** 记录成功 */
    public void recordSuccess(CallContext ctx) {
        long totalMs = java.time.Duration.between(ctx.startTime, Instant.now()).toMillis();
        long ttftMs = ctx.firstTokenTime != null
                ? java.time.Duration.between(ctx.startTime, ctx.firstTokenTime).toMillis() : totalMs;

        metrics.recordSuccess(ctx.sample, ctx.model, ttftMs, totalMs,
                ctx.promptTokens, ctx.completionTokens);
        log.info("AI_CALL_SUCCESS model={} totalMs={} ttftMs={} promptTokens={} completionTokens={} traceId={}",
                ctx.model, totalMs, ttftMs, ctx.promptTokens, ctx.completionTokens, MDC.get("traceId"));
    }

    /** 记录失败 */
    public void recordFailure(CallContext ctx, String errorType, String errorMessage) {
        long totalMs = java.time.Duration.between(ctx.startTime, Instant.now()).toMillis();
        metrics.recordFailure(ctx.sample, ctx.model, errorType, errorMessage);
        log.error("AI_CALL_FAILED model={} errorType={} errorMessage={} totalMs={} traceId={}",
                ctx.model, errorType, errorMessage, totalMs, MDC.get("traceId"));
    }
}
```

**ChatServiceImpl 接入示例**（在 `processStreamChat` 关键位置埋点）：

```java
@RestController
@RequestMapping("/ops")
@RequiredArgsConstructor
public class OpsController {

    private final BuildProperties buildProperties;  // Spring Boot 自动注入
    private final ApplicationContext ctx;

    @GetMapping("/version")
    public Result<Map<String, Object>> version() {
        Map<String, Object> info = new LinkedHashMap<>();
        info.put("application", "jinyu-chat");
        info.put("version", buildProperties.getVersion());
        info.put("groupId", buildProperties.getGroup());
        info.put("artifactId", buildProperties.getArtifact());
        info.put("buildTime", buildProperties.getTime().toString());

        // git.properties
        try {
            Properties gitProps = new Properties();
            gitProps.load(getClass().getClassLoader()
                    .getResourceAsStream("git.properties"));
            info.put("gitCommit", gitProps.getProperty("git.commit.id.abbrev", "unknown"));
            info.put("gitBranch", gitProps.getProperty("git.branch", "unknown"));
            info.put("gitCommitTime", gitProps.getProperty("git.commit.time", "unknown"));
        } catch (Exception e) {
            info.put("gitCommit", "unavailable");
        }

        info.put("javaVersion", System.getProperty("java.version"));
        info.put("javaVendor", System.getProperty("java.vendor"));
        info.put("osName", System.getProperty("os.name"));
        info.put("osArch", System.getProperty("os.arch"));

        // 启动时间
        if (ctx instanceof WebApplicationContext webCtx) {
            long uptime = ManagementFactory.getRuntimeMXBean().getUptime();
            info.put("uptimeSeconds", uptime / 1000);
            info.put("startupTime", new Date(
                    System.currentTimeMillis() - uptime).toString());
        }

        info.put("springBootVersion", SpringBootVersion.getVersion());
        info.put("activeProfiles",
                String.join(",", ctx.getEnvironment().getActiveProfiles()));

        return Result.success(info);
    }
}
```

### 3.2 `/ops/health/full` 接口

**改什么**：在 `OpsController` 中新增 `/ops/health/full`

**为什么改**：Actuator `/actuator/health` 不检查 AI API 可用性。运维需要一键看清所有依赖状态。

**怎么改**：

```java
@GetMapping("/health/full")
public Result<Map<String, Object>> fullHealth() {
    Map<String, Object> health = new LinkedHashMap<>();
    Map<String, Object> components = new LinkedHashMap<>();

    // 1. 应用自身
    components.put("application", Map.of("status", "UP", "uptime",
            ManagementFactory.getRuntimeMXBean().getUptime() / 1000 + "s"));

    // 2. MySQL
    components.put("database", checkDatabase());

    // 3. Redis
    components.put("redis", checkRedis());

    // 4. AI API (Gemini)
    components.put("aiApi", checkAiApi());

    // 5. 可选：支付网关连通性（仅检查，不发送真实交易）
    // components.put("paymentGateway", checkPaymentGateway());

    boolean allUp = components.values().stream()
            .allMatch(c -> "UP".equals(((Map<String, Object>) c).get("status")));
    health.put("overall", allUp ? "UP" : "DEGRADED");
    health.put("components", components);
    health.put("checkedAt", Instant.now().toString());

    return Result.success(health);
}

private Map<String, Object> checkDatabase() {
    try {
        // 通过 Druid 连接池获取当前状态
```

### 4.1 统一外部 HTTP 调用封装

**改什么**：
- 新增 `util/ExternalApiClient.java` — 统一封装
- 修改 `OAuth2ServiceImpl.java` 等使用方

**为什么改**：当前 RestTemplate 直接散布在 Service 中调用，无统一超时、重试、日志、异常分类。

**怎么改**：

```java
// ExternalApiClient.java
package com.instser.chat.util;

import lombok.extern.slf4j.Slf4j;
import org.slf4j.MDC;
import org.springframework.http.*;
import org.springframework.web.client.RestClientException;
import org.springframework.web.client.RestTemplate;

import java.time.Duration;
import java.time.Instant;
import java.util.function.Supplier;

@Slf4j
public class ExternalApiClient {

    private final RestTemplate restTemplate;
    private final String serviceName;
    private final int maxRetries;
    private final Duration retryDelay;

    public ExternalApiClient(RestTemplate restTemplate, String serviceName,
                              int maxRetries, Duration retryDelay) {
        this.restTemplate = restTemplate;
        this.serviceName = serviceName;
        this.maxRetries = maxRetries;
        this.retryDelay = retryDelay;
    }

    public <T> ApiCallResult<T> call(String url, HttpMethod method,
                                      Object requestBody, Class<T> responseType) {
        return callWithRetry(url, method, requestBody, responseType, HttpHeaders.EMPTY);
    }

    private <T> ApiCallResult<T> callWithRetry(String url, HttpMethod method,
            Object body, Class<T> responseType, HttpHeaders headers) {

        String traceId = MDC.get("traceId");
        Instant start = Instant.now();
        Exception lastException = null;
        int statusCode = 0;

        for (int attempt = 1; attempt <= maxRetries; attempt++) {
            try {
                HttpEntity<Object> entity = new HttpEntity<>(body, headers);
                ResponseEntity<T> response = restTemplate.exchange(url, method, entity, responseType);
                statusCode = response.getStatusCode().value();
                long costMs = Duration.between(start, Instant.now()).toMillis();

                if (response.getStatusCode().is2xxSuccessful()) {
                    log.info("EXT_API_SUCCESS service={} url={} method={} status={} costMs={} attempt={} traceId={}",
                            serviceName, url, method, statusCode, costMs, attempt, traceId);
                    return ApiCallResult.success(response.getBody(), statusCode, costMs);
                }

                // 4xx 不重试
                if (response.getStatusCode().is4xxClientError()) {
                    log.warn("EXT_API_CLIENT_ERROR service={} url={} status={} costMs={} traceId={}",
                            serviceName, url, statusCode, costMs, traceId);
                    return ApiCallResult.clientError(statusCode, response.getBody(), costMs);
                }

                // 5xx 可重试
                log.warn("EXT_API_SERVER_ERROR service={} url={} status={} attempt={}/{} traceId={}",
                        serviceName, url, statusCode, attempt, maxRetries, traceId);

            } catch (RestClientException e) {
                lastException = e;
                String errorType = classifyError(e);
                log.warn("EXT_API_NETWORK_ERROR service={} url={} errorType={} attempt={}/{} traceId={}",
                        serviceName, url, errorType, attempt, maxRetries, traceId);
            }

            // 重试等待
            if (attempt < maxRetries) {
                try { Thread.sleep(retryDelay.toMillis()); } catch (InterruptedException ignored) {}
            }
        }

        long costMs = Duration.between(start, Instant.now()).toMillis();
        log.error("EXT_API_ALL_RETRIES_FAILED service={} url={} attempts={} costMs={} traceId={}",
                serviceName, url, maxRetries, costMs, traceId);
        return ApiCallResult.networkError(classifyError(lastException), lastException.getMessage(), costMs);
    }

    private String classifyError(Exception e) {
        return switch (e) {
            case java.net.SocketTimeoutException t -> "timeout";
            case java.net.ConnectException c -> "connection_refused";
            case java.net.UnknownHostException u -> "dns_resolve_failed";
            case javax.net.ssl.SSLException s -> "ssl_error";
            default -> "network_error";
        };
    }
}
```

**使用示例**（OAuth2ServiceImpl 改造）：

```java

// 改造后

        restTemplate, "GoogleOAuth", 3, Duration.ofSeconds(2));

        googleTokenUri, HttpMethod.POST, request, String.class);

    // 处理 result.getData()

}
```

### 4.3 Redis Key 命名规范化

**改什么**：新增 `constants/CacheConstants.java`，收敛所有 Redis Key 定义

**为什么改**：当前 key 命名混乱（冒号/下划线混用，无统一前缀），排查时不易定位。

**怎么改**：

```java
// CacheConstants.java
package com.instser.chat.constants;

/**
 * Redis Key 命名规范常量
 * 格式：{项目}:{模块}:{类型}:{标识}
 * 示例：chat:user:account:12345
 */
public final class CacheConstants {

    public static final String PROJECT = "chat";

    // ===== 用户相关 =====
    public static final String USER_ACCOUNT = PROJECT + ":user:account:";
    public static final String USER_PACKAGE = PROJECT + ":user:package:";
    public static final String USER_DAILY_USAGE = PROJECT + ":user:daily_usage:";

    // ===== 会话相关 =====
    public static final String SESSION_MESSAGES = PROJECT + ":session:messages:";

    // ===== 分布式锁 =====
    public static final String LOCK_ORDER = PROJECT + ":lock:order:";
    public static final String LOCK_USER_PAYMENT = PROJECT + ":lock:user_payment:";

    // ===== AI 模型相关 =====
    public static final String MODEL_PERMISSION = PROJECT + ":model:permission:";

    // ===== 缓存标记 =====
    public static final String CACHE_PREFIX = PROJECT + ":cache:";

    // ===== 熔断器状态 =====
    public static final String CIRCUIT_BREAKER = PROJECT + ":circuit:";

    private CacheConstants() {}

    // 构造 key 的工厂方法
    public static String userAccount(Long userId) {
        return USER_ACCOUNT + userId;
    }

    public static String orderLock(String orderNo) {
        return LOCK_ORDER + orderNo;
    }
}
```

**迁移策略**：使用 `@Deprecated` 标记旧常量，逐步替换，避免一次性大面积改动。
