## 📋 需求概述

根据用户需求，对订单发起逻辑进行以下优化：

1. **优惠价格选择逻辑**：当用户满足 `/user/status/new` 接口结果为 `true` 且套餐有优惠价格时，发起优惠价格的订单
2. **易支付汇率转换**：数据库中的价格默认为USD，易支付订单需要通过汇率转换为CNY，海外支付宝保持USD支付

#### 1.3 价格选择逻辑
```java
private BigDecimal selectPrice(Long userId, Package packageInfo) {
    // 检查用户是否从未付费
    boolean isNewUser = userPaymentStatusService.hasNeverPaid(userId);
    
    // 检查套餐是否有优惠价格
    BigDecimal discountPrice = packageInfo.getDiscountPrice();
    boolean hasDiscountPrice = discountPrice != null && discountPrice.compareTo(BigDecimal.ZERO) > 0;
    
    if (isNewUser && hasDiscountPrice) {
        return discountPrice; // 使用优惠价格
    } else {
        return packageInfo.getPrice(); // 使用原价
    }
}
```

#### 1.4 汇率转换逻辑
```java
private BigDecimal convertPriceWithExchangeRate(BigDecimal amount, String fromCurrency, String toCurrency, String paymentMethod) {
    try {
        BigDecimal convertedAmount = exchangeRateService.convertPrice(amount, fromCurrency, toCurrency);
        log.info("支付方式{}汇率转换: {} {} -> {} {}", paymentMethod, amount, fromCurrency, convertedAmount, toCurrency);
        return convertedAmount;
    } catch (Exception e) {
        log.error("汇率转换失败，使用原始金额", e);
        return amount;
    }
}
```

## 📊 功能特性

### 1. 优惠价格选择
- **触发条件**：用户从未付费 AND 套餐有优惠价格
- **价格来源**：Package.discountPrice 字段
- **异常处理**：服务异常时使用原价，确保订单创建不受影响
- **日志记录**：详细记录价格选择过程和原因

### 2. 易支付汇率转换
- **转换范围**：仅易支付订单（alipay、wechatpay）
- **转换方向**：USD → CNY
- **汇率来源**：ExchangeRateService（支持实时汇率和默认汇率）
- **异常处理**：汇率服务异常时使用原始金额
- **日志记录**：记录转换前后金额和汇率

### 3. 海外支付宝保持USD
- **支付方式**：overseas_alipay（目前被禁用）
- **货币类型**：保持USD，不进行汇率转换
- **参数设置**：支持USD支付参数

## 🔄 业务流程

### 1. 订单创建流程
```
1. 获取套餐信息
2. 验证套餐状态
3. 选择价格（优惠价格 vs 原价）
4. 汇率转换（如果是易支付且目标货币为CNY）
5. 格式化金额精度
6. 创建订单记录
7. 返回订单信息
```

### 2. 价格选择决策树
```
用户从未付费？
├─ 是 → 套餐有优惠价格？
│   ├─ 是 → 使用优惠价格
│   └─ 否 → 使用原价
└─ 否 → 使用原价
```

### 3. 汇率转换决策树
```
易支付方式？
├─ 是 → 目标货币为CNY？
│   ├─ 是 → 执行USD→CNY转换
│   └─ 否 → 不转换
└─ 否 → 不转换
```
