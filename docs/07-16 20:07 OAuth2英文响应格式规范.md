# OAuth2 API响应消息英文化规范

**文档创建时间**: 2025年07月16日 20:07
**版本**: v1.0
**适用范围**: OAuth2登录功能所有API响应消息
**说明**: 仅API响应消息使用英文，代码注释和文档保持中文

## 📋 响应格式标准

### 成功响应格式
```json
{
  "success": true,
  "code": 200,
  "message": "Operation completed successfully",
  "data": {
    // 具体数据内容
  },
  "timestamp": "2025-07-16T20:07:00"
}
```

### 错误响应格式
```json
{
  "success": false,
  "code": 4001,
  "message": "Authentication failed. Please try again.",
  "data": null,
  "timestamp": "2025-07-16T20:07:00",
  "provider": "google"
}
```

## ❌ 错误响应详细规范

### 1. 用户取消授权
```json
{
  "success": false,
  "code": 4001,
  "message": "Authorization was cancelled. Please try again if you want to login with Google",
  "data": null,
  "provider": "google",
  "errorType": "access_denied"
}
```

### 2. 无效请求
```json
{
  "success": false,
  "code": 4002,
  "message": "Invalid login request. Please refresh the page and try again",
  "data": null,
  "provider": "github",
  "errorType": "invalid_request"
}
```

### 3. 服务器错误
```json
{
  "success": false,
  "code": 5001,
  "message": "Google service is temporarily unavailable. Please try again later or use email login",
  "data": null,
  "provider": "google",
  "errorType": "server_error"
}
```

### 4. 网络错误
```json
{
  "success": false,
  "code": 5002,
  "message": "Network connection error. Please check your connection and try again",
  "data": null,
  "provider": "github",
  "errorType": "network_error"
}
```

### 5. 频率限制
```json
{
  "success": false,
  "code": 4003,
  "message": "Too many login attempts. Please wait a moment and try again",
  "data": {
    "retryAfter": 60,
    "maxAttempts": 5

  "errorType": "rate_limit_exceeded"
}
```

### 6. 令牌过期
```json
{
  "success": false,
  "code": 4004,
  "message": "Login session expired. Please start the login process again",
  "data": null,
  "provider": "github",
  "errorType": "token_expired"
}
```

## 📝 错误码对照表

| 错误码 | 错误类型 | 英文消息 | 适用场景 |
|--------|----------|----------|----------|
| 4001 | access_denied | Authorization was cancelled | 用户取消授权 |
| 4002 | invalid_request | Invalid login request | 请求参数错误 |
| 4003 | rate_limit_exceeded | Too many login attempts | 频率限制 |
| 4004 | token_expired | Login session expired | 令牌过期 |
| 4005 | account_conflict | Account with this email already exists | 账号冲突 |
| 5001 | server_error | Service temporarily unavailable | 第三方服务错误 |
| 5002 | network_error | Network connection error | 网络连接错误 |
| 5003 | service_unhealthy | OAuth service health check failed | 服务健康检查失败 |

## 🌐 前端处理示例

### JavaScript错误处理
```javascript
// OAuth2响应处理
function handleOAuth2Response(response) {
    if (response.success) {
        // 成功处理
        showSuccessMessage(response.message);
        if (response.data.token) {
            localStorage.setItem('authToken', response.data.token);
            window.location.href = '/dashboard';
        }
    } else {
        // 错误处理
        const errorMessage = response.message || 'An unexpected error occurred';
        showErrorMessage(errorMessage);
        
        // 特殊错误处理
        switch (response.code) {
            case 4001:
                // 用户取消授权，提供重试选项
                showRetryOption(response.provider);
                break;
            case 4005:
                // 账号冲突，显示合并选项
                showAccountMergeDialog(response.data);
                break;
            case 5001:
            case 5002:
                // 服务或网络错误，提供备用登录方式
                showAlternativeLoginOptions();
                break;
        }
    }
}
```

---
**重要说明**: 所有OAuth2相关的API响应都必须使用英文消息，确保国际化兼容性和用户体验的一致性。错误消息应该清晰、友好，并提供明确的下一步操作指引。
