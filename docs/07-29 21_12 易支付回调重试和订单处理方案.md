# 07-29 21:12 易支付回调重试和订单处理方案

## 方案概述

针对易支付回调重试机制和网络问题导致的订单处理问题，制定完整的解决方案，确保支付订单的准确性和用户体验。

## 问题分析

### 1. 易支付回调重试机制
- **重试时间点**: 1分钟、3分钟、20分钟、1小时、2小时、8小时、24小时
- **重试原因**: 首次回调未成功（非200响应或响应非"success"）
- **建议处理**: 先返回"success"，后续逻辑异步处理

### 2. 网络问题场景
- **问题**: 后端因网络问题未接收到回调通知
- **用户行为**: 认为支付失败，重新发起订单并支付
- **风险**: 可能导致重复扣费或订单状态混乱

## 技术实现细节

### 1. 幂等性保证机制

#### 1.1 回调处理幂等
```java
public void processPaymentCallbackAsync(HttpServletRequest request) {
    String outTradeNo = request.getParameter("out_trade_no");
    String tradeNo = request.getParameter("trade_no");
    
    // 生成幂等键
    String idempotentKey = "payment_callback:" + outTradeNo + ":" + tradeNo;
    
    // 分布式锁防重复处理
    if (redisLockService.tryLock(idempotentKey, 300)) {
        try {
            // 检查是否已处理
            if (isCallbackProcessed(outTradeNo, tradeNo)) {
                log.info("回调已处理，跳过: {}", outTradeNo);
                return;
            }
            
            // 执行实际处理逻辑
            handlePaymentCallback(request);
            
            // 标记已处理
            markCallbackProcessed(outTradeNo, tradeNo);
        } finally {
            redisLockService.unlock(idempotentKey);
        }
    }
}
```

#### 1.2 订单状态更新幂等
```java
public boolean updateOrderStatus(String orderNo, Integer newStatus, String tradeNo) {
    // 乐观锁更新，防止并发修改

}
```

### 2. 异步处理线程池配置

```java
@Configuration
public class PaymentAsyncConfig {
    
    @Bean("paymentCallbackExecutor")
    public ThreadPoolTaskExecutor paymentCallbackExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(5);
        executor.setMaxPoolSize(20);
        executor.setQueueCapacity(100);
        executor.setThreadNamePrefix("payment-callback-");
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        return executor;
    }
}
```

```java
@Service
public class PaymentStatusSyncService {
    
    public void syncOrderStatus(String orderNo) {
        try {
            // 调用易支付查询接口
            YiPayQueryResult result = yiPayService.queryOrder(orderNo);
            
            if (result != null && result.isSuccess()) {

            }

        }
    }
}
```
