## 🏗️ 缓存架构设计

### 整体架构图
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   应用层请求     │───▶│   本地缓存层     │───▶│   Redis缓存层    │
│  (Controller)   │    │ (Caffeine Cache)│    │  (分布式缓存)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │                        │
                                ▼                        ▼
                       ┌─────────────────┐    ┌─────────────────┐
                       │   缓存未命中     │───▶│   数据库查询     │
                       │   (Cache Miss)  │    │   (MySQL)      │
                       └─────────────────┘    └─────────────────┘
```

## 📋 缓存分层策略

### 第一层：本地缓存 (Caffeine)
- **用途**: 热点数据快速访问
- **数据**: 套餐权限配置、用户账户信息
- **特点**: 毫秒级响应，减少网络开销

### 第二层：分布式缓存 (Redis)
- **用途**: 跨实例数据共享
- **数据**: 用户每日使用统计、实时限制状态
- **特点**: 支持集群，数据一致性

### 第三层：数据库 (MySQL)
- **用途**: 持久化存储
- **数据**: 原始数据和历史记录
- **特点**: 数据权威性，事务支持

## 🎯 具体缓存设计

### 1. 套餐权限配置缓存

#### 缓存Key设计
```
package:permissions:{packageId}
package:config:{packageId}
```

#### 实现代码
```java
@Component
@Slf4j
public class PackagePermissionCache {
    
    @Autowired
    private PackageService packageService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    // 本地缓存配置
    private final Cache<Long, Map<String, ModelPermission>> localCache = 
        Caffeine.newBuilder()
            .maximumSize(1000)
            .expireAfterWrite(Duration.ofMinutes(30))
            .recordStats()
            .build();
    
    /**
     * 获取套餐权限配置（多层缓存）
     */
    public Map<String, ModelPermission> getPackagePermissions(Long packageId) {
        if (packageId == null) {
            return new HashMap<>();
        }
        
        // 1. 本地缓存查询
        Map<String, ModelPermission> permissions = localCache.getIfPresent(packageId);
        if (permissions != null) {
            log.debug("本地缓存命中，套餐ID: {}", packageId);
            return permissions;
        }
        
        // 2. Redis缓存查询
        String redisKey = "package:permissions:" + packageId;
        try {
            permissions = (Map<String, ModelPermission>) redisTemplate.opsForValue().get(redisKey);
            if (permissions != null) {
                log.debug("Redis缓存命中，套餐ID: {}", packageId);
                // 回填本地缓存
                localCache.put(packageId, permissions);
                return permissions;
            }
        } catch (Exception e) {
            log.warn("Redis缓存查询失败，套餐ID: {}", packageId, e);
        }
        
        // 3. 数据库查询
        permissions = loadFromDatabase(packageId);
        if (permissions != null) {
            // 更新缓存
            updateCache(packageId, permissions);
        }
        
        return permissions != null ? permissions : new HashMap<>();
    }
    
    private Map<String, ModelPermission> loadFromDatabase(Long packageId) {
        try {
            Package packageInfo = packageService.getPackageById(packageId);
            if (packageInfo != null) {
                log.debug("数据库查询成功，套餐ID: {}", packageId);
                return packageInfo.getModelPermissionsMap();
            }
        } catch (Exception e) {
            log.error("数据库查询失败，套餐ID: {}", packageId, e);
        }
        return null;
    }
    
    private void updateCache(Long packageId, Map<String, ModelPermission> permissions) {
        // 更新本地缓存
        localCache.put(packageId, permissions);
        
        // 更新Redis缓存
        String redisKey = "package:permissions:" + packageId;
        try {
            redisTemplate.opsForValue().set(redisKey, permissions, Duration.ofHours(2));
            log.debug("缓存更新成功，套餐ID: {}", packageId);
        } catch (Exception e) {
            log.warn("Redis缓存更新失败，套餐ID: {}", packageId, e);
        }
    }
    
    /**
     * 清除套餐权限缓存
     */
    public void evictPackagePermissions(Long packageId) {
        // 清除本地缓存
        localCache.invalidate(packageId);
        
        // 清除Redis缓存
        String redisKey = "package:permissions:" + packageId;
        try {
            redisTemplate.delete(redisKey);
            log.info("套餐权限缓存清除成功，套餐ID: {}", packageId);
        } catch (Exception e) {
            log.warn("Redis缓存清除失败，套餐ID: {}", packageId, e);
        }
    }
}
```

### 2. 用户每日使用统计缓存

#### 缓存Key设计
```
usage:daily:{userId}:{modelName}:{date}
usage:remaining:{userId}:{modelName}:{date}
usage:stats:{userId}:{date}
```

#### 实现代码
```java
@Component
@Slf4j
public class UserUsageCache {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private UserDailyUsageService userDailyUsageService;
    
    /**
     * 获取用户今日使用情况（带缓存）
     */
    public UserDailyUsage getTodayUsage(Long userId, String modelName) {
        String cacheKey = String.format("usage:daily:%d:%s:%s", 
            userId, modelName, LocalDate.now().toString());
        
        try {
            // Redis缓存查询
            UserDailyUsage cached = (UserDailyUsage) redisTemplate.opsForValue().get(cacheKey);
            if (cached != null) {
                log.debug("使用统计缓存命中，用户: {}, 模型: {}", userId, modelName);
                return cached;
            }
        } catch (Exception e) {
            log.warn("使用统计缓存查询失败，用户: {}, 模型: {}", userId, modelName, e);
        }
        
        // 数据库查询
        UserDailyUsage usage = userDailyUsageService.getTodayModelUsage(userId, modelName);
        
        // 更新缓存
        if (usage != null) {
            updateUsageCache(cacheKey, usage);
        }
        
        return usage;
    }
    
    /**
     * 获取用户剩余使用次数（带缓存）
     */
    public int getRemainingChats(Long userId, String modelName, int dailyLimit) {
        String cacheKey = String.format("usage:remaining:%d:%s:%s", 
            userId, modelName, LocalDate.now().toString());
        
        try {
            Integer cached = (Integer) redisTemplate.opsForValue().get(cacheKey);
            if (cached != null) {
                log.debug("剩余次数缓存命中，用户: {}, 模型: {}", userId, modelName);
                return cached;
            }
        } catch (Exception e) {
            log.warn("剩余次数缓存查询失败，用户: {}, 模型: {}", userId, modelName, e);
        }
        
        // 计算剩余次数
        UserDailyUsage todayUsage = getTodayUsage(userId, modelName);
        int used = todayUsage != null ? todayUsage.getChatCountUsed() : 0;
        int remaining = Math.max(0, dailyLimit - used);
        
        // 更新缓存（较短过期时间，因为使用次数变化频繁）
        updateRemainingCache(cacheKey, remaining);
        
        return remaining;
    }
    
    /**
     * 记录使用并更新缓存
     */
    @Transactional
    public boolean recordUsageAndUpdateCache(Long userId, String modelName) {
        // 1. 记录到数据库
        boolean success = userDailyUsageService.recordModelChatUsage(userId, modelName);
        
        if (success) {
            // 2. 更新相关缓存
            invalidateUserUsageCache(userId, modelName);
            log.debug("使用记录成功，缓存已更新，用户: {}, 模型: {}", userId, modelName);
        }
        
        return success;
    }
    
    private void updateUsageCache(String cacheKey, UserDailyUsage usage) {
        try {
            // 缓存到当天结束
            long secondsUntilEndOfDay = getSecondsUntilEndOfDay();
            redisTemplate.opsForValue().set(cacheKey, usage, Duration.ofSeconds(secondsUntilEndOfDay));
        } catch (Exception e) {
            log.warn("使用统计缓存更新失败，key: {}", cacheKey, e);
        }
    }
    
    private void updateRemainingCache(String cacheKey, int remaining) {
        try {
            // 较短的缓存时间，因为使用次数变化频繁
            redisTemplate.opsForValue().set(cacheKey, remaining, Duration.ofMinutes(5));
        } catch (Exception e) {
            log.warn("剩余次数缓存更新失败，key: {}", cacheKey, e);
        }
    }
    
    /**
     * 清除用户使用相关缓存
     */
    public void invalidateUserUsageCache(Long userId, String modelName) {
        String dateStr = LocalDate.now().toString();
        String[] keys = {
            String.format("usage:daily:%d:%s:%s", userId, modelName, dateStr),
            String.format("usage:remaining:%d:%s:%s", userId, modelName, dateStr),
            String.format("usage:stats:%d:%s", userId, dateStr)
        };
        
        try {
            redisTemplate.delete(Arrays.asList(keys));
            log.debug("用户使用缓存清除成功，用户: {}, 模型: {}", userId, modelName);
        } catch (Exception e) {
            log.warn("用户使用缓存清除失败，用户: {}, 模型: {}", userId, modelName, e);
        }
    }
    
    private long getSecondsUntilEndOfDay() {
        LocalDateTime now = LocalDateTime.now();
        LocalDateTime endOfDay = now.toLocalDate().atTime(23, 59, 59);
        return Duration.between(now, endOfDay).getSeconds();
    }
}
```

### 3. 用户账户信息缓存

#### 实现代码
```java
@Component
@Slf4j
public class UserAccountCache {
    
    @Autowired
    private UserAccountService userAccountService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    // 本地缓存
    private final Cache<Long, UserAccount> localCache = 
        Caffeine.newBuilder()
            .maximumSize(5000)
            .expireAfterWrite(Duration.ofMinutes(15))
            .recordStats()
            .build();
    
    /**
     * 获取用户账户信息（多层缓存）
     */
    public UserAccount getUserAccount(Long userId) {
        if (userId == null) {
            return null;
        }
        
        // 1. 本地缓存
        UserAccount account = localCache.getIfPresent(userId);
        if (account != null) {
            return account;
        }
        
        // 2. Redis缓存
        String redisKey = "user:account:" + userId;
        try {
            account = (UserAccount) redisTemplate.opsForValue().get(redisKey);
            if (account != null) {
                localCache.put(userId, account);
                return account;
            }
        } catch (Exception e) {
            log.warn("用户账户Redis缓存查询失败，用户ID: {}", userId, e);
        }
        
        // 3. 数据库查询
        account = userAccountService.getUserAccount(userId);
        if (account != null) {
            updateAccountCache(userId, account);
        }
        
        return account;
    }
    
    private void updateAccountCache(Long userId, UserAccount account) {
        // 更新本地缓存
        localCache.put(userId, account);
        
        // 更新Redis缓存
        String redisKey = "user:account:" + userId;
        try {
            redisTemplate.opsForValue().set(redisKey, account, Duration.ofMinutes(30));
        } catch (Exception e) {
            log.warn("用户账户Redis缓存更新失败，用户ID: {}", userId, e);
        }
    }
    
    /**
     * 清除用户账户缓存
     */
    public void evictUserAccount(Long userId) {
        localCache.invalidate(userId);
        
        String redisKey = "user:account:" + userId;
        try {
            redisTemplate.delete(redisKey);
        } catch (Exception e) {
            log.warn("用户账户Redis缓存清除失败，用户ID: {}", userId, e);
        }
    }
}
```

## 📊 缓存策略总结

### 缓存时间策略
- **套餐权限配置**: 2小时（变更频率低）
- **用户账户信息**: 30分钟（相对稳定）
- **每日使用统计**: 到当天结束（按天重置）
- **剩余使用次数**: 5分钟（变化频繁）

### 缓存更新策略
- **主动更新**: 数据变更时主动清除相关缓存
- **被动更新**: 缓存过期后重新加载
- **预热机制**: 应用启动时预加载热点数据

### 缓存降级策略
- **Redis故障**: 降级到本地缓存
- **本地缓存满**: LRU淘汰策略
- **缓存穿透**: 空值缓存防护

---

**📝 总结**: 通过多层缓存架构，预计可以将用户每日限制检查的响应时间从平均50ms降低到5ms以内，缓存命中率达到90%以上，显著提升系统性能。
