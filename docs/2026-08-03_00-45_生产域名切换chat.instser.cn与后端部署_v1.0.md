# 2026-08-03 00:45 生产域名切换 chat.instser.cn 与后端部署

> 北京时间：2026-08-03 00:45  
> 版本：v1.0

## 背景

生产域名由 `chat.instser.xyz` / 历史 `chat.example.com` 切换为 `chat.instser.cn`。  
后端服务器主机名为 `home.example.com`。

## 本次改动

### 后端代码/配置
- `src/main/resources/application.yml`
  - CORS 默认允许源：`https://chat.instser.cn,http://chat.instser.cn`
  - 支付回调默认：`https://chat.instser.cn/api/payment/...`
  - PayPal return/cancel：`https://chat.instser.cn/payment/...`
  - Google/GitHub OAuth redirect：`https://chat.instser.cn/auth/callback/...`
- 8 个 Controller 中硬编码 CORS 白名单：`chat.example.com` → `chat.instser.cn`

### 前端
- 源码路径：`/Users/instser/Downloads/tousechat-main/frontend`
- `lib/api-utils.ts` 继续使用浏览器同源动态地址（`${protocol}//${host}`）
- `.env.production` 保持 `NEXT_PUBLIC_API_BASE_URL=` 为空，并注明生产域名为 `chat.instser.cn`
- 本轮未强制重发前端 standalone 产物（同源逻辑已兼容新域名）

### 后端部署
- 构建：JDK 17 + `mvn clean package -Dmaven.test.skip=true -Dmaven.compiler.proc=full`
- 产物：`target/chat-0.0.1-SNAPSHOT.jar`（约 111MB）
- 上传：`home.example.com:/tmp/chat-new.jar`
- 替换：`/opt/chat/chat-0.0.1-SNAPSHOT.jar`（备份 `chat-0.0.1-SNAPSHOT.jar.bak.domain-cn`）
- 重启：`supervisorctl restart chat:chat_00`
- 结果：`chat:chat_00 RUNNING`

## 验证结果

- `http://127.0.0.1:8081/actuator/health` → 200 `{"status":"UP"}`
