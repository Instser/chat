# 07-07 22:53 - 搜索提取方法返回类型扩展

## 更新时间
2025年7月7日 22:53 (北京时间)

## 版本标识
v1.5.0-search-extract-return-type-enhancement

## 功能概述
修改searchAndExtract方法的返回类型，使其返回包含searchResponse和extractResponse的综合结果对象，同时更新所有调用该方法的地方的参数解析逻辑。

## 核心修改

### 1. 新增实体类

#### WebSearchExtractResult.java
```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class WebSearchExtractResult {
    /**
     * 搜索响应结果
     */
    private TavilySearchResponse searchResponse;

    /**
     * 内容提取响应结果
     */
    private TavilyExtractResponse extractResponse;
}
```

### 2. 服务接口修改

#### WebSearchExtractService.java
- **返回类型变更**: 从`TavilyExtractResponse`改为`WebSearchExtractResult`
- **方法签名更新**: 两个重载方法都返回综合结果对象
- **注释更新**: 更新方法注释说明返回类型

```java
/**
 * @return 搜索和内容提取综合结果
 */
WebSearchExtractResult searchAndExtract(String query, int maxResults, int extractCount);
WebSearchExtractResult searchAndExtract(String query);
```

### 3. 服务实现修改

#### WebSearchExtractServiceImpl.java
- **返回类型更新**: 方法签名改为返回`WebSearchExtractResult`
- **返回逻辑修改**: 使用Builder模式构建综合结果对象
- **异常处理优化**: 空结果情况下返回包含searchResponse的对象

**关键修改点**:
```java
// 搜索无结果时
return WebSearchExtractResult.builder()
        .searchResponse(searchResponse)
        .extractResponse(null)
        .build();

// 正常返回时
return WebSearchExtractResult.builder()
        .searchResponse(searchResponse)
        .extractResponse(extractResponse)
        .build();
```

### 4. 调用方修改

#### ChatServiceImpl.java
- **参数解析更新**: 从直接使用extractResponse改为从综合结果中获取
- **兼容性处理**: 添加null检查确保稳定性

**修改前**:
```java
TavilyExtractResponse extractResponse = webSearchExtractService.searchAndExtract(query);
```

**修改后**:
```java
WebSearchExtractResult searchExtractResult = webSearchExtractService.searchAndExtract(query);
TavilyExtractResponse extractResponse = searchExtractResult != null ? 
    searchExtractResult.getExtractResponse() : null;
```

## 使用示例

### 基础使用（保持兼容）
```java
WebSearchExtractResult result = webSearchExtractService.searchAndExtract("Spring Boot教程");
TavilyExtractResponse extractResponse = result != null ? result.getExtractResponse() : null;

// 使用提取结果（与之前相同）
if (extractResponse != null && extractResponse.getResults() != null) {
    for (TavilyExtractResult item : extractResponse.getResults()) {
        System.out.println(item.getUrl() + ": " + item.getRawContent());
    }
}
```

### 扩展使用（利用搜索结果）
```java
WebSearchExtractResult result = webSearchExtractService.searchAndExtract("AI技术趋势");

// 获取搜索结果
TavilySearchResponse searchResponse = result.getSearchResponse();
if (searchResponse != null && searchResponse.getResults() != null) {
    System.out.println("找到 " + searchResponse.getResults().size() + " 个相关链接");
}

// 获取提取结果
TavilyExtractResponse extractResponse = result.getExtractResponse();
if (extractResponse != null && extractResponse.getResults() != null) {
    System.out.println("成功提取 " + extractResponse.getResults().size() + " 个页面内容");
}
```
