# 管理员前端 admin-web 落地

## 文档信息

- 编写时间：2026-08-03 22:05（北京时间）
- 版本标识：v1.0
- 路径：`admin-web/`
- 访问约定：`https://chat.instser.cn/admin/`

## 1. 技术栈

- Vue 3 + TypeScript + Vite 5
- Vue Router（`createWebHistory('/admin/')`）
- Pinia
- Element Plus
- Axios（`withCredentials: true`，baseURL `/api`）

## 2. 鉴权与集成

- 登录：`POST /api/auth/login`（`usernameOrEmail` + `password`）
- 身份：`GET /api/auth/me`，要求 `role=admin`
- 退出：`POST /api/auth/logout`
- JWT 仅 Cookie，不写 localStorage
- 管理/运维页面统一调用 `/api/admin/**`
- 浏览器不使用 `X-API-Key`

## 3. 页面

| 路由 | 说明 |
|---|---|
| `/admin/login` | 管理员登录 |
| `/admin/dashboard` | 概览与健康 |
| `/admin/users` | 用户列表/状态/角色 |
| `/admin/packages` | 套餐 CRUD/启停 |
| `/admin/models` | 模型 CRUD/凭据/测试 |
| `/admin/orders` | 订单查询/同步/取消 |
| `/admin/audits` | 操作/支付/OAuth 审计 |
| `/admin/ops` | 健康、缓存、日志、AI 分析 |

## 4. 本地与构建

```bash
cd admin-web
# 若环境 NODE_ENV=production，需：
# npm install --include=dev
unset NODE_ENV
npm run dev    # http://127.0.0.1:5174/admin/
npm run build  # 产物 dist/
```

已验证：`npm run build` 成功，输出 `admin-web/dist`。

## 5. 部署建议

- Nginx 将 `/admin/` 指向 `admin-web/dist`
- `/api/` 反代到后端 `127.0.0.1:8080`
- 与用户聊天前端隔离目录，但共享同域 Cookie
