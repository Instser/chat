# 运维监控图表标签与 TTFT [object Object] 修复 v1.0

- 时间：2026-08-06 15:44（北京时间）

## 问题

1. 图表数据标签/轴标签严重重叠。
2. TTFT（按模型耗时）悬停或标签显示 `[object Object]`。

## 根因

- 使用 ECharts `dataset` + `encode` 时，series 的 `value`/`data` 在 formatter 中常为**整行对象**；
  直接字符串化会得到 `[object Object]`。
- 多系列双 Y 轴 + 全量 dataLabel + 长模型名 + `hideOverlap:false` 导致轴/标签打架。

## 修复

1. TTFT 图改为**平行数值数组**（`calls`/`ttft`/`duration`），不再用 dataset 行对象喂 series。
2. tooltip 显式按 `number` 取值；线系列 `label.show=false`；柱顶次数标签仅 ≤8 类目时开启。
3. 模型名 / 路径 `shortModelLabel` / `shortPathLabel`；轴 `hideOverlap` + 旋转 + `containLabel`。
4. 饼图标签只显示名称，数值与百分比进 tooltip。
5. 图表高度 300→340，grid 预留 denser bottom。

## 部署

- 仅 admin-web 静态资源，已更新 `/opt/tousechat-admin`。
