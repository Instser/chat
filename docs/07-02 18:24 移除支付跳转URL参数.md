## 🔧 技术实现说明

### 1. 前端轮询机制

前端通过以下方式检测支付状态：

```typescript
// 前端轮询支付状态
const pollPaymentStatus = async (orderNo: string) => {
  const interval = setInterval(async () => {
    try {
      const response = await api.payment.getStatus(orderNo);
      if (response.data.status === 1) { // 支付成功
        clearInterval(interval);
        // 前端自动跳转到成功页面
        router.push('/payment/success');
      }
    } catch (error) {
      console.error('查询支付状态失败:', error);
    }
  }, 2000); // 每2秒查询一次
};
```

### 2. 支付平台跳转处理

完全移除支付平台跳转URL：

- **支付宝**: 不再设置PaymentRedirectUrl，用户支付完成后停留在支付平台页面
- **易支付**: 不再传递return_url参数，用户支付完成后停留在支付平台页面

**重要说明**：
- 完全移除 `return-url` 配置，不再进行页面跳转
- 保留 `notify-url` 配置，这是支付平台向后端发送回调通知的API接口URL
- 前端通过轮询支付状态API来检测支付完成并自主控制页面跳转

前端轮询机制会定期检查支付状态，一旦检测到支付成功就自动跳转。
