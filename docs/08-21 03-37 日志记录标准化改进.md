# 08-21 03:37 日志记录标准化改进

## 概述
本次更新对项目中的日志记录进行了全面的标准化改进，确保所有用户操作相关的info日志都包含用户ID和会话ID信息，提高了日志的可追溯性和问题排查效率。

## 更新时间
- 北京时间：2025年8月21日 03:37
- 版本标识：v2025.08.21.0337

## 主要改进内容

### 1. 创建统一日志工具类
- **文件位置**: `src/main/java/com/instser/chat/common/util/LogUtils.java`
- **功能**: 提供标准化的用户操作日志记录方法
- **主要方法**:
  - `logUserOperation()` - 记录用户操作信息日志
  - `logUserSessionOperation()` - 记录用户会话操作信息日志
  - `logUserWarning()` - 记录用户操作警告日志
  - `logUserSessionWarning()` - 记录用户会话操作警告日志
  - `logUserError()` - 记录用户操作错误日志
  - `logUserSessionError()` - 记录用户会话操作错误日志
  - `logUserDebug()` - 记录用户操作调试日志
  - `logUserSessionDebug()` - 记录用户会话操作调试日志

### 2. 日志格式标准化
- **统一格式**: `【操作类型】用户ID：{userId}，会话ID：{sessionId}，{详细信息}`
- **用户ID处理**: 当用户ID为null时显示"未知"
- **会话ID处理**: 当会话ID为null时显示"未知"
- **操作类型**: 明确标识操作类型，如"登录"、"发送消息"、"文件上传"等

## 技术实现细节

### 日志工具类设计
```java
public static void logUserSessionOperation(Logger logger, Long userId, String sessionId, 
                                         String operation, String message, Object... args) {
    if (userId != null && sessionId != null) {
        String logMessage = String.format("【%s】用户ID：%d，会话ID：%s，%s", 
                                        operation, userId, sessionId, message);
        logger.info(logMessage, args);
    }
    // 处理其他情况...
}
```

### 错误处理机制
- 当用户ID或会话ID为null时，仍然记录日志但标记为"未知"
- 异常信息正确传递给日志记录器
- 保持原有的日志级别（info、warn、error、debug）

### 向后兼容性
- 保留了原有的日志记录功能
- 新的LogUtils方法作为增强，不影响现有代码
- 逐步迁移策略，确保系统稳定性
