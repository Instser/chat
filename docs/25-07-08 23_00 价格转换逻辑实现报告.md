# 价格转换逻辑实现报告

**更新时间**: 2025年7月8日 23:00 (北京时间)  
**版本**: v1.0  
**执行人员**: Augment Agent

## 📋 概述

根据用户需求，重新实现了价格转换功能，支持CNY和USD两种货币的动态转换。数据库统一存储CNY价格，前端请求时根据currency参数进行实时汇率转换。

## 🎯 实现目标

### 1. 支持的货币类型
- **CNY (人民币)**: 数据库存储的基础货币
- **USD (美元)**: 通过汇率转换支持的货币

### 2. 转换逻辑
- 数据库存储CNY价格
- 前端请求CNY时直接返回数据库价格
- 前端请求USD时通过汇率API转换后返回
- 其他货币请求返回CNY价格（降级处理）

## 🔧 技术实现

### 1. ExchangeRateService - 汇率服务

#### 核心功能
```java
@Service
public class ExchangeRateService {
    // 默认汇率配置
    private static final BigDecimal DEFAULT_CNY_TO_USD = new BigDecimal("0.14");
    private static final BigDecimal DEFAULT_USD_TO_CNY = new BigDecimal("7.14");
    
    // 获取汇率（支持缓存）
    @Cacheable(value = "exchangeRates", key = "#fromCurrency + '_' + #toCurrency")
    public BigDecimal getExchangeRate(String fromCurrency, String toCurrency);
    
    // 价格转换
    public BigDecimal convertPrice(BigDecimal amount, String fromCurrency, String toCurrency);
    
    // 货币支持检查
    public boolean isCurrencySupported(String currency);
}
```

#### 汇率获取策略
1. **相同货币**: 直接返回1
2. **CNY→USD**: 尝试API获取，失败时使用默认汇率0.14
3. **USD→CNY**: 尝试API获取，失败时使用默认汇率7.14
4. **其他货币**: 返回1（不支持转换）

#### API集成
- **汇率API**: `https://api.exchangerate-api.com/v4/latest/{currency}`
- **缓存机制**: Spring Cache + Redis，缓存30分钟
- **降级处理**: API失败时使用预设默认汇率

### 2. VOConverter - 价格转换器

#### 方法重载设计
```java
// 不使用汇率转换的方法（向后兼容）
public static FrontendPackageVO toFrontendPackageVO(Package packageEntity, String currency);

// 支持汇率转换的方法
public static FrontendPackageVO toFrontendPackageVO(Package packageEntity, String currency, ExchangeRateService exchangeRateService);
```

#### 价格计算逻辑
```java
private static BigDecimal calculatePrice(Package packageEntity, String currency, ExchangeRateService exchangeRateService) {
    BigDecimal cnyPrice = packageEntity.getPrice(); // 获取CNY价格
    
    if ("CNY".equalsIgnoreCase(currency)) {
        return cnyPrice; // 直接返回CNY价格
    }
    
    if ("USD".equalsIgnoreCase(currency) && exchangeRateService != null) {
        return exchangeRateService.convertPrice(cnyPrice, "CNY", "USD"); // 转换为USD
    }
    
    return cnyPrice; // 其他情况返回CNY价格
}
```

## 📊 价格转换流程

### 1. 前端请求CNY价格
```
前端请求: GET /api/payment/packages?currency=CNY
↓
数据库查询: SELECT price FROM t_package (CNY价格)
↓
VOConverter: 检测到CNY，直接返回数据库价格
↓
前端响应: { "price": 69.99, "currency": "CNY" }
```

### 2. 前端请求USD价格
```
前端请求: GET /api/payment/packages?currency=USD
↓
数据库查询: SELECT price FROM t_package (CNY价格: 69.99)
↓
汇率服务: getExchangeRate("CNY", "USD") → 0.14
↓
价格转换: 69.99 * 0.14 = 9.80 (保留2位小数)
↓
前端响应: { "price": 9.80, "currency": "USD" }
```

### 3. 汇率获取流程
```
汇率请求: getExchangeRate("CNY", "USD")
↓
缓存检查: Redis查询 "exchangeRates::CNY_USD"
↓
缓存命中: 直接返回缓存汇率
↓
缓存未命中: 调用API获取实时汇率
↓
API成功: 缓存汇率并返回
↓
API失败: 返回默认汇率0.14
```

## ⚡ 性能优化

### 1. 缓存策略
- **汇率缓存**: 30分钟过期，减少API调用
- **缓存键**: `exchangeRates::CNY_USD` 格式
- **缓存更新**: 自动过期更新，支持手动清除

### 2. 降级机制
- **API超时**: 5秒超时，快速失败
- **默认汇率**: API失败时使用预设汇率
- **错误处理**: 异常时返回CNY价格

### 3. 精度控制
- **小数位数**: 统一保留2位小数
- **舍入模式**: 使用HALF_UP舍入
- **数值范围**: 支持0.01-99999.99的价格范围
