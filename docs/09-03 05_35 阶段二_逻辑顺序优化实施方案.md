### 3.1 第一步：创建统一权限验证框架（1-2天）

#### 3.1.1 权限验证结果类

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
public class PermissionValidationResult {
    private boolean success;
    private String errorCode;
    private String errorMessage;
    private UserAccount userAccount;
    private Package packageInfo;

    public static PermissionValidationResult success(UserAccount userAccount, Package packageInfo) {
        PermissionValidationResult result = new PermissionValidationResult();
        result.success = true;
        result.userAccount = userAccount;
        result.packageInfo = packageInfo;
        return result;
    }

    public static PermissionValidationResult failure(String errorCode, String errorMessage) {
        PermissionValidationResult result = new PermissionValidationResult();
        result.success = false;
        result.errorCode = errorCode;
        result.errorMessage = errorMessage;
        return result;
    }

    public boolean isFailure() {
        return !success;
    }
}
```

#### 3.1.2 统一权限验证器
```java
@Component
@Slf4j
public class UnifiedPermissionValidator {
    
    @Autowired
    private UserAccountService userAccountService;
    
    @Autowired
    private ChatLimitService chatLimitService;
    
    @Autowired
    private ChatInterruptService chatInterruptService;
    
    /**
     * 执行完整权限验证链（不改变数据状态）
     */
    public PermissionValidationResult validateCompletePermissions(
            Long userId, String sessionId, Long modelId, Authentication authentication) {
        
        try {
            // 1. 用户认证验证
            PermissionValidationResult authResult = validateUserAuthentication(authentication, userId);
            if (authResult.isFailure()) {
                return authResult;
            }

            // 2. 用户账户状态验证
            PermissionValidationResult accountResult = validateUserAccount(userId);
            if (accountResult.isFailure()) {
                return accountResult;
            }

            // 3. 聊天权限验证
            PermissionValidationResult chatResult = validateChatPermissions(userId, sessionId, modelId);
            if (chatResult.isFailure()) {
                return chatResult;
            }

            // 4. 活跃会话检查
            PermissionValidationResult sessionResult = validateActiveSession(userId);
            if (sessionResult.isFailure()) {
                return sessionResult;
            }

            // 所有验证通过
            return PermissionValidationResult.success(
                accountResult.getUserAccount(), 
                accountResult.getPackageInfo()
            );

        } catch (Exception e) {
            LogUtils.logUserError(log, userId, "权限验证", "统一权限验证异常", e);
            return PermissionValidationResult.failure("SYSTEM_ERROR", "系统异常，请稍后重试");
        }
    }

    private PermissionValidationResult validateUserAuthentication(Authentication authentication, Long userId) {
        if (authentication == null || !authentication.isAuthenticated()) {
            return PermissionValidationResult.failure("UNAUTHORIZED", "用户未认证");
        }

        Long authenticatedUserId = getCurrentUserId(authentication);
        if (!Objects.equals(authenticatedUserId, userId)) {
            LogUtils.logUserWarning(log, userId, "权限验证", "用户ID不匹配");
            return PermissionValidationResult.failure("FORBIDDEN", "无权限访问");
        }

        return PermissionValidationResult.success(null, null);
    }

    private PermissionValidationResult validateUserAccount(Long userId) {
        UserAccount userAccount = userAccountService.getUserAccount(userId);
        if (userAccount == null) {
            return PermissionValidationResult.failure("ACCOUNT_NOT_FOUND", "用户账户不存在");
        }

        if (userAccount.isPackageExpired()) {
            return PermissionValidationResult.failure("PACKAGE_EXPIRED", "套餐已过期");
        }

        return PermissionValidationResult.success(userAccount, null);
    }

    private PermissionValidationResult validateChatPermissions(Long userId, String sessionId, Long modelId) {
        String permissionError = chatLimitService.validateChatPermission(userId, sessionId, modelId);
        if (permissionError != null) {
            String errorMessage = getErrorMessage(permissionError);
            return PermissionValidationResult.failure(permissionError, errorMessage);
        }
        return PermissionValidationResult.success(null, null);
    }

    private PermissionValidationResult validateActiveSession(Long userId) {
        if (chatInterruptService.hasActiveSession(userId)) {
            return PermissionValidationResult.failure("ACTIVE_SESSION_EXISTS", 
                "当前正在聊天中，请结束当前聊天后重试");
        }
        return PermissionValidationResult.success(null, null);
    }

    private String getErrorMessage(String errorCode) {
        switch (errorCode) {
            case "PACKAGE_EXPIRED":
                return "Your package has expired.";
            case "MODEL_LIMIT_EXCEEDED":
                return "Your daily usage limit for this model has been reached.";
            case "MODEL_NOT_ACCESSIBLE":
                return "This model is not accessible with your current package.";
            default:
                return "Request failed. Please try again later.";
        }
    }
}
```

```java
@PostMapping("/retry")
public ChatResponseDTO processRetryChat(
        @RequestBody ChatRequestDTO request,
        Authentication authentication,
        HttpServletResponse response) {
    
    Long authenticatedUserId = getCurrentUserId(authentication);
    request.setUserId(authenticatedUserId);

    try {
        setStreamResponseHeaders(response);

        // ✅ 第一步：基础参数验证
        ParameterValidationResult paramResult = validateRetryParameters(request);
        if (paramResult.isFailure()) {
            writeErrorResponse(response, paramResult.getErrorMessage());
            return ChatResponseDTO.failure(paramResult.getErrorMessage());
        }

        // ✅ 第二步：验证消息存在性（不删除）
        ChatMessage retryMessage = chatMessageService.getByMessageId(request.getRetryMessageId());
        if (retryMessage == null) {
            String errorMessage = "要重试的消息不存在";
            writeErrorResponse(response, errorMessage);
            return ChatResponseDTO.failure(errorMessage);
        }

        // ✅ 第三步：完整权限验证（不改变数据状态）
        PermissionValidationResult permissionResult = unifiedPermissionValidator
            .validateCompletePermissions(request.getUserId(), request.getSessionId(), 
                request.getModelId(), authentication);
        
        if (permissionResult.isFailure()) {
            handlePermissionError(response, permissionResult);
            return ChatResponseDTO.failure(permissionResult.getErrorMessage());
        }

        // ✅ 第四步：权限验证通过，安全地执行数据操作
        boolean deleteSuccess = performSafeMessageDeletion(request.getRetryMessageId());
        if (!deleteSuccess) {
            String errorMessage = "删除重试消息失败";
            writeErrorResponse(response, errorMessage);
            return ChatResponseDTO.failure(errorMessage);
        }

        // ✅ 第五步：继续后续处理
        return continueRetryProcessing(request, response, permissionResult);

    } catch (Exception e) {
        return handleStreamChatException(e, request, response);
    }
}

/**
 * 安全地删除消息（带事务保护）
 */
@Transactional
private boolean performSafeMessageDeletion(String messageId) {
    try {
        // 再次确认消息存在
        ChatMessage message = chatMessageService.getByMessageId(messageId);
        if (message == null) {
            LogUtils.logError(log, "安全删除消息", "要删除的消息不存在: {}", messageId);
            return false;
        }
        
        // 执行删除操作
        boolean deleteSuccess = chatMessageService.deleteByMessageId(messageId);
        if (deleteSuccess) {
            LogUtils.logInfo(log, "安全删除消息", "成功删除消息: {}", messageId);
        }
        
        return deleteSuccess;
        
    } catch (Exception e) {
        LogUtils.logError(log, "安全删除消息", "删除消息异常: {}", e, messageId);
        throw e; // 让事务回滚
    }
}
```

### 3.4 第四步：统一错误处理机制（1天）

#### 3.4.1 创建统一错误处理器
```java
@Component
@Slf4j
public class ChatErrorHandler {
    
    /**
     * 处理权限验证错误
     */
    public void handlePermissionError(
            HttpServletResponse response, 
            PermissionValidationResult result) {
        
        String errorCode = result.getErrorCode();
        String errorMessage = result.getErrorMessage();
        
        // 根据错误类型设置不同的HTTP状态码
        int httpStatus = getHttpStatusForError(errorCode);
        
        try {
            response.setStatus(httpStatus);
            writeErrorResponse(response, errorMessage, errorCode);
            
        } catch (Exception e) {
            LogUtils.logError(log, "错误处理", "处理权限验证错误时异常", e);
        }
    }
    
    private int getHttpStatusForError(String errorCode) {
        switch (errorCode) {
            case "UNAUTHORIZED":
                return HttpStatus.UNAUTHORIZED.value();
            case "FORBIDDEN":
                return HttpStatus.FORBIDDEN.value();
            case "PACKAGE_EXPIRED":
            case "MODEL_LIMIT_EXCEEDED":
                return HttpStatus.PAYMENT_REQUIRED.value();
            case "ACTIVE_SESSION_EXISTS":
                return HttpStatus.CONFLICT.value();
            default:
                return HttpStatus.BAD_REQUEST.value();
        }
    }
}
```
