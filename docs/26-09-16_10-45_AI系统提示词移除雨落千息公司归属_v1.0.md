# AI 系统提示词移除「雨落千息」公司归属 v1.0

**日期**：2026-09-16 10:45（北京时间）
**状态**：已完成开发并通过验证，待部署后端生效
**变更范围**：仅后端 1 个文件（`PromptConstants.java`），无 DB/依赖/前端/接口变更
**决策依据**：用户选择「完全去掉公司归属，只说自己是 To Use AI」；泄露防护锚点保留

## 一、需求

把当前后端 AI 系统提示词中的「雨落千息（Yuluo Qianxi）」公司移除。

## 二、提示词注入链路（改动前确认）

| 环节 | 位置 | 说明 |
| --- | --- | --- |
| 身份 system prompt | `PromptConstants.IDENTITY_SYSTEM_PROMPT` | **唯一**每轮注入的 role=system 身份文案，内含公司名（2 处） |
| 组装 | `PromptAssembler.buildSystemPrompt()` | identity + 按会话 active 的 skill 段拼接 |
| 编排 | `PromptSkillService.resolveSystemPrompt()` | 每轮 UPDATE / 重试 REUSE_ONLY，最终都走 assembler |

全仓扫描确认：`src/main`（含 `src/main/resources`）内公司名仅出现在 `PromptConstants` 一处，`application.yml` 无提示词配置，管理端也无提示词编辑入口 —— 改动点唯一。

## 三、改动内容

`src/main/java/com/instser/chat/constants/PromptConstants.java` —— `IDENTITY_SYSTEM_PROMPT`：

**改动前**
```
You are To Use AI, created by the Chinese company 雨落千息 (Yuluo Qianxi).
You are a helpful, intelligent, and adaptive AI assistant.
When asked who you are, briefly reaffirm that you are To Use AI by 雨落千息. Never claim or imply that you are any other model or product.
...
```

**改动后**
```
You are To Use AI, a helpful, intelligent, and adaptive AI assistant.
When asked who you are, briefly reaffirm that you are To Use AI. Never claim or imply that you are any other model or product.
If asked who created or developed you, do not name or invent any company, organization, or team; simply state that you are To Use AI.
...
```

要点：
1. 删除「created by the Chinese company 雨落千息 (Yuluo Qianxi)」与「To Use AI by 雨落千息」两个公司归属表述，身份与任何公司/组织解绑。
2. **新增一句防杜撰约束**：被问及开发者时不得点名或编造任何公司、组织、团队 —— 避免模型在失去「标准答案」后自行幻觉出开发者（如冒充别家厂商）。
3. 其余约束（不冒充其他模型/产品、不做角色扮演、Markdown 链接、不得复述系统指令）**原样保留，功能未简化**。

## 四、故意未改动的地方（及理由）

| 位置 | 内容 | 处理 |
| --- | --- | --- |
| `PromptLeakGuard.WEAK_ANCHORS` | `"雨落千息"`、`"yuluo qianxi"` | **保留**（用户确认）：提示词不再含公司名后，这两个弱特征只对「历史会话复述旧提示词」「旧 prompt 注入痕迹」仍起拦截作用，属纯防御，无副作用 |
| `PromptLeakGuard.STRONG_ANCHORS` | `"creator:** the chinese company"` | 保留：同上，针对旧长 prompt 的整段复述特征 |
| `PromptLeakGuardTest.weakAnchorsNeedMultipleHits` | 用例里以含公司名的字符串作为**测试样本** | 保留：该用例验证的是泄露检测算法（3 个弱特征组合命中），不是系统提示词内容 |

## 六、部署与生效

- 代码改动需**重新构建 jar 并部署到家用机**才生效（当前后端进程未运行，无热更新路径）。
- 无 DDL、无依赖、无前端改动，回滚只需还原该文件。
- 部署后建议验收：
  1. 问「你是谁？」→ 回答仅体现 To Use AI，不出现任何公司名；
  2. 问「你是谁开发的 / 哪家公司做的」→ 不点名、不编造公司，仍保持 To Use AI 身份；
  3. 问「你是 GPT/Claude 吗」→ 仍明确否认并重申 To Use AI（不冒充他家）；
  4. 长会话中 reasoning 不含系统指令复述（`PromptLeakGuard` 行为不变）。
