## 优化概述

本次优化主要针对 `ChatServiceImpl` 类进行代码结构重构，目标是：
1. 删除未使用的方法和不需要的兼容方法
2. 提取重复的逻辑为统一方法
3. 保持逻辑正常运行和时序性不变
4. 提高代码可维护性和可读性

## 主要优化内容

### 1. 删除未使用的兼容方法

#### 1.1 删除 `saveUserOriginalMessage` 方法
- **位置**: ChatService接口 + ChatServiceImpl实现
- **原因**: 与 `saveUserMessage` 功能重复，未被实际使用
- **影响**: 无，该方法为冗余代码

#### 1.2 删除 `saveNewUserMessage` 私有方法
- **位置**: ChatServiceImpl私有方法
- **原因**: 功能与直接调用 `chatMessageService.sendMessage` 重复
- **替换**: 直接使用 `chatMessageService.sendMessage` 调用
- **影响**: 减少代码层次，逻辑更直接

#### 1.3 删除 `getAndValidateModel` 方法
- **位置**: ChatServiceImpl私有方法
- **原因**: 与优化后的 `validateAndGetModel` 功能重复
- **替换**: 统一使用 `validateAndGetModel` 方法
- **影响**: 统一模型验证逻辑

#### 1.4 删除 `isRealAiResponseButFiltered` 方法
- **位置**: ChatServiceImpl私有方法
- **原因**: 功能复杂但使用场景有限，逻辑可简化
- **影响**: 简化内容检测逻辑

### 2. 提取重复逻辑为统一方法

#### 2.1 统一错误响应处理
- **新增方法**: `handleErrorResponse(HttpServletResponse, String, String, Long, Long)`
- **功能**: 统一处理错误响应写入和数据库保存
- **替换场景**: 
  - 模型验证失败
  - 权限验证失败
  - 频率限制验证失败
- **优势**: 减少重复代码，统一错误处理逻辑

#### 2.2 优化权限验证逻辑
- **优化方法**: `validateChatPermission(Long, String, Long, HttpServletResponse)`
- **改进**: 
  - 统一参数格式
  - 集成错误响应处理
  - 减少重复的数据库保存逻辑
- **影响**: 3个调用点的代码得到简化

#### 2.3 优化模型验证逻辑
- **优化方法**: `validateAndGetModel(Long, String, Long, HttpServletResponse)`
- **改进**:
  - 集成错误响应处理
  - 统一参数格式
  - 减少重复的错误处理代码
- **影响**: 多个调用点的代码得到简化

#### 2.4 优化频率限制验证逻辑
- **优化方法**: `validateChatRateLimit(Long, String, Long, HttpServletResponse)`
- **改进**:
  - 返回统一的响应格式
  - 集成错误响应处理
  - 减少重复的验证逻辑
- **影响**: 3个调用点的代码得到简化

### 3. 代码重构细节

#### 3.1 提取用户消息内容逻辑
- **优化**: 在 `saveUserMessage` 中复用 `extractLatestUserMessage` 方法
- **效果**: 减少重复的消息提取逻辑

#### 3.2 修复类型安全警告

- **修复**: 添加 `@SuppressWarnings("unchecked")` 注解
