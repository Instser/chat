# 07-05 23:59 - 联网搜索功能开发

## 更新时间

## 版本标识
v1.0.0-websearch-init

## 功能概述
新增基于Tavily API的联网搜索功能，为AI聊天系统提供实时网络信息检索能力。

## 新增文件

### 实体类 (Entity)
1. **TavilySearchRequest.java** - Tavily搜索请求实体
   - 包含查询内容、搜索深度、结果数量等配置参数
   - 使用Builder模式，提供默认配置
   - 支持自定义搜索参数

2. **TavilySearchResult.java** - 单个搜索结果实体
   - 包含URL、标题、内容摘要、相关性评分等信息
   - 支持网站图标URL

3. **TavilyAutoParameters.java** - 自动参数实体
   - 记录API自动识别的主题分类

4. **TavilySearchResponse.java** - 完整搜索响应实体
   - 包含搜索结果列表、响应时间等完整信息
   - 支持后续问题建议和答案字段

### 服务层
1. **WebSearchService.java** - 联网搜索服务接口
   - 定义搜索方法和服务可用性检查
   - 支持简单查询和自定义请求参数

2. **WebSearchServiceImpl.java** - 联网搜索服务实现
   - 基于RestTemplate实现HTTP请求
   - 完整的异常处理和日志记录
   - 服务可用性检测功能

## 技术特点

### API集成
- **Tavily API**: 使用官方API进行网络搜索
- **认证方式**: Bearer Token认证
- **请求格式**: JSON格式的POST请求
- **响应解析**: 自动JSON反序列化

### 配置参数
- **API URL**: https://api.tavily.com/search
- **API Token**: your-tavily-api-key
- **默认配置**: 基础搜索深度，最多20个结果
- **可定制性**: 支持所有API参数的自定义配置

### 错误处理
- **参数验证**: 查询内容非空检查
- **HTTP异常**: 网络请求异常捕获
- **JSON解析**: 响应格式异常处理
- **服务检测**: 可用性测试机制

## 使用示例

### 简单搜索
```java
@Autowired
private WebSearchService webSearchService;

// 简单查询
TavilySearchResponse response = webSearchService.search("who is Leo Messi?");
```

### 自定义搜索
```java
// 自定义参数搜索
TavilySearchRequest request = TavilySearchRequest.builder()
    .query("Spring Boot tutorial")
    .maxResults("10")
    .searchDepth("advanced")
    .includeAnswer(true)
    .build();

TavilySearchResponse response = webSearchService.search(request);
```

### 服务检查
```java
// 检查服务可用性
boolean available = webSearchService.isServiceAvailable();
```
