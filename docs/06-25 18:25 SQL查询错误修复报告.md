## 问题概述

在执行SQL文件的7.3查询表约束信息时遇到错误：
```
1054 - Unknown column 'CONSTRAINT_TYPE' in 'field list'
```

## 错误分析

### 1. 错误原因
- 在`INFORMATION_SCHEMA.KEY_COLUMN_USAGE`表中不存在`CONSTRAINT_TYPE`字段
- 该字段实际存在于`INFORMATION_SCHEMA.TABLE_CONSTRAINTS`表中
- 查询语句使用了错误的表结构

### 2. 表结构差异

#### KEY_COLUMN_USAGE表结构
```sql
-- 主要字段：
CONSTRAINT_NAME
TABLE_NAME  
COLUMN_NAME
REFERENCED_TABLE_NAME
REFERENCED_COLUMN_NAME
-- 注意：没有CONSTRAINT_TYPE字段
```

#### TABLE_CONSTRAINTS表结构
```sql
-- 主要字段：
CONSTRAINT_NAME
CONSTRAINT_TYPE  -- 这个字段在这里
TABLE_NAME
```

## 修复方案

### 1. 简化查询（修复后）
```sql
-- 7.3 查看表的外键约束信息
SELECT 
    CONSTRAINT_NAME,
    TABLE_NAME,
    COLUMN_NAME,
    REFERENCED_TABLE_NAME,
    REFERENCED_COLUMN_NAME
FROM information_schema.KEY_COLUMN_USAGE 
WHERE TABLE_SCHEMA = DATABASE() 
AND TABLE_NAME = 't_file_upload'
AND REFERENCED_TABLE_NAME IS NOT NULL;
```

### 2. 完整查询（新增）
```sql
-- 7.4 查看表的所有约束类型信息
SELECT 
    tc.CONSTRAINT_NAME,
    tc.CONSTRAINT_TYPE,
    tc.TABLE_NAME,
    kcu.COLUMN_NAME,
    kcu.REFERENCED_TABLE_NAME,
    kcu.REFERENCED_COLUMN_NAME
FROM information_schema.TABLE_CONSTRAINTS tc
LEFT JOIN information_schema.KEY_COLUMN_USAGE kcu 
    ON tc.CONSTRAINT_NAME = kcu.CONSTRAINT_NAME 
    AND tc.TABLE_SCHEMA = kcu.TABLE_SCHEMA
WHERE tc.TABLE_SCHEMA = DATABASE() 
AND tc.TABLE_NAME = 't_file_upload';
```

### 常见的CONSTRAINT_TYPE值：
- `PRIMARY KEY` - 主键约束
- `FOREIGN KEY` - 外键约束
- `UNIQUE` - 唯一约束
- `CHECK` - 检查约束

## 技术要点

### 1. INFORMATION_SCHEMA使用
- `KEY_COLUMN_USAGE`: 包含键列的详细信息
- `TABLE_CONSTRAINTS`: 包含约束的类型信息
- 需要JOIN操作来获取完整信息

### 2. 查询优化
- 使用LEFT JOIN确保所有约束都被显示
- 通过TABLE_SCHEMA过滤确保只查询当前数据库
- 通过TABLE_NAME过滤确保只查询目标表

### 3. 兼容性考虑
- 适用于MySQL 5.7+版本
- 兼容Navicat等数据库管理工具
- 支持不同的MySQL配置
