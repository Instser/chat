## 📋 新增接口总览

### 1. 聊天管理接口

#### 1.1 获取聊天列表（支持分页）
- **路径**: `GET /api/chats`
- **参数**: `limit` (默认20), `offset` (默认0)
- **响应**: `Result<Map<String, Object>>`
- **数据结构**:
```json
{
  "code": 200,
  "message": "获取聊天列表成功",
  "data": {
    "chats": [...],
    "total": 100,
    "hasMore": true
  }
}
```

#### 1.2 AI自动生成聊天标题
- **路径**: `POST /api/chats/{chatId}/generate-title`
- **功能**: 基于聊天消息自动生成标题
- **响应**: `Result<Map<String, Object>>`
- **数据结构**:
```json
{
  "code": 200,
  "message": "标题生成成功",
  "data": {
    "chat": {...},
    "generatedTitle": "生成的标题"
  }
}
```

### 2. 消息管理接口

#### 2.1 获取聊天消息（支持分页）
- **路径**: `GET /api/chats/{chatId}/messages`
- **参数**: `limit` (默认50), `offset` (默认0)
- **响应**: `Result<Map<String, Object>>`
- **数据结构**:
```json
{
  "code": 200,
  "message": "获取消息成功",
  "data": {
    "messages": [...],
    "total": 50,
    "hasMore": false
  }
}
```

#### 2.2 更新消息内容
- **路径**: `PUT /api/chats/{chatId}/messages/{messageId}`
- **功能**: 编辑用户消息内容
- **请求体**: `{"content": "新的消息内容"}`
- **响应**: `Result<Void>`
- **安全控制**: 仅允许编辑用户角色的消息

#### 2.3 批量删除消息
- **路径**: `POST /api/messages/delete`
- **请求体**: `{"messageIds": ["1", "2"], "chatId": "chat123"}`
- **响应**: `Result<Map<String, Object>>`
- **数据结构**:
```json
{
  "code": 200,
  "message": "批量删除消息成功",
  "data": {
    "success": true,
    "deletedCount": 2
  }
}
```

#### 2.4 删除指定消息及之后的消息
- **路径**: `DELETE /api/messages/delete`
- **参数**: `messageId`, `chatId`
- **功能**: 删除指定消息及其之后的所有消息
- **响应**: `Result<Map<String, Object>>`

### 3. 文件上传接口

#### 3.1 文件上传
- **路径**: `POST /api/upload`
- **请求**: `multipart/form-data` 格式
- **参数**: `files` (文件数组)
- **响应**: `Result<Map<String, Object>>`
- **安全特性**:
  - 文件类型白名单验证
  - 文件大小限制（10MB）
  - 唯一文件名生成

#### 3.2 获取文件信息
- **路径**: `GET /api/files/{filename}`
- **响应**: `Result<Map<String, Object>>`
- **数据结构**:
```json
{
  "code": 200,
  "message": "获取文件信息成功",
  "data": {
    "name": "filename.jpg",
    "size": 1024,
    "url": "/uploads/filename.jpg",
    "lastModified": "2025-06-14T21:54:29"
  }
}
```

#### 3.3 删除文件
- **路径**: `DELETE /api/files/{filename}`
- **响应**: `Result<Void>`

### 4. AI聊天路径适配

#### 4.1 AI聊天接口（前端兼容）
- **路径**: `POST /api/chat`
- **功能**: 提供前端期望的聊天路径
- **响应**: SSE流式响应
- **参数适配**: 自动转换前端参数为后端格式

#### 4.2 AI聊天接口（EventSource）
- **路径**: `GET /api/chat`
- **参数**: `data` (JSON字符串)
- **响应**: SSE流式响应

## 🔧 技术实现特点

### 1. 响应格式一致性
- 所有接口均使用后端原有的 `Result<T>` 响应格式
- 保持与现有接口的一致性
- 不进行前端响应格式适配

### 2. 安全控制
- 用户权限验证
- 跨用户数据访问防护
- 文件类型和大小限制
- 消息编辑权限控制

### 3. 分页支持
- 统一的分页参数：`limit` 和 `offset`
- 完整的分页信息：`total` 和 `hasMore`
- 内存分页实现（适合中小规模数据）

### 4. 错误处理
- 统一的错误响应格式
- 详细的错误信息
- 适当的HTTP状态码（通过Result.code体现）
