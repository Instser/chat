```java
@Test
public void testConfigCompleteness() {
    // 测试配置完整时
    StripeConfig completeConfig = new StripeConfig();
    completeConfig.setPublicKey("pk_test_123");
    completeConfig.setSecretKey("sk_test_123");  
    completeConfig.setWebhookSecret("whsec_123");
    
    assertTrue(completeConfig.isConfigComplete());
    
    // 测试配置不完整时
    StripeConfig incompleteConfig = new StripeConfig();
    incompleteConfig.setPublicKey("pk_test_123");
    // 缺少secretKey和webhookSecret
    
    assertFalse(incompleteConfig.isConfigComplete());
}

@Test
public void testCurrencySupport() {
    StripeConfig config = new StripeConfig();
    
    // 测试支持的货币
    assertTrue(config.isCurrencySupported("usd"));
    assertTrue(config.isCurrencySupported("eur"));
    assertTrue(config.isCurrencySupported("gbp"));
    
    // 测试不支持的货币
    assertFalse(config.isCurrencySupported("xyz"));
    assertFalse(config.isCurrencySupported(null));
}
```

### 2. StripeService业务服务测试

#### **测试用例: 金额验证**
```java
@Test
public void testAmountValidation() {
    StripeService stripeService = new StripeService(mockStripeConfig);
    
    // 测试有效金额
    assertDoesNotThrow(() -> {
        stripeService.validateAmount(new BigDecimal("10.00"), "usd");
    });
    
    // 测试金额过小
    PaymentException exception = assertThrows(PaymentException.class, () -> {
        stripeService.validateAmount(new BigDecimal("0.10"), "usd");
    });
    assertTrue(exception.getMessage().contains("支付金额不能小于"));
    
    // 测试金额过大
    exception = assertThrows(PaymentException.class, () -> {
        stripeService.validateAmount(new BigDecimal("20000"), "usd");
    });
    assertTrue(exception.getMessage().contains("支付金额不能超过"));
}

@Test
public void testPaymentIntentStatusConversion() {
    StripeService stripeService = new StripeService(mockStripeConfig);
    
    // 测试成功状态转换
    assertEquals(Integer.valueOf(1), stripeService.convertPaymentIntentStatus("succeeded"));
    
    // 测试取消状态转换
    assertEquals(Integer.valueOf(2), stripeService.convertPaymentIntentStatus("canceled"));
    
    // 测试处理中状态转换
    assertEquals(Integer.valueOf(0), stripeService.convertPaymentIntentStatus("requires_payment_method"));
    
    // 测试未知状态转换
    assertEquals(Integer.valueOf(0), stripeService.convertPaymentIntentStatus("unknown_status"));
}
```

## 🎭 端到端测试

### 1. 完整支付流程E2E测试

#### **测试步骤**
```javascript
// 使用前端JavaScript模拟完整支付流程

// 1. 创建支付订单
const orderResponse = await fetch('/api/payment/create', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + jwtToken
  },
  body: JSON.stringify({
    packageId: 1,
    paymentMethod: 'stripe',
    currency: 'USD'
  })
});

const orderData = await orderResponse.json();
const { client_secret, publishable_key } = orderData.data;

// 2. 初始化Stripe
const stripe = await loadStripe(publishable_key);

// 3. 确认支付
const { error, paymentIntent } = await stripe.confirmCardPayment(client_secret, {
  payment_method: {
    card: {
      number: '4242424242424242', // Stripe测试卡号
      exp_month: 12,
      exp_year: 2030,
      cvc: '123'
    }
  }
});

if (error) {
  console.error('支付失败:', error);
} else if (paymentIntent.status === 'succeeded') {
  console.log('支付成功:', paymentIntent.id);
  
  // 4. 验证订单状态
  const statusResponse = await fetch(`/api/payment/status/${orderData.data.orderNo}`);
  const statusData = await statusResponse.json();
  
  console.log('订单状态:', statusData.data.message);
}
```

## 🚨 常见问题与解决方案

### 1. Stripe配置问题

**问题**: Stripe配置初始化失败
```
ERROR: Stripe配置不完整，跳过初始化
```

**解决方案**:
1. 检查环境变量是否正确设置
2. 验证Stripe密钥格式
3. 确认Webhook密钥配置

### 2. 支付创建失败

**问题**: PaymentIntent创建异常
```
ERROR: 创建Stripe PaymentIntent失败，订单: ORD_xxx
```

**解决方案**:
1. 检查Stripe账户状态
2. 验证API密钥权限
3. 检查金额和货币格式
4. 查看Stripe Dashboard日志

### 3. Webhook接收问题

**问题**: Webhook事件处理失败
```
ERROR: Stripe Webhook签名验证失败
```

**解决方案**:
1. 验证Webhook端点配置
2. 检查签名密钥正确性
3. 确认事件类型监听设置
4. 测试端点可访问性

### 4. 订单状态同步异常

**问题**: 支付成功但订单状态未更新
```
WARN: 订单状态同步失败，订单号: ORD_xxx
```

**解决方案**:
1. 检查数据库连接
2. 验证事务处理逻辑
3. 查看订单状态流转日志
4. 手动触发状态同步
