## 功能概述

本项目已成功实现了聊天请求中的提示词功能，支持两种模式：
1. **默认模式** (deepThinking=false): 使用标准的"To Use AI"身份提示词
2. **深度思考模式** (deepThinking=true): 使用包含详细思考协议的深度思考提示词

## 实现细节

### 1. 提示词常量类
- **文件位置**: `src/main/java/com/instser/chat/constants/PromptConstants.java`
- **包含内容**:
  - `DEFAULT_SYSTEM_PROMPT`: 默认系统提示词
  - `DEEP_THINKING_PROMPT`: 深度思考提示词

### 2. API接口修改
- **POST接口**: `/api/chat` (主要使用)
- **GET接口**: `/api/chat` (EventSource方式)
- **新增参数**: `deepThinking` (boolean/string/number类型)

### 3. 参数处理逻辑
```java
// 支持多种类型的deepThinking参数
boolean isDeepThink = false;
if (deepThinkingObj != null) {
    if (deepThinkingObj instanceof Boolean) {
        isDeepThink = (Boolean) deepThinkingObj;
    } else if (deepThinkingObj instanceof String) {
        isDeepThink = "true".equalsIgnoreCase((String) deepThinkingObj) || "1".equals(deepThinkingObj);
    } else if (deepThinkingObj instanceof Number) {
        isDeepThink = ((Number) deepThinkingObj).intValue() == 1;
    }
}
```

## 预期结果

### 默认模式预期行为
- AI会以"To Use AI"身份回应
- 回答风格专业、清晰、有帮助
- 不会显示思考过程
- 回答相对简洁直接

### 深度思考模式预期行为
- AI会显示详细的思考过程（在thinking代码块中）
- 思考过程包含问题分析、多角度考虑、验证等步骤
- 最终回答更加深入和全面
- 回答质量更高，考虑更周全

## 注意事项

1. **认证要求**: 所有请求都需要有效的JWT Token
2. **参数兼容性**: deepThinking参数支持boolean、string、number多种类型
3. **消息格式**: 系统会自动在用户消息前添加系统提示词
4. **性能影响**: 深度思考模式可能会产生更长的响应时间
5. **Token消耗**: 深度思考模式会消耗更多的AI模型Token

## 故障排除

### 常见问题
1. **提示词未生效**: 检查deepThinking参数是否正确传递
2. **认证失败**: 确认JWT Token有效性
3. **响应格式错误**: 检查Content-Type和Accept头部设置
4. **超时问题**: 深度思考模式响应时间较长，可能需要调整超时设置

### 调试方法
1. 查看应用日志中的参数解析信息
2. 检查消息列表中是否包含系统提示词
3. 验证AI响应中是否包含预期的身份标识
4. 对比两种模式的响应差异

---

**测试建议**: 建议先使用简单的问题测试两种模式的差异，然后逐步使用复杂问题验证深度思考模式的效果。
