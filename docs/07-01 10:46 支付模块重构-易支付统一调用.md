# 07-01 10:46 支付模块重构-易支付统一调用

## 修改概述

根据用户需求，对支付模块进行重构，将支付方式从 `alipay`、`yipai` 改为 `alipay` 和 `wechatpay`，并统一通过易支付调用支付宝和微信支付，暂时不调用现有的不完整的alipay模块。

## 主要变更

### 1. 新增支付策略类

#### YiPayAlipayStrategy.java
- **路径**: `src/main/java/com/instser/chat/strategy/impl/YiPayAlipayStrategy.java`
- **功能**: 通过易支付调用支付宝支付
- **支付方式标识**: `alipay`
- **特点**: 
  - 使用易支付的 `type=alipay` 参数
  - 完整的回调处理和状态查询
  - 包含内部类 `YiPayCallbackData` 和 `YiPayQueryResult`

#### YiPayWechatStrategy.java
- **路径**: `src/main/java/com/instser/chat/strategy/impl/YiPayWechatStrategy.java`
- **功能**: 通过易支付调用微信支付
- **支付方式标识**: `wechatpay`
- **特点**:
  - 使用易支付的 `type=wxpay` 参数
  - 完整的回调处理和状态查询
  - 包含内部类 `YiPayCallbackData` 和 `YiPayQueryResult`

### 2. 禁用原有支付宝策略

#### AlipayStrategy.java
- **修改**: 注释掉 `@Component` 注解
- **原因**: 用户要求暂时不调用不完整的alipay模块
- **状态**: 保留代码但不被Spring容器管理

### 3. 更新服务层

#### PaymentService.java
- **新增方法**:
  - `handleAlipayNotify(Map<String, String> notifyParams)` - 处理支付宝回调
  - `handleWechatPayNotify(Map<String, String> notifyParams)` - 处理微信支付回调

#### PaymentServiceImpl.java
- **修改支付方式显示名称**:
  - `alipay` -> "支付宝"
  - `wechatpay` -> "微信支付" (原来是 `wechat`)
  - `yipay` -> "易支付"
- **新增回调处理实现**:
  - `handleAlipayNotify()` - 调用支付宝策略处理回调
  - `handleWechatPayNotify()` - 调用微信支付策略处理回调

### 4. 更新控制器层

#### PaymentController.java
- **修改支付宝回调**: `/alipay/notify`
  - 改为接收表单参数而非JSON请求体
  - 使用易支付IP白名单验证
  - 调用新的 `handleAlipayNotify()` 方法
- **新增微信支付回调**: `/wechatpay/notify`
  - 接收表单参数
  - 使用易支付IP白名单验证
  - 调用新的 `handleWechatPayNotify()` 方法

## 技术实现细节

### 支付URL构建
两个新策略都使用相同的易支付URL构建逻辑：
```java
// 支付宝
params.put("type", "alipay");

// 微信支付
params.put("type", "wxpay");
```

### 回调处理
- 统一使用URL参数格式解析回调数据
- 使用MD5签名验证
- 支持状态映射：
  - `TRADE_SUCCESS`/`SUCCESS` -> 1 (已支付)
  - `TRADE_CLOSED`/`CLOSED`/`FAILED` -> 2 (已取消)
  - `TRADE_REFUND`/`REFUND` -> 3 (已退款)
  - 其他 -> 0 (未支付/处理中)

### 状态查询
- 支持API查询最新支付状态
- 包含重试机制（最多3次，指数退避）
- 自动同步数据库状态

## 前端影响

### 支付方式变更
前端获取套餐支付信息时，返回的支付方式将变为：
```json
{
  "paymentMethods": [
    {
      "id": "alipay",
      "name": "支付宝",
      "type": "alipay",
      "available": true
    },
    {
      "id": "wechatpay", 
      "name": "微信支付",
      "type": "wechatpay",
      "available": true
    }
  ]
}
```

### API兼容性
- 创建支付订单API保持不变
- 支付状态查询API保持不变
- 回调URL需要更新（如果前端有相关逻辑）

## 配置要求

### 易支付配置
确保 `application.yml` 中的易支付配置完整：
```yaml
yipay:
  pid: "商户ID"
  key: "商户密钥"
  url: "易支付网关地址"
  notify-url: "回调通知URL"
  return-url: "支付成功跳转URL"
  default-type: "alipay"
```

### IP白名单
回调处理使用易支付的IP白名单验证，确保安全配置正确。
