## 问题背景

在定时任务运行日志中发现以下问题：
```
2025-06-30 14:53:02.619 [pool-3-thread-1] DEBUG c.i.c.s.OptimizedScheduledTaskService - getOrdersForBatchProcessing方法尚未实现，返回空列表
```

OptimizedScheduledTaskService中的`getOrdersForBatchProcessing`方法尚未实现，导致定时任务无法正常处理订单。

## 实施内容

### 1. OrderService接口扩展

在`OrderService`接口中添加了以下新方法：

```java
/**
 * 获取需要批量处理的订单（包括过期订单和需要状态同步的订单）
 */
List<UserOrder> getOrdersForBatchProcessing();

/**
 * 获取过期的未支付订单
 */
List<UserOrder> getExpiredOrders();

/**
 * 获取需要状态同步的订单（长时间未更新的待支付订单）
 */
List<UserOrder> getOrdersNeedingStatusSync(int maxCount);
```

### 2. UserOrderDao查询方法实现

在`UserOrderDao`中添加了优化的批量查询方法：

```java
@Select("(" +
        "SELECT * FROM t_user_order WHERE payment_status = 0 AND expire_time < NOW() AND deleted = 0 " +
        "ORDER BY expire_time ASC LIMIT 50" +
        ") UNION ALL (" +
        "SELECT * FROM t_user_order WHERE payment_status = 0 AND expire_time > NOW() " +
        "AND update_time < DATE_SUB(NOW(), INTERVAL 1 HOUR) AND deleted = 0 " +
        "ORDER BY update_time ASC LIMIT 30" +
        ") ORDER BY expire_time ASC, update_time ASC")
List<UserOrder> selectOrdersForBatchProcessing();
```

**查询优化特点**：
- 使用UNION ALL合并过期订单和需要状态同步的订单
- 限制过期订单最多50个，状态同步订单最多30个
- 按时间排序，优先处理最早过期的订单

### 3. OrderServiceImpl实现

在`OrderServiceImpl`中实现了所有新增方法：

```java
@Override
public List<UserOrder> getOrdersForBatchProcessing() {
    try {
        log.debug("获取需要批量处理的订单");
        return baseMapper.selectOrdersForBatchProcessing();
    } catch (Exception e) {
        log.error("获取批量处理订单异常", e);
        return List.of();
    }
}
```

**实现特点**：
- 完整的异常处理机制
- 详细的日志记录
- 失败时返回空列表，不影响系统稳定性

### 4. 定时任务服务更新

更新了`OptimizedScheduledTaskService`中的实现：

```java
private List<UserOrder> getOrdersForProcessing() {
    try {
        // 查询所有需要处理的订单：过期的、长时间未支付的等
        return orderService.getOrdersForBatchProcessing();
    } catch (Exception e) {
        log.error("获取待处理订单异常", e);
        return List.of();
    }
}
```

同时更新了`OrderExpirationServiceImpl`：

```java
@Override
public List<UserOrder> getExpiredOrders() {
    try {
        // 查询过期时间小于当前时间且状态为未支付的订单

        return List.of();
    }
}
```
