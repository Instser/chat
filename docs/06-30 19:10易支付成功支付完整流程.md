# 易支付成功支付完整流程详解

**创建时间**: 2025年06月30日 19:10  
**版本**: v1.0  

## 概述

本文档详细描述一个完整的易支付成功支付流程中前后端的具体行为，包括用户操作、前端处理、后端逻辑、第三方回调等各个环节。

## 完整流程时序图

```
用户 -> 前端 -> 后端 -> 易支付平台 -> 后端回调 -> 套餐激活 -> 前端通知
```

```typescript
      const response = await api.package.getPaymentStatus(orderNo);
```

**PaymentController.yipayNotify()**:

```java
@PostMapping("/yipay/notify")
public ResponseEntity<String> yipayNotify(HttpServletRequest request) {
    // 1. 验证回调IP
    if (!paymentSecurityEnhancer.validateCallbackIP(request, "yipay")) {
        return ResponseEntity.status(HttpStatus.FORBIDDEN).body("IP not allowed");
    }
    
    // 2. 获取所有参数
    Map<String, String> notifyParams = new HashMap<>();
    request.getParameterMap().forEach((key, values) -> {
        if (values != null && values.length > 0) {
            notifyParams.put(key, values[0]);
        }
    });
    
    // 参数示例:
    // {
    //   "pid": "1674",
    //   "trade_no": "YP20250630191500789",
    //   "out_trade_no": "JY202506301910001234",
    //   "type": "alipay",
    //   "name": "套餐购买",
    //   "money": "68.00",
    //   "trade_status": "TRADE_SUCCESS",
    //   "sign": "md5_signature_here"
    // }
    
    // 3. 处理易支付回调
    boolean success = paymentService.handleYiPayNotify(notifyParams);
    
    if (success) {
        return ResponseEntity.ok("success");
    } else {
        return ResponseEntity.ok("fail");
    }
}
```

**PaymentServiceImpl.handleYiPayNotify()**:
```java
public boolean handleYiPayNotify(Map<String, String> notifyParams) {
    // 1. 解析回调参数
    String outTradeNo = notifyParams.get("out_trade_no");    // "JY202506301910001234"
    String tradeNo = notifyParams.get("trade_no");           // "YP20250630191500789"
    String tradeStatus = notifyParams.get("trade_status");   // "TRADE_SUCCESS"
    String money = notifyParams.get("money");                // "68.00"
    String sign = notifyParams.get("sign");                  // "md5_signature_here"
    
    // 2. 验证签名
    if (!verifyYiPaySignature(notifyParams)) {
        log.error("易支付回调签名验证失败");
        return false;
    }
    
    // 3. 查找订单
    UserOrder order = orderService.getOrderByOrderNo(outTradeNo);
    if (order == null) {
        log.error("未找到对应订单，订单号: {}", outTradeNo);
        return false;
    }
    
    // 4. 检查订单状态
    if (orderService.isOrderExpired(outTradeNo)) {
        log.warn("订单已过期，拒绝处理回调");
        return false;
    }
    
    // 5. 解析支付状态
    Integer newStatus = parseYiPayStatus(tradeStatus); // TRADE_SUCCESS -> 1
    
    // 6. 更新订单状态
    boolean updated = orderService.updatePaymentStatus(outTradeNo, newStatus, tradeNo);
    
    if (updated) {
        // 7. 如果支付成功，激活套餐
        if (newStatus == 1) {
            try {
                boolean activationSuccess = packageActivationService.activatePackageAfterPayment(outTradeNo);
                if (activationSuccess) {
                    log.info("易支付成功后套餐激活成功，订单号: {}", outTradeNo);
                } else {
                    log.error("易支付成功后套餐激活失败，订单号: {}", outTradeNo);
                }
            } catch (Exception e) {
                log.error("易支付成功后套餐激活异常，订单号: {}", outTradeNo, e);
            }
        }
        
        // 8. 释放用户支付会话锁
        redisPaymentSecurityService.releasePaymentSession(order.getUserId());
        
        return true;
    }
    
    return false;
}
```

```java
public boolean activatePackage(Long userId, Long packageId, Integer validityDays, Integer totalChatCount) {
    // 1. 计算过期时间
    LocalDateTime expireTime = LocalDateTime.now().plusDays(validityDays);
    // expireTime = 2025-07-30T19:15:00 (30天后)
    
    // 2. 更新用户账户
    int updated = baseMapper.insertOrUpdateAccount(
        userId,          // 12345L
        packageId,       // 3L
        expireTime,      // 2025-07-30T19:15:00
        totalChatCount   // 1000
    );
    
    // SQL执行:
    // INSERT INTO t_user_account (user_id, package_id, expire_time, chat_count_remaining, created_time, updated_time)
    // VALUES (12345, 3, '2025-07-30 19:15:00', 1000, NOW(), NOW())
    // ON DUPLICATE KEY UPDATE
    //   package_id = VALUES(package_id),
    //   expire_time = VALUES(expire_time),
    //   chat_count_remaining = VALUES(chat_count_remaining),

    if (updated > 0) {
```

## 关键技术点

### 1. 安全机制
- **IP白名单验证**: 验证回调请求来源
- **签名验证**: 验证回调数据完整性
- **防重放攻击**: 使用requestId和Redis锁
- **订单过期检查**: 防止过期订单被恶意激活

### 2. 并发控制
- **分布式锁**: 订单状态更新使用分布式锁
- **支付会话锁**: 防止用户并发支付
- **事务管理**: 套餐激活使用事务保证一致性

### 3. 容错机制
- **重试机制**: 支付状态查询支持重试
- **异常处理**: 各环节都有完善的异常处理
- **日志记录**: 详细的操作日志便于问题排查

### 4. 状态管理
- **状态码统一**: 0=待支付, 1=已支付, 2=已取消, 3=已退款
- **状态流转验证**: 确保状态变更的合法性
- **幂等性保证**: 重复回调不会重复处理

## 总结

整个易支付成功支付流程涉及前端、后端、第三方支付平台的协调配合，通过完善的安全机制、并发控制和容错处理，确保支付流程的可靠性和用户体验。
