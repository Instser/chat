# 图片解析器使用示例

## 📋 概述

图片解析器是聊天系统文档解析功能的扩展，支持将用户上传的图片文件通过AI服务进行智能分析，生成JSON格式的图片描述内容。

## 🚀 快速开始

### 1. 支持的图片格式

- **PNG**: image/png
- **JPEG**: image/jpeg, image/jpg  
- **GIF**: image/gif
- **WebP**: image/webp
- **BMP**: image/bmp
- **SVG**: image/svg+xml

### 2. 自动检测和处理

当用户上传图片文件时，系统会自动：

1. **魔数检测**: 检测文件的真实类型
2. **解析器分配**: 自动分配ImageDocumentParser
3. **Base64编码**: 将图片转换为Base64格式
4. **AI分析**: 调用AI服务进行图片内容分析
5. **结果存储**: 将AI分析结果存储到数据库

## 💻 代码示例

### 文件上传处理

```java
// 用户上传图片文件
@PostMapping("/upload")
public Result<FileUploadResponseVO> uploadFile(@RequestParam("file") MultipartFile file) {
    // 1. 系统自动检测文件类型
    String detectedType = MagicNumberDetector.detectFileType(file);
    // 结果: "image/png"
    
    // 2. 判断是否为图片文件
    boolean isImage = MagicNumberDetector.isImageFile(detectedType);
    // 结果: true
    
    // 3. 工厂模式获取解析器
    DocumentParser parser = DocumentParserFactory.getParser(detectedType);
    // 结果: ImageDocumentParser实例
    
    // 4. 执行图片解析
    String aiResult = parser.parseDocument(fileBytes, fileName, detectedType);
    // 结果: AI返回的JSON格式图片描述
    
    return Result.success(response);
}
```

### 手动使用解析器

```java
// 直接使用图片解析器
ImageDocumentParser parser = new ImageDocumentParser();

// 解析图片文件
byte[] imageBytes = Files.readAllBytes(imagePath);
String result = parser.parseDocument(imageBytes, "example.png", "image/png");

System.out.println("AI分析结果: " + result);
```

### Base64工具使用

```java
// Base64编码
byte[] imageBytes = Files.readAllBytes(imagePath);
String base64 = Base64Util.encodeToString(imageBytes);

// 生成data URL
String dataUrl = Base64Util.encodeImageToDataUrl(imageBytes, "image/png");
// 结果: "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."

// 从data URL提取Base64数据
String base64Data = Base64Util.extractBase64FromDataUrl(dataUrl);

// Base64解码
byte[] decodedBytes = Base64Util.decodeFromString(base64Data);
```

## 🔍 聊天中使用

### 文件附加到消息

当用户在聊天中上传图片时：

1. **图片上传**: 用户上传图片文件
2. **AI解析**: 系统自动调用AI服务分析图片内容
3. **内容附加**: 解析结果附加到用户消息中
4. **AI理解**: AI可以基于图片描述进行对话

### 消息格式

```
用户原始消息: "请帮我分析这张图片"

实际发送给AI的消息: "请帮我分析这张图片。以下是文件内容：[{"image.png":"这是一张包含蓝天白云的风景照片..."}]"
```

## ⚠️ 注意事项

### 1. 文件大小限制

- 图片文件大小限制为5MB
- 超过限制的文件会被拒绝上传

### 2. AI服务依赖

- 图片解析依赖外部AI服务
- AI服务不可用时解析会失败
- 建议实现降级处理机制

### 3. 网络要求

- 需要能够访问AI服务地址
- 建议配置合适的超时时间
- 考虑网络异常的重试机制

### 4. 成本考虑

- AI服务调用可能产生费用
- 建议监控API调用次数
- 考虑实现缓存机制避免重复分析

## 🛠️ 故障排除

### 常见问题

1. **图片解析失败**
   - 检查AI服务是否可用
   - 验证API密钥是否正确
   - 确认网络连接正常

2. **Base64编码错误**
   - 检查图片文件是否损坏
   - 验证文件类型是否支持
   - 确认文件大小在限制范围内

3. **响应格式异常**
   - 检查AI服务返回格式
   - 验证JSON解析逻辑
   - 查看详细错误日志
