## 测试概述

### 测试范围
本测试套件覆盖了AI聊天系统中所有错误处理场景，确保：
1. 错误消息统一返回"Request failed. Please try again later."
2. 错误响应正确保存到数据库
3. 响应格式符合Vercel AI SDK规范
4. 用户体验一致性

### 测试架构
```
测试层级
├── 单元测试 (ChatErrorHandlingTest)
│   ├── 服务层错误处理逻辑
│   ├── 参数验证
│   └── 错误响应保存
├── 控制器测试 (ChatApiControllerErrorTest)
│   ├── 参数验证错误
│   ├── 响应格式验证
│   └── HTTP头设置验证
└── 集成测试 (ChatErrorHandlingIntegrationTest)
    ├── 完整错误处理流程
    ├── 数据库保存验证
    └── 多接口一致性验证
```

## 测试数据验证

### 1. 数据库查询验证
```sql
-- 查看测试期间的错误响应记录
SELECT 
    id, session_id, role, content, user_id, model_id, create_time
FROM t_chat_message 
WHERE role = 'assistant' 
    AND content = 'Request failed. Please try again later.'
    AND create_time >= DATE_SUB(NOW(), INTERVAL 1 HOUR)
ORDER BY create_time DESC;

-- 验证用户消息和AI响应的配对
SELECT 
    session_id,
    COUNT(*) as message_count,
    SUM(CASE WHEN role = 'user' THEN 1 ELSE 0 END) as user_messages,
    SUM(CASE WHEN role = 'assistant' THEN 1 ELSE 0 END) as ai_messages
FROM t_chat_message 
WHERE create_time >= DATE_SUB(NOW(), INTERVAL 1 HOUR)
GROUP BY session_id;
```
