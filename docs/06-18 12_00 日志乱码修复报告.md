## 问题描述

### 问题现象
日志文件中的中文字符显示为乱码，如：
```
��ʼִ�й��ڶ�����������
��ʼִ�ж���״̬ͬ�����
Ԫ�����ݱ����ɸ�ʽ��ȷ���ַ����ݻ�����ɡ�
```

### 问题原因
1. **字符编码不匹配**：Windows环境下默认使用GBK编码
2. **应用程序使用UTF-8**：Java应用程序内部使用UTF-8编码
3. **日志配置缺失编码设置**：原有日志配置没有明确指定字符编码

### 影响范围
- 所有包含中文的日志信息无法正常阅读
- 错误信息难以理解和调试
- 运维监控困难

## 修复方案

### 🔧 核心修复

#### 1. 创建logback-spring.xml配置文件
```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <!-- 控制台输出 -->
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
            <charset>UTF-8</charset>  <!-- 关键：指定UTF-8编码 -->
        </encoder>
    </appender>
    
    <!-- 文件输出 -->
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <file>${LOG_HOME}/${APP_NAME}.log</file>
        <encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{50} - %msg%n</pattern>
            <charset>UTF-8</charset>  <!-- 关键：指定UTF-8编码 -->
        </encoder>
        <!-- ... 其他配置 -->
    </appender>
</configuration>
```

#### 2. 修改application.yml配置
```yaml
# 修改前：详细的日志配置
logging:
  level:
    com.instser.chat: debug
    root: info
  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"
    file: "%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{50} - %msg%n"
  file:
    name: logs/jinyu-chat.log

# 修改后：使用logback-spring.xml
logging:
  config: classpath:logback-spring.xml
```

## 技术实现

### 🎯 关键配置点

#### 1. 字符编码设置
```xml
<encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
    <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{50} - %msg%n</pattern>
    <charset>UTF-8</charset>  <!-- 明确指定UTF-8编码 -->
</encoder>
```

#### 2. 多环境支持
```xml
<!-- 开发环境配置 -->
<springProfile name="dev,default">
    <logger name="com.instser.chat" level="DEBUG"/>
</springProfile>

<!-- 生产环境配置 -->
<springProfile name="prod">
    <logger name="com.instser.chat" level="INFO"/>
</springProfile>
```

#### 3. 异步日志配置
```xml
<appender name="ASYNC_FILE" class="ch.qos.logback.classic.AsyncAppender">
    <discardingThreshold>0</discardingThreshold>
    <queueSize>512</queueSize>
    <appender-ref ref="FILE"/>
</appender>
```

#### 4. 日志分离
```xml
<!-- 错误日志单独输出 -->
<appender name="ERROR_FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
    <filter class="ch.qos.logback.classic.filter.LevelFilter">
        <level>ERROR</level>
        <onMatch>ACCEPT</onMatch>
        <onMismatch>DENY</onMismatch>
    </filter>
</appender>
```

### 🚀 新增功能

#### 1. 日志文件滚动策略
- **按大小滚动**：单个文件最大100MB
- **按时间滚动**：每天生成新文件
- **历史保留**：保留30天的日志文件
- **总大小限制**：最大3GB

#### 2. 错误日志分离
- **独立文件**：错误日志单独保存到 `jinyu-chat-error.log`
- **长期保留**：错误日志保留60天
- **便于监控**：方便运维人员监控系统错误

#### 3. 异步日志处理
- **性能优化**：使用异步appender提高性能
- **队列配置**：合理设置队列大小
- **不丢失日志**：设置discardingThreshold为0

#### 4. 多环境配置
- **开发环境**：DEBUG级别，控制台+文件输出
- **生产环境**：INFO级别，仅文件输出
- **测试环境**：DEBUG级别，控制台+文件输出
