# 07-29 20:35 易支付模块统一回调修复

## 修改概述

根据用户反馈，易支付平台发送GET请求到回调地址时返回405错误，需要修改支付模块逻辑：
1. 统一易支付微信和易支付支付宝的回调处理
2. 支持GET和POST两种请求方法
3. 移除单独的易支付策略，只保留易支付微信和易支付支付宝策略

## 问题分析

### 原始错误信息
```
https://api.example.com/api/payment/yipay/notify?pid=1674&trade_no=2025072920035764299&out_trade_no=JY202507292003477790&type=wxpay&name=product&money=3.09&trade_status=TRADE_SUCCESS&sign=d673d372c11a4385a49f0f86d03e8000&sign_type=MD5

返回: {"code":405,"message":"不支持的请求方法: GET","data":null,"timestamp":1753790973249}
```

### 问题原因
1. 易支付平台发送的是GET请求，但原回调接口只支持POST
2. 需要根据type参数区分微信支付(wxpay)和支付宝(alipay)

## 主要变更

### 1. 修改PaymentController.java

#### 统一易支付回调接口
- **路径**: `/payment/yipay/notify`
- **方法**: 支持GET和POST请求
- **功能**: 根据type参数自动路由到对应的处理方法

```java
@RequestMapping(value = "/yipay/notify", method = {RequestMethod.GET, RequestMethod.POST})
public ResponseEntity<String> yipayNotify(HttpServletRequest request) {
    // 根据type参数判断是微信还是支付宝支付
    String paymentType = notifyParams.get("type");

    if ("wxpay".equals(paymentType)) {
        // 处理微信支付回调
        success = paymentService.handleWechatPayNotify(notifyParams);
    } else if ("alipay".equals(paymentType)) {
        // 处理支付宝支付回调
        success = paymentService.handleAlipayNotify(notifyParams);
    }
}
```

#### 删除冗余回调接口
- **删除**: `/payment/alipay/notify` 接口（alipayNotify方法）
- **删除**: `/payment/wechatpay/notify` 接口（wechatpayNotify方法）
- **原因**: 统一使用 `/payment/yipay/notify` 处理所有易支付回调

### 2. 禁用YiPayStrategy.java

- **修改**: 添加@deprecated注解，注释掉@Component
- **原因**: 现在使用YiPayWechatStrategy和YiPayAlipayStrategy替代
- **影响**: 不再注册"yipay"支付方式，只保留"alipay"和"wechatpay"

### 3. 保持现有策略配置

- **YiPayAlipayStrategy**: 支付方式标识为"alipay"，type参数为"alipay"
- **YiPayWechatStrategy**: 支付方式标识为"wechatpay"，type参数为"wxpay"
- **回调地址**: 两者都使用统一的`https://api.example.com/api/payment/yipay/notify`

## 技术实现细节

### 回调处理流程
1. 易支付平台发送GET/POST请求到统一回调地址
2. 解析请求参数，获取type字段
3. 根据type值路由到对应的处理方法：
   - `type=wxpay` → `handleWechatPayNotify()`
   - `type=alipay` → `handleAlipayNotify()`
4. 各自的处理方法调用对应的策略类进行处理

### 安全验证
- IP白名单验证（易支付）
- MD5签名验证
- 防重放攻击检查
- 订单状态验证
