### 2. 重试机制验证

#### 主聊天重试流程
```
用户发送消息 → AI返回错误消息 → 系统检测错误 → 抛出ChatRetryException 
→ executeAiStreamResponse捕获 → 等待1秒重试 → 失败继续重试 → 最多3次
```

#### 续写重试流程
```
AI响应截断 → 触发续写 → 续写返回错误 → cleanAllTagsOnce检测 
→ 抛出ChatRetryException → continueAiResponse捕获 → 重试续写
```

#### 重试策略
- **最大重试次数**: 3次 ✅
- **等待时间**: 递增（1s, 2s, 3s）✅
- **失败处理**: 返回错误响应 ✅
