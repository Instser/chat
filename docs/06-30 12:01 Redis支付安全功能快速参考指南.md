## 🚀 快速开始

### 1. 依赖配置

```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
<dependency>
    <groupId>org.apache.commons</groupId>
    <artifactId>commons-pool2</artifactId>
</dependency>
<dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson-spring-boot-starter</artifactId>
    <version>3.24.3</version>
</dependency>
```

### 2. 基础配置

```yaml
# application.yml
spring:
  redis:
    host: localhost
    port: 6379
    timeout: 3000ms
    lettuce:
      pool:
        max-active: 20
        max-idle: 10

payment:
  security:
    frequency:
      max-count: 5      # 10分钟内最多5次支付
      time-window: 10   # 时间窗口（分钟）
    callback:
      expire-time: 60   # 回调过期时间（分钟）
    suspicious:
      threshold: 3      # 可疑行为阈值
      expire-days: 7    # 记录保存天数
```

## 🔧 核心功能使用

### 1. 支付频率限制

```java
// 检查用户支付频率
@Autowired
private RedisPaymentSecurityService securityService;

public boolean validatePayment(Long userId) {
    // 检查支付频率（10分钟内最多5次）
    if (!securityService.checkPaymentFrequency(userId)) {
        throw new PaymentException("支付频率过高，请稍后再试");
    }
    return true;
}
```

**Redis数据结构**:
```
Key: payment:freq:{userId}:{timeWindow}
Value: 支付次数
TTL: 10分钟
```

### 2. 防重放攻击

```java
// 支付回调处理
public boolean handlePaymentCallback(String clientId, String requestTime, String signature) {
    // 生成唯一回调ID
    String callbackId = generateCallbackId(clientId, requestTime, signature);
    
    // 检查是否重放攻击
    if (securityService.isCallbackProcessed(callbackId)) {
        log.warn("检测到重放攻击，回调ID: {}", callbackId);
        return false;
    }
    
    // 处理回调逻辑...
    return true;
}
```

**Redis数据结构**:
```
Key: payment:callback:{callbackId}
Value: 处理时间戳
TTL: 60分钟
```

### 3. 可疑行为记录

```java
// 记录可疑行为
public void handleSuspiciousActivity(Long userId, String reason) {
    // 记录可疑行为
    securityService.recordSuspiciousBehavior(userId, reason);
    
    // 检查是否超过阈值
    if (!securityService.checkSuspiciousBehavior(userId)) {
        // 用户可疑行为过多，采取安全措施
        handleHighRiskUser(userId);
    }
}
```

**Redis数据结构**:
```
Key: payment:suspicious:{userId}
Value: List["行为:时间戳", "行为:时间戳", ...]
TTL: 7天
```

### 4. 支付会话管理

```java
// 支付前获取会话锁
public void initiatePayment(PaymentRequestVO request) {
    Long userId = request.getUserId();
    
    // 检查是否有活跃支付会话
    if (securityService.hasActivePaymentSession(userId)) {
        throw new PaymentException("当前有正在进行的支付，请稍后再试");
    }
    
    // 获取支付会话锁
    if (!securityService.acquirePaymentSession(userId)) {
        throw new PaymentException("支付会话获取失败，请稍后再试");
    }
    
    try {
        // 执行支付逻辑...
    } finally {
        // 确保释放会话锁
        securityService.releasePaymentSession(userId);
    }
}
```

**Redis数据结构**:
```
Key: payment:session:{userId}
Value: "locked"
TTL: 30分钟
```

### 5. 分布式锁

```java
// 订单状态更新保护
@Autowired
private RedisDistributedLockService lockService;

public boolean updateOrderStatus(String orderNo, Integer status) {
    return lockService.executeOrderLock(orderNo, () -> {
        // 受保护的订单状态更新逻辑
        return orderMapper.updateStatus(orderNo, status) > 0;
    });
}

// 用户余额更新保护
public boolean updateUserBalance(Long userId, BigDecimal amount) {
    return lockService.executeUserPaymentLock(userId, () -> {
        // 受保护的余额更新逻辑
        return userMapper.updateBalance(userId, amount) > 0;
    });
}
```

## 📊 监控和调试

### 1. Redis命令监控

```bash

# 查看频率限制

# 查看可疑行为

# 查看支付会话

```

### 2. 应用监控

```java
// 添加监控日志
@Component
public class PaymentSecurityLogger {
    
    public void logFrequencyCheck(Long userId, int currentCount, boolean allowed) {
        if (allowed) {
            log.info("支付频率检查通过 - 用户: {}, 当前次数: {}", userId, currentCount);
        } else {
            log.warn("支付频率超限 - 用户: {}, 当前次数: {}", userId, currentCount);
        }
    }
    
    public void logSuspiciousBehavior(Long userId, String reason, int totalCount) {
        log.warn("可疑行为记录 - 用户: {}, 行为: {}, 总次数: {}", userId, reason, totalCount);
    }
}
```

## 🛠️ 常用工具方法

### 1. 批量清理

```java
// 清理用户的所有安全数据
public void clearUserSecurityData(Long userId) {
    // 清理频率限制
    Set<String> freqKeys = redisTemplate.keys("payment:freq:" + userId + ":*");
    if (freqKeys != null && !freqKeys.isEmpty()) {
        redisTemplate.delete(freqKeys);
    }
    
    // 清理可疑行为
    redisTemplate.delete("payment:suspicious:" + userId);
    
    // 清理支付会话
    redisTemplate.delete("payment:session:" + userId);
}
```

### 2. 健康检查

```java
// Redis连接健康检查
@Component
public class RedisHealthChecker {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    public boolean isRedisHealthy() {
        try {
            String testKey = "health:check:" + System.currentTimeMillis();
            redisTemplate.opsForValue().set(testKey, "ok", Duration.ofSeconds(10));
            String value = (String) redisTemplate.opsForValue().get(testKey);
            redisTemplate.delete(testKey);
            return "ok".equals(value);
        } catch (Exception e) {
            log.error("Redis健康检查失败", e);
            return false;
        }
    }
}
```
