## 限制策略调整

### 调整前的限制策略
```
用户级别：每分钟最多10次聊天请求
IP级别：每分钟最多30次聊天请求（保持不变）
套餐级别：根据用户套餐的每日/总次数限制（保持不变）
```

### 调整后的限制策略
```
用户级别：每分钟最多20次聊天请求
IP级别：每分钟最多30次聊天请求（保持不变）
套餐级别：根据用户套餐的每日/总次数限制（保持不变）
```

### 限制检查顺序（保持不变）
1. **用户分钟级频率限制**: 每分钟20次（已调整）
2. **IP分钟级频率限制**: 每分钟30次
3. **套餐级别限制**: 每日或总次数限制

## 影响评估

### 1. 用户体验改善
- **更高的交互频率**: 用户可以在短时间内进行更多的聊天交互
- **减少限制触发**: 降低因频率限制导致的用户请求被拒绝的情况
- **更流畅的对话体验**: 支持更快速的多轮对话

### 2. 系统资源影响
- **适度增加负载**: 每分钟最大请求数从10次增加到20次
- **仍在可控范围**: 20次/分钟的限制仍能有效防止恶意攻击
- **IP限制保持**: 30次/分钟的IP限制提供额外保护

### 3. 安全性保障
- **防滥用能力**: 20次/分钟仍能有效防止单用户过度使用
- **多层防护**: 用户、IP、套餐三层限制机制保持完整
- **恶意攻击防护**: 仍能有效防止短时间内的恶意请求
