## 📋 升级概述

## 🔄 主要变更

### 1. t_ai_model表升级

**新增字段**:
```sql
`is_visible` tinyint DEFAULT '1' COMMENT '是否可见（0-不可见，1-可见）'
```

**位置**: 在`is_available`字段之后

**用途**: 
- 控制AI模型在前端的可见性
- 支持内部测试模型（不可见）和公开API模型（可见）的区分
- 更精细的模型管理

**AUTO_INCREMENT更新**: 6 → 7

### 2. t_package表升级

**删除字段**:
- `chat_count` int NOT NULL DEFAULT '1000' COMMENT '对话次数'
- `daily_chat_limit` int NOT NULL DEFAULT '10' COMMENT '每日聊天次数限制'

**原因**: 
- 新版本完全使用`model_permissions` JSON字段管理权限
- 支持更灵活的模型级别权限控制
- 可以为不同模型类型设置不同的限制

**保留字段**: `model_permissions` (用于JSON权限管理)

### 3. t_file_upload表升级

**AUTO_INCREMENT更新**: 144 → 164
