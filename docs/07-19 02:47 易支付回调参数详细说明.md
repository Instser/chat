## 🔄 易支付支付宝回调参数详情

### 回调接口信息
- **URL**: `POST /api/payment/yipay/notify`
- **Content-Type**: `application/x-www-form-urlencoded`
- **请求方式**: POST

### 回调参数列表

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `pid` | String | 是 | 易支付商户ID | "1674" |
| `trade_no` | String | 是 | 易支付平台交易号 | "YP20250630191500789" |
| `out_trade_no` | String | 是 | 我们系统的订单号 | "JY202506301910001234" |
| `type` | String | 是 | 支付方式类型 | "alipay" (支付宝) |
| `name` | String | 是 | 商品名称 | "套餐购买" |
| `money` | String | 是 | 支付金额 | "68.00" |
| `trade_status` | String | 是 | 交易状态 | "TRADE_SUCCESS" |
| `sign` | String | 是 | MD5签名 | "md5_signature_here" |

### 完整回调示例
```
pid=1674
trade_no=YP20250630191500789
out_trade_no=JY202506301910001234
type=alipay
name=套餐购买
money=68.00
trade_status=TRADE_SUCCESS
sign=md5_signature_here
```

## ❌ 不包含的信息

### 用户支付宝ID
**重要说明**: 易支付回调参数中**不包含用户的支付宝ID**或任何用户敏感信息。

原因：
1. **隐私保护**: 第三方支付平台不会泄露用户的支付账号信息
2. **安全考虑**: 避免敏感信息在网络传输中暴露
3. **行业标准**: 符合支付行业的通用安全规范

### 其他不包含的信息
- 用户支付宝账号
- 用户真实姓名
- 用户手机号
- 支付宝用户ID
- 银行卡信息

## 🔍 如何获取用户信息

### 通过订单号查询
```java
// 通过回调中的out_trade_no查询订单
UserOrder order = orderService.getOrderByOrderNo(outTradeNo);

// 从订单中获取用户信息
Long userId = order.getUserId();
User user = userService.getUserById(userId);
```

### 数据关联流程
1. **创建订单时**: 订单记录包含用户ID
2. **支付回调时**: 通过订单号找到对应订单
3. **获取用户**: 从订单中提取用户ID，查询用户信息

## 🔐 安全验证机制

### 签名验证
```java
// 验证MD5签名
boolean signValid = verifyYiPaySign(signParams, sign);
```

### IP白名单验证
```java
// 验证回调来源IP
if (!paymentSecurityEnhancer.validateCallbackIP(request, "yipay")) {
    return ResponseEntity.status(HttpStatus.FORBIDDEN).body("IP not allowed");
}
```

### 防重放攻击
```java
// 生成回调唯一标识
String callbackId = generateCallbackId(outTradeNo, timestamp, sign);
if (redisPaymentSecurityService.isCallbackProcessed(callbackId)) {
    log.warn("检测到易支付重放攻击");
    return false;
}
```

## 📊 支付状态映射

| 易支付状态 | 系统状态码 | 状态描述 |
|------------|------------|----------|
| TRADE_SUCCESS | 1 | 支付成功 |
| TRADE_CLOSED | 2 | 交易关闭 |
| TRADE_FINISHED | 1 | 交易完成 |

## 🔄 处理流程

1. **接收回调**: 易支付POST请求到回调接口
2. **IP验证**: 验证请求来源IP是否在白名单
3. **参数解析**: 提取所有回调参数
4. **签名验证**: 验证MD5签名确保数据完整性
5. **防重放检查**: 检查是否为重复回调
6. **订单查询**: 通过订单号查找对应订单
7. **状态更新**: 更新订单支付状态
8. **套餐激活**: 支付成功后自动激活用户套餐
9. **会话释放**: 释放用户支付会话锁

## 📝 注意事项

1. **订单号唯一性**: `out_trade_no`是关联订单和用户的关键字段
2. **状态幂等性**: 重复回调不会重复处理相同状态
3. **异常处理**: 任何验证失败都会返回"fail"响应
4. **日志记录**: 详细记录回调处理过程便于问题排查
5. **安全优先**: 多重验证机制确保回调安全性
