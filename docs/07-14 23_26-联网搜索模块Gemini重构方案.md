## 版本标识

## 重构概述
将现有的联网搜索模块重构为使用Google Gemini API的grounding功能，基于gemini-test.py脚本的实现方式，对ID为6的AI模型进行联网请求，并解析响应中的sources字段作为联网搜索结果。

## 当前架构分析

### 现有实现
- **服务**: `NetworkAiService` / `NetworkAiServiceImpl`
- **实体**: `NetworkAiResponse`, `NetworkSearchResult`, `NetworkAiRequest`
- **数据流**: 用户查询 → 联网AI → NetworkSearchResult[] → WebSearchResult[] → 存储
- **模型配置**: 使用模型代码为 `network-ai` 的专用联网AI模型

### 目标Gemini实现
- **API**: Google Gemini API with grounding
- **模型**: ID为6的AI模型（需要配置为Gemini模型）
- **工具**: `google_search` grounding tool
- **响应解析**: 提取 `sources` 字段作为联网搜索结果

### 数据流转换
```
用户查询 → Gemini API (grounding) → GeminiGroundingResponse →
格式化完整响应内容(response_text + search_queries + sources + text_segments)拼接到用户消息 +
sources字段转换为WebSearchResult → 存储到数据库
```

```java
public class GeminiNetworkService {
    
    private final Client geminiClient;
    private final AiModelService aiModelService;
    
    public GeminiGroundingResponse queryWithGrounding(String userContext) {
        // 1. 获取ID为6的模型配置
        AiModel model = aiModelService.getById(6L);
        
        // 2. 构建grounding工具
        Tool groundingTool = Tool.builder()
            .googleSearch(GoogleSearch.builder().build())
            .build();
            
        // 3. 配置生成设置
        GenerateContentConfig config = GenerateContentConfig.builder()
            .tools(List.of(groundingTool))
            .build();
            
        // 4. 发送请求
        GenerateContentResponse response = geminiClient.models()
            .generateContent(
                model.getModelCode(), // 使用ID为6的模型代码
                userContext,
                config
            );
            
        // 5. 解析响应
        return parseGeminiResponse(response);
    }
}
```

#### 2.2 响应解析器
创建 `GeminiResponseParser.java`:
```java
@Component
public class GeminiResponseParser {
    
    public GeminiGroundingResponse parseResponse(GenerateContentResponse response) {
        GeminiGroundingResponse result = new GeminiGroundingResponse();
        
        // 解析基本响应文本
        result.setResponseText(response.getText());
        
        // 解析grounding metadata
        if (response.getCandidates().size() > 0) {
            Candidate candidate = response.getCandidates().get(0);
            GroundingMetadata gm = candidate.getGroundingMetadata();
            
            if (gm != null) {
                // 解析搜索查询
                result.setSearchQueries(extractSearchQueries(gm));
                
                // 解析sources（重点）
                List<GeminiSource> sources = extractSources(gm);
                result.setSources(sources);
                result.setTotalSources(sources.size());
                
                // 解析文本段落
                result.setTextSegments(extractTextSegments(gm, sources));
            }
        }
        
        return result;
    }
    
    private List<GeminiSource> extractSources(GroundingMetadata gm) {
        List<GeminiSource> sources = new ArrayList<>();
        
        if (gm.getGroundingChunks() != null) {
            for (int i = 0; i < gm.getGroundingChunks().size(); i++) {
                GroundingChunk chunk = gm.getGroundingChunks().get(i);
                
                GeminiSource source = new GeminiSource();
                source.setChunkIndex(i);
                
                if (chunk.getWeb() != null) {
                    source.setTitle(chunk.getWeb().getTitle());
                    source.setUrl(chunk.getWeb().getUri());
                }
                
                sources.add(source);
            }
        }
        
        return sources;
    }
}
```

### 阶段3：数据适配重构

#### 3.1 NetworkSearchResult适配器
重构 `NetworkAiServiceImpl.java`:
```java
@Override
public List<WebSearchResult> queryWithNetworkAsWebSearchResults(String userContext) {
    try {
        // 使用Gemini服务替代原有实现
        GeminiGroundingResponse geminiResponse = geminiNetworkService.queryWithGrounding(userContext);

        if (geminiResponse == null || geminiResponse.getSources() == null) {
            return new ArrayList<>();
        }

        // 转换Gemini sources为WebSearchResult（仅用于数据库存储）
        return geminiResponse.getSources().stream()
            .map(this::convertGeminiSourceToWebSearchResult)
            .collect(Collectors.toList());

    } catch (Exception e) {
        log.error("【Gemini联网】查询失败：{}", e.getMessage(), e);
        return new ArrayList<>();
    }
}

private WebSearchResult convertGeminiSourceToWebSearchResult(GeminiSource source) {
    WebSearchResult result = new WebSearchResult();
    result.setUrl(source.getUrl());
    result.setTitle(source.getTitle());

    // 使用标题作为内容摘要，因为主要内容已经在Gemini的完整响应中
    result.setContent(source.getTitle());

    // 设置默认值
    result.setFavicon(generateFaviconUrl(source.getUrl()));
    result.setRawContent(""); // Gemini不提供单独的原始内容
    result.setScore(1.0);

    return result;
}
```

### 阶段4：聊天集成重构

#### 4.1 聊天内容拼接
修改 `ChatServiceImpl.java` 中的联网内容处理：
```java
private NetworkSearchResult processNetworkSearchContent(List<Map<String, String>> messages, String query) {
    try {
        // 使用Gemini API进行联网搜索
        GeminiGroundingResponse geminiResponse = geminiNetworkService.queryWithGrounding(query);

        if (geminiResponse == null) {
            return new NetworkSearchResult(messages, new ArrayList<>());
        }

        // 格式化完整的Gemini响应内容
        String formattedNetworkContent = formatCompleteGeminiResponse(geminiResponse);

        // 将格式化后的完整响应拼接到最后一条用户消息
        List<Map<String, String>> updatedMessages = new ArrayList<>(messages);
        if (!updatedMessages.isEmpty()) {
            Map<String, String> lastMessage = updatedMessages.get(updatedMessages.size() - 1);
            if ("user".equals(lastMessage.get("role"))) {
                String originalContent = lastMessage.get("content");
                String updatedContent = originalContent + "\n\n" + formattedNetworkContent;
                lastMessage.put("content", updatedContent);
            }
        }

        // 转换sources为WebSearchResult用于数据库存储
        List<WebSearchResult> searchResults = convertGeminiSourcesToWebSearchResults(geminiResponse.getSources());

        return new NetworkSearchResult(updatedMessages, searchResults);

    } catch (Exception e) {
        log.error("【Gemini联网】处理联网搜索内容失败：{}", e.getMessage(), e);
        return new NetworkSearchResult(messages, new ArrayList<>());
    }
}

/**
 * 格式化完整的Gemini响应内容
 * 包括response_text、search_queries、sources、text_segments等所有信息
 */
private String formatCompleteGeminiResponse(GeminiGroundingResponse response) {
    StringBuilder formatted = new StringBuilder();

    // 1. 主要响应文本
    if (response.getResponseText() != null) {
        formatted.append(response.getResponseText()).append("\n\n");
    }

    // 2. 搜索查询信息
    if (response.getSearchQueries() != null && !response.getSearchQueries().isEmpty()) {
        formatted.append("搜索查询：\n");
        for (String query : response.getSearchQueries()) {
            formatted.append("- ").append(query).append("\n");
        }
        formatted.append("\n");
    }

    // 3. 来源信息
    if (response.getSources() != null && !response.getSources().isEmpty()) {
        formatted.append("参考来源：\n");
        for (int i = 0; i < response.getSources().size(); i++) {
            GeminiSource source = response.getSources().get(i);
            formatted.append(String.format("[%d] %s - %s\n",
                i + 1, source.getTitle(), source.getUrl()));
        }
        formatted.append("\n");
    }

    // 4. 文本段落支持信息（如果需要的话）
    if (response.getTextSegments() != null && !response.getTextSegments().isEmpty()) {
        formatted.append("引用详情：\n");
        for (GeminiTextSegment segment : response.getTextSegments()) {
            if (segment.getText() != null) {
                formatted.append("\"").append(segment.getText()).append("\" ");
                if (segment.getSourceIndices() != null && !segment.getSourceIndices().isEmpty()) {
                    formatted.append("(来源: ");
                    for (Integer index : segment.getSourceIndices()) {
                        formatted.append("[").append(index + 1).append("] ");
                    }
                    formatted.append(")");
                }
                formatted.append("\n");
            }
        }
    }

    return formatted.toString().trim();
}

private List<WebSearchResult> convertGeminiSourcesToWebSearchResults(List<GeminiSource> sources) {
    if (sources == null) {
        return new ArrayList<>();
    }

    return sources.stream()
        .map(source -> {
            WebSearchResult result = new WebSearchResult();
            result.setUrl(source.getUrl());
            result.setTitle(source.getTitle());
            result.setContent(source.getTitle()); // 使用标题作为内容摘要
            result.setFavicon(generateFaviconUrl(source.getUrl()));
            result.setRawContent(""); // Gemini不提供原始内容
            result.setScore(1.0);
            return result;
        })
        .collect(Collectors.toList());
}
```

## 关键变更说明

### 内容拼接方式变更
**重要**: 与原有实现不同，此次重构将**格式化Gemini API返回的完整响应内容**拼接到用户消息后面，而不是按照"来源、标题、内容"的格式重新组织搜索结果。

**变更对比**:
- **原有方式**: `来源：${url}，标题：${title}，内容：${content}；`
- **新方式**: 格式化完整的Gemini响应，包括：
  - response_text（主要回答内容）
  - search_queries（搜索查询列表）
  - sources（参考来源列表）
  - text_segments（引用详情）

**格式化示例**:
```
2024年欧洲杯足球锦标赛的冠军是**西班牙队**。他们在决赛中以2-1的比分战胜了英格兰队...

搜索查询：
- 2024年欧洲杯足球锦标赛冠军
- UEFA Euro 2024 winner
- 2024欧洲杯决赛结果

参考来源：
[1] wikipedia.org - https://vertexaisearch.cloud.google.com/...
[2] 6park.com - https://vertexaisearch.cloud.google.com/...
[3] people.com.cn - https://vertexaisearch.cloud.google.com/...

引用详情：
"他们在决赛中以2-1的比分战胜了英格兰队，第四次夺得欧洲杯冠军..." (来源: [1] [2] [3] )
"决赛于北京时间2024年7月15日凌晨在德国柏林奥林匹克球场举行" (来源: [2] [11] [3] )
```

**优势**:
1. **信息完整性**: 包含Gemini响应的所有结构化信息
2. **引用透明**: 清晰显示每个信息片段的来源
3. **搜索透明**: 显示实际执行的搜索查询
4. **用户体验**: 提供完整、结构化的联网搜索结果

### 响应内容用途
- **聊天内容**: 使用格式化后的完整Gemini响应（包括response_text、search_queries、sources、text_segments）
