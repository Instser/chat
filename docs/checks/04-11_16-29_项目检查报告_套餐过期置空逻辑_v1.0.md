## 关键调用链

### 链路 1: 过期套餐清理实现

`UserAccountServiceImpl.cleanExpiredPackages()`  
-> 计算 `beforeTime = 当前业务时间 - 7天`  
-> 调用 `UserAccountDao.cleanExpiredPackages()`  
-> 执行 SQL 将 `package_id`、`package_expire_time` 清空

### 链路 2: 聊天权限过期判断

`ChatLimitServiceImpl.validateChatPermission()`  
-> 检查 `userAccount.getPackageExpireTime()`  
-> 若过期直接返回 `PACKAGE_EXPIRED`  
-> 不修改数据库套餐字段
