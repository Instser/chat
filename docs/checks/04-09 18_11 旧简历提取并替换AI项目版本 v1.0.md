## 项目经历

### 广告投放检索系统

**项目简介**：该项目设计了一套可以实现用户进行广告资源检索的网站，主要包括广告的检索系统和投放系统，实现了广告主的广告投放和媒体方的广告检索系统。  

**技术栈**：SpringBoot、Mybatis、SpringMVC、Mysql、Redis、Kafka、Nginx  

**技术要点**：

- **微服务架构**：采用分离式架构，将整个项目分为广告投放模块，广告检索模块，数据库监听模块，统一网关模块。
- **广告投放模块**：使用JPA创建数据库表结构，将整个项目需求实体类。使用Spring三层框架。通过广告主请求创建实体类并储存在数据库中，实现用户广告投放功能。
- **构建索引对象缓存类**：为了让广告主高效检索和筛选广告。将数据库数据缓存在线程类的HashMap中，构建全量索引，根据key查询索引对象。通过构建的方法。将缓存类存在HashMap中，避免多次从容器获取。
- **数据库监听**：为了更新广告主对广告数据的修改，通过构建模板对象，实现对SQL不同表的BinlogEvent指定字段和操作的监听，通过解析数据库的BinlogEvent将数据库的操作投放到缓存类中，实现对缓存类的增删改查，实现增量索引功能。
- **实现服务熔断**：利用feign调用远程服务，并结合hytrix实现熔断器，实现当底层服务不可用时，可以阻断故障传播。
- **项目优化**：利用kafka作为Slave节点监听数据库Master节点，利用Kafka把主节点的BinLogEvent发给各个检索服务节点进行优化，提高数据库对各个检索节点传输BinLogEvent效率。

### AI智能对话平台后端系统（chat.example.com）

**项目简介**：该项目是一个面向 AI 对话场景的后端系统，主要实现了流式聊天、会话管理、文件上传解析、支付购买、套餐权限控制、联网搜索等功能，支持用户进行多轮对话、附件问答与支付开通服务。  

**技术栈**：Spring Boot、Spring MVC、Spring Security、JWT、MyBatis-Plus、MySQL、Redis、Redisson、WebClient、SSE 

**技术要点**：

- **流式对话模块**：基于 Spring MVC 请求链路 + WebClient + SSE 实现 AI 流式响应，针对上游返回内容被随机分片的问题，设计行缓冲与 JSON 缓冲双重重组机制，解决中文、Emoji 和 JSON 数据在流式传输中的丢失与乱码问题。
- **支付与套餐闭环**：实现订单创建、支付回调、订单状态同步、套餐激活等完整支付链路，修复重复下单、回调延迟导致状态不一致、支付成功后套餐未生效等问题，保证支付结果与用户权限一致。
- **文件解析与消息关联**：实现文件上传、文本解析、消息附件关联等能力，重构 edit-resend 场景下“删除旧消息、保留附件、创建新消息、转移关联”的执行顺序，解决消息误删和附件错绑问题。
- **并发安全优化**：针对用户账户扣减和套餐次数更新场景，采用数据库乐观锁 + 有限重试机制替代复杂分布式锁方案，在保证数据一致性的前提下降低系统复杂度和维护成本。
- **权限与缓存设计**：基于 Redis 实现用户权限、套餐状态、账户信息缓存，减少数据库重复查询，提升权限校验与账户读取效率。
