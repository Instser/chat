# 07-03 16:47 汇率API阻塞聊天问题修复

## 问题描述

用户反馈在进行续写或聊天时，系统自动调用API更新汇率会阻塞聊天功能，影响用户体验。

### 问题分析

经过代码审查发现以下问题：

#### 1. **汇率API同步调用阻塞**
- 在`PaymentServiceImpl.validatePaymentRequest()`方法中，第382行同步调用汇率服务
- `exchangeRateService.getExchangeRate("USD", "CNY")`是同步调用
- 汇率API调用包含重试机制（默认3次），每次重试有递增延迟（1秒、2秒、3秒）
- **总阻塞时间**：5秒超时 × 3次重试 + 6秒延迟 = 最多21秒

#### 2. **定时任务可能影响性能**
- `ExchangeRateUpdateService`每小时更新汇率
- `updateAllRates()`方法批量调用汇率API，每个货币对之间只有100ms间隔
- 如果汇率API响应慢，定时任务可能长时间占用线程池

#### 3. **缺乏超时控制**
- RestTemplate没有配置合理的超时时间
- 汇率API调用可能因网络问题长时间等待

## 解决方案

### 1. **汇率服务异步化改造**

#### 优先使用缓存策略
```java
public BigDecimal getExchangeRate(String fromCurrency, String toCurrency) {
    // 优先从本地缓存获取（避免阻塞）
    BigDecimal cachedRate = rateCache.get(rateKey);
    if (cachedRate != null) {
        return cachedRate;
    }

    // 缓存未命中时，使用默认汇率并异步更新
    asyncUpdateExchangeRate(fromCurrency, toCurrency);
    
    // 立即返回默认汇率，避免阻塞
    return getDefaultExchangeRate(fromCurrency, toCurrency);
}
```

#### 异步更新机制
```java
private void asyncUpdateExchangeRate(String fromCurrency, String toCurrency) {
    CompletableFuture.runAsync(() -> {
        try {
            BigDecimal rate = fetchExchangeRateFromApi(fromCurrency, toCurrency);
            if (rate != null && rate.compareTo(BigDecimal.ZERO) > 0) {
                String rateKey = fromCurrency.toUpperCase() + "_" + toCurrency.toUpperCase();
                rateCache.put(rateKey, rate);
                log.info("异步更新汇率成功: {} = {}", rateKey, rate);
            }
        } catch (Exception e) {
            log.warn("异步更新汇率失败: {} -> {}", fromCurrency, toCurrency, e);
        }
    });
}
```

### 2. **定时任务优化**

#### 异步执行批量更新
```java
public void updateAllRates() {
    // 异步执行批量更新，避免阻塞定时任务线程
    CompletableFuture.runAsync(() -> {
        int successCount = 0;
        int totalCount = 0;
        
        for (String baseCurrency : SUPPORTED_CURRENCIES) {
            for (String targetCurrency : SUPPORTED_CURRENCIES) {
                if (!baseCurrency.equals(targetCurrency)) {
                    totalCount++;
                    try {
                        BigDecimal rate = fetchExchangeRateFromApiWithTimeout(baseCurrency, targetCurrency);
                        if (rate != null) {
                            String rateKey = baseCurrency + "_" + targetCurrency;
                            rateCache.put(rateKey, rate);
                            successCount++;
                        }
                        Thread.sleep(200); // 增加间隔到200ms
                    } catch (Exception e) {
                        log.warn("更新汇率失败: {} -> {}", baseCurrency, targetCurrency, e);
                    }
                }
            }
        }
        
        log.info("批量更新汇率完成，成功: {}/{}", successCount, totalCount);
    });
}
```

### 3. **专用RestTemplate配置**

#### 创建汇率专用RestTemplate
```java
@Bean("exchangeRestTemplate")
public RestTemplate exchangeRestTemplate() {
    try {
        // 创建RestTemplate并配置超时时间
        RestTemplate restTemplate = new RestTemplate();
        
        // 配置超时时间（连接超时3秒，读取超时5秒）
        if (restTemplate.getRequestFactory() instanceof SimpleClientHttpRequestFactory) {
            SimpleClientHttpRequestFactory factory = (SimpleClientHttpRequestFactory) restTemplate.getRequestFactory();
            factory.setConnectTimeout(3000);  // 连接超时3秒
            factory.setReadTimeout(5000);     // 读取超时5秒
        }

        log.info("汇率专用RestTemplate已配置：连接超时3秒，读取超时5秒");
        return restTemplate;
    } catch (Exception e) {
        log.error("配置汇率RestTemplate时发生错误", e);
        return new RestTemplate();
    }
}
```
