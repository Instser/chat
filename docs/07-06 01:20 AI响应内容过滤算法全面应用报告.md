```java
/**
 * 一次性清理所有AI标记（带过滤检测）
 */
private String cleanAllTagsOnce(String content) {
    if (content == null || content.trim().isEmpty()) {
        return content;
    }

    String cleaned = content;
    log.debug("开始一次性清理所有标签，原始长度: {}", content.length());

    // 0. 首先检查是否包含需要过滤的内容
    if (shouldFilterContent(cleaned)) {
        log.info("续写内容检测到需要过滤的AI响应内容，已阻止向前端发送");
        return ""; // 返回空字符串，不向前端发送
    }

    // 1. 清理thinking标签块
    cleaned = removeThinkingBlocks(cleaned);
    // 2. 清理response标签
    cleaned = removeResponseTags(cleaned);
    // 3. 清理代码块开头标记
    cleaned = removeCodeBlockMarkers(cleaned);
    // 4. 清理多余空白
    cleaned = cleanExtraWhitespace(cleaned);

    return cleaned;
}
```

```java
 * 传统块发送模式（内容已经过滤和清理）

private void sendContentAsBlock(String content, HttpServletResponse response, ObjectMapper mapper) {
    try {
        // 注意：传入的content已经经过过滤和清理，不需要再次处理
        if (!content.isEmpty()) {
            String vercelFormat = String.format("0:%s\n", mapper.writeValueAsString(content));
            response.getWriter().write(vercelFormat);
            response.getWriter().flush();
            log.info("块发送模式数据发送成功: [{}]", content);
        } else {
            log.debug("块发送模式：内容为空，跳过发送");
        }
    } catch (Exception e) {
        log.error("块发送模式失败: {}", e.getMessage());
    }
}
```

## 技术实现细节

### 1. 过滤覆盖范围
- **普通聊天**: 通过`processCompleteJson`中的`cleanContentWithFilterInfo`方法
- **续写功能**: 通过`cleanAllTagsOnce`和`cleanContinuationContent`方法
- **续写后续内容**: 通过`processContinuationJson`中的直接过滤检测
- **重试功能**: 通过`streamChatWithAI` → `processCompleteJson`路径自动覆盖
- **编辑重发**: 通过`streamChatWithAI` → `processCompleteJson`路径自动覆盖

### 2. 过滤策略
- **关键词匹配**: 检测特定的推广关键词
- **大小写不敏感**: 同时检查原文和小写版本
- **正则表达式**: 检测markdown链接格式的推广内容
- **日志记录**: 记录过滤行为便于调试和监控

### 3. 状态保持策略
- **内容累积**: 被过滤的内容仍然累积到`aiResponseContent`中，确保`isRealAiResponse`状态正确
- **标题生成**: 过滤不影响标题生成逻辑，因为使用累积的完整内容
- **Token计算**: 过滤不影响Token计算和使用次数统计
- **数据库保存**: 保存完整的AI响应内容（包括被过滤的部分）
