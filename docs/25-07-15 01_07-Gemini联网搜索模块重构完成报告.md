## 技术架构变更

### 新的数据流
```
用户查询 → Gemini API (grounding) → GeminiGroundingResponse →
格式化完整响应内容拼接到用户消息 +
sources字段转换为WebSearchResult → 存储到数据库
```

### 响应格式示例
```
2024年欧洲杯足球锦标赛的冠军是**西班牙队**。他们在决赛中以2-1的比分战胜了英格兰队...

搜索查询：
- 2024年欧洲杯足球锦标赛冠军
- UEFA Euro 2024 winner

参考来源：
[1] wikipedia.org - https://example.com/...
[2] 6park.com - https://example.com/...

引用详情：
"他们在决赛中以2-1的比分战胜了英格兰队..." (来源: [1] [2])
```

