## 📋 问题根因分析

### 🔍 原始错误
```
org.springframework.jdbc.BadSqlGrammarException: 
### Error querying database.  Cause: java.sql.SQLSyntaxErrorException: Unknown column 'chat_count' in 'field list'
### SQL: SELECT id,package_name,description,package_type,price_usd,price_cny,validity_days,chat_count,daily_chat_limit,limit_type,model_permissions,is_enabled,sort_order,create_time AS createdTime,update_time,deleted FROM t_package WHERE id=? AND deleted=0
```

### 🎯 根本原因
1. **数据库字段已删除**: `chat_count` 和 `daily_chat_limit` 字段已从数据库表中删除
2. **实体类仍有字段定义**: Package 实体类中仍然定义了这些字段，导致 MyBatis-Plus 自动生成的 SQL 包含这些字段
3. **字段标记为 @Deprecated 无效**: MyBatis-Plus 不会忽略 @Deprecated 字段，仍然会在 SQL 中包含

### 2. 保留兼容方法

**保留的兼容方法**:
```java
/**
 * 获取套餐总聊天次数
 * 兼容方法：根据限制类型返回相应的总次数
 */
public Integer getChatCount() {
    if ("daily".equals(this.limitType)) {
        return -1; // -1表示无限制
    }
    
    Map<String, ModelPermission> permissions = getModelPermissionsMap();
    ModelPermission standardPermission = permissions.get("STANDARD");
    if (standardPermission != null && standardPermission.getDailyLimit() > 0) {
        return standardPermission.getDailyLimit() * (this.validityDays != null ? this.validityDays : 30);
    }
    
    return 1000; // 默认值
}

/**
 * 获取每日聊天次数限制
 * 兼容方法：从STANDARD模型权限配置获取
 */
public Integer getDailyChatLimit() {
    Map<String, ModelPermission> permissions = getModelPermissionsMap();
    ModelPermission standardPermission = permissions.get("STANDARD");
    return standardPermission != null ? standardPermission.getDailyLimit() : 0;
}
```
