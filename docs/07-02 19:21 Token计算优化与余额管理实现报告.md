## 🔧 主要改进

### 1. Token计算算法优化

#### 1.1 改进前的问题
- 使用简单的 `content.length() / 4` 估算方式
- 对中文内容计算不准确
- 没有区分不同字符类型

#### 1.2 优化后的算法
```java
/**
 * 计算文本的token数量
 * 使用更准确的算法，区分中英文字符
 */
private Integer calculateTokenCount(String content) {
    if (content == null || content.trim().isEmpty()) {
        return 0;
    }

    int chineseCount = 0;
    int englishCount = 0;
    int digitCount = 0;
    int punctuationCount = 0;
    int whitespaceCount = 0;

    for (char c : content.toCharArray()) {
        if (c >= 0x4e00 && c <= 0x9fff) {
            chineseCount++;  // 中文字符
        } else if (Character.isLetter(c)) {
            englishCount++;  // 英文字母
        } else if (Character.isDigit(c)) {
            digitCount++;    // 数字
        } else if (Character.isWhitespace(c)) {
            whitespaceCount++; // 空白字符
        } else {
            punctuationCount++; // 标点符号
        }
    }

    // Token计算规则（调整后更合理）：
    // - 中文字符：每个字符约1.2个token
    // - 英文字母：每4个字符约1个token
    // - 数字：每4个字符约1个token
    // - 标点符号：每3个字符约1个token
    // - 空白字符：每8个字符约1个token
    int totalTokens = (int) Math.ceil(
        chineseCount * 1.2 +
        englishCount / 4.0 +
        digitCount / 4.0 +
        punctuationCount / 3.0 +
        whitespaceCount / 8.0
    );

    return Math.max(1, totalTokens);
}
```

#### 1.3 计算规则说明
| 字符类型 | Token权重 | 说明 |
|---------|----------|------|
| 中文字符 | 1.2 token/字符 | 包括中文汉字和中文标点 |
| 英文字母 | 0.25 token/字符 | 每4个字符约1个token |
| 数字 | 0.25 token/字符 | 每4个字符约1个token |
| 标点符号 | 0.33 token/字符 | 每3个字符约1个token |
| 空白字符 | 0.125 token/字符 | 每8个字符约1个token |

#### 2.2 原子性数据库操作
在 `UserAccountMapper.xml` 中添加了原子性SQL操作：

```xml
<!-- 原子性减少Token余额 -->
<update id="decrementTokenBalance">
    UPDATE t_user_account
    SET token_balance = token_balance - #{tokenCount},
        update_time = NOW()
    WHERE user_id = #{userId}
      AND token_balance >= #{tokenCount}
      AND deleted = 0
</update>

<!-- 增加已使用Token统计 -->
<update id="incrementTokenUsed">
    UPDATE t_user_account
    SET token_used = COALESCE(token_used, 0) + #{tokenCount},
        update_time = NOW()
    WHERE user_id = #{userId}
      AND deleted = 0
</update>

<!-- 增加Token余额 -->
<update id="incrementTokenBalance">
    UPDATE t_user_account
    SET token_balance = COALESCE(token_balance, 0) + #{tokenCount},
        update_time = NOW()
    WHERE user_id = #{userId}
      AND deleted = 0
</update>
```

### 3. AI响应Token统计

#### 3.1 统计策略
- **只统计正确的AI响应**：只有 `isRealAiResponse()` 为true时才扣减Token
- **错误响应不扣减**：API错误、网络错误等不会影响用户Token余额
- **中断响应处理**：如果中断时有内容发送，会统计相应的Token

#### 3.2 实现逻辑
```java
@Override
public void saveAiResponse(String sessionId, Long userId, Long modelId, String content) {
    try {
        if (sessionId != null && userId != null && modelId != null && content != null && !content.trim().isEmpty()) {
            // 计算AI响应的Token数量
            Integer tokenCount = calculateTokenCount(content);
            
            // 保存AI响应消息到数据库
            Long messageId = chatMessageService.sendMessage(sessionId, "assistant", content, userId, modelId);
            
            // 记录AI响应的Token使用量
            if (messageId != null && tokenCount > 0) {
                boolean tokenRecorded = chatLimitService.recordTokenUsage(userId, tokenCount);
                if (tokenRecorded) {
                    log.debug("用户{}AI响应Token使用记录成功，使用了{}个Token", userId, tokenCount);
                } else {
                    log.warn("用户{}AI响应Token使用记录失败，可能余额不足", userId);
                }
            }
            
            log.info("AI响应已保存到数据库，会话ID：{}，用户ID：{}，模型ID：{}，内容长度：{}，Token数：{}", 
                    sessionId, userId, modelId, content.length(), tokenCount);
        }
    } catch (Exception e) {
        log.error("保存AI响应到数据库失败", e);
    }
}
```

## 🔄 使用流程

### 用户消息Token统计
1. 用户发送消息
2. 系统计算消息Token数量
3. 保存消息到数据库（包含Token数量）

### AI响应Token统计
1. AI服务返回响应
2. 判断是否为真实AI响应（`isRealAiResponse()`）
3. 如果是真实响应：
   - 计算响应内容的Token数量
   - 保存AI响应到数据库
   - 扣减用户Token余额
   - 更新已使用Token统计

### Token余额管理
1. 用户充值：调用 `addTokenBalance()`
2. 余额查询：调用 `getTokenBalance()`
3. 余额检查：调用 `hasEnoughTokens()`
4. 使用扣减：调用 `updateTokenUsage()`
