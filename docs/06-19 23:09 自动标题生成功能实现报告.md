**🎯 功能目标**: 实现AI聊天对话标题自动生成，在首次AI响应时自动为对话生成简洁标题

## 功能概述

### 需求背景
用户希望在新对话中，当检测到第一条AI响应时，自动将用户消息和AI回复合并发送给AI，生成一个对话标题并保存为用户对话的标题，提升用户体验。

### 解决方案
采用**基于消息列表判断的零数据库查询方案**，通过统计消息列表中用户消息数量来判断是否为首次AI响应，实现高性能的标题自动生成。

### 3. 核心逻辑实现

#### 3.1 首次AI响应检测
```java
/**
 * 检测是否为首次AI响应
 * 通过消息列表中用户消息的数量判断
 */
private boolean isFirstAiResponse(List<Map<String, String>> messages) {
    // 统计用户消息数量
    long userMessageCount = messages.stream()
        .filter(msg -> "user".equals(msg.get("role")))
        .count();
    
    // 如果只有1条用户消息，说明这是首次AI响应
    return userMessageCount == 1;
}
```

**优势**：
- **零数据库查询**：直接基于当前请求数据判断
- **高性能**：无额外网络开销
- **准确性高**：逻辑简单可靠

 * 异步生成并保存对话标题

private void generateAndSaveTitle(String sessionId, List<Map<String, String>> messages, AiModel model) {
    // 异步执行，不阻塞主流程
    CompletableFuture.runAsync(() -> {
        try {
            // 提取用户消息
            String userMessage = extractUserMessage(messages);
            
            // 构建标题生成提示词
            String titlePrompt = buildTitlePrompt(userMessage, "AI正在回复中...");

#### 3.3 标题清理逻辑
```java
/**
 * 清理标题内容
 */
private String cleanTitle(String title) {
    if (title == null) {
        return "新对话";
    }
    
    // 移除引号和多余空格
    title = title.trim()
        .replaceAll("^[\"']+|[\"']+$", "") // 移除开头和结尾的引号
        .replaceAll("\\s+", " ") // 合并多个空格
        .trim();
    
    // 限制长度
    if (title.length() > 15) {
        title = title.substring(0, 15);
    }
    
    // 如果清理后为空，使用默认标题
    if (title.isEmpty()) {
        title = "新对话";
    }
    
    return title;
}
```

## 性能优化

### 1. 零数据库查询
- 通过消息列表直接判断，避免额外数据库查询
- 相比数据库查询方案，性能提升显著

### 2. 异步处理
- 使用 `CompletableFuture.runAsync()` 异步执行
- 不阻塞主聊天流程，确保响应速度

### 3. 异常容错
- 标题生成失败不影响聊天功能
- 完善的异常处理和日志记录

## 功能特性

### 1. 智能触发
- **精确检测**：只在首次AI响应时触发一次
- **条件判断**：需要sessionId存在且为首次响应

- **即时生效**：标题生成后立即保存到数据库
