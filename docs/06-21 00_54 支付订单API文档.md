## 套餐相关接口

### 1. 获取套餐列表
**接口**: `GET /payment/packages`  
**描述**: 获取所有启用的套餐列表，返回前端兼容格式

**请求参数**:
| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| currency | String | 否 | CNY | 货币类型 |

**响应示例**:
```json
{
  "code": 200,
  "message": "获取套餐列表成功",
  "data": [
    {
      "id": 1,
      "name": "Free",
      "description": "Basic features for new users",
      "price": 0.00,
      "currency": "CNY",
      "period": 30,
      "features": ["gpt-3.5-turbo"]
    }
  ]
}
```

### 2. 获取套餐信息和支付方式
**接口**: `POST /payment/package/info`  
**描述**: 获取指定套餐的详细信息和可用支付方式

**请求参数**:
```json
{
  "packageId": 3,
  "currency": "CNY"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "获取套餐信息成功",
  "data": {
    "packageInfo": {
      "id": 3,
      "name": "Pro",
      "description": "Best for regular users",
      "price": 68.00,
      "currency": "CNY",
      "period": 30,
      "features": ["gpt-3.5-turbo", "gpt-4", "qwen-turbo"]
    },
    "paymentMethods": [
      {
        "id": "alipay",
        "name": "支付宝",
        "type": "alipay",
        "available": true
      },
      {
        "id": "yipay",
        "name": "易支付",
        "type": "yipay",
        "available": true
      }
    ]
  }
}
```

### 3. 根据类型获取套餐列表
**接口**: `GET /payment/packages/{type}`  
**描述**: 根据套餐类型获取套餐列表

**路径参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | String | 是 | 套餐类型(free/basic/premium/enterprise) |

## 支付相关接口

### 4. 创建支付订单
**接口**: `POST /payment/create`  
**描述**: 创建支付订单，返回支付链接或二维码

**请求参数**:
```json
{
  "packageId": 3,
  "currency": "CNY",
  "paymentMethod": "alipay"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "支付订单创建成功",
  "data": {
    "orderNo": "ORDER_20250621005400001",
    "paymentRequestId": "PAY_REQ_001",
    "paymentUrl": "https://payment.example.com/pay?id=xxx",
    "amount": 68.00,
    "currency": "CNY",
    "paymentStatus": 0,
    "success": true,
    "paymentMethod": "alipay",
    "message": "订单创建成功",
    "createdTime": "2025-06-21T00:54:00Z",
    "qrCodeUrl": "https://qr.example.com/qr123.png"
  }
}
```

### 5. 查询支付状态
**接口**: `GET /payment/status/{orderNo}`  
**描述**: 查询订单支付状态，返回简化格式

**路径参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderNo | String | 是 | 订单号 |

**响应示例**:
```json
{

  "data": {
    "orderNo": "ORDER_20250621005400001",

```

{
  "code": 200,
  "message": "查询支付状态成功",
  "data": {

## 状态同步接口

### 10. 手动同步单个订单状态
**接口**: `POST /payment/sync/{orderNo}`  
**描述**: 手动同步指定订单的支付状态

**路径参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderNo | String | 是 | 订单号 |

**响应示例**:
```json
{
  "code": 200,
  "message": "订单状态同步成功",
  "data": "订单状态同步成功"
}
```

### 11. 批量同步订单状态
**接口**: `POST /payment/sync/batch`  
**描述**: 批量同步待处理订单的支付状态

**请求参数**:
| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| maxCount | Integer | 否 | 50 | 最大同步数量 |

**响应示例**:
```json
{
  "code": 200,
  "message": "批量同步完成，同步订单数: 10",
  "data": {
    "syncCount": 10,
    "maxCount": 50,
    "message": "批量同步完成"
  }
}
```

### 12. 全量同步订单状态
**接口**: `POST /payment/sync/all`  
**描述**: 触发全量订单状态同步

**响应示例**:

## 回调接口

### 13. 支付宝支付回调
**接口**: `POST /payment/alipay/notify`  
**描述**: 支付宝支付结果回调接口（第三方调用）

**请求头**:
- `request-time`: 请求时间
- `client-id`: 客户端ID  
- `signature`: 签名

**请求体**: 支付宝回调数据（JSON格式）

### 14. 易支付回调
**接口**: `POST /payment/yipay/notify`  
**描述**: 易支付结果回调接口（第三方调用）

**请求参数**: Form表单格式的易支付回调参数

## 数据结构说明

### 支付状态码
| 状态码 | 说明 |
|--------|------|
| 0 | 待支付 |
| 1 | 已支付 |
| 2 | 已取消 |
| 3 | 已退款 |

### 支付方式
| 方式ID | 名称 | 类型 |
|--------|------|------|
| alipay | 支付宝 | alipay |
| yipay | 易支付 | yipay |
| wechat | 微信支付 | wechat |

### 套餐类型
| 类型 | 说明 |
|------|------|
| free | 免费套餐 |
| basic | 基础套餐 |
| premium | 高级套餐 |
| enterprise | 企业套餐 |

### 通用响应格式
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1640995200000
}
```

**状态码说明**:
- `200`: 成功
- `400`: 请求参数错误
- `404`: 资源不存在
- `500`: 服务器内部错误

## 注意事项

1. **用户认证**: 当前接口使用固定用户ID(1)，后续将从JWT token中获取
2. **货币支持**: 目前主要支持CNY(人民币)和USD(美元)
3. **支付方式**: 支持支付宝SDK和易支付，具体可用方式通过套餐信息接口获取
4. **订单号格式**: ORDER_YYYYMMDDHHMMSS + 序号
5. **时间格式**: 统一使用ISO 8601格式 (YYYY-MM-DDTHH:mm:ssZ)
6. **金额精度**: 使用BigDecimal，保留2位小数
7. **状态同步**: 支持手动和自动同步，建议在支付完成后调用同步接口确认状态
