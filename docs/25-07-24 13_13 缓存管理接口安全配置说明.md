# 缓存管理接口安全配置说明

**文档创建时间**: 2025年07月24日 13:13  
**配置版本**: v2.1  
**安全级别**: 高  
**适用范围**: 全系统缓存管理平台  

## 📋 安全配置概述

为了确保缓存管理接口的安全性，已将所有缓存管理接口配置为独立端口运行，并严格限制访问权限，仅允许本地访问。

## 🔒 安全配置详情

### 1. 端口配置
- **主应用端口**: 8080 (对外服务)
- **缓存管理端口**: 8081 (仅本地访问)
- **绑定地址**: 127.0.0.1 (仅本地绑定)

### 2. 访问限制
- **允许访问**: 仅 127.0.0.1 和 localhost
- **拒绝访问**: 所有远程IP地址
- **访问控制**: 基于IP地址过滤器实现

### 3. 接口地址
```
主应用接口: http://localhost:8080/api/*
缓存管理接口: http://127.0.0.1:8081/api/admin/cache/*
```

## 🛠️ 配置文件

### application.yml 配置
```yaml
# 主服务器配置
server:
  port: 8080
  servlet:
    context-path: /api

# 缓存管理服务器配置
cache:
  management:
    enabled: true          # 启用缓存管理服务器
    port: 8081            # 缓存管理接口端口
    bind-address: 127.0.0.1  # 只绑定到本地地址
```

## 🔧 技术实现

### 1. 访问控制过滤器
- **类名**: `CacheManagementAccessFilter`
- **拦截路径**: `/api/admin/cache/*`
- **过滤优先级**: 最高优先级
- **IP检测**: 支持多种代理头部检测

### 2. 独立端口配置
- **类名**: `CacheManagementServerConfig`
- **实现方式**: Tomcat额外连接器
- **线程配置**: 最大50线程，最小5线程
- **连接限制**: 最大100连接

### 3. IP地址检测逻辑
```java
// 检测顺序
1. X-Forwarded-For 头部
2. X-Real-IP 头部  
3. X-Forwarded-Proto 头部
4. RemoteAddr 属性

// 支持的本地地址
- 127.0.0.1 (IPv4)
- localhost (域名)
- ::1 (IPv6简写)
- 0:0:0:0:0:0:0:1 (IPv6完整)
```

## 🧪 使用示例

### 1. 本地访问示例
```bash
# 使用curl访问 (成功)
curl http://127.0.0.1:8081/api/admin/cache/stats

# 使用浏览器访问 (成功)
http://127.0.0.1:8081/api/admin/cache/health
```

### 2. 远程访问示例 (被拒绝)
```bash
# 从其他机器访问 (失败)
curl http://192.168.1.100:8081/api/admin/cache/stats
# 返回: {"code":403,"message":"缓存管理接口仅允许本地访问","data":null}
```

### 3. 代理环境访问
```bash
# 通过代理访问，X-Forwarded-For为本地IP (成功)
curl -H "X-Forwarded-For: 127.0.0.1" http://proxy:8081/api/admin/cache/stats

# 通过代理访问，X-Forwarded-For为远程IP (失败)
curl -H "X-Forwarded-For: 192.168.1.100" http://proxy:8081/api/admin/cache/stats
```

## ⚠️ 安全注意事项

### 1. 网络安全
- **防火墙**: 建议在防火墙层面也限制8081端口的外部访问
- **代理配置**: 如使用Nginx等代理，确保不转发缓存管理接口
- **监控告警**: 建议监控8081端口的访问日志

### 2. 运维安全
- **SSH隧道**: 如需远程管理，建议使用SSH隧道
- **VPN访问**: 可通过VPN连接到服务器后本地访问
- **堡垒机**: 通过堡垒机跳转到服务器本地访问

### 3. 日志监控
