## 问题描述

### 问题现象
在Windows终端中运行应用时，中文日志显示为乱码：
```
濂楅鏁版嵁宸插瓨鍦紝璺宠繃鍒濆鍖?
AI妯″瀷API閰嶇疆瀛楁宸插瓨鍦紝璺宠繃鍒濆鍖?
鏁版嵁鍒濆鍖栧畬鎴?
```

### 问题原因
1. **Windows终端编码**：Windows PowerShell/CMD默认使用GBK编码
2. **Java应用UTF-8输出**：应用程序使用UTF-8编码输出日志
3. **编码不匹配**：UTF-8内容在GBK终端中显示为乱码
4. **Logback配置不足**：虽然设置了UTF-8，但Windows终端不支持

## 修复方案

### 🔧 多层次解决方案

#### 1. 添加Jansi依赖
```xml
<!-- Jansi - Windows控制台UTF-8支持 -->
<dependency>
    <groupId>org.fusesource.jansi</groupId>
    <artifactId>jansi</artifactId>
    <version>2.4.0</version>
</dependency>
```

#### 2. 优化Logback配置
```xml
<!-- 控制台输出 -->
<appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
    <encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
        <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
        <charset>UTF-8</charset>
    </encoder>
    <!-- Windows环境下强制使用UTF-8输出 -->
    <withJansi>true</withJansi>
</appender>
```

#### 3. 创建控制台编码配置类
```java
@Component
public class ConsoleEncodingConfig implements ApplicationRunner {
    @Override
    public void run(ApplicationArguments args) throws Exception {
        // 初始化Jansi，支持Windows控制台ANSI转义序列
        AnsiConsole.systemInstall();
        
        // 设置系统属性
        System.setProperty("file.encoding", "UTF-8");
        System.setProperty("console.encoding", "UTF-8");
        
        // 设置控制台输出流编码
        System.setOut(new PrintStream(System.out, true, StandardCharsets.UTF_8.name()));
        System.setErr(new PrintStream(System.err, true, StandardCharsets.UTF_8.name()));
    }
}
```

#### 4. 创建启动脚本

##### Windows批处理脚本 (start.bat)
```batch
@echo off
REM 设置控制台编码为UTF-8
chcp 65001 > nul

REM 设置JVM参数解决中文乱码问题
set JAVA_OPTS=-Dfile.encoding=UTF-8 -Duser.timezone=Asia/Shanghai -Dconsole.encoding=UTF-8

echo 正在启动 Jinyu Chat 应用...
echo 控制台编码已设置为 UTF-8

mvn spring-boot:run %JAVA_OPTS%
```

##### PowerShell脚本 (start.ps1)
```powershell
# 设置控制台编码为UTF-8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding = [System.Text.Encoding]::UTF8

# 设置环境变量
$env:JAVA_OPTS = "-Dfile.encoding=UTF-8 -Duser.timezone=Asia/Shanghai"

mvn spring-boot:run
```

## 故障排除

### 🔍 常见问题

#### 1. 仍然显示乱码
**解决方案**：
```bash
# 使用提供的启动脚本
start.bat

# 或手动设置编码
chcp 65001
mvn spring-boot:run
```

#### 2. PowerShell执行策略限制
**解决方案**：
```powershell
# 临时允许执行脚本
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 执行脚本
.\start.ps1
```

#### 3. Jansi依赖问题
**解决方案**：
```bash
# 重新下载依赖
mvn clean compile
```

#### 4. IDE终端仍有乱码
**解决方案**：
- IntelliJ IDEA：File → Settings → Editor → General → Console → Default Encoding → UTF-8
- VS Code：设置terminal.integrated.encoding为utf8
