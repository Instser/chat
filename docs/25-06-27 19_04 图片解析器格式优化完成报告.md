### 3. 技术实现细节

#### 📝 核心处理方法
```java
public String processAiContent(String aiContent) {
    String content = aiContent.trim();
    
    // 移除markdown代码块格式
    content = content.replaceAll("```json\\s*", "");
    content = content.replaceAll("```\\s*$", "");
    content = content.replaceAll("^```\\s*", "");
    content = content.trim();
    
    // 检查是否已经包含说明文字
    if (!content.startsWith("Here's what the text in the image says.")) {
        if (content.trim().startsWith("{")) {
            content = "Here's what the text in the image says.\n" + content;
        } else {
            String jsonPart = extractJsonFromContent(content);
            if (jsonPart != null && !jsonPart.isEmpty()) {
                content = "Here's what the text in the image says.\n" + jsonPart;
            } else {
                content = "Here's what the text in the image says.\n{\"description\": \"" + 
                         content.replace("\"", "\\\"").replace("\n", "\\n") + "\"}";
            }
        }
    }
    
    return content;
}
```

#### 🔍 JSON提取逻辑
```java
private String extractJsonFromContent(String content) {
    try {
        int firstBrace = content.indexOf('{');
        int lastBrace = content.lastIndexOf('}');
        
        if (firstBrace != -1 && lastBrace != -1 && firstBrace < lastBrace) {
            String jsonCandidate = content.substring(firstBrace, lastBrace + 1);
            
            // 验证是否为有效的JSON
            ObjectMapper mapper = new ObjectMapper();
            mapper.readTree(jsonCandidate);
            
            return jsonCandidate;
        }
    } catch (Exception e) {
        log.debug("提取JSON失败: {}", e.getMessage());
    }
    
    return null;
}
```
