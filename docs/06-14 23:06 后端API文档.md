## 🔐 通用说明

### 响应格式
所有接口统一使用Result格式响应：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {...}
}
```

### 错误码说明
- `200`: 成功
- `400`: 请求参数错误
- `401`: 未授权/登录过期
- `404`: 资源不存在
- `500`: 服务器内部错误

### 认证方式
本系统使用**JWT Token认证**，支持两种传递方式：

#### 方式一：Cookie (推荐)
- **Cookie名称**: `auth-token`
- **自动管理**: 登录后服务器自动设置Cookie，后续请求浏览器自动发送
- **安全设置**: HttpOnly、SameSite=Strict
- **有效期**: 7天

#### 方式二：请求头 (备用)
- **请求头**: `Authorization: Bearer <token>`
- **手动管理**: 需要前端手动在每个请求中添加

**优先级**: 系统优先从Cookie中提取Token，如果Cookie中没有Token，则从Authorization请求头中提取
