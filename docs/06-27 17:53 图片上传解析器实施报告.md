## 🔧 技术实现细节

### 1. 图片处理流程

```
用户上传图片 → 魔数检测文件类型 → DocumentParserFactory.getParser() → ImageDocumentParser → Base64编码 → AI服务调用 → JSON响应解析 → 存储到数据库
```

### 2. Base64编码处理

#### 🔄 编码流程
1. **字节读取**: 读取图片文件的字节数组
2. **Base64编码**: 使用Java标准库进行编码
3. **Data URL生成**: 构建`data:image/type;base64,`格式
4. **AI请求**: 将data URL作为image_url参数发送

#### 📊 编码示例
```java
// 原始图片字节 → Base64字符串
String base64 = Base64Util.encodeToString(imageBytes);

// Base64字符串 → Data URL
String dataUrl = Base64Util.encodeImageToDataUrl(imageBytes, "image/png");
// 结果: "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."
```
