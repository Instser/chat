# 07-19 21:50 - 联网查询上下文传递问题修复

## 问题描述

### 发现的问题
在分析日志时发现，联网查询功能存在严重的上下文传递问题：

```
2025-07-19 21:36:57.403 [http-nio-8080-exec-13] DEBUG c.instser.chat.service.serviceimpl.ChatServiceImpl - 【联网内容拼接】处理前消息数量：3
2025-07-19 21:36:57.403 [http-nio-8080-exec-13] DEBUG c.instser.chat.service.serviceimpl.ChatServiceImpl - 【联网内容拼接】处理前最后一条用户消息长度：5，内容预览：那明天的呢
2025-07-19 21:36:57.403 [http-nio-8080-exec-13] INFO  c.instser.chat.service.serviceimpl.ChatServiceImpl - 【Gemini联网】开始处理联网搜索内容，查询：那明天的呢
2025-07-19 21:36:57.404 [http-nio-8080-exec-13] INFO  c.i.c.service.serviceimpl.GeminiNetworkServiceImpl - 【Gemini联网】开始处理联网查询，用户上下文长度：5
```

### 问题分析
1. **错误的逻辑**：系统只将最后一条用户消息（"那明天的呢"，长度5字符）发送给联网AI
2. **缺乏上下文**：联网AI无法理解用户的真实查询意图，因为缺少完整的对话历史
3. **影响范围**：影响所有联网查询功能，包括正常聊天、重试、编辑重发等场景

### 预期的正确逻辑
应该将整个会话的历史消息（用户和AI的完整对话）发送给联网AI，让其基于完整上下文理解用户的查询意图。

## 修复方案

### 1. 核心修改：processNetworkContent方法

**文件**：`src/main/java/com/instser/chat/service/serviceimpl/ChatServiceImpl.java`

**修改前**：
```java
// 使用Gemini API进行联网搜索
GeminiGroundingResponse geminiResponse = ((NetworkAiServiceImpl) networkAiService).queryWithGeminiGrounding(query);
```

**修改后**：
```java
// 构建完整的会话上下文发送给Gemini API
String fullContext = buildFullContextForNetworkSearch(messages);

// 使用Gemini API进行联网搜索，发送完整上下文
GeminiGroundingResponse geminiResponse = ((NetworkAiServiceImpl) networkAiService).queryWithGeminiGrounding(fullContext);
```

### 2. 新增方法：buildFullContextForNetworkSearch

**功能**：将整个会话历史转换为自然语言格式的上下文

**实现逻辑**：
1. 遍历所有消息，构建对话上下文
2. 清理内容，移除之前的联网搜索结果和文件内容
3. 对AI回复进行长度限制（前200字符），避免上下文过长
4. 格式化为自然语言对话格式

**代码示例**：
```java
private String buildFullContextForNetworkSearch(List<Map<String, String>> messages) {
    StringBuilder contextBuilder = new StringBuilder();
    contextBuilder.append("以下是用户与AI助手的完整对话历史，请基于这个上下文理解用户的最新需求并进行网络搜索：\n\n");
    
    for (int i = 0; i < messages.size(); i++) {
        Map<String, String> message = messages.get(i);
        String role = message.get("role");
        String content = message.get("content");
        
        String cleanContent = extractOriginalUserContent(content);
        
        if ("user".equals(role)) {
            contextBuilder.append("用户: ").append(cleanContent).append("\n\n");
        } else if ("assistant".equals(role)) {
            String shortContent = cleanContent.length() > 200 ? 
                cleanContent.substring(0, 200) + "..." : cleanContent;
            contextBuilder.append("AI助手: ").append(shortContent).append("\n\n");
        }
    }
    
    contextBuilder.append("请基于以上对话上下文，理解用户的最新需求并进行相关的网络搜索。");
    return contextBuilder.toString();
}
```
