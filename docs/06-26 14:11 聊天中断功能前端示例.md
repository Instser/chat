# 聊天中断功能前端示例

## 功能概述
实现用户在AI响应过程中主动中断聊天，并保存已接收的部分响应到数据库。

## 前端实现示例

### 1. 状态管理
```javascript
// 聊天状态管理
const [chatState, setChatState] = useState({
  isStreaming: false,
  canInterrupt: false,
  currentSessionId: null,
  currentMessageId: null
});

// 中断状态
const [interruptState, setInterruptState] = useState({
  isInterrupting: false,
  interruptRequested: false
});
```

### 2. 发送聊天请求
```javascript
const sendChatMessage = async (message, sessionId) => {
  try {
    // 更新状态：开始流式响应
    setChatState(prev => ({
      ...prev,
      isStreaming: true,
      canInterrupt: true,
      currentSessionId: sessionId
    }));

    // 重置中断状态
    setInterruptState({
      isInterrupting: false,
      interruptRequested: false
    });

    const response = await fetch('/chat', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify({
        messages: [{ role: 'user', content: message }],
        sessionId: sessionId,
        modelId: selectedModelId,
        userId: currentUserId
      })
    });

    if (!response.ok) {
      throw new Error('聊天请求失败');
    }

    // 处理流式响应
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      
      if (done) {
        console.log('流式响应完成');
        break;
      }

      // 检查是否请求了中断
      if (interruptState.interruptRequested) {
        console.log('检测到中断请求，停止读取流');
        reader.cancel();
        break;
      }

      buffer += decoder.decode(value, { stream: true });
      
      // 处理接收到的数据
      const lines = buffer.split('\n');
      buffer = lines.pop() || '';

      for (const line of lines) {
        if (line.trim()) {
          processStreamLine(line);
        }
      }
    }

  } catch (error) {
    console.error('聊天请求异常:', error);
  } finally {
    // 重置状态
    setChatState(prev => ({
      ...prev,
      isStreaming: false,
      canInterrupt: false
    }));
    setInterruptState({
      isInterrupting: false,
      interruptRequested: false
    });
  }
};
```

### 3. 中断聊天功能
```javascript
const interruptChat = async () => {
  if (!chatState.canInterrupt || interruptState.isInterrupting) {
    return;
  }

  try {
    // 设置中断状态
    setInterruptState(prev => ({
      ...prev,
      isInterrupting: true,
      interruptRequested: true
    }));

    console.log('发送中断请求...');

    const response = await fetch('/chat/stop', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify({
        sessionId: chatState.currentSessionId
      })
    });

    const result = await response.json();

    if (response.ok && result.success) {
      console.log('聊天中断成功:', result.data);
      
      // 显示中断成功提示
      showNotification('聊天已中断', 'success');
      
    } else {
      console.error('聊天中断失败:', result.message);
      showNotification(result.message || '中断失败', 'error');
      
      // 重置中断状态
      setInterruptState(prev => ({
        ...prev,
        interruptRequested: false
      }));
    }

  } catch (error) {
    console.error('中断请求异常:', error);
    showNotification('中断请求失败', 'error');
    
    // 重置中断状态
    setInterruptState(prev => ({
      ...prev,
      interruptRequested: false
    }));
  } finally {
    setInterruptState(prev => ({
      ...prev,
      isInterrupting: false
    }));
  }
};
```

### 4. 停止按钮组件
```jsx
const StopButton = () => {
  const isVisible = chatState.isStreaming && chatState.canInterrupt;
  const isDisabled = interruptState.isInterrupting;

  if (!isVisible) {
    return null;
  }

  return (
    <button
      onClick={interruptChat}
      disabled={isDisabled}
      className={`stop-button ${isDisabled ? 'stopping' : ''}`}
      title={isDisabled ? '正在停止...' : '停止响应'}
    >
      {isDisabled ? (
        <>
          <LoadingSpinner size="small" />
          正在停止...
        </>
      ) : (
        <>
          <StopIcon />
          停止
        </>
      )}
    </button>
  );
};
```

### 5. 流式数据处理
```javascript
const processStreamLine = (line) => {
  try {
    // 解析Vercel AI SDK格式的数据
    if (line.startsWith('0:')) {
      // 文本内容
      const content = JSON.parse(line.substring(2));
      appendToCurrentMessage(content);
      
    } else if (line.startsWith('d:')) {
      // 完成标记
      const data = JSON.parse(line.substring(2));
      
      if (data.interrupted) {
        console.log('收到中断完成标记');
        showNotification('响应已中断', 'info');
      } else if (data.finishReason === 'stop') {
        console.log('收到正常完成标记');
        
        // 处理标题生成
        if (data.title && typeof data.title === 'string') {
          updateSessionTitle(chatState.currentSessionId, data.title);
        }
      }
      
      // 标记流式响应完成
      setChatState(prev => ({
        ...prev,
        isStreaming: false,
        canInterrupt: false
      }));
    }
    
  } catch (error) {
    console.error('处理流式数据失败:', error);
  }
};
```

## 使用说明

1. **发送消息时**：自动显示停止按钮
2. **点击停止**：发送中断请求，按钮变为"正在停止..."状态
3. **中断成功**：显示成功提示，已接收的内容会保存到数据库
4. **中断失败**：显示错误提示，继续接收AI响应

## 注意事项

1. 只有在流式响应过程中才能中断
2. 中断请求发送后不能取消
3. 已接收的部分内容会自动保存到数据库
4. 中断的消息会标记为"[已中断]"
