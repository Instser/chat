# 07-07 15:33 易支付回调URL问题解决方案

## 问题描述
用户反馈：创建订单后，扫描后端返回的二维码，结果显示为没有回调URL。

## 问题分析

### 1. 技术验证结果
通过日志分析，发现支付URL中**确实包含了notify_url参数**：

```
支付链接: https://your-pay-gateway.example.com/submit.php?out_trade_no=JY202507071523142928&money=68.00&name=%E5%A5%97%E9%A4%90%E8%B4%AD%E4%B9%B0&sign=d2eae2dab3376b9bf50e9c65fa663988&pid=1674&type=wxpay&notify_url=https%3A%2F%2Fapi.example.com%2Fapi%2Fpayment%2Fyipay%2Fnotify&sign_type=MD5
```

解码后的notify_url: `https://api.example.com/api/payment/yipay/notify`

### 2. 回调URL可访问性验证
测试回调URL访问：
- URL: https://api.example.com/api/payment/yipay/notify
- 返回: `{"code":405,"message":"不支持的请求方法: GET","data":null}`
- 结论: ✅ 回调URL可正常访问，405错误是正常的（只接受POST请求）

### 3. 根本原因分析
根据易支付平台的通用规则，问题可能出现在：

1. **商户后台配置缺失**：大多数易支付平台要求在商户后台预先配置回调地址
2. **域名白名单限制**：回调域名可能需要加入白名单
3. **平台限制**：某些易支付平台不支持动态回调URL

## 解决方案

### 方案一：商户后台配置回调URL（推荐）

1. **登录易支付商户后台**
   - 网址：https://your-pay-gateway.example.com
   - 使用商户ID：1674 对应的账号登录

2. **设置回调地址**
   - 找到"支付配置"或"回调设置"选项
   - 设置异步回调地址：`https://api.example.com/api/payment/yipay/notify`
   - 设置同步回调地址（可选）：`https://example.com/payment/success`

3. **保存配置**
   - 确保配置保存成功
   - 测试回调地址的连通性

### 方案二：联系易支付客服

如果无法找到配置选项，需要：

1. **联系易支付平台客服**
   - 提供商户ID：1674
   - 请求设置回调URL：`https://api.example.com/api/payment/yipay/notify`
   - 请求将域名 `api.example.com` 加入白名单

2. **提供必要信息**
   - 商户ID：1674
   - 回调URL：https://api.example.com/api/payment/yipay/notify
   - 业务说明：在线支付系统回调通知

### 方案三：代码层面优化（辅助）

虽然代码层面已经正确设置了notify_url，但可以添加一些日志来帮助调试：
