## 优化概述
基于用户反馈，对联网查询结果存储功能进行优化，简化查询逻辑，优化外键约束，保留favicon字段增强用户体验，调整content字段限制为500字符，提升系统性能和可维护性。

## 核心优化点

### 1. 查询逻辑简化
**原方案问题**：设计了复杂的JSON内容查询功能
**优化方案**：
- 移除对JSON内容的直接查询需求
- 仅通过关联了联网内容的messageId查询联网表
- 简化数据访问模式，提升查询性能

### 2. 外键约束优化
**原方案问题**：外键约束过于严格，可能影响数据操作灵活性
**优化方案**：
- 保留核心外键约束，确保数据完整性
- 优化约束级联操作，避免意外数据丢失
- 增加约束验证逻辑，提升数据质量

## 外键约束优化说明

### 1. 约束级联策略优化
```sql
-- 用户约束：RESTRICT - 防止误删用户导致数据丢失
CONSTRAINT fk_web_search_user FOREIGN KEY (user_id) REFERENCES t_user (id) 
  ON DELETE RESTRICT ON UPDATE CASCADE

-- 会话约束：RESTRICT - 防止误删会话导致数据丢失  
CONSTRAINT fk_web_search_session FOREIGN KEY (session_id) REFERENCES t_chat_session (session_id) 
  ON DELETE RESTRICT ON UPDATE CASCADE

-- 消息约束：CASCADE - 消息删除时自动清理联网内容
CONSTRAINT fk_web_search_message FOREIGN KEY (message_id) REFERENCES t_chat_message (message_id) 
  ON DELETE CASCADE ON UPDATE CASCADE
```

### 2. 约束优化原理
- **用户和会话使用RESTRICT**：防止意外删除导致联网数据丢失
- **消息使用CASCADE**：消息删除时自动清理相关联网内容
- **统一使用UPDATE CASCADE**：支持ID更新时的数据同步

### 3. 优化的服务层实现
```java
@Service
@Slf4j
public class WebSearchContentServiceImpl implements WebSearchContentService {

    @Autowired
    private WebSearchContentDao webSearchContentDao;

    @Autowired
    private ChatMessageService chatMessageService;

    @Override
    @Transactional
    public boolean saveWebSearchContent(String messageId, String queryText,
                                      TavilySearchResponse searchResponse, Long userId, String sessionId) {
        try {
            // 1. 格式化搜索结果为优化JSON
            String contentJson = formatSearchResponseToOptimizedJson(searchResponse);
            int resultCount = getValidResultCount(searchResponse);

            // 2. 创建联网内容记录
            WebSearchContent webSearchContent = new WebSearchContent();
            webSearchContent.setWebSearchId(UUID.randomUUID().toString());
            webSearchContent.setUserId(userId);
            webSearchContent.setSessionId(sessionId);
            webSearchContent.setMessageId(messageId);
            webSearchContent.setQueryText(queryText);
            webSearchContent.setContent(contentJson);
            webSearchContent.setResultCount(resultCount);
            webSearchContent.setStatus(1);
            webSearchContent.setDeleted(0);

            // 3. 保存联网内容
            boolean saved = save(webSearchContent);

            // 4. 更新消息的联网标记
            if (saved) {
                chatMessageService.updateWebSearchFlag(messageId, true);
                log.info("联网查询结果保存成功，用户ID：{}，消息ID：{}，结果数量：{}", userId, messageId, resultCount);
            }

            return saved;
        } catch (Exception e) {
            log.error("保存联网查询结果失败，消息ID：{}，用户ID：{}", messageId, userId, e);
            return false;
        }
    }

    @Override
    public WebSearchContent getByMessageId(String messageId) {
        try {
            return webSearchContentDao.selectByMessageId(messageId);
        } catch (Exception e) {
            log.error("查询联网内容失败，消息ID：{}", messageId, e);
            return null;
        }
    }

    @Override
    @Transactional
    public boolean updateWebSearchContent(String oldMessageId, String newMessageId,
                                        String queryText, TavilySearchResponse searchResponse) {
        try {
            // 1. 格式化搜索结果为优化JSON
            String contentJson = formatSearchResponseToOptimizedJson(searchResponse);
            int resultCount = getValidResultCount(searchResponse);

            // 2. 更新联网内容记录的messageId和内容
            int updated = webSearchContentDao.updateContentAndMessageId(
                oldMessageId, newMessageId, queryText, contentJson, resultCount
            );

            if (updated > 0) {
                log.info("联网内容更新成功，旧消息ID：{}，新消息ID：{}，查询：{}", oldMessageId, newMessageId, queryText);
                return true;
            } else {
                log.warn("联网内容更新失败，未找到记录，旧消息ID：{}", oldMessageId);
                return false;
            }
        } catch (Exception e) {
            log.error("更新联网查询结果失败，旧消息ID：{}，新消息ID：{}", oldMessageId, newMessageId, e);
            return false;
        }
    }

    @Override
    public boolean deleteByMessageId(String messageId) {
        try {
            int deleted = webSearchContentDao.deleteByMessageId(messageId);
            if (deleted > 0) {
                log.info("联网内容删除成功，消息ID：{}", messageId);
                return true;
            }
            return false;
        } catch (Exception e) {
            log.error("删除联网内容失败，消息ID：{}", messageId, e);
            return false;
        }
    }

    @Override
    public List<WebSearchContent> getUserWebSearchHistory(Long userId, int page, int size) {
        try {
            int offset = (page - 1) * size;
            return webSearchContentDao.selectUserHistory(userId, offset, size);
        } catch (Exception e) {
            log.error("查询用户联网历史失败，用户ID：{}", userId, e);
            return new ArrayList<>();
        }
    }

    @Override
    public List<WebSearchContent> getSessionWebSearchContent(String sessionId) {
        try {
            return webSearchContentDao.selectBySessionId(sessionId);
        } catch (Exception e) {
            log.error("查询会话联网内容失败，会话ID：{}", sessionId, e);
            return new ArrayList<>();
        }
    }

    /**
     * 格式化搜索结果为优化JSON（保留favicon，限制content为500字符）
     */
    private String formatSearchResponseToOptimizedJson(TavilySearchResponse searchResponse) {
        List<Map<String, String>> validResults = new ArrayList<>();
        if (searchResponse.getResults() != null) {
            for (TavilySearchResult result : searchResponse.getResults()) {
                if (isValidResult(result)) {
                    Map<String, String> resultMap = new HashMap<>();
                    resultMap.put("url", result.getUrl() != null ? result.getUrl() : "");
                    resultMap.put("title", result.getTitle() != null ? result.getTitle() : "");
                    resultMap.put("content", truncateContent(result.getContent()));
                    resultMap.put("favicon", result.getFavicon() != null ? result.getFavicon() : "");
                    validResults.add(resultMap);
                }
            }
        }
        return JSON.toJSONString(validResults);
    }

    private boolean isValidResult(TavilySearchResult result) {
        return result != null &&
               (StringUtils.hasText(result.getUrl()) ||
                StringUtils.hasText(result.getTitle()) ||
                StringUtils.hasText(result.getContent()));
    }

    private String truncateContent(String content) {
        if (content == null) return "";
        return content.length() > 500 ? content.substring(0, 500) + "..." : content;
    }

    private int getValidResultCount(TavilySearchResponse searchResponse) {
        if (searchResponse.getResults() == null) return 0;
        return (int) searchResponse.getResults().stream()
                .filter(this::isValidResult)
                .count();
    }
}
```

## 性能监控建议

### 1. 关键指标监控
```java
// 在服务层添加性能监控
@Component
public class WebSearchPerformanceMonitor {

    private final MeterRegistry meterRegistry;

    public WebSearchPerformanceMonitor(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
    }

    public void recordSaveOperation(boolean success, long duration) {
        Timer.Sample sample = Timer.start(meterRegistry);
        sample.stop(Timer.builder("websearch.save.duration")
                .tag("success", String.valueOf(success))
                .register(meterRegistry));
    }

    public void recordQueryOperation(String queryType, long duration) {
        Timer.builder("websearch.query.duration")
                .tag("type", queryType)
                .register(meterRegistry)
                .record(duration, TimeUnit.MILLISECONDS);
    }
}
```

### 2. 慢查询监控
```sql
-- 开启慢查询日志
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;

-- 监控联网查询相关的慢查询
SELECT
    sql_text,
    exec_count,
    avg_timer_wait/1000000000 as avg_duration_seconds,
    max_timer_wait/1000000000 as max_duration_seconds
FROM performance_schema.events_statements_summary_by_digest
WHERE sql_text LIKE '%t_web_search_content%'
ORDER BY avg_timer_wait DESC;
```

这个优化方案通过简化查询逻辑、优化外键约束、精简数据结构等措施，为联网查询结果存储功能提供了高性能、易维护的解决方案。
