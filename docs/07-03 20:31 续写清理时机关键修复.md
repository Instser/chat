# 07-03 20:31 续写清理时机关键修复

## 问题概述

用户反馈了续写清理实现的关键错误：

### 🚨 **核心问题：清理时机错误**
- **错误实现**：在续写结束后保存时才进行标签清理
- **正确实现**：应该在续写的流式响应开始时，检查JSON缓冲块，清理响应开头的thinking标签块和代码标记块后，才开始向前端进行续写响应

## 问题分析

### 📊 **当前错误的实现流程**

#### 1. **错误的清理时机**
```java

if (success && hasContentSent[0]) {
    String finalContent = alignedContentForSaving.toString();

```

#### 2. **错误的清理方法**
```java

    // 1. 移除开头的 <response> 标签
```

### 🎯 **正确的实现应该是**

#### 1. **在流式响应时清理**
- 在`processContinuationJson`方法中处理每个JSON数据块时
- 立即清理thinking标签、response标签、代码块标记
- 清理完成后才发送给前端

#### 2. **保存时不再清理**
- 因为在流式响应时已经清理过了
- 直接保存已清理的内容

## 解决方案

### 🔧 **修复1：增强流式响应清理**

#### 修改cleanContinuationContent方法
```java
/**
 * 清理续写内容中的AI标记（在流式响应开始时执行）
 */
private String cleanContinuationContent(String content) {
    if (content == null || content.trim().isEmpty()) {
        return content;
    }

    String cleaned = content;
    log.debug("开始清理续写内容，原始长度: {}", content.length());

    // 1. 移除完整的 <thinking>...</thinking> 块（最重要的清理）
    cleaned = removeThinkingBlocks(cleaned);

    // 2. 移除开头的 <response> 标签
    cleaned = removeResponseTags(cleaned);

    // 3. 移除开头的代码块标记（```javascript, ```html 等）
    cleaned = removeCodeBlockMarkers(cleaned);

    // 4. 清理多余的空白行
    cleaned = cleanExtraWhitespace(cleaned);

    log.debug("续写内容清理完成，清理后长度: {}, 移除字符数: {}",
            cleaned.length(), content.length() - cleaned.length());

    return cleaned;
}
```

#### 新增removeThinkingBlocks方法
```java
/**
 * 移除 <thinking>...</thinking> 块和单独的thinking标记（用于流式响应清理）
 */
private String removeThinkingBlocks(String content) {
    if (content == null) return content;

    String result = content;

    // 1. 移除完整的 thinking 块，支持多行和嵌套
    String completeBlockPattern = "(?s)<thinking>.*?</thinking>\\s*";
    result = result.replaceAll(completeBlockPattern, "");

    // 2. 移除开头的单独 <thinking> 标记
    result = result.replaceAll("^\\s*<thinking>\\s*", "");

    // 3. 移除结尾的单独 </thinking> 标记
    result = result.replaceAll("\\s*</thinking>\\s*$", "");

    if (!result.equals(content)) {
        log.debug("移除了 thinking 相关标记，原长度: {}, 新长度: {}", content.length(), result.length());
    }

    return result;
}
```

## 技术特点

### ✅ **正确的清理时机**

#### 1. **流式响应时清理**
- **时机**：在`processContinuationJson`方法中处理每个JSON数据块时
- **内容**：thinking标签、response标签、代码块标记
- **效果**：用户看到的内容已经是清理后的干净内容

#### 2. **保存时不再清理**

- **response标签**：`<response>`
- **代码块标记**：````javascript`, ````html`等

### ✅ **性能优化**
