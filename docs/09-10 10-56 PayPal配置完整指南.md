# PayPal配置完整指南

**创建时间：** 2025年09月10日 10:56  
**文档类型：** 配置指南  
**适用环境：** 开发环境、测试环境、生产环境

## 配置概述

PayPal模块支持通过环境变量和application.yml文件两种方式进行配置。推荐在生产环境使用环境变量，开发环境可以选择任一方式。

## 配置方式

### 方式1：环境变量配置（推荐）

#### Windows环境配置

```bash
# PowerShell 配置命令
$env:PAYPAL_ENABLED="true"
$env:PAYPAL_CLIENT_ID="你的Client ID"
$env:PAYPAL_CLIENT_SECRET="你的Client Secret"
$env:PAYPAL_MODE="sandbox"  # 沙箱环境，生产环境使用 "live"
$env:PAYPAL_WEBHOOK_ID="你的Webhook ID"  # 可选
$env:PAYPAL_RETURN_URL="https://chat.example.com/payment/success"
$env:PAYPAL_CANCEL_URL="https://chat.example.com/payment/cancel"
```

#### Linux/macOS环境配置

```bash
# Bash/Zsh 配置命令
export PAYPAL_ENABLED=true
export PAYPAL_CLIENT_ID="你的Client ID"
export PAYPAL_CLIENT_SECRET="你的Client Secret"
export PAYPAL_MODE=sandbox  # 沙箱环境，生产环境使用 live
export PAYPAL_WEBHOOK_ID="你的Webhook ID"  # 可选
export PAYPAL_RETURN_URL="https://chat.example.com/payment/success"
export PAYPAL_CANCEL_URL="https://chat.example.com/payment/cancel"
```

#### 持久化环境变量

**Windows：**
1. 系统属性 → 高级 → 环境变量
2. 在用户变量或系统变量中添加PayPal配置

**Linux/macOS：**
```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
echo 'export PAYPAL_ENABLED=true' >> ~/.bashrc
echo 'export PAYPAL_CLIENT_ID="你的Client ID"' >> ~/.bashrc
echo 'export PAYPAL_CLIENT_SECRET="你的Client Secret"' >> ~/.bashrc
echo 'export PAYPAL_MODE=sandbox' >> ~/.bashrc
source ~/.bashrc
```

### 方式2：application.yml配置

编辑 `src/main/resources/application.yml` 文件：

```yaml
# 支付配置
payment:
  paypal:
    # 基础配置
    enabled: true                                    # 是否启用PayPal支付
    client-id: "AQxxxx...你的Client ID"              # PayPal客户端ID
    client-secret: "EJxxx...你的Client Secret"       # PayPal客户端密钥
    mode: sandbox                                    # 环境：sandbox(沙箱) 或 live(生产)
    
    # 货币配置
    currency: USD                                    # 默认货币
    supported-currencies: USD,EUR,GBP,CAD,AUD,JPY,CHF,SEK,NOK,DKK,CNY
    
    # URL配置
    return-url: https://chat.example.com/payment/success  # 支付成功跳转URL
    cancel-url: https://chat.example.com/payment/cancel   # 支付取消跳转URL
    
    # API配置
    connect-timeout: 30                              # 连接超时（秒）
    read-timeout: 80                                # 读取超时（秒）
    max-retries: 3                                  # 最大重试次数
    
    # Webhook配置（可选）
    webhook-id: "5WR12345...你的Webhook ID"          # Webhook验证ID
```

## 配置项详解

| 配置项 | 环境变量 | 默认值 | 说明 |
|--------|----------|--------|------|
| enabled | PAYPAL_ENABLED | true | 是否启用PayPal支付功能 |
| client-id | PAYPAL_CLIENT_ID | - | PayPal应用的客户端ID，必填 |
| client-secret | PAYPAL_CLIENT_SECRET | - | PayPal应用的客户端密钥，必填 |
| mode | PAYPAL_MODE | sandbox | 环境模式：sandbox(沙箱)/live(生产) |
| currency | PAYPAL_CURRENCY | USD | 默认货币类型 |
| supported-currencies | PAYPAL_SUPPORTED_CURRENCIES | USD,EUR,GBP... | 支持的货币列表 |
| connect-timeout | PAYPAL_CONNECT_TIMEOUT | 30 | API连接超时时间（秒） |
| read-timeout | PAYPAL_READ_TIMEOUT | 80 | API读取超时时间（秒） |
| max-retries | PAYPAL_MAX_RETRIES | 3 | API请求最大重试次数 |
| webhook-id | PAYPAL_WEBHOOK_ID | - | Webhook验证ID，用于签名验证 |
| return-url | PAYPAL_RETURN_URL | - | 支付成功后跳转URL |
| cancel-url | PAYPAL_CANCEL_URL | - | 支付取消后跳转URL |

## 沙箱环境配置

### 1. 获取沙箱凭据

1. 访问 [PayPal开发者平台](https://developer.paypal.com/)
2. 登录PayPal开发者账户
3. 进入 "My Apps & Credentials"
4. 选择 "Sandbox" 标签
5. 创建新应用或查看现有应用
6. 获取以下信息：
   - **Client ID** (格式：AQxxxx...)
   - **Client Secret** (格式：EJxxx...)

### 2. 沙箱账户配置

```bash
# 沙箱环境配置示例
export PAYPAL_CLIENT_ID="AQ4eV-W7JGkOKf1k7ZLr8kJ9oM5ZtR1b2NjH0r7cS8oKhF3gD9eA1fB2nC4mX8qP"
export PAYPAL_CLIENT_SECRET="EJNxxxxxx-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
export PAYPAL_MODE=sandbox
```

## 生产环境配置

### 1. 获取生产凭据

1. 在PayPal开发者平台切换到 "Live" 标签
2. 创建或查看生产应用
3. 获取生产环境的Client ID和Client Secret
4. 配置生产环境的Webhook（如需要）

### 2. 生产环境配置

```bash
# 生产环境配置示例
export PAYPAL_CLIENT_ID="ATxxxx...你的生产Client ID"
export PAYPAL_CLIENT_SECRET="ELxxx...你的生产Client Secret"
export PAYPAL_MODE=live
export PAYPAL_WEBHOOK_ID="5WRxxxx...你的生产Webhook ID"
```

## Webhook配置（可选）

### 1. 创建Webhook

1. 在PayPal开发者控制台中进入你的应用
2. 找到 "Webhooks" 部分
3. 点击 "Add webhook"
4. 配置Webhook URL：`https://你的域名/api/payment/paypal/webhook`
5. 选择事件类型：
   - CHECKOUT.ORDER.APPROVED
   - CHECKOUT.ORDER.COMPLETED
   - PAYMENT.CAPTURE.COMPLETED
   - PAYMENT.CAPTURE.DENIED

### 2. 配置Webhook ID

```bash
# 获取Webhook ID并配置
export PAYPAL_WEBHOOK_ID="5WR12345678901234567890ABCDEFGH"
```

## 常见配置问题

### 1. Client ID/Secret错误

**问题：** 启动时显示"PayPal配置不完整"  
**解决：** 检查Client ID和Client Secret是否正确设置

### 2. 环境模式错误

**问题：** API调用失败，401 Unauthorized  
**解决：** 确认mode设置正确：
- 沙箱环境：`mode: sandbox`
- 生产环境：`mode: live`

### 3. 网络连接问题

**问题：** 连接超时或网络错误  
**解决：** 调整超时配置：
```yaml
payment:
  paypal:
    connect-timeout: 60  # 增加连接超时时间
    read-timeout: 120   # 增加读取超时时间
```

### 4. 货币不支持

**问题：** 创建支付时提示货币不支持  
**解决：** 检查supported-currencies配置是否包含所需货币

## 安全建议

### 1. 密钥管理

- ✅ 生产环境使用环境变量存储密钥
- ✅ 不要将密钥提交到版本控制系统
- ✅ 定期轮换PayPal应用密钥
- ✅ 限制PayPal应用的权限范围

### 2. 网络安全

- ✅ 生产环境使用HTTPS
- ✅ 配置防火墙限制API访问
- ✅ 启用Webhook签名验证
- ✅ 监控异常API调用

### 3. 配置文件安全

```yaml
# ❌ 错误：不要在配置文件中硬编码密钥
client-secret: "EJNxxxxxx-real-secret-key"

# ✅ 正确：使用环境变量
client-secret: ${PAYPAL_CLIENT_SECRET:}
```
