## 🔒 安全机制详解

### 1. 多层安全防护

#### 网络层防护
- **端口绑定**: 8081端口仅绑定127.0.0.1
- **连接限制**: 最大100个并发连接
- **超时控制**: 30秒连接超时

#### 应用层防护
- **IP过滤器**: 检查所有HTTP请求的来源IP
- **代理检测**: 支持X-Forwarded-For、X-Real-IP等头部
- **访问拒绝**: 返回403状态码和错误信息

#### 日志监控
- **访问记录**: 记录所有访问尝试
- **拒绝日志**: 特别记录被拒绝的访问
- **调试信息**: 详细的IP检测过程

### 2. IP地址检测逻辑

#### 检测顺序
1. **X-Forwarded-For**: 代理转发的原始IP
2. **X-Real-IP**: 真实客户端IP
3. **X-Forwarded-Proto**: 协议转发头
4. **RemoteAddr**: 直接连接的IP地址

#### 支持的本地地址
- `127.0.0.1` (IPv4 localhost)
- `localhost` (域名形式)
- `::1` (IPv6 localhost 简写)
- `0:0:0:0:0:0:0:1` (IPv6 localhost 完整)

### 3. 访问控制示例

#### 允许的访问
```bash
# 本地直接访问
curl http://127.0.0.1:8081/api/admin/cache/stats

# 通过代理，原始IP为本地
curl -H "X-Forwarded-For: 127.0.0.1" http://proxy:8081/api/admin/cache/stats
```

#### 被拒绝的访问
```bash
# 远程IP访问
curl http://192.168.1.100:8081/api/admin/cache/stats
# 返回: {"code":403,"message":"缓存管理接口仅允许本地访问","data":null}

# 通过代理，原始IP为远程
curl -H "X-Forwarded-For: 192.168.1.100" http://proxy:8081/api/admin/cache/stats
# 返回: {"code":403,"message":"缓存管理接口仅允许本地访问","data":null}
```
