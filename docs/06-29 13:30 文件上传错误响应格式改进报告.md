# 文件上传错误响应格式改进报告

**📅 创建时间**: 2025-06-29 13:30:00  
**👤 创建人员**: Augment Agent  
**📊 文档版本**: v1.0  
**🎯 改进目标**: 修改文件上传错误处理，使用Result.success返回统一的错误响应格式

## 需求背景

用户要求文件上传出错时，不用返回聊天信息，而是按照正常的错误响应格式，用Result.success返回。响应体中data的数据格式为：
```json
{
  "code": 0,
  "message": []
}
```
其中code是错误码，message是报错信息。

### 4. 修改FileController错误响应格式

**文件**: `src/main/java/com/instser/chat/controller/FileController.java`

**响应格式改进**:

#### 4.1 空文件错误
```java
if (files == null || files.length == 0) {
    Map<String, Object> errorData = new HashMap<>();
    errorData.put("code", ResultCode.FILE_EMPTY.getCode());
    errorData.put("message", "No files uploaded");
    return Result.success(errorData);
}
```

#### 4.2 文件上传失败错误
```java
if (validatedFileIds.isEmpty()) {
    Map<String, Object> errorData = new HashMap<>();
    errorData.put("code", ResultCode.FILE_UPLOAD_FAILED.getCode());
    errorData.put("message", "File upload failed. Please try again later.");
    return Result.success(errorData);
}
```

#### 4.3 FileUploadException处理
```java
} catch (FileUploadException e) {
    Map<String, Object> errorData = new HashMap<>();
    
    // 根据错误类型返回对应的错误码
    switch (e.getErrorType()) {
        case "FILE_EMPTY":
            errorData.put("code", ResultCode.FILE_EMPTY.getCode());
            break;
        case "FILE_SIZE_EXCEEDED":
            errorData.put("code", ResultCode.FILE_SIZE_EXCEEDED.getCode());
            break;
        case "FILE_TYPE_NOT_SUPPORTED":
            errorData.put("code", ResultCode.FILE_TYPE_NOT_SUPPORTED.getCode());
            break;
        case "FILE_PARSE_FAILED":
            errorData.put("code", ResultCode.FILE_PARSE_FAILED.getCode());
            break;
        default:
            errorData.put("code", ResultCode.FILE_UPLOAD_FAILED.getCode());
            break;
    }
    
    errorData.put("message", e.getErrorMessage());
    return Result.success(errorData);
}
```

### 5. 修改GlobalExceptionHandler

**文件**: `src/main/java/com/instser/chat/common/exception/GlobalExceptionHandler.java`

**文件大小超限异常处理**:
```java
@ExceptionHandler(value = MaxUploadSizeExceededException.class)
public Result<Map<String, Object>> handleMaxUploadSizeExceededException(MaxUploadSizeExceededException e, HttpServletRequest request) {
    log.warn("文件上传大小超限 [{}] {}: {} - {}", method, requestUrl, originalMessage, e.getMessage());
    
    Map<String, Object> errorData = new HashMap<>();
    errorData.put("code", ResultCode.FILE_SIZE_EXCEEDED.getCode());
    errorData.put("message", "File size exceeds limit");
    
    return Result.success(errorData);
}
```

## 错误响应格式

### 统一响应结构
所有文件上传错误都使用`Result.success()`返回，响应结构为：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "code": 5001,
    "message": "File upload failed. Please try again later."
  },
  "timestamp": 1719648600000
}
```

### 错误码对应关系

| 错误场景 | 错误码 | 错误消息 |
|---------|--------|----------|
| 文件为空 | 5005 | No files uploaded |
| 文件大小超限 (>10MB) | 5002 | File size exceeds limit |
| 不支持的文件类型 | 5003 | File type not supported |
| 文件解析失败 | 5004 | File parsing failed |
| 通用上传失败 | 5001 | File upload failed. Please try again later. |
| 文件不存在 | 5006 | File not found |

## 与聊天错误处理的区别

### 聊天错误处理
- 返回错误内容作为聊天消息
- 保存到数据库作为assistant角色消息
- 统一返回"Request failed. Please try again later."

### 文件上传错误处理
- 使用Result.success返回标准API响应格式
- 不保存到聊天数据库
- 在data中包含具体的错误码和错误消息
- 根据错误类型返回不同的错误码
