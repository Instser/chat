## 问题描述
联网搜索功能在实际使用中可能出现500错误，主要原因是：
1. 联网搜索结果内容过长，导致请求体过大
2. 搜索结果包含特殊字符，导致JSON格式错误
3. 未对搜索结果数量进行限制，可能返回过多内容
4. 缺乏对HTML标签和控制字符的处理

## 解决方案

### 1. 内容长度限制

#### 多层级长度控制
```java
final int MAX_RESULTS = 5; // 限制最多处理5个结果
final int MAX_CONTENT_LENGTH = 2000; // 限制每个结果的最大内容长度
final int MAX_TOTAL_CONTENT_LENGTH = 10000; // 限制总内容长度
```

#### 智能截断机制
```java
// 单个结果内容截断
if (content.length() > MAX_CONTENT_LENGTH) {
    content = content.substring(0, MAX_CONTENT_LENGTH) + "...";
    log.info("内容过长，已截断，URL：{}，原长度：{}，截断后长度：{}", 
            result.getUrl(), result.getRawContent().length(), content.length());
}

// 总内容长度检查
if (newContent.length() > MAX_TOTAL_CONTENT_LENGTH) {
    log.warn("用户消息总长度过长，长度：{}，将进行截断", newContent.length());
    newContent = newContent.substring(0, MAX_TOTAL_CONTENT_LENGTH) + "...]";
}
```

### 2. 内容清理优化

#### 新增cleanNetworkContent方法
```java
/**
 * 清理联网搜索内容，移除可能导致问题的字符和格式
 *
 * @param content 原始内容
 * @return 清理后的内容
 */
private String cleanNetworkContent(String content) {
    if (content == null) {
        return "";
    }
    
    return content.trim()
            // 移除多余的空白字符
            .replaceAll("\\s+", " ")
            // 移除HTML标签
            .replaceAll("<[^>]+>", "")
            // 移除特殊的Unicode字符
            .replaceAll("[\\u0000-\\u001F\\u007F-\\u009F]", " ")
            // 移除连续的标点符号
            .replaceAll("[.]{3,}", "...")
            // 确保内容不为空
            .trim();
}
```

#### 增强JSON转义处理
```java
private String escapeJsonString(String str) {
    if (str == null) {
        return "";
    }
    return str.replace("\\", "\\\\")
              .replace("\"", "\\\"")
              .replace("\n", "\\n")
              .replace("\r", "\\r")
              .replace("\t", "\\t")
              .replace("\b", "\\b")
              .replace("\f", "\\f")
              .replace("/", "\\/")
              // 移除或替换可能导致问题的控制字符
              .replaceAll("[\\x00-\\x1F\\x7F]", " ");
}
```

### 3. 处理流程优化

#### 结果数量控制
```java
int processedCount = 0;
for (com.instser.chat.entity.TavilyExtractResult result : extractResponse.getResults()) {
    if (processedCount >= MAX_RESULTS) {
        log.info("已达到最大结果数量限制：{}，停止处理更多结果", MAX_RESULTS);
        break;
    }
    // 处理逻辑...
    processedCount++;
}
```

#### 分层内容验证
```java
// 第一层：单个结果内容清理和截断
String content = cleanNetworkContent(result.getRawContent());
if (content.length() > MAX_CONTENT_LENGTH) {
    content = content.substring(0, MAX_CONTENT_LENGTH) + "...";
}

// 第二层：联网内容总长度检查
if (networkContent.length() > MAX_TOTAL_CONTENT_LENGTH) {
    networkContent = networkContent.substring(0, MAX_TOTAL_CONTENT_LENGTH) + "...]";
}

// 第三层：最终用户消息长度检查
if (newContent.length() > MAX_TOTAL_CONTENT_LENGTH) {
    newContent = newContent.substring(0, MAX_TOTAL_CONTENT_LENGTH) + "...]";
}
```

## 技术特点

### 防御性编程
- **多层防护**: 在多个层级进行内容长度和格式检查
- **优雅降级**: 内容过长时进行智能截断而非报错
- **异常隔离**: 格式化错误不影响基础聊天功能

### 性能优化
- **早期截断**: 在处理过程中及时截断过长内容
- **结果限制**: 限制处理的搜索结果数量，避免过度处理
- **内存控制**: 通过长度限制控制内存使用

### 内容质量
- **HTML清理**: 移除HTML标签，提取纯文本内容
- **字符规范**: 统一处理特殊字符和控制字符
- **格式统一**: 标准化空白字符和标点符号
