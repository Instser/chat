# 07-31 02:30 支付回调异常和Redis连接问题修复报告

**时间**: 2025-07-31 02:30  
**版本**: v1.2.1

## 问题概述

本次修复解决了两个关键问题：
1. **PaymentController中的StringIndexOutOfBoundsException**：在处理易支付回调时发生字符串索引越界
2. **Redis连接超时问题**：Redisson无法稳定连接到Redis服务器

## 问题分析

### 1. StringIndexOutOfBoundsException问题

#### 1.1 错误信息
```
2025-07-31 02:26:12.128 [http-nio-8080-exec-18] ERROR com.instser.chat.controller.PaymentController - 处理易支付回调异常
java.lang.StringIndexOutOfBoundsException: begin 0, end -1, length 6
	at java.base/java.lang.String.checkBoundsBeginEnd(String.java:4606)
	at java.base/java.lang.String.substring(String.java:2709)
```

#### 1.2 问题根因
在`PaymentSecurityUtil.generateCallbackRequestId()`方法中，当signature参数为空字符串时，`signature.length()`返回0，导致`Math.min(8, 0)`返回0，然后`substring(0, 0)`会导致索引越界。

#### 1.3 问题代码
```java
// 原有代码 - 存在问题
public String generateCallbackRequestId(String orderNo, String timestamp, String signature) {
    return String.format("%s_%s_%s", orderNo, timestamp, 
            signature != null ? signature.substring(0, Math.min(8, signature.length())) : "");
}
```

### 2. Redis连接超时问题

#### 2.1 错误信息
```
2025-07-31 02:26:53.241 [redisson-netty-2-10] ERROR org.redisson.connection.SingleEntry - Unable to change master
java.util.concurrent.CompletionException: org.redisson.client.RedisConnectionException: Unable to connect to Redis server
Caused by: org.redisson.client.RedisTimeoutException: Command execution timeout for command: (AUTH)
```

#### 2.2 问题根因
- Redis连接配置缺少DNS监控和编解码器设置
- 连接超时处理不够完善
- 缺少适当的重试机制配置

## 修复方案

### 1. 修复StringIndexOutOfBoundsException

#### 1.1 主要修复 - PaymentSecurityUtil
**文件**: `src/main/java/com/instser/chat/util/PaymentSecurityUtil.java`
**行号**: 88-101

```java
public String generateCallbackRequestId(String orderNo, String timestamp, String signature) {
    // 安全处理signature参数，避免StringIndexOutOfBoundsException
    String signaturePart = "";
    if (signature != null && !signature.trim().isEmpty()) {
        int length = signature.length();
        if (length > 0) {
            signaturePart = signature.substring(0, Math.min(8, length));
        }
    }
    return String.format("%s_%s_%s", 
            orderNo != null ? orderNo : "unknown", 
            timestamp != null ? timestamp : "0", 
            signaturePart);
}
```

#### 1.2 次要修复 - OAuth2SecurityUtil
**文件**: `src/main/java/com/instser/chat/util/OAuth2SecurityUtil.java`
**行号**: 162-168


#### 1.3 修复要点

- **哈希安全**: 修复OAuth2SecurityUtil中的潜在字符串截取问题
