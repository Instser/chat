**时间**: 2025-06-30 16:42  
**版本**: v1.0  
**问题**: MySQL 5.7语法兼容性错误修复

## 🚨 问题描述

### 错误信息
```sql
[ERR] 1064 - You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'IF NOT EXISTS `idx_order_expire_status` ON `t_user_order` (`expire_time`, `payme' at line 2
```

### 根本原因
原始SQL脚本使用了`CREATE INDEX IF NOT EXISTS`语法，这是MySQL 8.0的特性，在MySQL 5.7中不支持。

## 🔧 修复方案

### 1. 问题分析
- **原始语法**: `CREATE INDEX IF NOT EXISTS`
- **支持版本**: MySQL 8.0+
- **当前环境**: MySQL 5.7
- **解决方案**: 使用动态SQL检查索引是否存在

### 2. 修复策略
采用以下兼容性策略：
1. 使用`INFORMATION_SCHEMA.STATISTICS`查询索引是否存在
2. 使用动态SQL(`PREPARE`/`EXECUTE`)条件创建索引
3. 提供详细的执行反馈信息

### 3. 修复代码示例
```sql
-- 检查索引是否存在
SET @index_exists = (
    SELECT COUNT(1) 
    FROM INFORMATION_SCHEMA.STATISTICS 
    WHERE TABLE_SCHEMA = DATABASE() 
    AND TABLE_NAME = 't_user_order' 
    AND INDEX_NAME = 'idx_order_expire_status'
);

-- 动态创建索引
SET @sql = IF(@index_exists = 0, 
    'CREATE INDEX `idx_order_expire_status` ON `t_user_order` (`expire_time`, `payment_status`, `deleted`)',
    'SELECT "索引已存在，跳过创建" as message'
);

PREPARE stmt FROM @sql;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;
```

## 🔍 技术细节

### MySQL版本兼容性对比
| 功能 | MySQL 5.7 | MySQL 8.0 | 修复方案 |
|------|-----------|-----------|----------|
| `CREATE INDEX IF NOT EXISTS` | ❌ 不支持 | ✅ 支持 | 动态SQL检查 |
| `CREATE OR REPLACE VIEW` | ✅ 支持 | ✅ 支持 | 无需修改 |
| `CREATE TABLE IF NOT EXISTS` | ✅ 支持 | ✅ 支持 | 无需修改 |
| `INFORMATION_SCHEMA` | ✅ 支持 | ✅ 支持 | 用于索引检查 |

### 动态SQL执行流程
1. **查询阶段**: 使用`INFORMATION_SCHEMA.STATISTICS`检查索引
2. **判断阶段**: 使用`IF()`函数生成条件SQL
3. **执行阶段**: 使用`PREPARE`/`EXECUTE`动态执行
4. **清理阶段**: 使用`DEALLOCATE PREPARE`释放资源
