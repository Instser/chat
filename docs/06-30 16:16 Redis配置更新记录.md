# Redis配置更新记录

**时间**: 2025-06-30 16:16

## 更新概述

本次更新将Redis服务器配置从本地环境迁移到云端服务器，并添加了用户名认证支持。

## 配置变更详情

### 原配置
```yaml

  host: localhost
  port: 6379
  password: (无)
  database: 0

  host: your-db-host.example.com
  port: 31122
  username: default
  password: pt7tv2k4
  database: 0
```

## 具体修改内容

### 1. application.yml配置文件更新

**文件路径**: `src/main/resources/application.yml`

**修改内容**:
```yaml
# Redis配置
redis:
  host: ${REDIS_HOST:your-db-host.example.com}
  port: ${REDIS_PORT:31122}
  username: ${REDIS_USERNAME:default}  # 新增用户名配置
  password: ${REDIS_PASSWORD:pt7tv2k4}
  database: ${REDIS_DATABASE:0}
  timeout: 3000ms
  lettuce:
    pool:
      max-active: 20
      max-idle: 10
      min-idle: 5
      max-wait: 1000ms
```

### 2. 环境变量支持

配置支持以下环境变量：
- `REDIS_HOST`: Redis服务器地址
- `REDIS_PORT`: Redis服务器端口
- `REDIS_USERNAME`: Redis用户名
- `REDIS_PASSWORD`: Redis密码
- `REDIS_DATABASE`: Redis数据库编号

## 连接池配置

### Lettuce连接池参数
- **最大活跃连接数**: 20
- **最大空闲连接数**: 10
- **最小空闲连接数**: 5
- **最大等待时间**: 1000ms
- **连接超时时间**: 3000ms

## 支付安全配置

### Redis在支付模块中的应用
1. **防重放攻击**: 缓存支付请求ID，防止重复提交
2. **频率限制**: 记录用户支付请求频率
3. **可疑行为记录**: 记录异常支付行为
4. **分布式锁**: 使用Redisson实现订单状态保护
