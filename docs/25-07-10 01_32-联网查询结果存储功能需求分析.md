# 07-10 01:32 - 联网查询结果存储功能需求分析

## 需求概述
为聊天系统增加联网查询结果的持久化存储功能，实现联网内容与消息的关联管理，支持用户重新发送或重试时的内容更新机制。

## 功能需求分析

### 1. 核心需求
1. **消息联网标记**：在message表中增加字段标记消息是否使用了联网功能
2. **联网内容存储**：新增专门的联网内容关联表，存储查询结果
3. **内容格式化**：将searchResponse中的有效结果格式化为JSON存储
4. **关联管理**：建立message与联网内容的一对一关联关系
5. **内容更新**：支持用户edit-resend或retry时重新查询并更新内容

```sql
CREATE TABLE t_web_search_content (
  id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
  web_search_id VARCHAR(64) NOT NULL COMMENT '联网内容ID（UUID）',
  user_id BIGINT NOT NULL COMMENT '用户ID',
  session_id VARCHAR(64) NOT NULL COMMENT '会话ID',
  message_id VARCHAR(64) NOT NULL COMMENT '消息ID',
  query_text TEXT NOT NULL COMMENT '查询内容',
  content JSON NOT NULL COMMENT '联网查询结果JSON',
  result_count INT DEFAULT 0 COMMENT '结果数量',
  status TINYINT DEFAULT 1 COMMENT '状态（0-失败，1-成功）',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  deleted TINYINT DEFAULT 0 COMMENT '逻辑删除标志（0-未删除，1-已删除）',
  
  UNIQUE KEY uk_message_id (message_id),
  KEY idx_user_id (user_id),
  KEY idx_session_id (session_id),
  KEY idx_web_search_id (web_search_id),
  KEY idx_user_session_time (user_id, session_id, create_time),
  KEY idx_status_time (status, create_time),
  
  CONSTRAINT fk_web_search_user FOREIGN KEY (user_id) REFERENCES t_user (id),
  CONSTRAINT fk_web_search_session FOREIGN KEY (session_id) REFERENCES t_chat_session (session_id),
  CONSTRAINT fk_web_search_message FOREIGN KEY (message_id) REFERENCES t_chat_message (message_id) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='联网查询内容表';
```

### 5. 业务流程设计

#### 5.1 联网查询存储流程
```
1. 用户发送需要联网的消息
2. 系统执行联网查询获得searchResponse
3. 提取有效结果并格式化为JSON
4. 保存到t_web_search_content表
5. 更新t_chat_message表的has_web_search字段为1
6. 返回AI响应给用户
```

#### 5.2 重新查询更新流程
```
1. 检测用户edit-resend或retry操作
2. 查询原消息是否有联网内容关联
3. 如果有，保存原联网内容记录
4. 删除旧消息记录，创建新消息记录
5. 执行新的联网查询
6. 更新联网内容记录的message_id为新消息ID
7. 更新查询内容和搜索结果
8. 生成新的AI响应
```

### 6. 与文件关联模块的差异分析

#### 6.1 相似点
- 都使用关联表模式
- 都有用户权限验证
- 都支持逻辑删除
- 都有会话和消息关联

#### 6.2 关键差异
| 特性 | 文件关联 | 联网关联 |
|------|----------|----------|
| 关联关系 | 一对多（一个消息多个文件） | 一对一（一个消息一个联网内容） |
| 内容存储 | 文件内容或路径 | JSON格式的查询结果 |
| Edit-Resend处理 | 转移文件关联到新消息 | 更新联网记录的messageId和内容 |
| 更新机制 | 文件不变，关联可变 | 内容和关联都可更新 |
| 生命周期 | 独立于消息存在 | 与消息强绑定 |
| 查询频率 | 低频查询 | 可能高频查询 |

#### 9.2 服务层核心实现
```java
@Service
@Slf4j
public class WebSearchContentServiceImpl implements WebSearchContentService {

    @Autowired
    private WebSearchContentDao webSearchContentDao;

    @Autowired
    private ChatMessageService chatMessageService;

    @Override
    @Transactional
    public boolean saveWebSearchContent(String messageId, String queryText,
                                      TavilySearchResponse searchResponse, Long userId, String sessionId) {
        try {
            // 1. 格式化搜索结果为JSON
            String contentJson = formatSearchResponseToJson(searchResponse, queryText);

            // 2. 创建联网内容记录
            WebSearchContent webSearchContent = new WebSearchContent();
            webSearchContent.setWebSearchId(UUID.randomUUID().toString());
            webSearchContent.setUserId(userId);
            webSearchContent.setSessionId(sessionId);
            webSearchContent.setMessageId(messageId);
            webSearchContent.setQueryText(queryText);
            webSearchContent.setContent(contentJson);
            webSearchContent.setResultCount(getValidResultCount(searchResponse));
            webSearchContent.setStatus(1);

            // 3. 保存联网内容
            boolean saved = save(webSearchContent);

            // 4. 更新消息的联网标记
            if (saved) {
                chatMessageService.updateWebSearchFlag(messageId, true);
            }

            return saved;
        } catch (Exception e) {
            log.error("保存联网查询结果失败，消息ID：{}，用户ID：{}", messageId, userId, e);
            return false;
        }
    }

    @Override
    @Transactional
    public boolean updateWebSearchContent(String oldMessageId, String newMessageId,
                                        String queryText, TavilySearchResponse searchResponse) {
        try {
            // 1. 格式化搜索结果为JSON
            String contentJson = formatSearchResponseToJson(searchResponse, queryText);
            int resultCount = getValidResultCount(searchResponse);

            // 2. 更新联网内容记录的messageId和内容
            int updated = webSearchContentDao.updateContentAndMessageId(
                oldMessageId, newMessageId, queryText, contentJson, resultCount
            );

            if (updated > 0) {
                log.info("联网内容更新成功，旧消息ID：{}，新消息ID：{}，查询：{}",
                        oldMessageId, newMessageId, queryText);
                return true;
            } else {
                log.warn("联网内容更新失败，未找到记录，旧消息ID：{}", oldMessageId);
                return false;
            }
        } catch (Exception e) {
            log.error("更新联网查询结果失败，旧消息ID：{}，新消息ID：{}", oldMessageId, newMessageId, e);
            return false;
        }
    }

    private String formatSearchResponseToJson(TavilySearchResponse searchResponse, String queryText) {
        // 实现JSON格式化逻辑
        // 过滤有效结果，直接序列化results数组
        List<Map<String, String>> validResults = new ArrayList<>();
        if (searchResponse.getResults() != null) {
            for (TavilySearchResult result : searchResponse.getResults()) {
                if (isValidResult(result)) {
                    Map<String, String> resultMap = new HashMap<>();
                    resultMap.put("url", result.getUrl() != null ? result.getUrl() : "");
                    resultMap.put("title", result.getTitle() != null ? result.getTitle() : "");
                    resultMap.put("content", truncateContent(result.getContent()));
                    resultMap.put("favicon", result.getFavicon() != null ? result.getFavicon() : "");
                    validResults.add(resultMap);
                }
            }
        }
        return JSON.toJSONString(validResults);
    }

    private boolean isValidResult(TavilySearchResult result) {
        return result != null &&
               (StringUtils.hasText(result.getUrl()) ||
                StringUtils.hasText(result.getTitle()) ||
                StringUtils.hasText(result.getContent()));
    }

    private String truncateContent(String content) {
        if (content == null) return "";
        return content.length() > 2000 ? content.substring(0, 2000) + "..." : content;
    }
}
```

### 10. 集成点分析

#### 10.1 与现有聊天流程的集成
1. **消息发送流程**：在AI响应生成前保存联网内容
2. **消息查询流程**：查询消息时同时加载联网内容
3. **消息删除流程**：删除消息时级联删除联网内容
4. **会话管理流程**：会话删除时清理相关联网内容

#### 10.2 与联网搜索服务的集成
```java
// 在现有的聊天服务中集成
@Service
public class ChatServiceImpl {

    @Autowired
    private WebSearchExtractService webSearchExtractService;

    @Autowired
    private WebSearchContentService webSearchContentService;

    public void processUserMessage(ChatRequest request) {
        // 1. 保存用户消息
        ChatMessage userMessage = saveUserMessage(request);

        // 2. 检查是否需要联网查询
        if (needWebSearch(request.getContent())) {
            // 3. 执行联网查询
            WebSearchExtractResult searchResult = webSearchExtractService.searchAndExtract(request.getContent());

            // 4. 保存联网查询结果（只保存results数组）
            webSearchContentService.saveWebSearchContent(
                userMessage.getMessageId(),
                request.getContent(),
                searchResult.getSearchResponse(),
                request.getUserId(),
                request.getSessionId()
            );

            // 5. 将联网内容附加到AI请求中
            String enhancedPrompt = buildPromptWithWebSearch(request.getContent(), searchResult);
            request.setContent(enhancedPrompt);
        }

        // 6. 生成AI响应
        generateAIResponse(request);
    }

    // Edit-Resend处理逻辑
    public void processEditResendWithWebSearch(EditResendRequest request) {
        // 1. 检查原消息是否有联网内容
        ChatMessage originalMessage = chatMessageService.getByMessageId(request.getOriginalMessageId());
        WebSearchContent originalWebSearch = null;

        if (originalMessage.getHasWebSearch() == 1) {
            originalWebSearch = webSearchContentService.getByMessageId(request.getOriginalMessageId());
        }

        // 2. 删除旧消息，创建新消息
        String newMessageId = processEditResendMessage(request);

        // 3. 处理联网查询
        if (needWebSearch(request.getNewContent())) {
            // 执行新的联网查询
            WebSearchExtractResult searchResult = webSearchExtractService.searchAndExtract(request.getNewContent());

            if (originalWebSearch != null) {
                // 更新现有联网记录到新消息ID
                webSearchContentService.updateWebSearchContent(
                    request.getOriginalMessageId(),
                    newMessageId,
                    request.getNewContent(),
                    searchResult.getSearchResponse()
                );
            } else {
                // 创建新的联网记录
                webSearchContentService.saveWebSearchContent(
                    newMessageId,
                    request.getNewContent(),
                    searchResult.getSearchResponse(),
                    request.getUserId(),
                    request.getSessionId()
                );
            }
        } else if (originalWebSearch != null) {
            // 新内容不需要联网，删除原有联网记录
            webSearchContentService.deleteByMessageId(request.getOriginalMessageId(), request.getUserId());
        }

        // 4. 生成AI响应
        generateAIResponse(request);
    }
}
```
