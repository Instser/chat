### 4. Flyway 生产禁用（关键修复）

**问题**：新进程启动后一直崩溃重启（pid 不断变化），日志报 `SELECT command denied to user 'chat'@'192.168.1.2' for table 'user_variables_by_thread'`。根因是 memory bank 记录的"已引入 Flyway"在生产库启动时查询 `user_variables_by_thread` 系统表被拒绝（生产库用户 `chat` 无该权限）。

**修复**：在 supervisor 配置 `/www/server/panel/plugin/supervisor/profile/chat.ini` 加 `environment=FLYWAY_ENABLED="false"` 禁用 Flyway（application.yml 已支持 `${FLYWAY_ENABLED:true}`），然后 `supervisorctl reread + update + restart`。修复后进程正常启动，8080 监听。

```ini
[program:chat]
...
user=root
environment=FLYWAY_ENABLED="false"   # 本次新增
...
```

> 后续修复方向：给生产库用户 `chat` 授予 `user_variables_by_thread` 系统表 SELECT 权限后，可移除此 environment 配置启用 Flyway。
