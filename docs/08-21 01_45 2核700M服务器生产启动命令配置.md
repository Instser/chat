- **CPU**: 2核心

- **磁盘空间**: 建议至少5GB可用空间

- **非堆内存**: 约150MB (元空间、直接内存等)
- **系统预留**: 150MB (操作系统和其他进程)

### 基础启动命令
```bash
java -server \
  -Xms200m -Xmx400m \
  -XX:+UseG1GC \
  -XX:MaxGCPauseMillis=200 \
  -XX:+UseStringDeduplication \
  -XX:+UseCompressedOops \
  -Dspring.profiles.active=prod \
  -Dfile.encoding=UTF-8 \
  -Duser.timezone=Asia/Shanghai \
  -jar target/chat-0.0.1-SNAPSHOT.jar
```

### 完整优化启动命令
```bash
#!/bin/bash
# 金语聊天系统生产启动脚本 - 2核700M优化版

# 设置环境变量
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# JVM参数配置
JVM_OPTS="-server"

# 内存配置 (2核700M优化)
MEMORY_OPTS="-Xms200m -Xmx400m"
MEMORY_OPTS="$MEMORY_OPTS -XX:MetaspaceSize=64m -XX:MaxMetaspaceSize=128m"
MEMORY_OPTS="$MEMORY_OPTS -XX:DirectMemorySize=64m"

# GC配置 (G1GC适合小内存)
GC_OPTS="-XX:+UseG1GC"
GC_OPTS="$GC_OPTS -XX:MaxGCPauseMillis=200"
GC_OPTS="$GC_OPTS -XX:G1HeapRegionSize=8m"
GC_OPTS="$GC_OPTS -XX:+UseStringDeduplication"

# 性能优化
PERF_OPTS="-XX:+UseCompressedOops"
PERF_OPTS="$PERF_OPTS -XX:+TieredCompilation"
PERF_OPTS="$PERF_OPTS -XX:TieredStopAtLevel=1"

# 系统配置
SYSTEM_OPTS="-Dspring.profiles.active=prod"
SYSTEM_OPTS="$SYSTEM_OPTS -Dfile.encoding=UTF-8"
SYSTEM_OPTS="$SYSTEM_OPTS -Duser.timezone=Asia/Shanghai"
SYSTEM_OPTS="$SYSTEM_OPTS -Djava.awt.headless=true"

# 日志配置
LOG_OPTS="-Dlogging.level.com.instser.chat=INFO"
LOG_OPTS="$LOG_OPTS -Dlogging.level.org.springframework=WARN"
LOG_OPTS="$LOG_OPTS -Dlogging.level.com.alibaba.druid=WARN"

# 应用配置覆盖 (2核700M优化)
APP_OPTS="-Dserver.tomcat.threads.max=50"
APP_OPTS="$APP_OPTS -Dserver.tomcat.threads.min-spare=10"
APP_OPTS="$APP_OPTS -Dserver.tomcat.max-connections=200"
APP_OPTS="$APP_OPTS -Dspring.datasource.druid.initial-size=3"
APP_OPTS="$APP_OPTS -Dspring.datasource.druid.min-idle=5"
APP_OPTS="$APP_OPTS -Dspring.datasource.druid.max-active=15"

# 启动应用
java $JVM_OPTS $MEMORY_OPTS $GC_OPTS $PERF_OPTS $SYSTEM_OPTS $LOG_OPTS $APP_OPTS \
  -jar target/chat-0.0.1-SNAPSHOT.jar
```

## 📊 配置参数说明

### 内存参数优化
| 参数 | 值 | 说明 |
|------|----|----|
| `-Xms200m` | 200MB | 初始堆内存，避免频繁扩容 |
| `-Xmx400m` | 400MB | 最大堆内存，为系统预留300MB |
| `-XX:MetaspaceSize=64m` | 64MB | 元空间初始大小 |
| `-XX:MaxMetaspaceSize=128m` | 128MB | 元空间最大大小 |
| `-XX:DirectMemorySize=64m` | 64MB | 直接内存限制 |

### GC参数优化
| 参数 | 值 | 说明 |
|------|----|----|
| `-XX:+UseG1GC` | 启用 | G1垃圾收集器，适合小内存 |
| `-XX:MaxGCPauseMillis=200` | 200ms | 最大GC暂停时间 |
| `-XX:G1HeapRegionSize=8m` | 8MB | G1堆区域大小 |
| `-XX:+UseStringDeduplication` | 启用 | 字符串去重，节省内存 |

### 应用参数优化
| 参数 | 值 | 说明 |
|------|----|----|
| `server.tomcat.threads.max=50` | 50 | 最大工作线程数 |
| `server.tomcat.max-connections=200` | 200 | 最大连接数 |
| `spring.datasource.druid.max-active=15` | 15 | 数据库最大连接数 |

## 🔧 启动脚本创建

### 1. 创建启动脚本
```bash
# 创建启动脚本
cat > start-prod-2c700m.sh << 'EOF'
#!/bin/bash
# 金语聊天系统生产启动脚本 - 2核700M优化版

# 检查Java环境
if ! command -v java &> /dev/null; then
    echo "错误: 未找到Java环境，请安装JDK 17"
    exit 1
fi

# 检查JAR文件
if [ ! -f "target/chat-0.0.1-SNAPSHOT.jar" ]; then
    echo "错误: 未找到应用JAR文件，请先执行 mvn clean package"
    exit 1
fi

# 设置环境变量
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

echo "正在启动金语聊天系统 (2核700M优化版)..."
echo "启动时间: $(date '+%Y-%m-%d %H:%M:%S')"

# 启动应用
java -server \
  -Xms200m -Xmx400m \
  -XX:MetaspaceSize=64m -XX:MaxMetaspaceSize=128m \
  -XX:DirectMemorySize=64m \
  -XX:+UseG1GC \
  -XX:MaxGCPauseMillis=200 \
  -XX:G1HeapRegionSize=8m \
  -XX:+UseStringDeduplication \
  -XX:+UseCompressedOops \
  -XX:+TieredCompilation \
  -XX:TieredStopAtLevel=1 \
  -Dspring.profiles.active=prod \
  -Dfile.encoding=UTF-8 \
  -Duser.timezone=Asia/Shanghai \
  -Djava.awt.headless=true \
  -Dlogging.level.com.instser.chat=INFO \
  -Dlogging.level.org.springframework=WARN \
  -Dlogging.level.com.alibaba.druid=WARN \
  -Dserver.tomcat.threads.max=50 \
  -Dserver.tomcat.threads.min-spare=10 \
  -Dserver.tomcat.max-connections=200 \
  -Dspring.datasource.druid.initial-size=3 \
  -Dspring.datasource.druid.min-idle=5 \
  -Dspring.datasource.druid.max-active=15 \
  -jar target/chat-0.0.1-SNAPSHOT.jar

EOF

# 设置执行权限
chmod +x start-prod-2c700m.sh
```

### 2. 创建后台启动脚本
```bash
# 创建后台启动脚本
cat > start-prod-daemon.sh << 'EOF'
#!/bin/bash
# 金语聊天系统后台启动脚本 - 2核700M优化版

# 创建日志目录
mkdir -p logs

# 后台启动
nohup java -server \
  -Xms200m -Xmx400m \
  -XX:MetaspaceSize=64m -XX:MaxMetaspaceSize=128m \
  -XX:DirectMemorySize=64m \
  -XX:+UseG1GC \
  -XX:MaxGCPauseMillis=200 \
  -XX:G1HeapRegionSize=8m \
  -XX:+UseStringDeduplication \
  -XX:+UseCompressedOops \
  -XX:+TieredCompilation \
  -XX:TieredStopAtLevel=1 \
  -Dspring.profiles.active=prod \
  -Dfile.encoding=UTF-8 \
  -Duser.timezone=Asia/Shanghai \
  -Djava.awt.headless=true \
  -Dlogging.level.com.instser.chat=INFO \
  -Dlogging.level.org.springframework=WARN \
  -Dlogging.level.com.alibaba.druid=WARN \
  -Dserver.tomcat.threads.max=50 \
  -Dserver.tomcat.threads.min-spare=10 \
  -Dserver.tomcat.max-connections=200 \
  -Dspring.datasource.druid.initial-size=3 \
  -Dspring.datasource.druid.min-idle=5 \
  -Dspring.datasource.druid.max-active=15 \
  -jar target/chat-0.0.1-SNAPSHOT.jar \
  > logs/application.log 2>&1 &

# 保存进程ID
echo $! > app.pid
echo "应用已后台启动，进程ID: $(cat app.pid)"
echo "日志文件: logs/application.log"
echo "查看日志: tail -f logs/application.log"

EOF

chmod +x start-prod-daemon.sh
```

## 🛠️ 故障处理

### 内存不足处理
1. 检查系统内存使用: `free -h`
2. 调整JVM参数: 减少`-Xmx`值到300m
3. 重启应用服务

### 启动失败处理
1. 检查Java版本: `java -version`
2. 检查端口占用: `netstat -tlnp | grep 8080`
3. 查看启动日志: `tail -f logs/application.log`
