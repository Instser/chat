## 🎯 优化方案对比

### 方案一：JSON配置方案（推荐）
**核心思想**：扩展现有表结构，使用JSON存储配置，复用现有机制

### 方案二：代码配置方案
**核心思想**：完全使用代码配置，无需数据库修改

### 方案三：混合缓存方案
**核心思想**：最小数据库修改 + Redis缓存优化

## 🏆 推荐方案：JSON配置 + 现有表扩展

// 添加解析 model_permissions 的方法
public Map<String, ModelPermission> getModelPermissionsMap() {
    if (StringUtils.isBlank(this.modelPermissions)) {
        return getDefaultModelPermissions();
    }
    
    try {
        ObjectMapper mapper = new ObjectMapper();
        TypeReference<Map<String, ModelPermission>> typeRef = 
            new TypeReference<Map<String, ModelPermission>>() {};
        return mapper.readValue(this.modelPermissions, typeRef);
    } catch (Exception e) {
        log.warn("解析套餐{}模型权限配置失败，使用默认配置", this.getId(), e);
        return getDefaultModelPermissions();
    }
}

private Map<String, ModelPermission> getDefaultModelPermissions() {
    Map<String, ModelPermission> defaults = new HashMap<>();
    
    // 根据套餐类型返回默认配置
    switch (this.packageType) {
        case "basic":
            defaults.put("STANDARD", new ModelPermission(300, "标准模型"));
            defaults.put("PERFORMANCE", new ModelPermission(20, "性能模型"));
            defaults.put("BETA_MODEL", new ModelPermission(5, "测试模型"));
            break;
        case "medium":
            defaults.put("STANDARD", new ModelPermission(500, "标准模型"));
            defaults.put("PERFORMANCE", new ModelPermission(300, "性能模型"));
            defaults.put("BETA_MODEL", new ModelPermission(20, "测试模型"));
            break;
        case "high":
            defaults.put("STANDARD", new ModelPermission(-1, "标准模型"));
            defaults.put("PERFORMANCE", new ModelPermission(-1, "性能模型"));
            defaults.put("BETA_MODEL", new ModelPermission(-1, "测试模型"));
            break;
        default:
            // 默认无权限
            break;
    }
    
    return defaults;
}

@Override
public boolean canChatWithModel(Long userId, Long packageId, String modelName) {
    // 1. 获取套餐信息和模型权限配置
    Package packageInfo = packageService.getPackageById(packageId);
    if (packageInfo == null) {
        log.warn("套餐{}不存在", packageId);
        return false;
    }
    
    Map<String, Package.ModelPermission> modelPermissions = packageInfo.getModelPermissionsMap();
    Package.ModelPermission permission = modelPermissions.get(modelName);
    
    if (permission == null) {
        log.warn("套餐{}不支持模型{}", packageId, modelName);
        return false;
    }
    
    // 2. 如果是无限制，直接允许
    if (permission.getDailyLimit() == -1) {
        return true;
    }
    
    // 3. 检查今日使用情况
    UserDailyUsage todayUsage = getTodayModelUsage(userId, packageId, modelName);
    if (todayUsage == null) {
        return true; // 今日未使用
    }
    
    return todayUsage.getChatCountUsed() < permission.getDailyLimit();
}

@Override
@Transactional
public boolean recordModelChatUsage(Long userId, Long packageId, String modelName) {
    // 1. 获取套餐模型权限配置
    Package packageInfo = packageService.getPackageById(packageId);
    if (packageInfo == null) {
        return false;
    }
    
    Map<String, Package.ModelPermission> modelPermissions = packageInfo.getModelPermissionsMap();
    Package.ModelPermission permission = modelPermissions.get(modelName);
    
    if (permission == null) {
        return false;
    }
    
    // 2. 检查当前使用情况
    if (permission.getDailyLimit() != -1) { // 非无限制套餐
        UserDailyUsage todayUsage = getTodayModelUsage(userId, packageId, modelName);
        if (todayUsage != null && todayUsage.getChatCountUsed() >= permission.getDailyLimit()) {
            log.warn("用户{}模型{}今日使用次数已达限制", userId, modelName);
            return false;
        }
    }
    
    // 3. 使用原子性操作记录使用
    LocalDate businessDate = getBusinessDate();
    int dailyLimit = permission.getDailyLimit();
    
    int updated = baseMapper.insertOrIncrementModelUsage(userId, packageId, modelName, 
        businessDate, dailyLimit);
    
    if (updated > 0) {
        log.info("用户{}模型{}使用记录成功", userId, modelName);
        return true;
    }
    
    return false;
}

@Override
public int getRemainingModelChats(Long userId, Long packageId, String modelName) {
    // 1. 获取套餐模型权限配置
    Package packageInfo = packageService.getPackageById(packageId);
    if (packageInfo == null) {
        return 0;
    }
    
    Map<String, Package.ModelPermission> modelPermissions = packageInfo.getModelPermissionsMap();
    Package.ModelPermission permission = modelPermissions.get(modelName);
    
    if (permission == null) {
        return 0;
    }
    
    // 2. 无限制套餐
    if (permission.getDailyLimit() == -1) {
        return -1;
    }
    
    // 3. 计算剩余次数
    UserDailyUsage todayUsage = getTodayModelUsage(userId, packageId, modelName);
    if (todayUsage == null) {
        return permission.getDailyLimit();
    }
    
    return Math.max(0, permission.getDailyLimit() - todayUsage.getChatCountUsed());
}

@Override
public UserDailyUsage getTodayModelUsage(Long userId, Long packageId, String modelName) {
    return baseMapper.selectByUserPackageModelDate(userId, packageId, modelName, getBusinessDate());
}

## 🚀 性能优化策略

### 1. Redis缓存优化
```java
@Service
public class ModelUsageCacheService {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String CACHE_PREFIX = "model_usage:";
    private static final int CACHE_TTL = 86400; // 24小时
    
    /**
     * 缓存套餐模型权限配置
     */
    public void cachePackageModelPermissions(Long packageId, Map<String, Package.ModelPermission> permissions) {
        String key = CACHE_PREFIX + "package:" + packageId;
        redisTemplate.opsForValue().set(key, permissions, CACHE_TTL, TimeUnit.SECONDS);
    }
    
    /**
     * 获取缓存的套餐模型权限配置
     */
    @SuppressWarnings("unchecked")
    public Map<String, Package.ModelPermission> getCachedPackageModelPermissions(Long packageId) {
        String key = CACHE_PREFIX + "package:" + packageId;
        return (Map<String, Package.ModelPermission>) redisTemplate.opsForValue().get(key);
    }
    
    /**
     * 缓存用户今日模型使用情况
     */
    public void cacheUserModelUsage(Long userId, String modelName, UserDailyUsage usage) {
        String key = CACHE_PREFIX + "user:" + userId + ":model:" + modelName + ":date:" + LocalDate.now();
        redisTemplate.opsForValue().set(key, usage, CACHE_TTL, TimeUnit.SECONDS);
    }
    
    /**
     * 获取缓存的用户今日模型使用情况
     */
    public UserDailyUsage getCachedUserModelUsage(Long userId, String modelName) {
        String key = CACHE_PREFIX + "user:" + userId + ":model:" + modelName + ":date:" + LocalDate.now();
        return (UserDailyUsage) redisTemplate.opsForValue().get(key);
    }
}
```

    result.setModelName(modelName);
    result.setModelRemainingToday(userDailyUsageService.getRemainingModelChats(userId, userAccount.getPackageId(), modelName));
    
    return result;
}

## 📊 方案优势对比

| 特性 | 原方案 | 优化方案 |
|------|--------|----------|
| 数据库修改 | 新增2张表 | 1个字段+1个索引 |
| 代码复杂度 | 新增多个类 | 扩展现有类 |
| 查询性能 | 需要多表关联 | 单表查询+缓存 |
| 维护成本 | 较高 | 较低 |
| 扩展性 | 很好 | 好 |
| 向后兼容 | 需要迁移 | 完全兼容 |

## 📋 总结

这个优化方案的核心优势：

1. **最小化数据库修改**：只需1个字段和1个索引修改
2. **复用现有架构**：扩展而非重写现有代码
3. **保证查询效率**：单表查询 + Redis缓存
4. **向后兼容**：现有功能完全不受影响
5. **易于维护**：代码结构清晰，维护成本低

这个方案在满足功能需求的同时，最大程度减少了对现有系统的影响，是一个平衡性能、复杂度和维护成本的最优解。
