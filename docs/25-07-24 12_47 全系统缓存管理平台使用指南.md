## 📋 概述

本指南介绍如何使用全系统缓存管理平台，包括混合缓存策略、熔断器机制、监控告警等功能，帮助业务模块快速集成高性能、高可用的缓存解决方案。

## 🏗️ 缓存架构概览

### 缓存层级结构
```
┌─────────────────────────────────────────────────────────┐
│                   全局缓存管理平台                        │
├─────────────────────────────────────────────────────────┤
│  L1缓存(内存)  │  L2缓存(Redis)  │  L3缓存(数据库)    │
│  Caffeine      │  分布式缓存      │  持久化存储        │
│  < 1ms         │  5-10ms         │  50-100ms         │
└─────────────────────────────────────────────────────────┘
```

### 核心组件
- **GlobalCacheManager**: 全局缓存管理器，统一管理所有缓存实例
- **HybridCacheManager**: 混合缓存管理器，实现多层缓存策略
- **RedisCircuitBreaker**: Redis熔断器，提供自动降级和恢复
- **CacheMonitoringService**: 缓存监控服务，实时监控和告警
- **CacheRegistryService**: 缓存注册服务，自动发现缓存实例

## 🚀 快速开始

### 1. 基础依赖注入

在你的服务类中注入全局缓存管理器：

```java
@Service
public class YourBusinessService {

    @Autowired
    private GlobalCacheManager globalCacheManager;

    @Autowired
    private CacheMonitoringService monitoringService;
}
```

### 2. 注册缓存实例

在服务初始化时注册你的缓存：

```java
@PostConstruct
public void init() {
    // 注册业务缓存
    globalCacheManager.registerCache(
        "your-module",                              // 模块名
        "your-cache-name",                          // 缓存名称
        GlobalCacheManager.CacheType.HYBRID,       // 缓存类型
        "业务数据缓存",                              // 描述
        Duration.ofMinutes(30)                      // TTL
    );
}
```

### 3. 使用缓存

```java
public YourDataType getBusinessData(String key) {
    return globalCacheManager.get(
        "your-cache-name",                          // 缓存名称
        key,                                        // 缓存键
        () -> loadDataFromDatabase(key)             // 数据库回退函数
    );
}

public void updateBusinessData(String key, YourDataType data) {
    // 更新数据库
    saveDataToDatabase(key, data);
    
    // 更新缓存
    globalCacheManager.put("your-cache-name", key, data);
    
    // 记录监控统计
    monitoringService.recordModuleOperation("your-module", true, false, false);
}
```

## 🎯 缓存类型选择指南

### HYBRID (混合缓存) - 推荐
**适用场景**: 高频访问、对性能要求高的业务数据
```java
// 自动实现 L1(内存) + L2(Redis) + L3(数据库) 策略
globalCacheManager.registerCache(
    "user", "user-profile", 
    GlobalCacheManager.CacheType.HYBRID,
    "用户资料缓存", Duration.ofMinutes(30)
);
```

**优势**:
- 最高性能：L1缓存 < 1ms 响应
- 高可用性：Redis异常时自动降级
- 智能回填：自动维护缓存一致性

### SPRING_CACHE (Spring缓存)
**适用场景**: 已使用@Cacheable注解的现有代码
```java
@Cacheable(value = "exchange-rates", key = "#from + '_' + #to")
public BigDecimal getExchangeRate(String from, String to) {
    // 业务逻辑
}
```

### LOCAL (本地缓存)
**适用场景**: 单机部署、配置数据、静态数据
```java
// Caffeine本地缓存
private final Cache<String, Object> localCache = Caffeine.newBuilder()
    .maximumSize(1000)
    .expireAfterWrite(30, TimeUnit.MINUTES)
    .build();
```

### REDIS (Redis缓存)
**适用场景**: 分布式共享、会话数据、临时数据
```java
// 直接使用Redis，支持熔断器
globalCacheManager.registerCache(
    "session", "user-sessions",
    GlobalCacheManager.CacheType.REDIS,
    "用户会话缓存", Duration.ofMinutes(30)
);
```

## 🔧 最佳实践

### 1. 缓存键命名规范

```java
// 推荐格式：模块:业务类型:标识符[:附加参数]
String cacheKey = String.format("user:profile:%d", userId);
String cacheKey = String.format("order:status:%d:%s", orderId, status);
String cacheKey = String.format("chat:messages:%s:page:%d", sessionId, pageNum);
```

### 2. 缓存过期时间设置

```java
// 热点数据：5-15分钟
Duration.ofMinutes(10)

// 一般业务数据：30分钟-2小时
Duration.ofMinutes(30)

// 配置数据：1-24小时
Duration.ofHours(1)

// 静态数据：1天以上
Duration.ofDays(1)
```

### 3. 异常处理模式

```java
public YourDataType getDataWithFallback(String key) {
    try {
        return globalCacheManager.get("your-cache", key, () -> {
            // 数据库查询
            YourDataType data = repository.findByKey(key);
            
            // 记录监控统计
            monitoringService.recordModuleOperation("your-module", 
                false, false, false); // miss, no redis failure, no fallback
            
            return data;
        });
    } catch (Exception e) {
        log.error("缓存获取异常，key: {}", key, e);
        
        // 记录异常统计
        monitoringService.recordModuleOperation("your-module", 
            false, true, true); // miss, redis failure, fallback used
        
        // 直接查询数据库
        return repository.findByKey(key);
    }
}
```

### 4. 缓存预热策略

```java
@Component
public class CacheWarmupService {

    @EventListener(ApplicationReadyEvent.class)
    public void warmupCache() {
        log.info("开始缓存预热");
        
        // 预热热点数据
        List<String> hotKeys = getHotKeys();
        for (String key : hotKeys) {
            try {
                globalCacheManager.get("your-cache", key, () -> loadFromDatabase(key));
            } catch (Exception e) {
                log.warn("缓存预热失败，key: {}", key, e);
            }
        }
        
        log.info("缓存预热完成，预热{}个键", hotKeys.size());
    }
}
```

## 🔄 业务模块集成示例

### 用户模块集成

```java
@Service
public class UserAccountServiceImpl implements UserAccountService {

    @Autowired
    private GlobalCacheManager globalCacheManager;
    
    @Autowired
    private CacheMonitoringService monitoringService;

    @PostConstruct
    public void init() {
        // 注册用户账户缓存
        globalCacheManager.registerCache(
            "user", "user-account",
            GlobalCacheManager.CacheType.HYBRID,
            "用户账户信息缓存", Duration.ofMinutes(15)
        );
        
        // 注册用户套餐缓存
        globalCacheManager.registerCache(
            "user", "user-package",
            GlobalCacheManager.CacheType.HYBRID,
            "用户套餐信息缓存", Duration.ofMinutes(30)
        );
    }

    @Override
    public UserAccount getUserAccount(Long userId) {
        String cacheKey = "user:account:" + userId;
        
        return globalCacheManager.get("user-account", cacheKey, () -> {
            // 数据库查询
            UserAccount account = userAccountDao.selectByUserId(userId);
            
            // 记录统计
            monitoringService.recordModuleOperation("user", false, false, false);
            
            return account;
        });
    }

    @Override
    public void updateUserAccount(UserAccount account) {
        // 更新数据库
        userAccountDao.updateById(account);
        
        // 更新缓存
        String cacheKey = "user:account:" + account.getUserId();
        globalCacheManager.put("user-account", cacheKey, account);
        
        // 记录统计
        monitoringService.recordModuleOperation("user", true, false, false);
    }
}
```

## 📈 性能优化建议

### 1. 缓存命中率优化
- 合理设置缓存过期时间
- 实施缓存预热策略
- 优化缓存键设计
- 监控热点数据访问模式

### 2. 内存使用优化
- 控制L1缓存大小
- 定期清理过期数据
- 使用合适的序列化方式
- 监控内存使用情况

### 3. 网络开销优化
- 批量操作减少网络往返
- 使用管道技术
- 合理设置连接池大小
- 启用数据压缩
