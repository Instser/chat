# 07-27 19:11 8081端口完整API调用文档

## 概述

本文档详细描述了8081端口所有可用的API接口，包括缓存管理、日志管理和Spring Boot Actuator监控端点。所有接口都需要API密钥验证，支持远程访问。

## 认证方式

### API密钥验证
所有8081端口的接口都需要提供有效的API密钥：

**Header方式**（推荐）：
```bash
curl -H "X-API-Key: your-api-key-here" http://127.0.0.1:8081/admin/cache/test
```

**参数方式**：
```bash
curl "http://127.0.0.1:8081/admin/cache/test?apiKey=your-api-key-here"
```

### 获取API密钥
1. 查看应用启动日志中的自动生成密钥
2. 通过环境变量 `CACHE_API_KEY` 设置自定义密钥
3. 调用 `/admin/cache/security/api-keys` 接口查看密钥信息

## 统一响应格式

所有API接口都使用统一的响应格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1722085860000
}
```

**响应状态码**：
- `200`: 操作成功
- `403`: API密钥验证失败
- `500`: 服务器内部错误

## 错误处理

### 常见错误码

**403 Forbidden - API密钥验证失败**:
```json
{
  "code": 403,
  "message": "访问被拒绝：需要有效的API密钥",
  "data": null,
  "timestamp": 1722085860000
}
```

**500 Internal Server Error - 服务器内部错误**:
```json
{
  "code": 500,
  "message": "服务器内部错误",
  "data": null,
  "timestamp": 1722085860000
}
```

### 故障排查

1. **API密钥问题**:
   - 检查密钥是否正确
   - 确认密钥传递方式（Header或参数）
   - 查看应用启动日志获取正确的密钥

2. **网络连接问题**:
   - 确认8081端口是否开放
   - 检查防火墙设置
   - 验证服务是否正常运行

3. **服务状态问题**:
   - 调用 `/actuator/health` 检查服务健康状态
   - 查看应用日志排查具体错误
