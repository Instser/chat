# 06-29 17:12 MySQL 5.7到8.0数据迁移操作指南

## 概述

本指南提供了将聊天系统数据从MySQL 5.7完整迁移到MySQL 8.0的详细操作步骤，确保数据完整性和业务连续性。

## 迁移准备

### 环境要求

- **源环境**: MySQL 5.7.40-log
- **目标环境**: MySQL 8.0.40
- **操作系统**: Linux/Windows/macOS
- **磁盘空间**: 至少为当前数据库大小的3倍
- **网络**: 源和目标服务器之间网络稳定

### 工具准备

```bash
# 确保安装了MySQL客户端工具
mysql --version
mysqldump --version

# 安装数据传输工具（可选）
# 对于大数据量，推荐使用 mydumper/myloader
sudo apt-get install mydumper  # Ubuntu/Debian
# 或
brew install mydumper          # macOS
```

## 迁移方案选择

### 方案一：停机迁移（推荐）

**适用场景**: 可以接受短时间停机的生产环境
**停机时间**: 根据数据量，通常10分钟-2小时
**数据一致性**: 100%保证

### 方案二：在线迁移

**适用场景**: 不能停机的关键业务系统
**停机时间**: 几乎为0
**复杂度**: 较高，需要主从复制

### 方案三：逐表迁移

**适用场景**: 大数据量，需要分批迁移
**停机时间**: 分阶段短暂停机
**灵活性**: 最高

## 详细操作步骤

### 第一步：数据备份和验证

#### 1.1 检查源数据库状态

```sql
-- 连接到MySQL 5.7
mysql -h [5.7_host] -u [username] -p

-- 检查数据库版本和状态
SELECT VERSION() as mysql_version, 
       DATABASE() as current_database,
       NOW() as check_time;

-- 统计各表数据量
USE chat;
SELECT 
    table_name,
    table_rows,
    ROUND(((data_length + index_length) / 1024 / 1024), 2) AS 'Size_MB'
FROM information_schema.tables 
WHERE table_schema = 'chat'
ORDER BY table_rows DESC;
```

#### 1.2 创建完整备份

```bash
# 方法1：使用mysqldump（推荐）
mysqldump -h [5.7_host] -u [username] -p \
  --single-transaction \
  --routines \
  --triggers \
  --set-gtid-purged=OFF \
  --default-character-set=utf8mb4 \
  --hex-blob \
  --complete-insert \
  chat > chat_57_full_backup_$(date +%Y%m%d_%H%M%S).sql

# 方法2：使用mydumper（大数据量推荐）
mydumper -h [5.7_host] -u [username] -p[password] \
  --database=chat \
  --compress \
  --build-empty-files \
  --threads=4 \
  --outputdir=./chat_backup_$(date +%Y%m%d_%H%M%S)
```

#### 1.3 验证备份完整性

```bash
# 检查备份文件大小
ls -lh chat_57_full_backup_*.sql

# 验证备份文件内容
head -20 chat_57_full_backup_*.sql
tail -20 chat_57_full_backup_*.sql

# 统计备份中的表数量
grep -c "CREATE TABLE" chat_57_full_backup_*.sql
```

### 第二步：准备MySQL 8.0环境

#### 2.1 安装MySQL 8.0

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install mysql-server-8.0

# CentOS/RHEL
sudo yum install mysql-server

# 启动服务
sudo systemctl start mysql
sudo systemctl enable mysql
```

#### 2.2 配置MySQL 8.0

```bash
# 编辑配置文件
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf

# 添加以下配置
[mysqld]
# 基础配置
default_authentication_plugin=mysql_native_password
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci

# 性能优化
innodb_buffer_pool_size=1G
innodb_log_file_size=256M
innodb_flush_log_at_trx_commit=2
innodb_flush_method=O_DIRECT

# MySQL 8.0特性
innodb_dedicated_server=ON
innodb_redo_log_capacity=512M

# 重启MySQL服务
sudo systemctl restart mysql
```

#### 2.3 创建目标数据库

```sql
-- 连接到MySQL 8.0
mysql -h [8.0_host] -u root -p

-- 创建数据库
CREATE DATABASE chat_new 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 创建用户（如果需要）
CREATE USER 'chat_user'@'%' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON chat_new.* TO 'chat_user'@'%';
FLUSH PRIVILEGES;
```

### 第三步：执行数据迁移

#### 3.1 方法一：直接导入备份

```bash
# 导入完整备份
mysql -h [8.0_host] -u [username] -p chat_new < chat_57_full_backup_*.sql

# 监控导入进度（另开终端）
watch -n 5 "mysql -h [8.0_host] -u [username] -p -e 'SELECT COUNT(*) FROM chat_new.t_chat_message'"
```

#### 3.2 方法二：使用myloader（大数据量）

```bash
# 使用myloader导入
myloader -h [8.0_host] -u [username] -p[password] \
  --database=chat_new \
  --threads=4 \
  --directory=./chat_backup_*
```

#### 3.3 方法三：分表迁移

```bash
# 导出单个表
mysqldump -h [5.7_host] -u [username] -p \
  --single-transaction \
  --default-character-set=utf8mb4 \
  chat t_ai_model > t_ai_model.sql

# 导入单个表
mysql -h [8.0_host] -u [username] -p chat_new < t_ai_model.sql

# 重复以上步骤迁移所有表
```

### 第四步：数据验证

#### 4.1 验证数据完整性

```sql
-- 连接到MySQL 8.0
USE chat_new;

-- 验证记录数量
SELECT 'AI模型表' as table_name, COUNT(*) as record_count FROM t_ai_model WHERE deleted = 0
UNION ALL
SELECT '用户表', COUNT(*) FROM t_user WHERE deleted = 0
UNION ALL

UNION ALL

UNION ALL

UNION ALL

UNION ALL
SELECT '用户套餐表', COUNT(*) FROM t_user_package WHERE deleted = 0
UNION ALL
SELECT '文件上传表', COUNT(*) FROM t_upload WHERE deleted = 0;
```

#### 4.2 验证外键关系

```sql
-- 检查外键约束
SELECT 
    TABLE_NAME,
    CONSTRAINT_NAME,
    CONSTRAINT_TYPE
FROM information_schema.table_constraints 
WHERE table_schema = 'chat_new' 
  AND constraint_type = 'FOREIGN KEY';

-- 验证外键数据完整性
SELECT 
    'chat_session外键检查' as check_name,
    COUNT(*) as invalid_count
FROM t_chat_session s 
LEFT JOIN t_user u ON s.user_id = u.id 
LEFT JOIN t_ai_model m ON s.model_id = m.id
WHERE u.id IS NULL OR m.id IS NULL;
```

#### 4.3 验证字符集和排序规则

```sql
-- 检查字符集配置
SELECT 
    table_name,
    table_collation
FROM information_schema.tables 
WHERE table_schema = 'chat_new';

-- 检查列字符集
SELECT 
    table_name,
    column_name,
    character_set_name,
    collation_name
FROM information_schema.columns 
WHERE table_schema = 'chat_new' 
  AND character_set_name IS NOT NULL;
```

## 故障排除

### 常见问题及解决方案

#### 1. 字符集问题

```sql
-- 问题：中文乱码
-- 解决：检查并修复字符集
ALTER DATABASE chat_new CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
ALTER TABLE t_chat_message CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 2. 外键约束错误

```sql
-- 问题：外键约束失败
-- 解决：临时禁用外键检查
SET FOREIGN_KEY_CHECKS = 0;
-- 执行导入操作
SET FOREIGN_KEY_CHECKS = 1;
```

#### 3. 大数据量导入超时

```bash
# 问题：导入超时
# 解决：调整MySQL超时设置
mysql -e "SET GLOBAL max_allowed_packet=1073741824;"
mysql -e "SET GLOBAL wait_timeout=28800;"
```

#### 4. 磁盘空间不足

```bash
# 问题：磁盘空间不足
# 解决：清理临时文件或扩展磁盘
df -h
sudo rm -rf /tmp/mysql_*
sudo resize2fs /dev/sda1
```

## 快速迁移脚本

对于小到中等数据量（<1GB），可以使用以下快速迁移脚本：

```bash
#!/bin/bash
# 快速迁移脚本 - quick_migration.sh

# 配置变量
SOURCE_HOST="localhost"
SOURCE_USER="root"
SOURCE_DB="chat"
TARGET_HOST="localhost"
TARGET_USER="root"
TARGET_DB="chat_new"
BACKUP_DIR="./migration_backup_$(date +%Y%m%d_%H%M%S)"

echo "开始MySQL 5.7到8.0快速迁移..."

# 1. 创建备份目录
mkdir -p $BACKUP_DIR

# 2. 备份源数据库
echo "正在备份源数据库..."
mysqldump -h $SOURCE_HOST -u $SOURCE_USER -p \
  --single-transaction --routines --triggers \
  --set-gtid-purged=OFF --default-character-set=utf8mb4 \
  $SOURCE_DB > $BACKUP_DIR/source_backup.sql

# 3. 创建目标数据库
echo "正在创建目标数据库..."
mysql -h $TARGET_HOST -u $TARGET_USER -p -e "CREATE DATABASE IF NOT EXISTS $TARGET_DB CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 4. 导入数据
echo "正在导入数据到MySQL 8.0..."
mysql -h $TARGET_HOST -u $TARGET_USER -p $TARGET_DB < $BACKUP_DIR/source_backup.sql

# 5. 验证数据
echo "正在验证数据完整性..."
mysql -h $TARGET_HOST -u $TARGET_USER -p $TARGET_DB -e "
SELECT 'AI模型表' as table_name, COUNT(*) as record_count FROM t_ai_model WHERE deleted = 0
UNION ALL SELECT '用户表', COUNT(*) FROM t_user WHERE deleted = 0
UNION ALL SELECT '聊天会话表', COUNT(*) FROM t_chat_session WHERE deleted = 0
UNION ALL SELECT '聊天消息表', COUNT(*) FROM t_chat_message WHERE deleted = 0;"

# 6. 优化表
echo "正在优化表结构..."
mysql -h $TARGET_HOST -u $TARGET_USER -p $TARGET_DB -e "
ANALYZE TABLE t_ai_model, t_user, t_chat_session, t_chat_message, t_package, t_user_order, t_user_package, t_upload;
OPTIMIZE TABLE t_ai_model, t_user, t_chat_session, t_chat_message, t_package, t_user_order, t_user_package, t_upload;"

echo "迁移完成！备份文件保存在: $BACKUP_DIR"
echo "请更新应用配置文件中的数据库连接信息。"
```

使用方法：
```bash
chmod +x quick_migration.sh
./quick_migration.sh
```
