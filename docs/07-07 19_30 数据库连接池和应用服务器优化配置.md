# 数据库连接池和应用服务器优化配置

**优化时间**: 2025年7月7日 19:30 (北京时间)  
**版本**: v1.0  
**目标服务器**: 8核8G内存  
**预期性能提升**: 2-3倍并发支持能力

## 🎯 优化目标

- **当前并发能力**: 200-300 用户
- **优化后目标**: 600-800 用户
- **峰值处理能力**: 800-1200 用户

## 🔧 主要优化内容

### 1. 数据库连接池优化 (Druid)

#### 优化前配置
```yaml
druid:
  initial-size: 5          # 初始连接数过少
  min-idle: 10            # 最小空闲连接不足
  max-active: 20          # 最大连接数严重不足
  max-wait: 60000         # 等待时间过长
```

#### 优化后配置
```yaml
druid:
  initial-size: 15                    # 提升到15 (3倍)
  min-idle: 20                        # 提升到20 (2倍)
  max-active: 80                      # 提升到80 (4倍)
  max-wait: 15000                     # 降低到15秒
  
  # 连接检测优化
  time-between-eviction-runs-millis: 30000    # 30秒检测一次
  min-evictable-idle-time-millis: 180000      # 3分钟最小空闲
  max-evictable-idle-time-millis: 600000      # 10分钟最大空闲
  
  # 性能优化参数
  validation-query: SELECT 1                  # MySQL优化查询
  validation-query-timeout: 3                 # 3秒验证超时
  max-pool-prepared-statement-per-connection-size: 50  # 预编译缓存提升
```

### 2. Tomcat服务器优化

#### 新增配置
```yaml
server:
  tomcat:
    threads:
      max: 400                    # 最大工作线程 (8核 * 50)
      min-spare: 50              # 最小空闲线程
    max-connections: 2000         # 最大连接数
    accept-count: 200            # 等待队列长度
    connection-timeout: 20000    # 连接超时 (20秒)
    keep-alive-timeout: 60000    # Keep-Alive超时 (60秒)
    max-keep-alive-requests: 1000 # 最大Keep-Alive请求数
```

### 3. MyBatis-Plus优化

#### 优化配置
```yaml
mybatis-plus:
  configuration:
    cache-enabled: true              # 开启二级缓存
    lazy-loading-enabled: true       # 开启延迟加载
    aggressive-lazy-loading: false   # 关闭积极延迟加载
    default-executor-type: REUSE     # 重用执行器
```

### 4. JVM参数优化

#### 启动脚本优化
```bash
# 堆内存配置 (8G服务器)
HEAP_SIZE="-Xms4g -Xmx6g"

# G1垃圾收集器配置
GC_CONFIG="-XX:+UseG1GC -XX:MaxGCPauseMillis=200"

# 性能优化参数
PERFORMANCE="-server -XX:+UseCompressedOops -XX:+UseStringDeduplication"
```

## ⚠️ 注意事项

### 1. 内存使用
- JVM堆内存设置为4G-6G
- 确保服务器有足够的可用内存
- 监控内存使用率，避免OOM

### 2. 数据库服务器
- 确保MySQL服务器能支持80个并发连接
- 监控数据库服务器的CPU和内存使用
- 建议数据库服务器配置不低于8核16G

### 3. 网络带宽
- 确保网络带宽能支持更高的并发
- 监控网络延迟和吞吐量

## 📈 监控指标
