# AI聊天错误处理测试指南

**📅 创建时间**: 2025-06-20 22:53:54
**👤 创建人员**: Augment Agent
**📊 文档版本**: v1.0

## 功能概述

本次优化实现了AI聊天错误处理的改进，主要特性：

1. **通用错误消息**: AI请求错误时返回"请求错误"而不是具体错误信息
2. **数据库记录保存**: 错误消息作为正常AI响应保存到数据库
3. **使用次数保护**: 错误情况下不扣减用户的聊天使用次数
4. **完整流式响应**: 错误响应也遵循Vercel AI SDK格式
5. **智能标题生成**: 只有真正的AI成功响应才会触发自动标题生成，错误响应不会生成标题

## 测试场景

### 1. AI API连接错误测试

**测试步骤**:
1. 临时修改AI模型的API地址为无效地址
2. 发送聊天请求
3. 验证返回"请求错误"消息
4. 检查数据库是否保存了错误响应记录
5. 验证用户使用次数未被扣减

**预期结果**:
- 前端收到"请求错误"消息
- 数据库t_chat_message表中有新的assistant角色记录，内容为"请求错误"
- 用户的聊天使用次数保持不变
- 如果是第一条消息，不会自动生成会话标题（保持"新对话"）

### 2. AI API超时错误测试

**测试步骤**:
1. 临时将超时时间设置为很短（如1秒）
2. 发送聊天请求
3. 等待超时发生
4. 验证错误处理逻辑

**预期结果**:
- 超时后返回"请求错误"消息
- 数据库正常保存错误响应
- 使用次数不被扣减

### 3. AI API认证错误测试

**测试步骤**:
1. 临时修改AI模型的API Key为无效值
2. 发送聊天请求
3. 验证401认证错误的处理

**预期结果**:
- 返回通用"请求错误"消息
- 不暴露具体的认证错误信息
- 正常保存错误记录
- 不会触发标题生成

### 4. 首次消息错误响应标题测试

**测试步骤**:
1. 创建新的聊天会话
2. 发送第一条用户消息
3. 模拟AI服务错误（如修改API地址）
4. 验证错误响应和标题生成行为

**预期结果**:
- 收到"请求错误"响应
- 会话标题保持为"新对话"，不会自动生成新标题
- 数据库中保存了错误响应记录
- 使用次数未被扣减

### 5. 后续消息错误响应测试

**测试步骤**:
1. 在已有成功对话的会话中
2. 发送新消息时模拟AI错误
3. 验证错误处理不影响已有标题

**预期结果**:
- 收到"请求错误"响应
- 会话标题保持不变（不会重新生成）
- 正常保存错误记录

## 数据库验证

### 检查聊天消息记录
```sql
-- 查看最近的聊天消息，包括错误响应
SELECT 
    id,
    session_id,
    role,
    content,
    status,
    error_message,
    create_time
FROM t_chat_message 
WHERE role = 'assistant' 
    AND content = '请求错误'
ORDER BY create_time DESC 
LIMIT 10;
```

### 检查用户使用次数
```sql
-- 查看用户的使用次数变化
SELECT
    user_id,
    package_id,
    chat_count_remaining,
    update_time
FROM t_user_account
WHERE user_id = ? -- 替换为测试用户ID
ORDER BY update_time DESC;
```

```sql
-- 查看会话标题是否正确生成
SELECT
    session_id,
    title,
    user_id,
    status,
    create_time,
    update_time
FROM t_chat_session
WHERE user_id = ? -- 替换为测试用户ID

LIMIT 10;
```

## 日志验证

### 关键日志信息
1. `AI API流式响应处理失败` - 表示AI API调用失败
2. `错误响应已保存到数据库` - 表示错误消息已保存
3. `AI服务调用失败，不记录聊天次数` - 表示使用次数未扣减

### 日志查看命令
```bash
# 查看最近的错误处理日志
tail -f logs/application.log | grep -E "(错误响应|AI服务调用失败|请求错误)"
```
