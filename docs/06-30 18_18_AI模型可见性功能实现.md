# AI模型可见性功能实现

**📅 创建时间**: 2025-06-30 18:18  
**👤 开发人员**: Augment Agent  
**📊 版本**: v1.0  
**🎯 功能**: AI模型可见性控制

## 功能概述

为t_ai_model表增加可见性参数，实现AI模型的公开API访问控制。当模型的可见性参数为true时，前端通过api/models接口可以获取到该模型；当为false时，模型不会在API中返回，仅供项目内部使用。

## 实现内容

### 1. 数据库结构修改

#### 新增字段
- 表名：`t_ai_model`
- 字段名：`is_visible`
- 类型：`tinyint`
- 默认值：`1`
- 注释：是否可见（0-不可见，1-可见）

#### SQL脚本
```sql
-- 添加is_visible字段
ALTER TABLE `t_ai_model` 
ADD COLUMN `is_visible` tinyint DEFAULT '1' COMMENT '是否可见（0-不可见，1-可见）' 
AFTER `is_available`;

-- 更新现有数据，默认所有模型都可见
UPDATE `t_ai_model` SET `is_visible` = 1 WHERE `deleted` = 0;
```

### 2. 实体类修改

#### AiModel.java
- 新增`isVisible`字段
- 添加`@TableField("is_visible")`注解
- 位置：在`isAvailable`字段之后

### 3. 数据访问层修改

#### AiModelMapper.xml
- 更新`BaseResultMap`，添加`is_visible`字段映射
- 更新`Base_Column_List`，包含`is_visible`字段
- 新增`selectVisibleModels`查询方法

#### AiModelDao.java
- 新增`selectVisibleModels()`方法声明

### 4. 服务层修改

#### AiModelService.java
- 新增`getVisibleModels()`方法接口

#### AiModelServiceImpl.java
- 实现`getVisibleModels()`方法
- 更新`initDefaultModels()`方法，为新创建的模型设置可见性

### 5. 控制器层修改

#### ApiController.java
- 修改`/api/models`接口，使用`getVisibleModels()`替代`getAvailableModels()`
- 更新注释：从"获取可用的AI模型列表"改为"获取可见的AI模型列表"

#### ChatApiController.java
- 修改`/api/chat/models`接口，使用`getVisibleModels()`替代`getAvailableModels()`
- 更新注释：从"获取可用模型列表"改为"获取可见模型列表"

## 功能特性

### 1. 向后兼容
- 现有数据默认设置为可见（is_visible = 1）
- 不影响现有功能的正常运行

### 2. 灵活控制
- 可以通过数据库直接修改模型的可见性
- 支持动态控制模型在API中的展示

### 3. 内部使用
- 不可见的模型仍然可以在项目内部使用
- `getAvailableModels()`方法保持不变，用于内部逻辑

## 使用场景

### 1. 测试模型
- 将测试中的模型设置为不可见
- 避免用户在前端看到不稳定的模型

### 2. 内部专用模型
- 某些模型仅供系统内部功能使用
- 如自动标题生成等功能专用模型

### 3. 临时下线
- 快速隐藏有问题的模型
- 无需删除数据，便于后续恢复

## 数据库操作示例

### 隐藏模型
```sql
UPDATE t_ai_model SET is_visible = 0 WHERE model_code = 'test-model';
```

### 显示模型
```sql
UPDATE t_ai_model SET is_visible = 1 WHERE model_code = 'production-model';
```

### 查询可见模型
```sql
SELECT * FROM t_ai_model 
WHERE is_available = 1 AND is_visible = 1 AND deleted = 0;
```

## 注意事项

1. **数据一致性**：确保在修改可见性时，模型仍然是可用状态（is_available = 1）
2. **缓存更新**：如果使用了缓存，需要在修改可见性后清除相关缓存
3. **权限控制**：建议只有管理员权限才能修改模型的可见性
4. **日志记录**：重要的可见性变更应该记录操作日志
