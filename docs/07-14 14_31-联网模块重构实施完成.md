## 重构概述
成功实施联网模块重构，将原有的两步式联网模块（Tavily搜索 + Tavily提取）重构为单步式联网AI模块，通过向专门的联网AI发送一次请求获取结构化的联网响应。

## 实施内容

### 阶段1：新服务实现 ✅
1. **创建新实体类**
   - `NetworkSearchResult.java` - 联网AI返回的单个搜索结果
   - `NetworkAiResponse.java` - 联网AI响应实体
   - `NetworkAiRequest.java` - 联网AI请求实体

2. **创建NetworkAiService**
   - `NetworkAiService.java` - 联网AI服务接口
   - `NetworkAiServiceImpl.java` - 联网AI服务实现
   - 实现联网AI调用逻辑，处理非流式JSON响应解析
   - 添加错误处理和重试机制
   - 提供适配器方法`queryWithNetworkAsWebSearchResults()`

3. **配置联网AI模型**
   - 创建SQL脚本 `sql/07-12-network-ai-model-config.sql`
   - 添加模型代码为 `network-ai` 的专用联网AI模型配置

### 阶段2：集成新服务 ✅
1. **修改ChatServiceImpl**
   - 添加NetworkAiService依赖注入
   - 重构`processNetworkContent`方法，使用NetworkAiService替代WebSearchExtractService
   - 保持所有其他逻辑完全不变（数据处理、存储、响应逻辑等）

2. **重命名和数据适配**
   - 创建`WebSearchResult.java`作为统一搜索结果格式
   - 修改`NetworkSearchResult`内部类使用WebSearchResult
   - 更新ChatRequestDTO的networkSearchResults字段类型
   - 创建适配器方法`convertWebSearchResultsToTavilyResponse()`确保存储兼容性

### 阶段3：清理和重命名 ✅
1. **清除Tavily相关代码**
   - 移除`WebSearchService.java`和`WebSearchServiceImpl.java`
   - 移除`WebSearchExtractService.java`和`WebSearchExtractServiceImpl.java`
   - 移除Tavily相关实体类：
     - `TavilySearchRequest.java`
     - `TavilyExtractRequest.java`
     - `TavilyExtractResponse.java`
     - `TavilyExtractResult.java`
     - `TavilyAutoParameters.java`
     - `WebSearchExtractResult.java`

2. **保留兼容性组件**
   - 保留`TavilySearchResult.java`和`TavilySearchResponse.java`
   - 保持与WebSearchContentService的兼容性
   - 通过适配器确保数据格式完全兼容

## 技术实现细节

### 联网AI服务架构
```java
NetworkAiService.queryWithNetworkAsWebSearchResults(userContext)
    ↓
NetworkAiServiceImpl.queryWithNetwork(userContext)
    ↓
发送HTTP请求到联网AI API
    ↓
解析JSON响应为NetworkAiResponse
    ↓
转换为List<WebSearchResult>格式
```

### 数据流转换
```
用户查询 → 联网AI → NetworkSearchResult[] → WebSearchResult[] → TavilySearchResult[] → 存储
```
