## 📋 概述

前端使用的 `ai/react` 库的 `useAIChat` Hook 期望接收 **OpenAI 标准的流式响应格式**。这是一个基于 Server-Sent Events (SSE) 的流式协议。

## 📡 期望的响应格式

### 1. 响应头设置
```
Content-Type: text/plain; charset=utf-8
Cache-Control: no-cache
Connection: keep-alive
```

### 2. 流式数据格式

#### 标准的OpenAI流式响应格式：
```
data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1234567890,"choices":[{"index":0,"delta":{"content":"你好"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1234567890,"choices":[{"index":0,"delta":{"content":"，"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1234567890,"choices":[{"index":0,"delta":{"content":"我是"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1234567890,"choices":[{"index":0,"delta":{"content":"AI助手"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1234567890,"choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

### 3. 数据结构详解

#### 每个数据块的结构：
```typescript
interface ChatCompletionChunk {
  id: string                    // 聊天完成的唯一标识符
  object: "chat.completion.chunk" // 固定值
  created: number               // Unix时间戳
  choices: Array<{
    index: number               // 选择的索引（通常为0）
    delta: {
      content?: string          // 增量内容（可选）
      role?: string            // 角色（仅在第一个chunk中出现）
    }
    finish_reason: string | null // 完成原因："stop", "length", "content_filter" 或 null
  }>
}
```

#### 示例数据块：

**第一个块（包含角色信息）：**
```json

  "object": "chat.completion.chunk",

  "choices": [{
    "index": 0,
    "delta": {
      "role": "assistant",
      "content": ""
    },
    "finish_reason": null

```

## 🔧 后端实现要求

### 1. 响应头设置
```javascript
res.setHeader('Content-Type', 'text/plain; charset=utf-8')
res.setHeader('Cache-Control', 'no-cache')
res.setHeader('Connection', 'keep-alive')
```

### 2. 数据发送格式
每个数据块必须以 `data: ` 开头，以双换行符 `\n\n` 结尾：
```javascript
res.write(`data: ${JSON.stringify(chunk)}\n\n`)
```

### 3. 完整的后端示例（Node.js）
```javascript
app.post('/api/chat', (req, res) => {
  // 设置SSE响应头
  res.setHeader('Content-Type', 'text/plain; charset=utf-8')
  res.setHeader('Cache-Control', 'no-cache')
  res.setHeader('Connection', 'keep-alive')
  
  const chatId = `chatcmpl-${Date.now()}`
  const created = Math.floor(Date.now() / 1000)
  
  // 发送第一个块（包含角色）
  const firstChunk = {
    id: chatId,
    object: "chat.completion.chunk",
    created: created,
    choices: [{
      index: 0,
      delta: { role: "assistant", content: "" },
      finish_reason: null
    }]
  }
  res.write(`data: ${JSON.stringify(firstChunk)}\n\n`)
  
  // 模拟流式发送内容
  const content = "你好，我是AI助手"
  for (let i = 0; i < content.length; i++) {
    const chunk = {
      id: chatId,
      object: "chat.completion.chunk", 
      created: created,
      choices: [{
        index: 0,
        delta: { content: content[i] },
        finish_reason: null
      }]
    }
    res.write(`data: ${JSON.stringify(chunk)}\n\n`)
  }
  
  // 发送完成标记
  const finalChunk = {
    id: chatId,
    object: "chat.completion.chunk",
    created: created,
    choices: [{
      index: 0,
      delta: {},
      finish_reason: "stop"
    }]
  }
  res.write(`data: ${JSON.stringify(finalChunk)}\n\n`)
  
  // 发送结束标记
  res.write('data: [DONE]\n\n')
  res.end()
})
```

## ⚠️ 重要注意事项

### 1. 格式严格性
- 每行必须以 `data: ` 开头
- JSON数据必须在同一行
- 每个数据块后必须有双换行符 `\n\n`
- 最后必须发送 `data: [DONE]\n\n`

### 2. 字段要求
- `id`: 必须是唯一的字符串
- `object`: 必须是 `"chat.completion.chunk"`
- `created`: Unix时间戳
- `choices[0].index`: 通常为 0
- `choices[0].delta.content`: 增量内容
- `choices[0].finish_reason`: 完成时为 "stop"，进行中为 null

### 3. 错误处理
如果发生错误，应该发送错误格式的数据块：
```json
{
  "error": {
    "message": "错误描述",
    "type": "error_type",
    "code": "error_code"
  }
}
```
