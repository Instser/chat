## 📊 功能特性

### 1. 数据存储
- 优惠价格字段允许为NULL，表示该套餐没有优惠价格
- 当discount_price不为NULL时，表示该套餐有优惠价格
- 优惠价格以人民币为单位存储

### 2. 前端展示
- 前端可以根据discountPrice是否为NULL来决定是否显示优惠价格
- 当有优惠价格时，可以显示原价和优惠价的对比
- 支持在套餐列表和详情页面显示优惠信息

### 3. 业务逻辑
- 优惠价格应该小于原价格（建议在业务逻辑中添加验证）
- 支持动态设置和取消优惠价格
- 与现有的价格转换逻辑兼容

## 🔍 使用示例

### 1. 设置优惠价格
```sql
-- 为套餐ID为1的套餐设置优惠价格为8.88元
UPDATE `t_package` SET `discount_price` = 8.88 WHERE `id` = 1;
```

### 2. 取消优惠价格
```sql
-- 取消套餐ID为1的优惠价格
UPDATE `t_package` SET `discount_price` = NULL WHERE `id` = 1;
```

### 3. 前端判断逻辑
```javascript
// 判断是否有优惠价格
if (packageInfo.discountPrice !== null) {
    // 显示优惠价格和原价

} else {
    // 只显示原价
    console.log(`价格: ${packageInfo.price}`);
}
```
