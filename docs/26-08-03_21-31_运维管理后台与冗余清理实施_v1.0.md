## 1. 已完成

### 1.1 阶段 A 安全收口（此前完成）

- 支付审计/同步管理员限制
- API Key 仅 Header
- analyze-error 脱敏与长度限制
- README-OPS 端口/鉴权修正

### 1.2 管理员后端骨架与核心 API（开发方案阶段 1–5 后端）

新增包 `com.instser.chat.admin`：

| 模块 | 路径前缀 | 能力 |
|---|---|---|
| 用户 | `/admin/users` | 分页、详情、状态、角色、套餐激活/续期/更换、订单/会话摘要 |
| 套餐 | `/admin/packages` | 列表、CRUD、启停、排序 |
| 模型 | `/admin/models` | 列表、CRUD、凭据更新、可用性/可见性、连通测试（Key 脱敏） |
| 订单 | `/admin/orders`、`/admin/payment/analytics` | 分页、详情、单笔/批量同步、取消未支付、支付分析 |
| 审计 | `/admin/audits` | 操作/支付/OAuth 审计、按 traceId 聚合 |
| 仪表盘 | `/admin/dashboard` | overview/health/alerts |
| 运维 | `/admin/ops` | version/health/metrics/cache 清理/logger 白名单/AI 分析 |

鉴权：JWT + `@PreAuthorize("hasRole('ADMIN')")`。写操作写入 `t_operation_audit`（`AdminAuditPublisher`）。

### 1.3 清理阶段 B/C 安全项

- JWT 新入口 `/admin/ops/**` 替代交互式缓存/日志/错误分析
- 旧 `/admin/cache/**`、`/admin/logs/**` 标记 `@Deprecated`，兼容期保留 API Key 入口
- 删除误导性 `CacheManagementConfig`、`CacheManagementServerConfig`
- `TestController` 限制 `dev/test/local` Profile
- `ModelUsageController.init-package-config` 返回 410
- `DataInitializer`：生产不再自动创建默认管理员；移除启动 DDL

### 1.4 数据库

- 增量：`sql/2026-08-03_t_operation_audit_admin_fields.sql`
- 回滚：`sql/2026-08-03_t_operation_audit_admin_fields_rollback.sql`
- 实体 `OperationAudit` 已扩展对应字段

## 4. 部署注意

1. 先执行 `sql/2026-08-03_t_operation_audit_admin_fields.sql`（若生产尚无新列）。
2. 管理员使用现有 `POST /api/auth/login`，`role=admin` 后访问 `/api/admin/**`。
3. 生产 active profile 不要包含 `dev/test/local`，避免默认管理员与 TestController。
4. 旧脚本依赖 `?apiKey=` 必须改为 Header。
5. 无新增 Maven 依赖，JDK 保持 17。
