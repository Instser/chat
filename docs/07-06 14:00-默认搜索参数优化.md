# 07-06 14:00 - 默认搜索参数优化

## 更新时间
2025年7月6日 14:00 (北京时间)

## 版本标识
v1.1.1-websearch-params-optimization

## 功能概述
优化联网搜索和内容提取的默认参数，提高搜索覆盖率和内容获取完整性。

## 参数调整

### 修改前的默认参数
- **搜索结果数量**: 10个
- **内容提取数量**: 前3个链接
- **覆盖率**: 30% (3/10)

### 修改后的默认参数
- **搜索结果数量**: 20个
- **内容提取数量**: 所有返回链接 (20个)
- **覆盖率**: 100% (20/20)

## 修改的文件

### 服务实现类
1. **WebSearchExtractServiceImpl.java**
   - 修改`searchAndExtract(String query)`方法
   - 从`searchAndExtract(query, 10, 3)`改为`searchAndExtract(query, 20, 20)`

### 服务接口
2. **WebSearchExtractService.java**
   - 更新接口注释说明
   - 从"默认搜索10个结果，提取前3个的详细内容"改为"默认搜索20个结果，提取所有返回链接的详细内容"

### 测试类
3. **WebSearchExtractServiceTest.java**
   - 更新测试注释
   - 从"默认参数：搜索10个结果，提取前3个"改为"默认参数：搜索20个结果，提取所有返回链接"

## 优化效果

### 搜索覆盖率提升
- **结果数量**: 从10个增加到20个，提升100%
- **信息丰富度**: 更多相关链接，提供更全面的信息源
- **选择多样性**: 更多不同来源的内容，避免信息偏向

### 内容提取完整性
- **提取比例**: 从30%提升到100%
- **信息完整性**: 获取所有搜索结果的详细内容
- **内容深度**: 每个链接的完整Markdown内容

### 用户体验改善
- **一次性获取**: 单次调用获得最全面的信息
- **减少交互**: 无需多次调用获取更多内容
- **信息质量**: 更丰富的内容支持更好的AI回答

## 使用示例

### 优化前的效果
```java
// 只能获取3个链接的详细内容
WebSearchExtractResult result = webSearchExtractService.searchAndExtract("Spring Boot教程");
// 搜索结果: 10个链接
// 详细内容: 仅前3个链接
// 覆盖率: 30%
```

### 优化后的效果
```java
// 获取所有搜索结果的详细内容
WebSearchExtractResult result = webSearchExtractService.searchAndExtract("Spring Boot教程");
// 搜索结果: 20个链接
// 详细内容: 所有20个链接
// 覆盖率: 100%
```

### 自定义参数仍然支持
```java
// 如果需要更精确的控制，仍可使用自定义参数
WebSearchExtractResult result = webSearchExtractService.searchAndExtract(
    "Spring Boot教程", 
    10,  // 搜索10个结果
    5    // 只提取前5个的详细内容
);
```

## 性能考虑

### API调用成本
- **搜索API**: 从10个结果增加到20个结果
- **提取API**: 从3个URL增加到20个URL
- **总成本**: 约增加6-7倍的API调用

### 响应时间
- **搜索时间**: 略有增加（20个结果vs 10个结果）
- **提取时间**: 显著增加（20个URL vs 3个URL）
- **总时间**: 预计增加3-5倍

### 内存使用
- **内容大小**: 每个URL约1-10KB Markdown内容
- **总内存**: 20个URL约20-200KB内容
- **影响**: 对系统内存影响较小
