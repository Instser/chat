## 🚨 常见问题排查

### 问题1: 续写中断但保存为正常响应
**可能原因**: 中断标记检测失败
**排查方法**: 
1. 检查日志中是否有`CONTINUATION_INTERRUPTED:`标记
2. 验证`finalInterruptedStatus`是否正确设置
3. 确认主流程中断标志`isInterrupted[0]`是否被设置

### 问题2: 会话状态清理过早
**可能原因**: 时序问题未完全解决
**排查方法**:
1. 检查`markSessionCompleted`调用时机
2. 验证续写线程是否能正确检测中断
3. 确认finally块中的清理逻辑

### 问题3: 内容拼接不正确
**可能原因**: 字符串处理错误
**排查方法**:
1. 检查`substring`操作是否正确
2. 验证内容长度计算
3. 确认拼接逻辑的顺序

## 📊 性能监控

### 关键指标
- **续写成功率**: 正常完成的续写请求比例
- **续写中断率**: 被用户中断的续写请求比例
- **内容完整性**: 保存内容的完整性检查
- **响应时间**: 续写处理的平均响应时间

### 监控查询
```sql
-- 续写相关统计（最近24小时）
SELECT 
    DATE_FORMAT(created_time, '%H:00') as hour,
    COUNT(*) as total_messages,
    SUM(CASE WHEN content LIKE '%续写%' THEN 1 ELSE 0 END) as continuation_messages,
    SUM(CASE WHEN content LIKE '%中断%' THEN 1 ELSE 0 END) as interrupted_messages
FROM t_chat_message 
WHERE role = 'assistant' 
    AND created_time >= DATE_SUB(NOW(), INTERVAL 24 HOUR)
GROUP BY DATE_FORMAT(created_time, '%H:00')
ORDER BY hour;
```
