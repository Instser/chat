# 聊天日志简化配置说明

**📅 更新时间**: 2025-07-04 14:55:15  
**👤 操作人员**: Augment Agent  
**📊 文档版本**: v1.0  
**🔧 功能类型**: 日志优化配置

## 概述

为了减少聊天和续写功能产生的大量详细日志，对ChatServiceImpl和相关服务的日志输出进行了简化配置。

## 修改内容

### 1. 代码级别的日志简化

#### ChatServiceImpl.java 主要修改：
- **AI响应行日志**：`log.info` → `log.debug`，并截断长内容
- **用户消息保存日志**：`log.info` → `log.debug`
- **AI响应保存日志**：`log.info` → `log.debug`
- **续写相关详细日志**：大部分改为 `log.debug` 或移除
- **JSON处理日志**：简化或移除详细内容输出
- **WebClient请求日志**：`log.info` → `log.debug`

#### 具体简化的日志类型：
```java
// 原来：详细输出完整内容
log.info("收到AI响应行: [{}]", line);

// 现在：DEBUG级别 + 内容截断
log.debug("收到AI响应行: [{}]", line.length() > 100 ? line.substring(0, 100) + "..." : line);
```

### 2. 日志配置文件修改

#### logback-spring.xml 配置：

## 本地开启DEBUG日志的方法

### 方法1：修改application.yml配置文件

在 `src/main/resources/application.yml` 中添加或修改：

```yaml
logging:
  level:
    com.instser.chat.service.serviceimpl.ChatServiceImpl: DEBUG
    com.instser.chat.service.serviceimpl.TruncationDetectionServiceImpl: DEBUG
    # 或者开启整个包的DEBUG日志
    com.instser.chat: DEBUG
```

### 方法2：使用Spring Profile

创建 `application-debug.yml` 文件：

```yaml
logging:
  level:
    root: INFO
    com.instser.chat: DEBUG
    com.instser.chat.service.serviceimpl.ChatServiceImpl: DEBUG
```

然后启动时指定profile：

```bash
# 方式1：使用Maven
mvn spring-boot:run -Dspring-boot.run.profiles=debug

# 方式2：使用Java命令
java -jar target/chat-0.0.1-SNAPSHOT.jar --spring.profiles.active=debug

# 方式3：设置环境变量
export SPRING_PROFILES_ACTIVE=debug
java -jar target/chat-0.0.1-SNAPSHOT.jar
```

### 方法3：运行时动态修改日志级别

使用Spring Boot Actuator（如果已启用）：

```bash
# 查看当前日志级别
curl http://localhost:8080/actuator/loggers/com.instser.chat.service.serviceimpl.ChatServiceImpl

# 动态修改日志级别为DEBUG
curl -X POST http://localhost:8080/actuator/loggers/com.instser.chat.service.serviceimpl.ChatServiceImpl \
  -H "Content-Type: application/json" \
  -d '{"configuredLevel": "DEBUG"}'

# 恢复为INFO级别
curl -X POST http://localhost:8080/actuator/loggers/com.instser.chat.service.serviceimpl.ChatServiceImpl \
  -H "Content-Type: application/json" \
  -d '{"configuredLevel": "INFO"}'
```

### 方法4：使用JVM参数

启动时添加JVM参数：

```bash
java -jar target/chat-0.0.1-SNAPSHOT.jar \
  -Dlogging.level.com.instser.chat.service.serviceimpl.ChatServiceImpl=DEBUG \
  -Dlogging.level.com.instser.chat.service.serviceimpl.TruncationDetectionServiceImpl=DEBUG
```

### 方法5：临时修改logback-spring.xml

直接修改 `src/main/resources/logback-spring.xml` 文件：

```xml
<!-- 临时开启DEBUG日志 -->
<logger name="com.instser.chat.service.serviceimpl.ChatServiceImpl" level="DEBUG" additivity="false">
    <appender-ref ref="CONSOLE"/>
    <appender-ref ref="ASYNC_FILE"/>
    <appender-ref ref="ASYNC_ERROR_FILE"/>
</logger>
```

## 日志级别说明

| 级别 | 用途 | 包含内容 |
|------|------|----------|
| ERROR | 错误日志 | 系统错误、异常信息 |
| WARN | 警告日志 | 潜在问题、非致命错误 |
| INFO | 信息日志 | 关键操作、业务流程节点 |
| DEBUG | 调试日志 | 详细的执行过程、变量值 |
| TRACE | 跟踪日志 | 最详细的执行信息 |

## 注意事项

1. **生产环境**：建议保持INFO级别，避免大量DEBUG日志影响性能
2. **开发调试**：可以临时开启DEBUG级别进行问题排查
3. **日志文件大小**：DEBUG日志会显著增加日志文件大小，注意磁盘空间
4. **性能影响**：大量的字符串拼接和格式化会影响性能
5. **敏感信息**：DEBUG日志可能包含用户输入内容，注意数据安全
