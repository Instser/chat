## 🎯 方案概述

### 目标
- 建立统一的日志记录标准，提高系统可观测性
- 在INFO级别记录关键业务数据，便于运营监控
- 在DEBUG级别记录详细运行过程，便于问题排查
- 在WARN和ERROR级别记录异常情况，便于及时响应

### 原则
- **结构化记录**：使用统一的格式和标识符
- **分级管理**：不同级别记录不同详细程度的信息
- **安全优先**：严格保护敏感信息，避免泄露
- **性能考虑**：避免日志记录影响系统性能

## 📊 日志级别标准

### INFO 级别 - 关键信息
**用途**：记录系统关键操作、状态变更和重要业务流程

**内容标准**：
- 用户操作的关键节点（登录、注册、支付等）
- 系统启动、初始化和关闭信息
- 业务流程的开始和结束（包含用户ID、会话ID等关键标识）
- 定期性能统计报告
- 关键数据的简要摘要（不包含敏感信息）

**格式规范**：
```
【操作类型】用户ID：xxx，关键参数：xxx，结果：xxx
【模块名称】关键操作：xxx，状态：xxx
```

### DEBUG 级别 - 详细信息
**用途**：记录详细的执行过程和数据，用于问题排查

**内容标准**：
- 方法调用的详细参数和返回值
- 业务流程的中间步骤和状态变化
- 条件判断和分支选择的详细信息
- 外部系统交互的请求和响应详情
- 数据处理的中间结果

**格式规范**：
```
【详细】方法：xxx，参数：xxx，返回：xxx
【处理】步骤：xxx，数据：xxx，结果：xxx
```

### WARN 级别 - 警告信息
**用途**：记录潜在问题或异常情况，但不影响系统正常运行

**内容标准**：
- 业务规则验证失败
- 资源使用接近阈值（内存、连接池等）
- 重试操作
- 性能下降预警
- 用户可疑行为（频繁登录失败、异常访问模式）

**格式规范**：
```
【警告】用户ID：xxx，操作：xxx，原因：xxx
【资源警告】资源类型：xxx，当前使用率：xxx%，阈值：xxx%
```

### ERROR 级别 - 错误信息
**用途**：记录系统错误和异常，需要立即关注和处理

**内容标准**：
- 未捕获的异常详情（包括堆栈跟踪）
- 业务流程中断
- 外部系统连接失败
- 数据一致性错误
- 安全相关错误（认证失败、权限不足）

**格式规范**：
```
【错误】用户ID：xxx，操作：xxx，错误类型：xxx，详细信息：xxx
【系统错误】模块：xxx，方法：xxx，异常：xxx，堆栈：xxx
```

## 💻 代码实现示例

### 工具方法
```java
/**
 * 日志工具类
 */
public class LogUtils {
    
    /**
     * 邮箱脱敏
     */
    public static String maskEmail(String email) {
        if (email == null || !email.contains("@")) {
            return email;
        }
        String[] parts = email.split("@");
        String username = parts[0];
        if (username.length() <= 2) {
            return username.charAt(0) + "***@" + parts[1];
        }
        return username.charAt(0) + "***" + username.charAt(username.length() - 1) + "@" + parts[1];
    }
    
    /**
     * 内容截断
     */
    public static String truncateContent(String content) {
        if (content == null || content.length() <= 30) {
            return content;
        }
        return content.substring(0, 15) + "..." + content.substring(content.length() - 15);
    }
    
    /**
     * 手机号脱敏
     */
    public static String maskPhone(String phone) {
        if (phone == null || phone.length() < 7) {
            return phone;
        }
        return phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4);
    }
}
```

### 业务方法示例
```java
@Slf4j
@Service
public class UserServiceImpl implements UserService {
    
    @Override
    public Long registerUser(String username, String email, String password) {
        log.info("【用户注册开始】邮箱：{}，用户名：{}", LogUtils.maskEmail(email), username);
        
        try {
            // 检查邮箱是否已存在
            if (getUserByEmail(email) != null) {
                log.warn("【注册失败】邮箱已存在：{}", LogUtils.maskEmail(email));
                throw new BusinessException("邮箱已被注册");
            }
            
            log.debug("【注册验证】邮箱验证通过：{}", LogUtils.maskEmail(email));
            
            // 检查用户名是否已存在
            if (getUserByUsername(username) != null) {
                log.warn("【注册失败】用户名已存在：{}", username);
                throw new BusinessException("用户名已被使用");
            }
            
            log.debug("【注册验证】用户名验证通过：{}", username);
            
            // 创建用户
            User user = new User();
            user.setUsername(username);
            user.setEmail(email);
            user.setPassword(passwordEncoder.encode(password));
            user.setRole("user");
            user.setStatus(1);
            user.setCreatedTime(LocalDateTime.now());
            user.setUpdateTime(LocalDateTime.now());
            
            this.save(user);
            
            log.info("【用户注册成功】用户ID：{}，邮箱：{}，用户名：{}", 
                user.getId(), LogUtils.maskEmail(email), username);
            
            // 自动绑定默认套餐
            bindDefaultPackage(user.getId());
            
            return user.getId();
            
        } catch (BusinessException e) {
            log.warn("【用户注册失败】邮箱：{}，原因：{}", LogUtils.maskEmail(email), e.getMessage());
            throw e;
        } catch (Exception e) {
            log.error("【用户注册异常】邮箱：{}，异常：{}", LogUtils.maskEmail(email), e.getMessage(), e);
            throw new BusinessException("注册失败", e);
        }
    }
    
    @Override
    public User login(String email, String password) {
        log.info("【用户登录开始】邮箱：{}", LogUtils.maskEmail(email));
        
        try {
            User user = getUserByEmail(email);
            if (user == null) {
                log.warn("【登录失败】用户不存在：{}", LogUtils.maskEmail(email));
                throw new BusinessException("用户不存在");
            }
            
            log.debug("【登录验证】用户存在检查通过，用户ID：{}", user.getId());
            
            if (user.getStatus() == 0) {
                log.warn("【登录失败】账户已禁用，用户ID：{}", user.getId());
                throw new BusinessException("账户已被禁用");
            }
            
            log.debug("【登录验证】账户状态检查通过，用户ID：{}", user.getId());
            
            if (!passwordEncoder.matches(password, user.getPassword())) {
                log.warn("【登录失败】密码错误，用户ID：{}", user.getId());
                throw new BusinessException("密码错误");
            }
            
            log.debug("【登录验证】密码验证通过，用户ID：{}", user.getId());
            
            // 更新最后登录时间
            updateLastLoginTime(user.getId());
            
            log.info("【用户登录成功】用户ID：{}，邮箱：{}", user.getId(), LogUtils.maskEmail(email));
            return user;
            
        } catch (BusinessException e) {
            log.warn("【用户登录失败】邮箱：{}，原因：{}", LogUtils.maskEmail(email), e.getMessage());
            throw e;
        } catch (Exception e) {
            log.error("【用户登录异常】邮箱：{}，异常：{}", LogUtils.maskEmail(email), e.getMessage(), e);
            throw new BusinessException("登录失败", e);
        }
    }
}
```
