## 📋 方案概述

本方案旨在优化联网搜索结果的流式响应架构，解决当前实现中的时序性、复杂性和跨线程数据传递问题。通过引入专门的服务组件和会话级状态管理，实现更可靠、更易维护的流式响应机制。

## 🚨 **核心问题分析**

### 1. **当前实现的问题**
- **时序依赖性强**：依赖方法调用顺序，容易出错
- **状态管理分散**：搜索结果通过ChatRequestDTO传递，耦合度高
- **跨线程数据传递问题**：processNetworkContent（主HTTP线程）和handleStreamCompletionWithInterruptStatus（流式响应线程）无法共享ThreadLocal数据
- **代码重复**：响应格式化逻辑分散在多处
- **测试困难**：需要构造完整的请求上下文

### 2. **线程模型分析**
```java
// 主HTTP请求线程
buildAiRequestMessages() -> processNetworkContent() -> 存储搜索结果

// 流式响应处理线程（异步）
流式响应回调 -> handleStreamCompletionWithInterruptStatus() -> 发送搜索结果
```

**关键发现**：两个方法在不同线程中执行，ThreadLocal无法跨线程传递数据！

## 🎯 **解决方案设计**

### **核心思路**
1. **服务分离**：创建专门的流式响应服务
2. **会话级状态管理**：使用会话ID实现跨线程数据传递
3. **简化架构**：避免过度设计，保持方案简洁可靠

### **架构设计原则**
- **单一职责**：每个服务只负责自己的核心功能
- **跨线程安全**：支持不同线程间的数据传递
- **简化优先**：优先选择简单可靠的解决方案
- **易于测试**：独立组件，便于单元测试

### 1. **NetworkSearchResultManager（会话级状态管理）- 风险优化版**

```java
@Component
public class NetworkSearchResultManager {

    private static final Logger log = LoggerFactory.getLogger(NetworkSearchResultManager.class);

    // 使用会话ID作为键的状态管理，解决跨线程问题
    private final ConcurrentHashMap<String, NetworkSearchData> sessionSearchData = new ConcurrentHashMap<>();

    // 会话级同步锁，解决时序问题
    private final ConcurrentHashMap<String, Object> sessionLocks = new ConcurrentHashMap<>();

    // 定时清理过期数据
    private final ScheduledExecutorService cleanupExecutor = Executors.newSingleThreadScheduledExecutor();

    // 健康检查器
    private final StreamingResponseHealthChecker healthChecker;

    public NetworkSearchResultManager(StreamingResponseHealthChecker healthChecker) {
        this.healthChecker = healthChecker;
    }

    @PostConstruct
    public void init() {
        // 每5分钟清理一次过期数据
        cleanupExecutor.scheduleAtFixedRate(this::cleanupExpiredData, 5, 5, TimeUnit.MINUTES);
        log.info("NetworkSearchResultManager已初始化，清理周期：5分钟");
    }

    /**
     * 存储搜索结果（线程安全，带风险检测）
     */
    public void storeSearchResults(List<TavilySearchResult> results, String sessionId) {
        if (sessionId == null || results == null || results.isEmpty()) {
            log.warn("无效的存储参数：sessionId={}, results={}",
                    sessionId, results != null ? results.size() : "null");
            return;
        }

        Object lock = sessionLocks.computeIfAbsent(sessionId, k -> new Object());
        synchronized (lock) {
            // 检查是否已经被获取，避免重复存储
            if (!sessionSearchData.containsKey(sessionId)) {
                NetworkSearchData data = new NetworkSearchData(results, sessionId);
                sessionSearchData.put(sessionId, data);
                log.debug("已存储{}个搜索结果到会话：{}", results.size(), sessionId);

                // 记录存储时间用于时序检测
                healthChecker.recordStoreTime(sessionId, System.currentTimeMillis());
            } else {
                log.warn("会话{}的搜索结果已存在，跳过存储", sessionId);
                healthChecker.recordDuplicateStore(sessionId);
            }
        }
    }

    /**
     * 获取并清理搜索结果（线程安全，带状态检测）
     */
    public List<TavilySearchResult> getAndClear(String sessionId) {
        if (sessionId == null) {
            log.warn("会话ID为空，无法获取搜索结果");
            return Collections.emptyList();
        }

        long retrieveTime = System.currentTimeMillis();
        Object lock = sessionLocks.get(sessionId);

        if (lock != null) {
            synchronized (lock) {
                NetworkSearchData data = sessionSearchData.remove(sessionId);
                sessionLocks.remove(sessionId); // 清理锁对象，避免内存泄漏

                if (data != null) {
                    // 时序检测
                    healthChecker.checkTimingIssue(sessionId, data.getTimestamp(), retrieveTime);

                    if (data.hasResults() && !data.isExpired()) {
                        List<TavilySearchResult> results = data.getAndMarkConsumed();
                        if (!results.isEmpty()) {
                            log.debug("获取{}个搜索结果从会话：{}", results.size(), sessionId);
                            healthChecker.recordRetrieveSuccess(sessionId, results.size());
                            return results;
                        }
                    } else if (data.isExpired()) {
                        log.warn("会话{}的搜索结果已过期", sessionId);
                        healthChecker.recordExpiredData(sessionId);
                    } else if (data.isConsumed()) {
                        log.warn("会话{}的搜索结果已被消费", sessionId);
                        healthChecker.recordDuplicateRetrieve(sessionId);
                    }
                }
            }
        }

        log.debug("会话{}无搜索结果可获取", sessionId);
        return Collections.emptyList();
    }

    /**
     * 检查是否有有效的搜索结果
     */
    public boolean hasValidSearchResults(String sessionId) {
        if (sessionId == null) return false;

        NetworkSearchData data = sessionSearchData.get(sessionId);
        return data != null && data.hasResults() && !data.isExpired() && !data.isConsumed();
    }

    /**
     * 强制清理会话数据（带异常处理）
     */
    public void forceCleanup(String sessionId) {
        if (sessionId != null) {
            try {
                NetworkSearchData removedData = sessionSearchData.remove(sessionId);
                sessionLocks.remove(sessionId);

                if (removedData != null) {
                    log.debug("强制清理会话数据：{}, 数据状态：{}", sessionId, removedData);
                } else {
                    log.debug("会话{}无数据需要清理", sessionId);
                }
            } catch (Exception e) {
                log.error("强制清理会话数据失败：{}", sessionId, e);
                healthChecker.recordCleanupError(sessionId, e.getMessage());
            }
        }
    }

    /**
     * 清理过期数据（防止内存泄漏，带异常处理）
     */
    private void cleanupExpiredData() {
        int cleanedDataCount = 0;
        int cleanedLockCount = 0;

        try {
            // 清理过期的搜索数据
            Iterator<Map.Entry<String, NetworkSearchData>> dataIterator = sessionSearchData.entrySet().iterator();
            while (dataIterator.hasNext()) {
                Map.Entry<String, NetworkSearchData> entry = dataIterator.next();
                if (entry.getValue().isExpired()) {
                    dataIterator.remove();
                    cleanedDataCount++;
                }
            }

            // 清理孤立的锁对象
            Iterator<Map.Entry<String, Object>> lockIterator = sessionLocks.entrySet().iterator();
            while (lockIterator.hasNext()) {
                Map.Entry<String, Object> entry = lockIterator.next();
                if (!sessionSearchData.containsKey(entry.getKey())) {
                    lockIterator.remove();
                    cleanedLockCount++;
                }
            }

            if (cleanedDataCount > 0 || cleanedLockCount > 0) {
                log.info("定时清理完成：清理数据{}个，清理锁{}个，当前活跃会话{}个",
                        cleanedDataCount, cleanedLockCount, sessionSearchData.size());
            }

        } catch (Exception e) {
            log.error("定时清理过程中发生异常", e);
            healthChecker.recordCleanupError("SYSTEM", e.getMessage());
        }
    }

    /**
     * 获取当前存储的会话数量（用于监控）
     */
    public int getActiveSessionCount() {
        return sessionSearchData.size();
    }

    /**
     * 获取当前锁对象数量（用于监控）
     */
    public int getActiveLockCount() {
        return sessionLocks.size();
    }

    /**
     * 获取管理器状态信息
     */
    public Map<String, Object> getManagerStatus() {
        Map<String, Object> status = new HashMap<>();
        status.put("activeSessionCount", getActiveSessionCount());
        status.put("activeLockCount", getActiveLockCount());
        status.put("cleanupExecutorStatus", cleanupExecutor.isShutdown() ? "SHUTDOWN" : "RUNNING");
        return status;
    }

    @PreDestroy
    public void destroy() {
        try {
            cleanupExecutor.shutdown();
            if (!cleanupExecutor.awaitTermination(5, TimeUnit.SECONDS)) {
                cleanupExecutor.shutdownNow();
                log.warn("强制关闭清理执行器");
            }

            int dataCount = sessionSearchData.size();
            int lockCount = sessionLocks.size();

            sessionSearchData.clear();
            sessionLocks.clear();

            log.info("NetworkSearchResultManager已关闭，清理了{}个数据和{}个锁", dataCount, lockCount);
        } catch (Exception e) {
            log.error("关闭NetworkSearchResultManager时发生异常", e);
        }
    }
}
```

### 2. **NetworkSearchData（数据传输对象）- 状态跟踪增强版**

```java
public class NetworkSearchData {

    private final List<TavilySearchResult> searchResults;
    private final long timestamp;
    private final String sessionId;
    private volatile boolean consumed = false; // 消费状态标记
    private static final long EXPIRY_TIME = TimeUnit.MINUTES.toMillis(10); // 10分钟过期

    public NetworkSearchData(List<TavilySearchResult> searchResults, String sessionId) {
        this.searchResults = searchResults != null ? new ArrayList<>(searchResults) : new ArrayList<>();
        this.timestamp = System.currentTimeMillis();
        this.sessionId = sessionId;
        this.consumed = false;
    }

    /**
     * 标记为已消费（原子操作）
     */
    public synchronized boolean markAsConsumed() {
        if (consumed) {
            return false; // 已经被消费
        }
        consumed = true;
        return true;
    }

    /**
     * 检查是否已被消费
     */
    public boolean isConsumed() {
        return consumed;
    }

    /**
     * 获取搜索结果（只有未消费且未过期才返回）
     */
    public List<TavilySearchResult> getSearchResults() {
        if (consumed || isExpired()) {
            return Collections.emptyList();
        }
        return Collections.unmodifiableList(searchResults);
    }

    /**
     * 安全的结果获取（带状态检查和标记）
     */
    public List<TavilySearchResult> getAndMarkConsumed() {
        if (!markAsConsumed() || isExpired()) {
            return Collections.emptyList();
        }
        return Collections.unmodifiableList(searchResults);
    }

    /**
     * 检查是否有搜索结果
     */
    public boolean hasResults() {
        return !searchResults.isEmpty();
    }

    /**
     * 获取结果数量
     */
    public int getResultCount() {
        return searchResults.size();
    }

    /**
     * 检查数据是否过期
     */
    public boolean isExpired() {
        return System.currentTimeMillis() - timestamp > EXPIRY_TIME;
    }

    /**
     * 检查数据是否有效（未过期且未消费）
     */
    public boolean isValid() {
        return !isExpired() && !consumed && hasResults();
    }

    /**
     * 获取数据年龄（毫秒）
     */
    public long getAge() {
        return System.currentTimeMillis() - timestamp;
    }

    /**
     * 获取剩余有效时间（毫秒）
     */
    public long getRemainingTime() {
        long remaining = EXPIRY_TIME - getAge();
        return Math.max(0, remaining);
    }

    // Getters
    public long getTimestamp() { return timestamp; }
    public String getSessionId() { return sessionId; }

    @Override
    public String toString() {
        return String.format("NetworkSearchData{sessionId='%s', resultCount=%d, timestamp=%d, " +
                           "expired=%s, consumed=%s, age=%dms, remainingTime=%dms}",
                           sessionId, searchResults.size(), timestamp, isExpired(), consumed,
                           getAge(), getRemainingTime());
    }
}
```

### 3. **StreamingResponseService（流式响应服务）**

```java
@Service
public class StreamingResponseService {

    private static final Logger log = LoggerFactory.getLogger(StreamingResponseService.class);
    private final SearchResultFormatter searchResultFormatter;
    private final CompletionFormatter completionFormatter;
    private final StreamingResponseMetrics metrics;

    public StreamingResponseService(SearchResultFormatter searchResultFormatter, 
                                  CompletionFormatter completionFormatter,
                                  StreamingResponseMetrics metrics) {
        this.searchResultFormatter = searchResultFormatter;
        this.completionFormatter = completionFormatter;
        this.metrics = metrics;
    }

    /**
     * 发送联网搜索结果
     */
    public boolean sendNetworkSearchResults(HttpServletResponse response, List<TavilySearchResult> results) {
        if (results == null || results.isEmpty()) {
            log.debug("无联网搜索结果需要发送");
            return true;
        }

        try {
            log.info("开始发送{}个联网搜索结果给前端", results.size());
            
            for (TavilySearchResult result : results) {
                String formattedResult = searchResultFormatter.formatAsStreamingData(result);
                writeToResponse(response, formattedResult);
            }
            
            metrics.recordSearchResultsSent(results.size());
            log.info("成功发送{}个联网搜索结果给前端", results.size());
            return true;
            
        } catch (Exception e) {
            metrics.recordSearchResultsFailed();
            log.error("发送联网搜索结果失败，结果数量: {}", results.size(), e);
            return false;
        }
    }

    /**
     * 发送完成标记
     */
    public boolean sendCompletion(HttpServletResponse response, CompletionData data) {
        try {
            String completionJson = completionFormatter.formatAsStreamingData(data);
            writeToResponse(response, completionJson);
            
            log.debug("发送完成标记成功");
            return true;
        } catch (Exception e) {
            log.error("发送完成标记失败", e);
            return false;
        }
    }

    private void writeToResponse(HttpServletResponse response, String data) throws IOException {
        response.getWriter().write(data);
        response.getWriter().flush();
    }
}
```

```java
@Component
public class SearchResultFormatter {

    private static final Logger log = LoggerFactory.getLogger(SearchResultFormatter.class);
    private final ObjectMapper objectMapper;

    public SearchResultFormatter() {
        this.objectMapper = new ObjectMapper();
    }

    /**
     * 将搜索结果格式化为流式数据格式
     */
    public String formatAsStreamingData(TavilySearchResult result) {
        try {
            Map<String, Object> resultMap = new HashMap<>();
            resultMap.put("url", result.getUrl() != null ? result.getUrl() : "");
            resultMap.put("title", result.getTitle() != null ? result.getTitle() : "");

            // 限制content字段为前100个字符
            String content = result.getContent() != null ? result.getContent() : "";
            if (content.length() > 100) {
                content = content.substring(0, 100) + "...";
            }
            resultMap.put("content", content);

            resultMap.put("favicon", result.getFavicon() != null ? result.getFavicon() : "");

            String jsonString = objectMapper.writeValueAsString(resultMap);
            return String.format("u:%s\n", jsonString);

        } catch (Exception e) {
            log.error("格式化搜索结果失败", e);
            // 返回基本格式，确保不会中断流式响应
            return "u:{\"url\":\"\",\"title\":\"Error\",\"content\":\"Failed to format result\",\"favicon\":\"\"}\n";
        }
    }
}
```

```java
@Component
public class StreamingResponseMetrics {

    private static final Logger log = LoggerFactory.getLogger(StreamingResponseMetrics.class);

    // 使用简单的计数器，避免复杂的监控框架依赖
    private final AtomicLong searchResultsSentCount = new AtomicLong(0);
    private final AtomicLong searchResultsFailedCount = new AtomicLong(0);
    private final AtomicLong completionSentCount = new AtomicLong(0);
    private final AtomicLong completionFailedCount = new AtomicLong(0);

    /**
     * 记录搜索结果发送成功
     */
    public void recordSearchResultsSent(int count) {
        searchResultsSentCount.addAndGet(count);
        log.debug("搜索结果发送成功，本次: {}, 总计: {}", count, searchResultsSentCount.get());
    }

    /**
     * 记录搜索结果发送失败
     */
    public void recordSearchResultsFailed() {
        searchResultsFailedCount.incrementAndGet();
        log.warn("搜索结果发送失败，失败总计: {}", searchResultsFailedCount.get());
    }

    /**
     * 记录完成标记发送成功
     */
    public void recordCompletionSent() {
        completionSentCount.incrementAndGet();
        log.debug("完成标记发送成功，总计: {}", completionSentCount.get());
    }

    /**
     * 记录完成标记发送失败
     */
    public void recordCompletionFailed() {
        completionFailedCount.incrementAndGet();
        log.warn("完成标记发送失败，失败总计: {}", completionFailedCount.get());
    }

    /**
     * 获取统计信息
     */
    public Map<String, Long> getMetrics() {
        Map<String, Long> metrics = new HashMap<>();
        metrics.put("searchResultsSent", searchResultsSentCount.get());
        metrics.put("searchResultsFailed", searchResultsFailedCount.get());
        metrics.put("completionSent", completionSentCount.get());
        metrics.put("completionFailed", completionFailedCount.get());
        return metrics;
    }

    /**
     * 获取成功率
     */
    public double getSearchResultsSuccessRate() {
        long total = searchResultsSentCount.get() + searchResultsFailedCount.get();
        if (total == 0) return 1.0;
        return (double) searchResultsSentCount.get() / total;
    }

    /**
     * 重置统计信息
     */
    public void reset() {
        searchResultsSentCount.set(0);
        searchResultsFailedCount.set(0);
        completionSentCount.set(0);
        completionFailedCount.set(0);
        log.info("流式响应统计信息已重置");
    }
}
```

```java
        // 异常情况下发送基本完成标记
        try {
            streamingResponseService.sendCompletion(response,
                CompletionData.builder().finishReason("error").build());
        } catch (Exception ex) {
            log.error("发送异常完成标记失败", ex);
        }

        return finalInterruptedStatus;
    } finally {
        // 强制清理会话数据，确保无内存泄漏
        networkSearchResultManager.forceCleanup(request.getSessionId());
    }
}
```

### **1. 跨线程数据传递的时序风险 [高风险]**

**风险描述：**
- **数据竞争条件**：主HTTP线程存储数据和流式响应线程获取数据之间存在时序窗口
- **数据丢失风险**：如果流式响应线程在存储完成前就执行了`getAndClear()`操作
- **重复获取问题**：虽然使用了原子的`remove`操作，但在高并发下仍可能出现意外情况

**具体场景：**
```java
// 时序问题场景
Thread-1 (HTTP): processNetworkContent() -> 准备存储搜索结果
Thread-2 (Stream): handleStreamCompletion() -> getAndClear() -> 返回空结果
Thread-1 (HTTP): storeSearchResults() -> 数据存储完成（但已经太晚）
```

**影响范围：** 用户无法看到联网搜索结果，体验严重下降

### **2. 会话ID依赖的逻辑风险 [中风险]**

**风险描述：**
- **会话ID为空**：如果`request.getSessionId()`返回null，整个机制失效
- **会话ID重复**：不同用户使用相同会话ID可能导致数据混乱
- **会话ID生命周期**：会话ID的生成和管理逻辑可能与新架构不匹配

**影响范围：** 功能完全失效或数据错乱

### **3. 内存管理的时序风险 [中风险]**

**风险描述：**
- **过期时间设置**：10分钟的过期时间可能过长或过短
- **清理时机冲突**：定时清理任务与正常获取操作可能发生冲突
- **强制清理时机**：在`finally`块中强制清理可能过早，导致数据丢失

**影响范围：** 内存泄漏或数据意外丢失

### **4. 异常处理的逻辑风险 [中风险]**

```java
@Component
public class NetworkSearchResultManager {

    private final ConcurrentHashMap<String, NetworkSearchData> sessionSearchData = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, Object> sessionLocks = new ConcurrentHashMap<>();

    /**
     * 线程安全的存储操作
     */
    public void storeSearchResults(List<TavilySearchResult> results, String sessionId) {
        if (sessionId == null || results == null || results.isEmpty()) {
            log.warn("无效的存储参数：sessionId={}, results={}", sessionId, results != null ? results.size() : "null");
            return;
        }

        Object lock = sessionLocks.computeIfAbsent(sessionId, k -> new Object());
        synchronized (lock) {
            // 检查是否已经被获取，避免重复存储
            if (!sessionSearchData.containsKey(sessionId)) {
                NetworkSearchData data = new NetworkSearchData(results, sessionId);
                sessionSearchData.put(sessionId, data);
                log.debug("已存储{}个搜索结果到会话：{}", results.size(), sessionId);
            } else {
                log.warn("会话{}的搜索结果已存在，跳过存储", sessionId);
            }
        }
    }

    /**
     * 线程安全的获取和清理操作
     */
    public List<TavilySearchResult> getAndClear(String sessionId) {
        if (sessionId == null) {
            log.warn("会话ID为空，无法获取搜索结果");
            return Collections.emptyList();
        }

        Object lock = sessionLocks.get(sessionId);
        if (lock != null) {
            synchronized (lock) {
                NetworkSearchData data = sessionSearchData.remove(sessionId);
                sessionLocks.remove(sessionId); // 清理锁对象，避免内存泄漏

                if (data != null && data.hasResults() && !data.isExpired()) {
                    log.debug("获取{}个搜索结果从会话：{}", data.getResultCount(), sessionId);
                    return data.getSearchResults();
                } else if (data != null && data.isExpired()) {
                    log.warn("会话{}的搜索结果已过期", sessionId);
                }
            }
        }

        log.debug("会话{}无搜索结果可获取", sessionId);
        return Collections.emptyList();
    }

    /**
     * 检查数据状态（用于监控）
     */
    public boolean hasValidSearchResults(String sessionId) {
        if (sessionId == null) return false;

        NetworkSearchData data = sessionSearchData.get(sessionId);
        return data != null && data.hasResults() && !data.isExpired();
    }
}
```

```java
public class NetworkSearchData {

    private final List<TavilySearchResult> searchResults;
    private final long timestamp;
    private final String sessionId;
    private volatile boolean consumed = false; // 添加消费状态标记
    private static final long EXPIRY_TIME = TimeUnit.MINUTES.toMillis(10);

    public NetworkSearchData(List<TavilySearchResult> searchResults, String sessionId) {
        this.searchResults = searchResults != null ? new ArrayList<>(searchResults) : new ArrayList<>();
        this.timestamp = System.currentTimeMillis();
        this.sessionId = sessionId;
        this.consumed = false;
    }

    /**
     * 标记为已消费（原子操作）
     */
    public boolean markAsConsumed() {
        if (consumed) {
            return false; // 已经被消费
        }
        consumed = true;
        return true;
    }

    /**
     * 检查是否已被消费
     */
    public boolean isConsumed() {
        return consumed;
    }

    /**
     * 获取搜索结果（只有未消费且未过期才返回）
     */
    public List<TavilySearchResult> getSearchResults() {
        if (consumed || isExpired()) {
            return Collections.emptyList();
        }
        return Collections.unmodifiableList(searchResults);
    }

    /**
     * 安全的结果获取（带状态检查）
     */
    public List<TavilySearchResult> getAndMarkConsumed() {
        if (!markAsConsumed() || isExpired()) {
            return Collections.emptyList();
        }
        return Collections.unmodifiableList(searchResults);
    }

    // 其他方法保持不变...
    public boolean hasResults() { return !searchResults.isEmpty(); }
    public int getResultCount() { return searchResults.size(); }
    public boolean isExpired() { return System.currentTimeMillis() - timestamp > EXPIRY_TIME; }
    public long getTimestamp() { return timestamp; }
    public String getSessionId() { return sessionId; }

    @Override
    public String toString() {
        return String.format("NetworkSearchData{sessionId='%s', resultCount=%d, timestamp=%d, expired=%s, consumed=%s}",
                           sessionId, searchResults.size(), timestamp, isExpired(), consumed);
    }
}
```

```java
        long totalSearchResults = searchResultSuccessCount.get() + searchResultFailureCount.get();
        double searchResultSuccessRate = totalSearchResults > 0 ?
            (double) searchResultSuccessCount.get() / totalSearchResults : 1.0;

        return HealthReport.builder()
            .dataLossCount(dataLossCount.get())
            .timingIssueCount(timingIssueCount.get())
            .searchResultSuccessCount(searchResultSuccessCount.get())
            .searchResultFailureCount(searchResultFailureCount.get())
            .searchResultSuccessRate(searchResultSuccessRate)
            .completionFailureCount(completionFailureCount.get())
            .systemErrorCount(systemErrorCount.get())
            .recentErrorCount(recentErrors.size())
            .build();
    }

    /**
     * 获取最近的错误记录
     */
    public List<ErrorRecord> getRecentErrors(int limit) {
        return recentErrors.stream()
            .sorted((a, b) -> Long.compare(b.getTimestamp(), a.getTimestamp()))
            .limit(limit)
            .collect(Collectors.toList());
    }

    /**
     * 重置统计信息
     */
    public void reset() {
        dataLossCount.set(0);
        timingIssueCount.set(0);
        searchResultSuccessCount.set(0);
        searchResultFailureCount.set(0);
        completionFailureCount.set(0);
        systemErrorCount.set(0);
        recentErrors.clear();
        log.info("健康检查统计信息已重置");
    }

    /**
     * 错误记录类
     */
    public static class ErrorRecord {
        private final String sessionId;
        private final String errorType;
        private final String details;
        private final long timestamp;

        public ErrorRecord(String sessionId, String errorType, String details, long timestamp) {
            this.sessionId = sessionId;
            this.errorType = errorType;

            this.timestamp = timestamp;
        }

        // Getters
        public String getSessionId() { return sessionId; }
        public String getErrorType() { return errorType; }
        public String getDetails() { return details; }
        public long getTimestamp() { return timestamp; }

        @Override
        public String toString() {
            return String.format("ErrorRecord{sessionId='%s', errorType='%s', details='%s', timestamp=%d}",
                               sessionId, errorType, details, timestamp);
        }
    }

    /**
     * 健康报告类
     */
    public static class HealthReport {
        private final long dataLossCount;
        private final long timingIssueCount;
        private final long searchResultSuccessCount;
        private final long searchResultFailureCount;
        private final double searchResultSuccessRate;
        private final long completionFailureCount;
        private final long systemErrorCount;
        private final int recentErrorCount;

        private HealthReport(Builder builder) {
            this.dataLossCount = builder.dataLossCount;
            this.timingIssueCount = builder.timingIssueCount;
            this.searchResultSuccessCount = builder.searchResultSuccessCount;
            this.searchResultFailureCount = builder.searchResultFailureCount;
            this.searchResultSuccessRate = builder.searchResultSuccessRate;
            this.completionFailureCount = builder.completionFailureCount;
            this.systemErrorCount = builder.systemErrorCount;
            this.recentErrorCount = builder.recentErrorCount;
        }

        public static Builder builder() { return new Builder(); }

        // Getters
        public long getDataLossCount() { return dataLossCount; }
        public long getTimingIssueCount() { return timingIssueCount; }
        public long getSearchResultSuccessCount() { return searchResultSuccessCount; }
        public long getSearchResultFailureCount() { return searchResultFailureCount; }
        public double getSearchResultSuccessRate() { return searchResultSuccessRate; }
        public long getCompletionFailureCount() { return completionFailureCount; }
        public long getSystemErrorCount() { return systemErrorCount; }
        public int getRecentErrorCount() { return recentErrorCount; }

        public static class Builder {
            private long dataLossCount;
            private long timingIssueCount;
            private long searchResultSuccessCount;
            private long searchResultFailureCount;
            private double searchResultSuccessRate;
            private long completionFailureCount;
            private long systemErrorCount;
            private int recentErrorCount;

            public Builder dataLossCount(long dataLossCount) { this.dataLossCount = dataLossCount; return this; }
            public Builder timingIssueCount(long timingIssueCount) { this.timingIssueCount = timingIssueCount; return this; }
            public Builder searchResultSuccessCount(long count) { this.searchResultSuccessCount = count; return this; }
            public Builder searchResultFailureCount(long count) { this.searchResultFailureCount = count; return this; }
            public Builder searchResultSuccessRate(double rate) { this.searchResultSuccessRate = rate; return this; }
            public Builder completionFailureCount(long count) { this.completionFailureCount = count; return this; }
            public Builder systemErrorCount(long count) { this.systemErrorCount = count; return this; }
            public Builder recentErrorCount(int count) { this.recentErrorCount = count; return this; }

            public HealthReport build() { return new HealthReport(this); }
        }
    }
```
