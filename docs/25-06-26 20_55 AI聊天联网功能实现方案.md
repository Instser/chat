## 📋 项目现状分析

### 当前架构
- **后端**: Spring Boot + MyBatis Plus
- **AI集成**: 支持多模型（通过AiModel实体配置）
- **流式响应**: 使用WebClient进行AI API调用
- **前端**: Next.js + Vercel AI SDK
- **消息处理**: 支持文件附件、深度思考模式

### 现有AI调用流程
1. 用户发送消息 → ChatApiController
2. ChatService处理业务逻辑
3. 调用外部AI API（OpenAI格式）
4. 流式返回响应给前端

## 🌐 联网功能方案设计

### 方案一：搜索引擎集成方案（推荐）

#### 1.1 技术选型
- **搜索API**: Google Custom Search API / Bing Search API / DuckDuckGo API
- **实现方式**: 在AI请求前进行搜索，将结果作为上下文
- **触发机制**: 关键词检测 + 用户主动选择

#### 1.2 实现架构
```
用户消息 → 联网检测 → 搜索引擎API → 结果整理 → AI处理 → 流式响应
```

#### 1.3 核心组件设计

**SearchService接口**
```java
public interface SearchService {
    SearchResultDTO search(String query, int maxResults);
    boolean shouldEnableWebSearch(String message);
    String formatSearchResults(List<SearchResult> results);
}
```

**WebSearchConfig配置**
```java
@ConfigurationProperties(prefix = "web.search")
public class WebSearchConfig {
    private String provider; // google/bing/duckduckgo
    private String apiKey;
    private String searchEngineId;
    private int maxResults = 5;
    private boolean autoDetect = true;

```

## 🎯 推荐实施方案

### 选择方案一：搜索引擎集成方案

**理由：**
1. **实现简单**: 与现有架构兼容性好
2. **成本可控**: 按搜索次数付费
3. **效果稳定**: 搜索引擎结果质量高
4. **扩展性强**: 支持多种搜索引擎

### 实施步骤

#### 阶段一：基础搜索功能（1-2周）
1. **配置管理**
   - 添加搜索引擎配置
   - 支持多搜索引擎切换
   
2. **搜索服务实现**
   - GoogleSearchService
   - BingSearchService
   - 搜索结果格式化

3. **触发机制**
   - 关键词检测（"最新"、"今天"、"现在"等）
   - 用户主动开启联网模式

#### 阶段二：智能集成（2-3周）
1. **AI消息处理增强**
   - 修改ChatService支持搜索
   - 搜索结果作为系统消息注入
   
2. **前端交互优化**
   - 联网开关控件
   - 搜索状态显示
   - 搜索来源展示

3. **数据记录**
   - 搜索记录存储
   - 使用统计分析

#### 阶段三：高级功能（3-4周）
1. **智能搜索优化**
   - 查询重写和优化
   - 多轮搜索支持

2. **内容质量控制**
   - 结果去重和过滤

   - 时效性验证

## 🔧 技术实现细节

### 搜索结果处理
```java
public String formatSearchResults(List<SearchResult> results) {
    StringBuilder formatted = new StringBuilder();
    formatted.append("以下是相关的网络搜索结果：\n\n");
    
    for (int i = 0; i < results.size(); i++) {
        SearchResult result = results.get(i);
        formatted.append(String.format("%d. **%s**\n", i + 1, result.getTitle()));
        formatted.append(String.format("   来源：%s\n", result.getUrl()));
        formatted.append(String.format("   摘要：%s\n\n", result.getSnippet()));
    }
    
    formatted.append("请基于以上搜索结果回答用户问题。");
    return formatted.toString();
}
```

### 消息注入逻辑
```java
// 在现有的streamChatWithAI方法中添加搜索逻辑
if (shouldEnableWebSearch(request)) {
    String searchQuery = extractSearchQuery(request.getMessages());
    SearchResultDTO searchResults = searchService.search(searchQuery, 5);
    
    if (searchResults.hasResults()) {
        // 将搜索结果作为系统消息注入
        Map<String, String> searchMessage = new HashMap<>();
        searchMessage.put("role", "system");
        searchMessage.put("content", formatSearchResults(searchResults.getResults()));
        messagesWithPrompt.add(searchMessage);
    }
}
```
