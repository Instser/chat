# 支付相关API文档

## 概述

本文档描述了项目中所有与支付(payment)和套餐(package)相关的API接口，包括套餐管理、支付订单创建、支付状态查询、支付回调等功能。

## 基础信息

- **API基础路径**: `/api/payment`
- **认证方式**: Bearer Token (JWT)
- **数据格式**: JSON
- **字符编码**: UTF-8

## 数据模型

### 套餐信息 (Package)

```typescript
interface Package {
  id: number;           // 套餐ID
  name: string;         // 套餐名称
  description: string;  // 套餐描述
  price: number;        // 价格
  currency: string;     // 货币类型 (USD/CNY)
  period: number;       // 有效期天数
  features: string[];   // 功能特性列表
}
```

### 支付方式 (PaymentMethod)

```typescript
interface PaymentMethod {
  id: string;           // 支付方式ID
  name: string;         // 显示名称
  type: string;         // 支付方式类型
  available: boolean;   // 是否可用
}
```

### 支付请求 (PaymentRequest)

```typescript
interface PaymentRequest {
  packageId: number;    // 套餐ID (必填)
  currency: string;     // 货币类型 (必填)
  paymentMethod: string; // 支付方式 (必填)
  returnUrl?: string;   // 支付成功后跳转URL (可选)
}
```

### 支付响应 (PaymentResponse)

```typescript
interface PaymentResponse {
  orderNo: string;          // 订单号
  paymentRequestId: string; // 支付请求ID
  paymentUrl: string;       // 支付跳转URL
  amount: number;           // 订单金额
  currency: string;         // 货币类型
  paymentStatus: number;    // 支付状态
  success: boolean;         // 是否成功
  paymentMethod: string;    // 支付方式
  message: string;          // 响应消息
  createdTime: string;      // 订单创建时间
  qrCodeUrl?: string;       // 支付二维码URL (可选)
}
```

### 支付状态响应 (PaymentStatusResponse)

```typescript
interface PaymentStatusResponse {
  status: number;       // 支付状态 (0=待支付, 1=已支付, 2=已取消, 3=已退款)
  message: string;      // 状态描述信息
  orderNo?: string;     // 订单号
}
```

## API接口

### 1. 获取套餐列表

**接口地址**: `GET /api/payment/packages`

**请求参数**:
- `currency` (query, 可选): 货币类型，默认为 "CNY"

**响应示例**:
```json
{
  "code": 200,
  "message": "获取套餐列表成功",
  "data": [
    {
      "id": 1,
      "name": "基础套餐",
      "description": "适合个人用户的基础套餐",
      "price": 29.99,
      "currency": "CNY",
      "period": 30,
      "features": ["100次AI对话", "基础模型访问"]
    }
  ]
}
```

### 2. 获取套餐信息和支付方式

**接口地址**: `POST /api/payment/package/info`

**请求体**:
```json
{
  "packageId": 1,
  "currency": "CNY"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "获取套餐信息成功",
  "data": {
    "packageInfo": {
      "id": 1,
      "name": "基础套餐",
      "description": "适合个人用户的基础套餐",
      "price": 29.99,
      "currency": "CNY",
      "period": 30,
      "features": ["100次AI对话", "基础模型访问"]
    },
    "paymentMethods": [
      {
        "id": "alipay",
        "name": "支付宝",
        "type": "alipay",
        "available": true
      },
      {
        "id": "yipay",
        "name": "易支付",
        "type": "yipay",
        "available": true
      }
    ]
  }
}
```

### 3. 创建支付订单

**接口地址**: `POST /api/payment/create`

**认证**: 需要Bearer Token

**请求体**:
```json
{
  "packageId": 1,
  "currency": "CNY",
  "paymentMethod": "alipay",
  "returnUrl": "https://example.com/payment/success"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "支付订单创建成功",
  "data": {
    "orderNo": "ORDER_20240101_123456",
    "paymentRequestId": "PAY_REQ_123456",
    "paymentUrl": "https://payment.example.com/pay?id=123456",
    "amount": 29.99,
    "currency": "CNY",
    "paymentStatus": 0,
    "success": true,
    "paymentMethod": "alipay",
    "message": "订单创建成功",
    "createdTime": "2024-01-01T12:00:00Z",
    "qrCodeUrl": "https://qr.example.com/123456.png"
  }
}
```

### 4. 查询支付状态

**接口地址**: `GET /api/payment/status/{orderNo}`

**路径参数**:
- `orderNo`: 订单号

**响应示例**:
```json
{
  "code": 200,
  "message": "查询支付状态成功",
  "data": {
    "status": 1,
    "message": "支付成功",
    "orderNo": "ORDER_20240101_123456"
  }
}
```

### 5. 查询支付状态并同步

**接口地址**: `GET /api/payment/status/sync/{orderNo}`

**路径参数**:
- `orderNo`: 订单号

**说明**: 此接口会主动向支付平台查询最新状态并同步到本地数据库

**响应格式**: 与查询支付状态接口相同

### 6. 取消支付订单

**接口地址**: `POST /api/payment/cancel/{orderNo}`

**路径参数**:
- `orderNo`: 订单号

**响应示例**:
```json
{
  "code": 200,
  "message": "订单取消成功",
  "data": "订单取消成功"
}
```

## 支付回调接口

### 1. 支付宝支付回调

**接口地址**: `POST /api/payment/alipay/notify`

**说明**: 支付宝支付成功后的异步通知接口，由支付宝服务器调用

**安全验证**:
- IP白名单验证
- 签名验证
- 防重放攻击

### 2. 易支付回调

**接口地址**: `POST /api/payment/yipay/notify`

**说明**: 易支付成功后的异步通知接口，由易支付服务器调用

**安全验证**:
- IP白名单验证
- 签名验证

## 支付状态说明

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| 0      | 待支付   | 订单已创建，等待用户支付 |
| 1      | 已支付   | 支付成功，订单完成 |
| 2      | 已取消   | 订单已取消 |
| 3      | 已退款   | 订单已退款 |

## 支付方式说明

| 支付方式ID | 显示名称 | 类型 | 说明 |
|------------|----------|------|------|
| alipay     | 支付宝   | alipay | 支付宝SDK支付 |
| yipay      | 易支付   | yipay  | 第三方易支付平台 |

- **AUD**: 澳元
- **CAD**: 加拿大元

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 4001   | 重复的支付请求 |
| 4002   | 套餐不存在 |
| 4003   | 套餐已下架 |
| 4004   | 支付方式不可用 |
| 4005   | 订单不存在 |
| 4006   | 订单状态异常 |
| 5001   | 支付服务异常 |
| 5002   | 汇率服务异常 |

## 安全机制

1. **防重放攻击**: 使用requestId防止重复提交
2. **IP白名单**: 回调接口限制IP访问
3. **签名验证**: 验证支付平台回调签名
4. **Token认证**: 用户接口需要JWT认证
5. **审计日志**: 记录所有支付操作日志

## 注意事项

1. 所有金额字段使用BigDecimal类型，避免精度丢失
2. 时间字段使用ISO 8601格式
3. 支付回调接口需要返回特定格式的响应
4. 汇率数据会定时更新，建议缓存使用
5. 订单号具有唯一性，不可重复使用
