# 前端套餐API文档

## 概述

本文档描述了前端套餐管理系统的所有API接口路径，包括套餐信息获取、支付订单管理、用户套餐状态等功能。

## 基础信息

- **API Base URL**: `/api`
- **认证方式**: Bearer Token (通过 Authorization 头或 Cookie)
- **数据格式**: JSON
- **字符编码**: UTF-8

## API路径列表

### 套餐信息相关

#### 获取套餐信息和支付方式
- **路径**: `POST /api/package/info`
- **功能**: 获取指定套餐的详细信息和可用支付方式

#### 获取所有可用套餐列表
- **路径**: `GET /api/package/list`
- **功能**: 获取系统中所有可用的套餐列表

#### 获取套餐详情
- **路径**: `GET /api/package/{packageId}`
- **功能**: 获取指定套餐的详细信息

### 支付订单相关

#### 创建支付订单
- **路径**: `POST /api/payment/create`
- **功能**: 创建新的支付订单

#### 查询订单状态
- **路径**: `GET /api/payment/status/{orderId}`
- **功能**: 查询指定订单的支付状态

#### 获取用户订单列表
- **路径**: `GET /api/payment/orders`
- **功能**: 获取当前用户的所有订单列表

#### 取消订单
- **路径**: `POST /api/payment/cancel/{orderId}`
- **功能**: 取消指定的未支付订单

### 用户套餐状态相关

#### 获取用户当前套餐信息
- **路径**: `GET /api/user/package`
- **功能**: 获取当前用户的套餐信息和使用状态

#### 获取用户套餐使用统计
- **路径**: `GET /api/user/package/usage`
- **功能**: 获取用户套餐的使用统计信息

#### 获取用户套餐历史
- **路径**: `GET /api/user/package/history`
- **功能**: 获取用户的套餐购买和使用历史

### 支付方式相关

#### 获取可用支付方式
- **路径**: `GET /api/payment/methods`
- **功能**: 获取系统支持的所有支付方式

#### 支付宝支付
- **路径**: `POST /api/payment/alipay`
- **功能**: 创建支付宝支付订单

#### 微信支付
- **路径**: `POST /api/payment/wechat`
- **功能**: 创建微信支付订单

### 支付回调相关

#### 支付宝支付回调
- **路径**: `POST /api/payment/callback/alipay`
- **功能**: 处理支付宝支付结果回调

#### 微信支付回调
- **路径**: `POST /api/payment/callback/wechat`
- **功能**: 处理微信支付结果回调

### 优惠券相关

#### 获取用户可用优惠券
- **路径**: `GET /api/coupon/available`
- **功能**: 获取用户可用的优惠券列表

#### 验证优惠券
- **路径**: `POST /api/coupon/validate`
- **功能**: 验证优惠券是否可用

#### 使用优惠券
- **路径**: `POST /api/coupon/use`
- **功能**: 在支付时使用优惠券

### 发票相关

#### 申请发票
- **路径**: `POST /api/invoice/apply`
- **功能**: 为已支付订单申请发票

#### 获取发票列表
- **路径**: `GET /api/invoice/list`
- **功能**: 获取用户的发票申请列表

#### 下载发票
- **路径**: `GET /api/invoice/download/{invoiceId}`
- **功能**: 下载指定的发票文件

### 退款相关

#### 申请退款
- **路径**: `POST /api/refund/apply`
- **功能**: 为已支付订单申请退款

#### 查询退款状态
- **路径**: `GET /api/refund/status/{refundId}`
- **功能**: 查询退款申请的处理状态

#### 获取退款列表
- **路径**: `GET /api/refund/list`
- **功能**: 获取用户的退款申请列表

### 管理员相关 (需要管理员权限)

#### 获取所有订单
- **路径**: `GET /api/admin/orders`
- **功能**: 获取系统中所有的订单信息

#### 获取套餐统计
- **路径**: `GET /api/admin/package/stats`
- **功能**: 获取套餐销售统计信息

#### 管理套餐
- **路径**: `POST /api/admin/package/manage`
- **功能**: 创建、更新或删除套餐

#### 处理退款申请
- **路径**: `POST /api/admin/refund/process`
- **功能**: 处理用户的退款申请

## 套餐ID映射

前端定义了6个不同的套餐ID，对应3个套餐的月付和年付版本：

| 套餐类型 | 月付ID | 年付ID | 月付价格 | 年付价格 | 说明 |
|----------|--------|--------|----------|----------|------|
| Free | 1 | 2 | ¥0 | ¥0 | 免费套餐 |
| Pro | 3 | 4 | ¥68 | ¥680 | 专业版（年付2个月免费） |
| Premium | 5 | 6 | ¥128 | ¥1280 | 高级版（年付2个月免费） |

## 通用响应格式

所有API响应都遵循统一的格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1640995200000
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 状态码，200表示成功 |
| message | string | 响应消息 |
| data | object | 响应数据，具体结构见各接口说明 |
| timestamp | number | 响应时间戳 |

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或认证失败 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 1001 | 套餐不存在 |
| 1002 | 支付方式不支持 |
| 1003 | 订单已过期 |
| 1004 | 订单状态异常 |
| 1005 | 余额不足 |
| 1006 | 优惠券无效 |
| 1007 | 退款申请失败 |

## 注意事项

1. 所有需要认证的接口都需要在请求头中携带有效的Bearer Token
2. 支付相关接口需要特别注意安全性，建议使用HTTPS
3. 回调接口需要验证签名以确保请求来源的合法性
4. 订单状态查询建议使用轮询方式，避免频繁请求
5. 退款处理可能需要较长时间，建议异步处理
