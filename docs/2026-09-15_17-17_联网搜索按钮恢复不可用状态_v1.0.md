## 「哪次修改把按钮打开了」结论

**不是任何一次代码提交，而是 2026-08-27 的首次脚本化部署（deploy.sh frontend）**。

排查证据：

1. 前端仓库 git 全量历史中，联网按钮自 `21b77c9`（2025-06-26 添加网络搜索开关功能）起就是可点击的 toggle，仅有 `6e18310`（2025-07-01 优化悬浮按钮）样式调整——**不存在任何"禁用该按钮"的提交**；
2. `git reflog` 完整（2025-07-28 clone 起）、无 stash、无悬空提交——本地也没有过禁用改动；
3. 2026-08-06 热修仅 rsync 静态文件 + 重启，未重新构建；**2026-08-27 首次用 deploy.sh 从 git 源码全新构建并替换 `/opt/tousechat-frontend`**。

推断：当时的"禁用"只存在于旧生产构建（手工构建、含未提交改动）中，从未进入 git；2026-08-27 从 git 干净源码重建后，按钮自然回到仓库里的"可用"状态。
