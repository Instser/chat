# 06-27 15:29 文档解析器文档名称显示优化

## 📋 问题描述

在解析Word文档时，发现元数据中的文档名称显示为"未命名文档"，而不是实际的文件名。经过检查发现，所有文档解析器都存在类似问题：

### 原始问题
- **Word解析器**：依赖文档内部元数据获取标题，大多数文档元数据为空，导致显示"未命名文档"
- **Excel解析器**：没有显示文档名称
- **PowerPoint解析器**：没有显示文档名称

### 根本原因
1. 很多Office文档在创建时没有设置内部标题属性
2. 解析器没有使用传入的`fileName`参数
3. 缺乏统一的文档名称获取逻辑

## 🎯 解决方案

### 1. 优化文档名称获取逻辑

实现统一的文档名称获取策略：
1. **优先使用文件名**：使用传入的`fileName`参数（去掉扩展名）
2. **回退到元数据**：如果文件名为空，尝试从文档元数据获取标题
3. **默认名称**：最后使用"未命名文档"作为默认值

### 2. 修改的文件

#### Word文档解析器 (`WordDocumentParser.java`)
- 更新`parseDocx`和`parseDoc`方法，添加`fileName`参数
- 替换`getDocumentTitle`方法为`getDocumentName`方法
- 实现智能文档名称获取逻辑

#### Excel文档解析器 (`ExcelDocumentParser.java`)
- 添加文档名称显示功能
- 实现`getDocumentName`方法
- 在解析结果中显示文档名称

#### PowerPoint文档解析器 (`PowerPointDocumentParser.java`)
- 更新`parsePptx`和`parsePpt`方法，添加`fileName`参数
- 添加文档名称显示功能
- 实现`getDocumentName`方法

## ✅ 修改详情

### 1. Word解析器优化

```java
// 修改前
private String getDocumentTitle(XWPFDocument document) {
    try {
        String title = document.getProperties().getCoreProperties().getTitle();
        return title != null && !title.trim().isEmpty() ? title : "未命名文档";
    } catch (Exception e) {
        return "未命名文档";
    }
}

// 修改后
private String getDocumentName(XWPFDocument document, String fileName) {
    // 优先使用文件名（去掉扩展名）
    if (fileName != null && !fileName.trim().isEmpty()) {
        String name = fileName.trim();
        int lastDotIndex = name.lastIndexOf('.');
        if (lastDotIndex > 0) {
            name = name.substring(0, lastDotIndex);
        }
        return name;
    }
    
    // 回退到文档元数据
    if (document != null) {
        try {
            String title = document.getProperties().getCoreProperties().getTitle();
            if (title != null && !title.trim().isEmpty()) {
                return title.trim();
            }
        } catch (Exception e) {
            log.debug("无法获取文档元数据标题: {}", e.getMessage());
        }
    }
    
    return "未命名文档";
}
```
