# 金语聊天系统 - 产品背景

## 项目目的
金语聊天系统是一个基于Spring Boot 3.1的现代化AI聊天系统后端服务，旨在为用户提供多种AI模型的聊天体验，支持完整的用户认证、会话管理和流式对话功能。

## 解决的问题
1. **多AI模型集成**: 统一接入GPT、Claude、通义千问等主流AI模型
2. **用户体验优化**: 提供流式响应的实时对话体验
3. **用户管理**: 完整的用户注册、登录、权限管理系统
4. **数据持久化**: 聊天会话和消息的完整存储和管理
5. **支付集成**: 支持用户购买套餐，管理订单和支付流程

## 工作方式
- **前后端分离**: RESTful API设计，统一的响应格式
- **流式响应**: 基于WebFlux的SSE流式对话
- **数据库设计**: 使用MyBatis-Plus + MySQL，支持雪花ID、逻辑删除
- **安全性**: Spring Security密码加密，用户认证机制
- **监控运维**: Druid连接池监控，结构化日志记录

## 核心功能模块
1. **用户认证模块**: 注册、登录、用户信息管理
2. **AI对话模块**: 多模型支持、流式响应、会话管理
3. **消息管理模块**: 消息存储、历史记录、会话管理
4. **支付订单模块**: 套餐管理、订单处理、支付集成
5. **系统管理模块**: 模型配置、用户管理、数据监控
